majordomus_cli::economics

Module model 

Source
Expand description

The typed records of the economics subsystem: the declarations it reads (methodology, suites, tasks), the raw facts it records (runs), and the answer it derives (summary).

Raw facts and derived answers are different types on purpose. A run holds what the provider reported and what the success gates found, and nothing computed from them; a pair, a metric and a summary are recomputed from runs on every read, so a change to how a number is derived never needs the runs rewritten.

Every public type is prefixed Economics: the OpenAPI document keeps one flat namespace of schema names, and Token* and Evidence* already belong to other subsystems.

use majordomus_cli::economics::model::EconomicsClass;
assert!(EconomicsClass::Observed.is_measurement());
assert!(!EconomicsClass::Counterfactual.is_measurement());
assert_eq!(EconomicsClass::Derived.weakest(EconomicsClass::Estimated), EconomicsClass::Estimated);
