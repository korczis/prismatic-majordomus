What is this intent for?

What the work is for, what it holds the work to, and whether the evidence says it is met.

the-mesh-is-operated-from-any-device

The owner understands and operates the whole mesh from one page, on any device

plannedunknown0 of 4 criteria metClose

From a phone, a desktop or a Claude Code session the owner sees which nodes, sessions and tasks are live, what is blocked and why, and performs an authorised action whose result and evidence come back live; the page is a client of the persistent runtime, so closing it or ending a session loses nothing and changes nothing.

What does it hold the work to?

  • The page reads only capabilities the runtime already serves; it keeps no registry, scheduler, event bus or identity of its own
  • A caller beyond loopback changes nothing it cannot authenticate (ADR 0126)
  • Every state shown carries its source and when it was observed; stale is said, never hidden
  • A model may propose an operation; only the authorisation path executes it
