# Rules, skills, memory, MCP, a cockpit and multi-agent runs are what the category converges on; only the combination is defensible

Several products observed in this period independently built persistent rules from corrections, skills, memory, approval gates, cockpits and background agents, and platforms (GitHub agent management, OpenAI's agent harness) sell agent governance and orchestration. Each of these features is therefore expected hygiene, not a reason to adopt. What none of the observed products claimed is the combination Majordomus holds: an intent, its evidence and the work between them over one canonical repository state, provider-neutral, with every surface derived. A generated dashboard is now cheap; consistency, continuity and evidence over a long-lived project are the contested ground. Durability estimates given at the time are opinions and are not recorded.
