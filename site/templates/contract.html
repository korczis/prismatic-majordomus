all {{ requires | length }} met → finish: accepted, outcome completed, exit {{ ok_codes[0].code }}

any unmet → finish: refused, n unmet, exit {{ unmet_code }}

On refusal nothing is written: the task stays active, no outcome is set, and no completion note is filed. Each failing line is named, with the command that reproduces it.

On acceptance the outcome is recorded, the verification command and its exit code are appended to the ledger, and the note is filed under the completed records.

There is no flag that turns a refusal into a warning.
