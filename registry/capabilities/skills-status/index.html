skills.status

Every skill the index holds, each with the tests that name it and the evidence state of their latest runs, its page projection, the doctrine and gates that hold it, every invocation that references it, and the standing those derive: proven, partial, orphan, invalid, or not_required for a draft or deprecated skill.

Every skill with its derived standing, and how many stand where: what majordomus skills status, GET /api/v1/skills and the majordomus_skills tool answer.

};
assert_eq!(empty.count, 0);
propertytyperequireddescription
count integer yes How many skills.
skills array yes Every skill, in index order.
standings object yes How many in each standing, keyed by the standing word.
