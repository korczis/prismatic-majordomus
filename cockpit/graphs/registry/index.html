Capability registry

Every module, the capabilities it composes, the source file each was declared in, and the MCP, HTTP, command-line and Cockpit projections derived from it. The executable's own architecture, read back from the registry that produces every interface — this page among them.

What the shapes mean

Nodes

capability
one canonical declaration: a query, a command, or a declarative resource
module
a module composed with module! and named in compose_modules!, or one kind of declarative object
projection
an external interface the descriptor is projected onto, the Cockpit included
source
the file the declaration was read from

Edges

composes
the module composes the capability
declared_in
the capability was declared in that file
projects
the capability is exposed through that interface
