# Quick start

## Sequential

Run prompts `01` through `10` from the same canonical feature worktree, preferably one fresh large-context Claude Code session per prompt.

## One shot

Paste `00_MASTER_ORCHESTRATOR.md`.

## Runtime credentials

Do not put ChatGPT cookies/tokens in prompts or repository files. The browser adapter should connect to an explicitly configured authenticated browser/profile and sanitize observations before persistence.

## Definition of done

"Can list conversations once" is not done.

Done means typed, capability-driven, incremental, idempotent, provider-generic, provenance-preserving, deterministic, observable, documented, schema-backed, tested, enforced, and visible through all canonical Majordomus surfaces.
