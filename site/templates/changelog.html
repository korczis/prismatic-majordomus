A release is a record of the layer, not a file somebody edits after the fact. majordomus generate changelog reads those records, pairs each one with the decisions dated inside its window and the commits in its range, and writes the result as one value in three encodings — docs/generated/changelog.json for a program, .yaml beside it, .md for a reader. This page is a fourth projection of the same value, so it cannot say anything the tool does not.

What that buys: a version cannot appear here without a release record, a change cannot appear without a commit that carries it, and an artifact cannot appear without the record's own evidence for it — the file name and the SHA-256 the record read off the file it published.
