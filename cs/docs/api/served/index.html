HTTP API: served

Zda nasazení servíruje commit, který mělo: identita buildu, kterou web servíruje, čtená zvenčí tak, jak ji čte návštěvník, posuzovaná podle obsažení commitu a zaznamenaná tak, aby ji pozdější čtenář mohl posoudit znovu. Prochází jen `served`; web, který nebyl dostupný, identita, kterou nešlo přečíst, build z necommitnutého stromu a servírovaný commit, který tento klon nemá, jsou každý nezodpovězená otázka, nikdy ne ano. Pozorování sahá na síť a je příkazem důvěryhodného příkazového řádku; čtení zaznamenaného stavu je čtení na každém povrchu.

served

Zda nasazení servíruje commit, který mělo: identita buildu, kterou web servíruje, čtená zvenčí tak, jak ji čte návštěvník, posuzovaná podle obsažení commitu a zaznamenaná tak, aby ji pozdější čtenář mohl posoudit znovu. Pozorování sahá na síť a je příkazem důvěryhodného příkazového řádku; čtení zaznamenaného stavu je čtení na každém povrchu.

GET /api/v1/served served.show

Co každý deployment naposledy obsluhoval

The newest recorded observation of each deployment, re-judged against a commit (HEAD unless named), and for a deployment the layer declares as an object its status derived from that: `active` only while it serves the commit. A record keeps proving every commit its served build contains and stops proving the moment the commit asked about is not among them; a record that received nothing proves nothing. Asks no network and writes nothing.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache vypnuta
  • nástroj MCP majordomus_served
  • Zdroj MCP {"name": "served", "uri": "majordomus://served"}
  • $ served show

Vyzkoušejte

Port je ten, který server zalogoval; 8741 je ten, o který žádá jako první. Hodnoty jsou první příklad operace.

curl -s "http://127.0.0.1:8741/api/v1/served?commit=HEAD&deployment=pages"

Testováno v apps/majordomus-cli/tests/http_serve.rs, který přehrává routu s těmito hodnotami proti serveru na skutečném socketu.

Schémata

Komponenty, které používají jen operace tohoto tagu. Každý řádek je pole daného typu, jeho doc komentář je popis; typ vlastněný jinou stránkou na ni odkazuje.

BuildIdentity

object
Identita buildu, kterou nasazení poskytuje, tak daleko, jak se na ni tento modul spoléhá. Ostatní pole poskytovaného dokumentu se ignorují, ne odmítají: dokument píše jiný program a pole, které přidá, není poškození.

use majordomus_cli::served::BuildIdentity;
let id = BuildIdentity {
    commit: "a".repeat(40),
    dirty: false,
    source_version: Some("0.7.0".into()),
    source_hash: None,
};
// what is judged is the commit and whether the tree it was built from was committed
assert_eq!(id.commit.len(), 40);
assert!(!id.dirty);

commit string ano
Celý commit, ze kterého byl servírovaný build vytvořen.
špinavé boolean ano
Zda strom, z něhož byl sestaven, měl necommitnuté změny. Špinavý build jmenuje commit, kterému se nerovná, takže žádný commit nedokazuje.

source_hash string | null ne
Otisk kanonických vstupů webu, pokud ho sestavení uvádí.

Používá Observation

DeploymentStanding

object
Nejnovější záznam jednoho nasazení a co dokazuje o dotazovaném commitu. Nese se obojí: zaznamenané posouzení je to, co bylo viděno, now je to, co stále dokazuje.

use majordomus_cli::capability::builtin::served::DeploymentStanding;
use majordomus_cli::served::ServedVerdict;
let json = r#"{"deployment":"pages","observation":{"schema":"majordomus.served-observation/v1",
  "deployment":"pages","url":"https://majordomus.dev/build.json",
  "expected":"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa","verdict":"served",
  "reason":"the deployment serves aaaaaaaaaaaa","at":"1970-01-01T00:00:00Z"},
  "now":{"verdict":"stale","reason":"it does not contain bbbbbbbbbbbb"}}"#;
let s: DeploymentStanding = serde_json::from_str(json).unwrap();
// seen as served, and no longer proving the commit asked about
assert_eq!(s.observation.judgement.verdict, ServedVerdict::Served);
assert_eq!(s.now.verdict, ServedVerdict::Stale);
vlastnosttyppovinnépopis
nasazení string ano
Název nasazení.
pozorování Observation → Observation ano
Jeho nejnovější záznam.
nyní Judgement → Judgement ano
Ten záznam znovu posouzený vůči commitu, na který se ptáme. To, ne zaznamenaný úsudek, je to, podle čeho čtenář jedná.
status DeploymentStatus | null → DeploymentStatus ne
For a deployment the layer declares as an object: active while now is served, declared otherwise, retired when the object says so. Derived from the newest observation, never set by hand (I3822); absent for a name no object carries.

Používá DeploymentStanding

Pozorování

object
Jedno pozorování jednoho nasazení, tak jak bylo zaznamenáno: na co se ptalo, co bylo servírováno, co bylo posouzeno a kdy. Vše potřebné k jeho opětovnému posouzení je v záznamu, což umožňuje Observation::rejudge odpovídat bez zkoumání.

use majordomus_cli::served::{observe, Fetch, Fetched, GitAncestry, Observation, OBSERVATION_SCHEMA};
use std::{path::Path, time::SystemTime};
struct None_;
impl Fetch for None_ {
    fn fetch(&self, _: &str) -> Fetched { Fetched::Unreachable("no route".into()) }
}
let git = GitAncestry { root: Path::new(env!("CARGO_MANIFEST_DIR")) };
let o: Observation = observe("pages", "https://s", "build.json", &"a".repeat(40), &None_,
                              &git, SystemTime::UNIX_EPOCH);
assert_eq!(o.schema, OBSERVATION_SCHEMA);
assert_eq!(o.url, "https://s/build.json");
assert_eq!(o.at, "1970-01-01T00:00:00Z");

Používá served.show

ServedVerdict

"served" | "stale" | "unreachable" | "malformed" | "dirty" | "undecided"
Co pozorování říká o očekávaném commitu. Důkazem je jen ServedVerdict::Served; ostatních pět je každé jiným důvodem, proč otázka nebyla zodpovězena ano.

use majordomus_cli::served::ServedVerdict;
// a measured no and an unanswered question are never spelled the same
assert!(ServedVerdict::Served.passes());
assert_eq!(ServedVerdict::Stale.exit_code(), 10);
assert_eq!(ServedVerdict::Unreachable.exit_code(), 12);
  • servedObsluhovaný build je očekávaný commit nebo ho obsahuje. Jediný vyhovující verdikt.
  • staleObsluhovaný build neobsahuje očekávaný commit: nasazení zaostává.
  • unreachableNic se nepřijalo. Nasazení se neměřilo.
  • malformedNěco bylo přijato a není to identita sestavení.
  • dirtyServírované sestavení vzniklo z necommitnutého stromu, takže neprokazuje žádný commit.
  • undecidedServírovaný commit není v tomto klonu, nebo se git nepodařilo dotázat; zahrnutí zůstává nerozhodnuté. Stažení vzdáleného repozitáře to obvykle změní na odpověď.
