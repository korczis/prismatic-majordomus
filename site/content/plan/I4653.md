description = "Slice S13 of milestone one-frame-one-kit-one-library-per-job, taken after S1 and S2 (I4535, I4536) and before S7 and S8 (I4541, I4542), which mount every graph and chart through it. Add one wrapper, share/design/js/visual, that every chart, graph and scene on /ui, /cockpit and the site is mounted through. It opens the visual to the full viewport and back (a Flowbite modal driven through I4536's instance API), closes it with Escape and returns focus to the control that opened it, gives it a deep link (its fragment address, ADR 0152's #diagram-<name> form), and holds the visual's driven state (its parameters, time, filters and selection) in the URL, so a reload or a shared link restores it. It is grown from the full-viewport and Escape handling site/diagrams.js already has (toggleFullscreen, line 255), which moves into the wrapper, rather than written a second time. A visual that is not driven declares itself static with its reason in its definition, and the wrapper shows the reason. Ship the rules project.viz-ergonomics and project.everything-interlinked under .ai/repo/rules/project, class: blocking, after the owner's template rules of those names, each tested by a gate that runs in scripts/ci/run-plan (the local verify, its gates declared in .ai/repo/ci/gates.yaml), validate.yml and the pre-push hook: viz-ergonomics refuses a chart, graph or scene mounted outside the wrapper, or with neither driven state in the URL nor a static declaration with a reason; everything-interlinked refuses an entity name or a mark standing for an entity without the link I4540's resolver gives it (until I4540 lands it reads the data-entity mark). Both gates start as ratchets over a committed baseline of today's visuals and marks that only shrinks; I4541 and I4542 shrink it as they mount each visual, and I4546 holds it at zero. Add an interaction spec that, on every visual of the three surfaces, maximises it, presses Escape, changes a driven parameter, reloads the URL and finds the state restored."
