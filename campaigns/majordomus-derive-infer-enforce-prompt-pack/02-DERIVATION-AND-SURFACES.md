# Mission 02: One truth, derived everywhere

Reuse product/capability registries, generic projection layer and typed schemas. Eliminate manually duplicated counts, versions, routes, commands, categories where machine-inferable, model/vendor inventories, peers, readiness/status and support matrix. Audit CLI/structured JSON, REST/OpenAPI/Swagger, MCP, Cockpit and site/docs. Ensure same canonical identity, semantics, order, freshness and provenance across applicable consumers. Extend generic projection mechanisms rather than building a second UI data service. OpenAPI must trace actual capability schema/HTTP bindings; documentation must not invent implementation. Cockpit is read/edit/actions only through appropriate existing typed command semantics, authorized and audited; no synthetic independent state. Establish explicit policy for fields which are *editorial* rather than inferable. Add fixture-driven cross-surface tests proving zero consumer-registration when a capability is added, and stable output when input ordering differs. Test missing/invalid metadata and collision handling. Run generated drift check twice to prove idempotence.
