Artefakty

Každý soubor, který generátor zapisuje: každý dokument s kódováními, ve kterých je commitnut, schématem, které jeho obsah splňuje, původem a hashem.

Registr Spustitelný soubor Moduly Schopnosti Příkazová řádka MCP HTTP API Artefakty Měření výkonu

Každý soubor, který majordomus generate zapisuje, tak jak ho generátor deklaruje. Dokument je jedna hodnota — registr schopností, příkazová řádka, matice měření výkonu, dokument OpenAPI, tento manifest — a commituje se v každém kódování, v němž ho toto úložiště commituje: JSON pro program, YAML vedle něj, Markdown tam, kde je publikem čtenář. Kódování jsou vykreslení jedné hodnoty, takže se nemohou rozcházet.

Tato stránka ukazuje, co se generuje, ne na co bajty právě teď hashují: velikost a hash jsou fakta okamžiku a tento web se sestavuje z commitu. Velikosti a hashe jsou v docs/generated/artifacts.md a živě na ně odpovídá majordomus generate --check, který porovnává každý z těchto souborů bajt po bajtu a odmítne zastaralý strom, a majordomus_artifacts přes MCP a GET /api/v1/artifacts, které sesouhlasí manifest s pracovním stromem.
