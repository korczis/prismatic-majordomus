Use after `00-MASTER-CLAUDE-CODE.md`. This is an acceptance contract, not authorization to bypass existing repo procedures.

Run two-week baseline/treatment where permitted. Include Majordomus and authorized OSCILLA/OSINT/ISIR projects. Track instrumentation completeness, equivalent task families, task complexity, accepted outcomes, elapsed time, direct/estimated/subscription cost, cache and retries; randomize or match conditions.
