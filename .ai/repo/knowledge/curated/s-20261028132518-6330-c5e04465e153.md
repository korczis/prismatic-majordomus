# start --help says majordomus evidence with no arguments lists the obligation tokens; it prints usage only

Observed as defect about command:start in episode s-20261028132518-6330.

# Evidence

- `file:lib/evidence.sh`

# Evidence

- Reproduced on 2026-11-07 with the 1.0.0-alpha.10 executable: `majordomus start --help` says the requires tokens are "listed by `majordomus evidence` with no arguments", and `majordomus evidence` with no arguments prints only its usage lines (`usage: majordomus evidence --covers <token> ...`).
- The tokens are listed by the capability obligations.vocabulary, which has no command-line projection (`cli: None` in apps/majordomus-cli/src/capability/builtin/obligations.rs) and answers at GET /api/v1/obligations and as the MCP tool majordomus_obligations.
- Fixed in this evolve: lib/start.sh's help names those two and says what `evidence` alone prints.
