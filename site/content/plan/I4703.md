description = "When the caller of `finish` (any outcome) or `handover` is not the episode that opened the active task, the runtime asks the one liveness predicate of I4346 (worktree.liveness) about the task's worktree before it writes anything. It proceeds only on `reclaim`. On `keep`, it refuses with exit 15 and names each piece of evidence of life: a process whose working directory is inside the worktree (other than the caller and the server), a file in the worktree's index or work tree changed since the task's last checkpoint and not in a commit, a mtime newer than the policy's session.stranded_after, or a mesh claim or board announcement that names the worktree. A predicate that cannot read its input refuses, as every destructive sweep does (project.destructive-sweeps-fail-closed). The caller's own task, judged by the ADR 0164 attribution as today, is never asked. The same check guards `recover tasks` (I4416). A refused close is a ledger event, task.close_refused, carrying the evidence."
