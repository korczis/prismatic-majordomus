mesh.peers

Who cooperates, machine by machine

What it is

Machine → runtime → session → claim: every runtime this one is linked to or has heard through the journal, grouped by machine, local first; each runtime with its liveness, the milliseconds since its beat rose, its link and its newest live claim. The default `summary` view lists only the active sessions, each with its live claims counted and its intent cut; `view=full` lists every session with every claim. `session` and `runtime` narrow either. Remote and local runtimes share one shape, and the whole fold's digest closes the answer: equal digests, equal state.

query
A query. It reads and changes nothing.

`summary` (the default) or `full`.

`all` (the default) or `live`: whether ended claims are kept.

Only sessions, claims and handovers whose latest Lamport stamp is above this. Reviews and overlaps carry no stamp of their own and are kept or dropped with their sessions.

Only what belongs to this session: its key (`<stream>/<session>`) or its bare id.

Only what belongs to this runtime: `<node>-<runtime>`, or a node id for every runtime of that machine.

Only this collection; the others are answered empty.

At most this many of each collection: the newest by Lamport stamp where it has one, kept in the fold's own order.

Only what is still open: active sessions, live claims, review requests nobody has answered and handovers nobody has taken.

Only what mentions this text, ignoring case: a path, a branch, an issue, a pull request, a word of an intent or a subject.
