Postupujte podle procedury, kterou repozitář definuje, a přidejte další

Přečtěte dovednosti repozitáře, převezměte jednu tak, jak je napsána, a novou přidejte napsáním jejího souboru — bez registru, bez kódu a s kontrolou, která řekne, co prověřila.

○zaručeno Rozšířenízákladnímaintaineragentjen pro čtení

Situace

Repozitář má postupy, které by jeho workeři, lidé i stroje, měli dodržovat: jak se tu dělá review, jak se provádí změna, jak se nasazuje web. Žijí v něčí hlavě, ve wiki, kterou nikdo neaktualizuje, nebo vložené do konfiguračního souboru providera, kde je další nástroj nepřečte.

Scénář

setup: installed-skill
given:
  - 'a repository whose skills section holds one skill directory with SKILL.md and one example, tracked in git'
steps:
  - id: list
    run: ['skills', 'list']
    note: 'the inventory is the directory: what is tracked is what is listed'
    expect:
      exit: 0
      stdout_contains: ['^release-notes +active +v1 ']
  - id: read-one
    run: ['skills', 'show', 'release-notes']
    note: 'the canonical path, then the file as written — the procedure, not a paraphrase'
    expect:
      exit: 0
      stdout_contains: ['^\.ai/repo/skills/release-notes/SKILL\.md$', '^# Procedure$']
  - id: machine-readable
    run: ['skills', 'show', 'release-notes', '--json']
    note: 'the same skill for a program: metadata, provenance, examples and the body'
    expect:
      exit: 0
      stdout_contains: ['"uri":"majordomus://skill/release-notes"', '"path":".ai/repo/skills/release-notes/SKILL.md"', '"valid":true']
  - id: check
    run: ['skills', 'check']
    note: 'a clean result states what it examined; a repository with no skills is reported, never passed'
    expect:
      exit: 0
      stdout_contains: ['^OK   skill', 'skills: 1 discovered']
  - id: refuse-unknown
    run: ['skills', 'show', 'nosuch']
    note: 'a skill that does not exist is named, with the command that lists what does'
    expect:
      exit: 12
      stdout_contains: ["no skill 'nosuch'", 'majordomus skills list']
then:
  - 'the listing, the catalogue the site renders and the resources the MCP server serves all come from the same discovery'
  - 'adding a skill is adding its directory; removing it removes the skill from every surface'

Výsledek

Každý postup je jeden adresář v sekci dovedností vrstvy, který drží SKILL.md, objevený tím, že soubor existuje. skills list je inventář, skills show je postup tak, jak je napsán, s cestou, odkud pochází, a skills check hlásí, co prozkoumal — dovednosti, příklady a reference — takže úspěch je důkaz, a ne slovo. Ze stejného katalogu se promítají stránky dovedností na webu i zdroje MCP, takže žádný povrch nevede vlastní seznam.

Provedeno proti skutečnému nástroji v repozitáři připraveném pomocí installed-skill, při každém generování tohoto webu. To, co následuje, není popis toho, co by se mělo stát; je to to, co se stalo.

schema: skill/v1
id: release-notes
version: 1
title: Release notes
description: Write the release notes for a tagged version from the ledger and the closed issues, never from memory.
status: active
tags: [release, documentation]
inputs:
  - the tag being released and the previous tag
outputs:
  - a release-notes section per closed issue, each naming its evidence
---
# Purpose

Turn what the ledger and the plan record into the notes a reader of the tag needs.

# Procedure

1. List the issues closed between the two tags with `majordomus plan list`.
2. For each, quote its outcome and the evidence attached to it.
3. Refuse to describe a change that no closed issue records.

# Output

One section per issue: title, what changed, the evidence, in plan order.

Uplatněné záruky

  • ○zaručeno Dovednost je jeden adresář v sekci skills vrstvy obsahující SKILL.md, objevený třídou zdrojů `skill`, kterou čtou shellový nástroj i spustitelný soubor v Rustu, takže přidání souboru je celou registrací a katalog, příkaz, doctor, MCP i web se z něj odvozují
  • ○zaručeno Každá dovednost se validuje proti seznamu povolených hodnot generovanému z jejího schématu, adresáře, sekcí a odkazů, porušení pojmenuje soubor i každý důvod a repozitář bez dovedností se ohlásí, a ne propustí
