pub fn resolve(root: &Path, working: Option<&Object>) -> Resolved
Expand description

Resolve the declaration in force for the repository at root, given the working tree’s declaration object as the index found it. None means the index found none, and then there is nothing to obey and nothing to ask git.

use majordomus_cli::mesh::root::resolve;
let nowhere = tempfile::tempdir().unwrap();
assert!(resolve(nowhere.path(), None).narrowed.is_empty());
