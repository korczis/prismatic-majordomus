# on a machine below the build floor a tree of the published release's generation can be derived, checked and committed with that release's own executable (gh release download, SHA256SUMS verified, MAJORDOMUS_BIN=<archive>/libexec/majordomus-cli, MAJORDOMUS_BIN_COMMIT=<RELEASE.json commit>): mj_rust_same_generation accepts it when the crate inputs match byte for byte; an older executable whose crate inputs differ is refused (derive rc 15), as an alpha.10 executable was against 1.0.0 on 2026-11-07

# Evidence

- lib/rust_bin.sh:215 `mj_rust_same_generation()` accepts an executable whose recorded crate inputs match the tree's byte for byte, whatever built it.
- 2026-11-07 01:50Z (the seat's record): PR #2955 was derived, checked and committed on a Mac below the build floor with the v1.0.0 release's own executable (`gh release download v1.0.0`, SHA256SUMS verified, MAJORDOMUS_BIN=<archive>/libexec/majordomus-cli, MAJORDOMUS_BIN_COMMIT=<RELEASE.json commit>); the primary's alpha.10 executable was refused by derive (rc 15) because six crate inputs differed (Cargo.toml, Cargo.lock, four generator stamps).
