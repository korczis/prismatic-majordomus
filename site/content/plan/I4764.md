description = "Two parts. First, the standard rule package carries majordomus.a-credential-never-reaches-an-agent@1, an advisory rule every adopter vendors. It says a credential a person holds is read from a 0600 file when it is used, printed as its path and never as its value, never logged, never passed in argv or a URL, and never inherited by a coding agent or its helpers. Second, doctor scans what an agent could read, reusing redaction::redact_secrets, the redactor Majordomus already applies to its own output. It looks at (a) the log files the policy declares and the run and log paths of Majordomus's own serve and mcp daemons, (b) those files' modes, and (c) the argv and environment of the repository's running serve, mcp and declared services. It names each finding by shape, location and file mode, and never prints the value."
