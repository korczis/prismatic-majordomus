HTTP API: repository

Repozitář, který tento proces obsluhuje: jeho vrstva, stav gitu, stav indexu z něj postaveného a jeho rozsah: co z něj pracovník čte a co nikdy nečte.

Rejstřík HTTP API

na této stránce

  • repository.info
  • repository.scope
  • repository.scope_classify

Vykresleno z docs/generated/openapi.json, který spustitelný soubor generuje ze svého registru schopností a CI jej odmítne, je-li zastaralý. Surový dokument je na /openapi.json; běžící server servíruje stejný dokument na vlastní /openapi.json a Swagger UI na /swagger.

repozitář

Repozitář, který tento proces obsluhuje: jeho vrstva, stav gitu, stav indexu z něj postaveného a jeho rozsah: co z něj pracovník čte a co nikdy nečte.

GET /api/v1/repository repository.info

Stav repozitáře a indexu

Kořen repozitáře, sekce vrstvy, stav gitu, režim zjišťování, přítomné druhy, každá diagnostika a spočítaný registr schopností.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • generace cache (max_entries=1)
  • nástroj MCP majordomus_repository
  • Zdroj MCP {"name": "repository", "uri": "majordomus://repository"}

Žádné parametry.

Vyzkoušejte

Port je ten, který server zalogoval; 8741 je ten, o který žádá jako první. Hodnoty jsou první příklad operace.

curl -s "http://127.0.0.1:8741/api/v1/repository"

Testováno v apps/majordomus-cli/tests/http_serve.rs, který přehrává routu s těmito hodnotami proti serveru na skutečném socketu.

RepositoryObservations

object
Dva snímky, které proces pořizuje z repozitáře, každý s časem pořízení.

Obraz bez okna nikdy nezastará a jeho okno se neserializuje.

use std::time::{Duration, UNIX_EPOCH};
use majordomus_cli::index::{AnswerObservation, RepositoryObservations};
let now = RepositoryObservations {
    index: AnswerObservation::taken("index build", UNIX_EPOCH, None),
    git: AnswerObservation::taken("git read", UNIX_EPOCH, Some(Duration::from_secs(120))),
};
let json = serde_json::to_value(&now).unwrap();
assert_eq!(json["git"]["stale_after"], "1970-01-01T00:02:00Z");
assert!(json["index"].get("stale_after").is_none());
let back: RepositoryObservations = serde_json::from_value(json).unwrap();
assert_eq!(back, now);
