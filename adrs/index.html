Where these come from

52 objects of kind adr, read from the repository's own layer. Nothing on this page is typed into the site: the source class that discovers the files is declared in the repository's knowledge sources, the executable indexes them, and this page, majordomus entity show adr/<slug>, the MCP resource majordomus://adr/<identity> and the Cockpit route /cockpit/objects/adr/<slug> are all projections of that one index.

The references and backlinks each page shows are edges of one graph. A reference is declared in the front matter of the object that makes it; the backlink is that same edge read from the other end, so nothing declares a relationship twice and nothing can declare half of one.
