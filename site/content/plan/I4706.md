description = "A policy key `dependencies.consumed` lists the paths of dependencies that the repository consumes and must never edit. Each entry is a git submodule, or a vendored directory with a declared sync command, and names its upstream (a remote URL and optionally a branch). commit.validate, run by the commit-msg hook, and `finish --check`, run by the pre-push hook, judge each commit that touches such a path. For a submodule, the only allowed change is its gitlink, moving to a commit that is reachable from the declared upstream branch or tag at the time of the check. A gitlink that points at a commit the upstream does not hold is refused, because that commit was made by editing the dependency locally. For a vendored directory, a change is allowed only when the commit's trailer names the declared sync command and the tree equals what that command produces. doctor names a declared submodule whose checkout is dirty or detached from its pinned commit. A refusal names the path, the commit and the remedy: change the dependency upstream, then bump the pin."
