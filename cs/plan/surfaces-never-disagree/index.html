Problém

Jádrová projekce drží: 181 rout /api/v1 živého serveru se rovná 181 operacím OpenAPI, které se rovnají commitovanému docs/generated/openapi.json, a executor je jedinou cestou dispatche (apps/majordomus-cli/src/capability/executor.rs:156). Kolem toho: aktuálnost není jednotná, protože dashboard/overview, episodes, lifecycle/runtime, plan/status, served a mesh nenesou observed_at, odznak přehledu je na nečinném repozitáři trvale zastaralý (apps/majordomus-cli/src/index.rs:44, apps/majordomus-cli/src/live.rs:250-252) a GET / řekl stale: null, zatímco servíroval build o 12 commitů za HEAD. Vlastnost parity porovnává HTTP jen pro GET routy a vylučuje koordinační read modely (apps/majordomus-cli/tests/properties.rs:166-168,300) a nic neporovnává JSON z CLI s HTTP. /swagger nemá CSP ani SRI na stejném originu jako zápisové routy (apps/majordomus-cli/src/http/swagger.rs:52,79). Cockpit a web drží nejméně devět katalogů na straně konzumenta toho, co registr deklaruje, a ADR 0004 říká, že nic nemá druhý registr. Změřeno v auditu základního stavu runtime z 2026-10-09 na masteru 1fb8d6be44 (plan/RUNTIME_BASELINE.md).

Aktuální stav

Implementováno: trasy, OpenAPI, MCP a generovaný dataset registru jsou odvozeny z registru a kontrolovány na drift. Částečně: čerstvost, parita, přístup Cockpitu k datům (pět stránek čte ctx.registry přímo, .ai/repo/ui-integrity-baseline.txt:9-13). Druhé registry: strom clap (kontrolovaný oběma směry apps/majordomus-cli/src/capability/closure.rs), cli/local.rs LOCAL (89 příkazů), nativní webové povrchy (apps/majordomus-cli/src/web/discover.rs:150), trasy Cockpitu (tři seznamy, vzájemně křížově kontrolované) a kopie spotřebitelů uvedené v plan/RUNTIME_BASELINE.md.

Cílový stav

Každá odpověď hlásící stav nese observed_at a source, vynuceno nad registrem; vlastnost parity pokrývá zapisovatele a CLI; žádný soubor Cockpitu ani webu nejmenuje hodnotu, kterou už deklaruje enum, schopnost nebo HttpExposure; /swagger a každé GET odmítají, co by mohla udělat nepřátelská stránka nebo rebindingový hostitel.

Mimo rozsah

  • Odstranění stromu clap nebo cli/local.rs LOCAL; obojí jsou změřené druhé deklarace (SURFACES F-1, F-4) a tento milník je zaznamenává, nepřepisuje CLI.
  • Psaní statického webu, který tvrdí živý stav; web zůstává obrázkem označeným jako obrázek.
  • Hlášení vyměněného spustitelného souboru, což je I1502.

Kritéria přijetí

  • Test nad registrem selže, když schopnost hlásící stav odpoví bez observed_at
  • Test parity pokrývá každou schopnost s HTTP trasou a každou schopnost s cestou CLI
  • GET /swagger odpovídá s CSP a hashi integrity a cizí Host je na GET odmítnut
  • Kontrola selže na doslovné cestě /api/v1/ nebo zkopírované hodnotě enumu v kódu Cockpitu či webu
