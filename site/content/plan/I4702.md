description = "Add an optional `delivery` field to the issue schema, with the values `change` (the default) and `record`. An issue that declares `delivery: record` is delivered by its own stamps and evidence: its work is a record, a decision or an observation, and no merge will name it. plan delivery reports its stage as `record` once it is DONE. plan drift never classes it as done_without_trace. Its delivery is a merge only if a commit outside the plan's records names it, and then drift reports that commit as a contradiction of the declaration. plan validate, in both plan engines, refuses `delivery: record` on an issue whose scope names a path outside `.ai/repo/` and the projections derived from it. The remedy of done_without_trace names the field."
