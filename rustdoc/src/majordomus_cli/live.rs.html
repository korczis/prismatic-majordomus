1//! The repository as a long-lived process must see it: current, not as it was when the
2//! process started.
3//!
4//! # The defect this exists to end
5//!
6//! [`crate::app::App::load`] builds one [`Index`](crate::index::Index) and one
7//! [`Context`] and hands them out as `Arc`s. For a command that answers a question and
8//! exits, that is exactly right: the picture cannot go stale inside a process that lives
9//! for 40 ms. The shared server lives for hours, and it held the same two values for its
10//! whole life. A session would commit, ask `GET /api/v1/repository` for the head it had
11//! just written, and be told the head the server had read when it started — the same
12//! answer from MCP, from the Cockpit and from every capability that reads the index, with
13//! nothing in any of them saying the picture was old. Measured on `origin/master` at
14//! `faba8fdef`: head `A` before a commit, head `A` after it, a rule committed while the
15//! server ran absent from `objects`, and a working tree reported `clean` while it was
16//! dirty. Only restarting the process fixed it.
17//!
18//! # What is watched, and why it is these files
19//!
20//! Git announces every move of the repository by writing a small, fixed set of files:
21//! `HEAD`, the staging index, `packed-refs`, the reflog, and the in-progress markers a
22//! merge or a rebase leaves. A commit, a checkout, a reset, a merge, a rebase and a branch
23//! switch each write at least one of them. So the question "has the repository moved?"
24//! is [`Stamp`]: the size and modification time of those files, hashed — one `stat` per
25//! watched file, taken on the request's own thread before it is answered, which
26//! `the_stamp_is_cheap_enough_to_take_on_every_request` holds to well under the
27//! millisecond that would make it matter. No thread, no interval, no watcher to leak, and
28//! nothing over the network.
29//!
30//! The limit, named rather than hidden: an edit to a tracked file that is never staged
31//! changes no git control file, so this does not see it. Seeing it would mean a `stat` per
32//! declared object on every request — a number that grows with the layer, against an HTTP
33//! p50 the benchmark baselines record in the hundreds of microseconds — which is the
34//! per-request regression the performance doctrine refuses. What a long-lived session
35//! actually loses to the frozen picture is the commit it just made, and a commit always
36//! moves git. `git add` moves it too: the staging index is watched.
37//!
38//! One kind of unstaged edit is seen anyway: the ones this process makes. A capability whose
39//! effect is a repository mutation — `plan.transition` stamping an issue — writes a tracked
40//! file and moves no git control file, and a Cockpit page read right after the move showed
41//! the status from before it. The executor counts every such call that succeeds, whichever
42//! transport or execution made it, and outlives a reload; a generation records the count it
43//! was built after, and a count that has moved is a repository that has moved.
44//!
45//! # The obligation that comes with watching: this process must not write them
46//!
47//! `git status` and `git diff` refresh the staging index as a side effect, writing back
48//! stat data that has gone stale or is *racily* close to the index's own modification
49//! time. So a served page that asked git about the working tree moved the stamp itself,
50//! and the *next* request paid a whole [`crate::app::App::load`] for a repository that had
51//! not moved — an observer disturbing what it observes, and charging the following caller
52//! for it. Measured over the Cockpit page sweep against a committed fixture:
53//! `repository_scans` 1 → 2 → 4 across `/cockpit/continuity` and `/cockpit/health`, with
54//! `.git/index`'s modification time moving at exactly those two points and its size never
55//! changing. Every read this crate makes therefore goes through
56//! [`crate::git::read_only`], which is that one rule made into a constructor;
57//! `a_page_costs_no_rebuild_of_anything_canonical` holds it, page by page.
58//!
59//! # What a new generation costs, and who pays it
60//!
61//! Rebuilding is a whole [`crate::app::App::load`]: discovery, every declared file read
62//! and validated, the registry, the Why catalogue, the product model, the web topology.
63//! It is paid once per repository move, by the one request that noticed, and never
64//! concurrently — a second request arriving mid-rebuild waits for it and is answered from
65//! the generation it produced, because it has seen the move too and the previous
66//! generation is the stale answer it was asking about. Everything a generation carries is a projection of the
67//! index and is therefore rebuilt with it. What is *not* a projection of the index is
68//! carried across: the peer board, the executions this process is running and the
69//! capability executor, because a reload is not a restart and an attached peer must not
70//! lose its place on the board because somebody committed.
71//!
72//! ```
73//! use std::sync::Arc;
74//! use majordomus_cli::live::Live;
75//!
76//! // A pinned view never asks the filesystem anything: what a one-shot command,
77//! // a benchmark and a test want, and what they cost.
78//! # fn example(ctx: Arc<majordomus_cli::capability::Context>) {
79//! let live = Live::pinned(ctx);
80//! assert_eq!(live.generation(), 0, "a pinned view has one generation, forever");
81//! let a = live.current();
82//! let b = live.current();
83//! assert!(Arc::ptr_eq(&a, &b), "and hands out the same context every time");
84//! # }
85//! ```

93/// The git control files whose size and modification time say the repository has moved.
94///
95/// Relative to the *per-worktree* git directory (`git rev-parse --git-dir`): a linked
96/// worktree has its own `HEAD`, its own staging index and its own reflog, and watching the
97/// primary checkout's instead would make every worktree's server blind to its own commits.
98pub const WORKTREE_FILES: [&str; 6] = [
99    "HEAD",
100    "index",
101    "ORIG_HEAD",
102    "MERGE_HEAD",
103    "logs/HEAD",
104    "rebase-merge",
105];
106
107/// The git control files shared by every worktree of one repository
108/// (`git rev-parse --git-common-dir`): where a ref that is not this worktree's moves.
109///
110/// `refs` is the directory itself, which changes when a ref file is created, renamed or
111/// removed — the shape a ref update takes, since git writes a lock file and renames it
112/// over the target.
113pub const COMMON_FILES: [&str; 2] = ["packed-refs", "refs"];
114
115/// The salt the stamp is taken under, so that it can never collide with another
116/// fingerprint computed over the same files for another purpose.
117pub const SALT: &str = "live/repository-generation";
118
119/// A picture of the git control files: what the repository looked like when a generation
120/// was built.
121///
122/// Two stamps that are equal mean git has not been asked to move anything. They are
123/// compared, never interpreted: nothing reads a head or a branch out of one.
124///
125/// ```
126/// use majordomus_cli::live::Stamp;
127/// use std::process::Command;
128///
129/// let dir = tempfile::tempdir().expect("a temporary directory");
130/// let git = |args: &[&str]| {
131///     Command::new("git").arg("-C").arg(dir.path()).args(args).output().expect("git")
132/// };
133/// git(&["init", "-q"]);
134/// git(&["config", "user.email", "t@example.com"]);
135/// git(&["config", "user.name", "t"]);
136/// std::fs::write(dir.path().join("a"), "a").expect("a file");
137/// git(&["add", "-A"]);
138/// git(&["commit", "-qm", "one"]);
139///
140/// let watch = Stamp::watching(dir.path()).expect("a work tree is watchable");
141/// let before = watch.take();
142/// assert_eq!(before, watch.take(), "nothing moved, nothing changed");
143///
144/// std::fs::write(dir.path().join("b"), "b").expect("a second file");
145/// git(&["add", "-A"]);
146/// git(&["commit", "-qm", "two"]);
147/// assert_ne!(before, watch.take(), "a commit moved the repository");
148/// ```
149#[derive(Debug, Clone)]
150pub struct Stamp {
151    root: PathBuf,
152    paths: Vec<String>,
153}
154
155impl Stamp {
156    /// The control files of the checkout at `root`, resolved once.
157    ///
158    /// `git rev-parse` is run exactly here — one subprocess for the life of the process —
159    /// because the two directories it names do not move while a checkout exists, and a
160    /// subprocess on the request path is the cost this whole module exists to avoid.
161    /// `None` when the directory is not a work tree, which is a repository of the layer
162    /// that is simply not version controlled: it has no moves to follow.
163    ///
164    /// ```
165    /// use majordomus_cli::live::Stamp;
166    ///
167    /// // a directory git knows nothing about has nothing to watch, and that is not a failure
168    /// let plain = tempfile::tempdir().expect("a temporary directory");
169    /// assert!(Stamp::watching(plain.path()).is_none());
170    /// ```
171    pub fn watching(root: &Path) -> Option<Stamp> {
172        let git_dir = resolve(root, "--git-dir")?;
173        let common = resolve(root, "--git-common-dir").unwrap_or_else(|| git_dir.clone());
174        let mut paths: Vec<String> = Vec::with_capacity(WORKTREE_FILES.len() + COMMON_FILES.len());
175        for name in WORKTREE_FILES {
176            paths.push(git_dir.join(name).to_string_lossy().into_owned());
177        }
178        for name in COMMON_FILES {
179            paths.push(common.join(name).to_string_lossy().into_owned());
180        }
181        Some(Stamp {
182            root: root.to_path_buf(),
183            paths,
184        })
185    }
186
187    /// The files this stamp is taken over, absolute. The hash sorts them, so this order
188    /// is the order they were collected in and carries no meaning of its own.
189    pub fn paths(&self) -> &[String] {
190        &self.paths
191    }
192
193    /// Take the stamp: one `stat` per watched file, hashed.
194    ///
195    /// A file that is not there contributes its absence, which is itself a move worth
196    /// noticing — `MERGE_HEAD` appearing and disappearing is how a merge begins and ends.
197    /// The work is [`crate::environment::cache::fingerprint_of`], which is the
198    /// fingerprint-over-files this crate already had; a second implementation of it would
199    /// be a second thing to keep correct.
200    ///
201    /// ```
202    /// use majordomus_cli::live::Stamp;
203    /// use std::process::Command;
204    ///
205    /// let dir = tempfile::tempdir().expect("a temporary directory");
206    /// Command::new("git").arg("-C").arg(dir.path()).args(["init", "-q"]).output().expect("git");
207    /// let watch = Stamp::watching(dir.path()).expect("a work tree");
208    /// // taking it twice over a repository nobody touched gives one value
209    /// assert_eq!(watch.take(), watch.take());
210    /// ```
211    pub fn take(&self) -> String {
212        crate::environment::cache::fingerprint_of(&self.root, &self.paths, &[SALT])
213    }
214}
215
216fn resolve(root: &Path, flag: &str) -> Option<PathBuf> {
217    let out = crate::git::read_only(root)
218        .args(["rev-parse", flag])
219        .output()
220        .ok()?;
221    if !out.status.success() {
222        return None;
223    }
224    let text = String::from_utf8_lossy(&out.stdout).trim().to_string();
225    if text.is_empty() {
226        return None;
227    }
228    let path = PathBuf::from(text);
229    Some(if path.is_absolute() {
230        path
231    } else {
232        root.join(path)
233    })
234}

236/// One generation of the repository: the context built from it and the stamp it was built
237/// at.
238struct Generation {
239    ctx: Arc<Context>,
240    stamp: String,
241    number: u64,
242    /// The executor's write count this generation was built after. A write to a tracked
243    /// file moves no git control file; a write this process made moves this.
244    writes: u64,
245}
246
247impl Generation {
248    /// Is this generation still the repository as it is: git has not moved it, and this
249    /// process has not written it since?
250    fn current(&self, taken: &str) -> bool {
251        self.stamp == taken && self.writes == self.ctx.executor.writes()
252    }
253}

255/// The repository a process reads, kept current.
256///
257/// Two forms, and the difference is whether anything is watched at all:
258///
259/// - [`Live::pinned`] — one context, forever, at no cost. A command that answers and
260///   exits, a benchmark, a test: the picture cannot go stale inside them, and making them
261///   pay a `stat` per call to prove it would be a regression bought with nothing.
262/// - [`Live::watching`] — the shared server's form. Every [`Live::current`] takes a
263///   [`Stamp`] first and rebuilds when it differs from the one the generation it holds was
264///   built at.
265///
266/// ```
267/// # use std::sync::Arc;
268/// # use majordomus_cli::live::Live;
269/// # use majordomus_cli::capability::Context;
270/// # fn example(ctx: Arc<Context>, args: majordomus_cli::cli::RepoArgs) {
271/// // the shared server follows the repository; a one-shot command does not
272/// let followed = Live::watching(args, Arc::clone(&ctx));
273/// let pinned = Live::pinned(ctx);
274/// assert_eq!(pinned.generation(), followed.generation(), "both start at the first");
275/// # }
276/// ```
277pub struct Live {
278    watch: Option<Watch>,
279    state: RwLock<Generation>,
280    /// Held by the one thread rebuilding. A request that finds it taken waits: it has
281    /// seen the repository move, so the generation that exists is not an answer to it.
282    rebuilding: Mutex<()>,
283}
284
285struct Watch {
286    args: RepoArgs,
287    stamp: Stamp,
288}
289
290impl std::fmt::Debug for Live {
291    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
292        let state = read(&self.state);
293        f.debug_struct("Live")
294            .field("watching", &self.watch.is_some())
295            .field("generation", &state.number)
296            .finish()
297    }
298}

300impl Live {
301    /// One context that never changes: no stamp is taken and nothing is rebuilt.
302    ///
303    /// ```
304    /// # use std::sync::Arc;
305    /// # use majordomus_cli::live::Live;
306    /// # fn example(ctx: Arc<majordomus_cli::capability::Context>) {
307    /// let live = Live::pinned(Arc::clone(&ctx));
308    /// assert!(Arc::ptr_eq(&live.current(), &ctx), "the very context it was given");
309    /// # }
310    /// ```
311    pub fn pinned(ctx: Arc<Context>) -> Live {
312        let writes = ctx.executor.writes();
313        Live {
314            watch: None,
315            state: RwLock::new(Generation {
316                ctx,
317                stamp: String::new(),
318                number: 0,
319                writes,
320            }),
321            rebuilding: Mutex::new(()),
322        }
323    }
324
325    /// A context that follows the repository, reloaded with `args` when git moves it.
326    ///
327    /// `args` is how the process was pointed at the repository in the first place, kept so
328    /// that a reload discovers the same root, the same distribution and the same discovery
329    /// mode the first load did. Falls back to [`Live::pinned`] when the root is not a work
330    /// tree: there is nothing to follow, and pretending otherwise would take a stamp over
331    /// a handful of absent files on every request forever.
332    ///
333    /// ```
334    /// # use std::sync::Arc;
335    /// # use majordomus_cli::live::Live;
336    /// # fn example(ctx: Arc<majordomus_cli::capability::Context>, args: majordomus_cli::cli::RepoArgs) {
337    /// let live = Live::watching(args, ctx);
338    /// // the first reading is the one it was handed; a commit makes the next one the second
339    /// assert_eq!(live.view().generation, 0);
340    /// # }
341    /// ```
342    pub fn watching(args: RepoArgs, ctx: Arc<Context>) -> Live {
343        let root = PathBuf::from(&ctx.index.repository.root);
344        // The root is pinned to the one already discovered rather than left to be
345        // rediscovered from `--repo`, which is `None` for a process started in the
346        // repository: a server is detached from the terminal that started it, and a
347        // reload that began from the current directory would rediscover whatever
348        // directory the process happens to be in — a different repository, or none.
349        let args = RepoArgs {
350            repo: Some(root.clone()),
351            ..args
352        };
353        let Some(stamp) = Stamp::watching(&root) else {
354            tracing::info!(
355                root = %root.display(),
356                "the repository is not a git work tree: this process serves the layer as it reads it now and has no moves to follow"
357            );
358            return Live::pinned(ctx);
359        };
360        let taken = stamp.take();
361        tracing::info!(
362            watched = stamp.paths().len(),
363            "following the repository: every request compares {} git control file(s) and reloads the layer when they move",
364            stamp.paths().len()
365        );
366        let writes = ctx.executor.writes();
367        Live {
368            watch: Some(Watch { args, stamp }),
369            state: RwLock::new(Generation {
370                ctx,
371                stamp: taken,
372                number: 0,
373                writes,
374            }),
375            rebuilding: Mutex::new(()),
376        }
377    }
378
379    /// Which generation is current, without taking a stamp.
380    ///
381    /// Only for a caller that already holds a [`View`] and wants to say which one it is; a
382    /// caller that is about to *use* the context must take [`Live::view`], because reading
383    /// the number and then the context is two reads with a reload possible between them —
384    /// the bug this whole module exists to end, one layer in. A projection memoised under
385    /// the number read before the reload is the previous generation's, handed out as the
386    /// current one.
387    ///
388    /// ```
389    /// # use std::sync::Arc;
390    /// # use majordomus_cli::live::Live;
391    /// # fn example(ctx: Arc<majordomus_cli::capability::Context>) {
392    /// let live = Live::pinned(ctx);
393    /// assert_eq!(live.generation(), live.view().generation);
394    /// # }
395    /// ```
396    pub fn generation(&self) -> u64 {
397        read(&self.state).number
398    }
399
400    /// The context as it is now: the one that was loaded, or a newly built one when the
401    /// repository has moved under this process.
402    ///
403    /// ```
404    /// # use std::sync::Arc;
405    /// # use majordomus_cli::live::Live;
406    /// # fn example(ctx: Arc<majordomus_cli::capability::Context>) {
407    /// let live = Live::pinned(ctx);
408    /// assert!(Arc::ptr_eq(&live.current(), &live.view().ctx));
409    /// # }
410    /// ```
411    pub fn current(&self) -> Arc<Context> {
412        self.view().ctx
413    }
414
415    /// The current generation and the context of it, as one reading.
416    ///
417    /// One call, so that a caller keying a memo on the number and filling it from the
418    /// context cannot key the new context under the old number.
419    ///
420    /// ```
421    /// # use std::sync::Arc;
422    /// # use majordomus_cli::live::{Live, Memo};
423    /// # fn example(ctx: Arc<majordomus_cli::capability::Context>) {
424    /// let live = Live::pinned(ctx);
425    /// let memo: Memo<usize> = Memo::default();
426    /// // the shape every projection uses: one reading, keyed and filled from itself
427    /// let view = live.view();
428    /// let objects = memo.get_or_init(view.generation, || view.ctx.index.objects.len());
429    /// assert_eq!(*objects, view.ctx.index.objects.len());
430    /// # }
431    /// ```
432    pub fn view(&self) -> View {
433        let Some(watch) = self.watch.as_ref() else {
434            let state = read(&self.state);
435            return View {
436                generation: state.number,
437                ctx: Arc::clone(&state.ctx),
438            };
439        };
440        let taken = watch.stamp.take();
441        {
442            let state = read(&self.state);
443            if state.current(&taken) {
444                return View {
445                    generation: state.number,
446                    ctx: Arc::clone(&state.ctx),
447                };
448            }
449        }
450        self.reload(watch, taken)
451    }
452
453    fn reload(&self, watch: &Watch, taken: String) -> View {
454        // A caller that arrives mid-rebuild has already seen the stamp move: the generation
455        // that exists is known to be stale, and answering from it is the frozen picture
456        // again for as long as a load takes. The server's own tick takes a view twice a
457        // second, so it is usually the one rebuilding, and a session that commits and asks
458        // at once was handed the commit before its own. It waits instead; the check below
459        // then finds the new generation, or rebuilds when the rebuilder's stamp was older
460        // than this caller's.
461        let _one_at_a_time = self
462            .rebuilding
463            .lock()
464            .unwrap_or_else(std::sync::PoisonError::into_inner);
465        let previous = {
466            let state = read(&self.state);
467            if state.current(&taken) {
468                return View {
469                    generation: state.number,
470                    ctx: Arc::clone(&state.ctx),
471                };
472            }
473            Arc::clone(&state.ctx)
474        };
475        // read before the load: a write that lands while the layer is being read is one the
476        // new generation may not carry, and it must leave the next reading stale
477        let writes = previous.executor.writes();
478        let built = crate::app::App::load(&watch.args);
479        let mut state = write(&self.state);
480        state.writes = writes;
481        match built {
482            Ok(app) => {
483                state.ctx = Arc::new(app.context.continuing(&previous));
484                state.number += 1;
485                state.stamp = taken;
486                tracing::info!(
487                    generation = state.number,
488                    objects = state.ctx.index.objects.len(),
489                    head = %head_of(&state.ctx),
490                    "the repository moved; this process reads generation {} of it",
491                    state.number
492                );
493            }
494            Err(e) => {
495                // A repository caught mid-rebase, a manifest being edited, a checkout half
496                // written: the last generation that loaded is a better answer than an
497                // error, and the stamp is recorded so the failure is not retried on every
498                // request until something changes again.
499                state.stamp = taken;
500                tracing::warn!(
501                    error = %e,
502                    "the repository moved but the layer would not load; serving generation {} until it changes again",
503                    state.number
504                );
505            }
506        }
507        View {
508            generation: state.number,
509            ctx: Arc::clone(&state.ctx),
510        }
511    }
512}

514/// One reading of the repository: which generation, and the context of it.
515///
516/// The pair is taken together because a memo keyed on the number and filled from the
517/// context must not mix two readings: taking the number first, then the context, lets a
518/// reload happen between them and files the new context under the old number, where the
519/// next request finds the *previous* generation and calls it current. That is the original
520/// defect in miniature, and it is why there is no way to ask for the two separately on the
521/// path that uses them.
522///
523/// ```
524/// # use std::sync::Arc;
525/// # use majordomus_cli::live::Live;
526/// # use majordomus_cli::live::View;
527/// # fn example(ctx: Arc<majordomus_cli::capability::Context>) {
528/// let view: View = Live::pinned(ctx).view();
529/// assert_eq!(view.generation, 0);
530/// assert!(view.ctx.registry.len() > 0, "the context of that generation, not another");
531/// # }
532/// ```
533#[derive(Clone)]
534pub struct View {
535    /// Which generation of the repository this is.
536    pub generation: u64,
537    /// The context built from it.
538    pub ctx: Arc<Context>,
539}

545            .field("objects", &self.ctx.index.objects.len())
546            .finish()
547    }

550/// What a projection is built over: something that can hand out the current context.
551///
552/// One trait so that the shared server passes the [`Live`] it watches with and every other
553/// caller — one-shot commands, benchmarks, the crate's own tests — passes the
554/// [`Arc<Context>`] it already has and gets a pinned view without saying so.
555///
556/// ```
557/// # use std::sync::Arc;
558/// # use majordomus_cli::live::{IntoLive, Live};
559/// # fn example(ctx: Arc<majordomus_cli::capability::Context>, live: Arc<Live>) {
560/// // a projection takes either, and neither caller has to say which it holds
561/// fn projection(over: impl IntoLive) -> u64 { over.into_live().generation() }
562/// assert_eq!(projection(ctx), 0);
563/// assert_eq!(projection(live), 0);
564/// # }
565/// ```
566pub trait IntoLive {
567    /// The live view this value stands for.
568    ///
569    /// ```
570    /// # use std::sync::Arc;
571    /// # use majordomus_cli::live::IntoLive;
572    /// # fn example(ctx: Arc<majordomus_cli::capability::Context>) {
573    /// // a plain context becomes a view that follows nothing and costs nothing
574    /// assert_eq!(ctx.into_live().generation(), 0);
575    /// # }
576    /// ```
577    fn into_live(self) -> Arc<Live>;
578}
579
580impl IntoLive for Arc<Live> {
581    fn into_live(self) -> Arc<Live> {
582        self
583    }
584}
585
586impl IntoLive for Arc<Context> {
587    fn into_live(self) -> Arc<Live> {
588        Arc::new(Live::pinned(self))
589    }

592/// A value derived from one generation of the repository, kept until that generation ends.
593///
594/// The OpenAPI document, the MCP tool and resource listings and the resolved web surfaces
595/// are all expensive functions of the index and the registry, and all of them used to be
596/// `OnceLock`s — right while the index was immutable for the life of a process, and a
597/// second frozen picture the moment it was not. A memo answers from the generation it was
598/// built for and rebuilds for the next one.
599///
600/// ```
601/// use majordomus_cli::live::Memo;
602///
603/// let memo: Memo<String> = Memo::default();
604/// let a = memo.get_or_init(0, || "built once".to_string());
605/// let b = memo.get_or_init(0, || panic!("the same generation must not rebuild"));
606/// assert_eq!(*a, *b);
607/// let c = memo.get_or_init(1, || "built again".to_string());
608/// assert_eq!(*c, "built again", "a new generation is a new value");
609/// ```
610#[derive(Debug)]
611pub struct Memo<T> {
612    cell: Mutex<Option<(u64, Arc<T>)>>,
613}
614
615impl<T> Default for Memo<T> {
616    fn default() -> Self {
617        Memo {
618            cell: Mutex::new(None),
619        }
620    }
621}
622
623impl<T> Memo<T> {
624    /// The value for `generation`, building it once when this memo does not hold it.
625    ///
626    /// The lock is held across `build`, so two threads that arrive together on a new
627    /// generation do the work once rather than twice.
628    ///
629    /// ```
630    /// use majordomus_cli::live::Memo;
631    ///
632    /// let memo: Memo<Vec<u8>> = Memo::default();
633    /// let first = memo.get_or_init(3, || vec![1, 2, 3]);
634    /// let again = memo.get_or_init(3, || unreachable!("the same generation is not rebuilt"));
635    /// assert!(std::sync::Arc::ptr_eq(&first, &again));
636    /// assert_eq!(*memo.get_or_init(4, Vec::new), Vec::<u8>::new(), "a new generation rebuilds");
637    /// ```
638    pub fn get_or_init(&self, generation: u64, build: impl FnOnce() -> T) -> Arc<T> {
639        let mut cell = self.cell.lock().unwrap_or_else(|e| e.into_inner());
640        if let Some((held, value)) = cell.as_ref() {
641            if *held == generation {
642                return Arc::clone(value);
643            }
644        }
645        let value = Arc::new(build());
646        *cell = Some((generation, Arc::clone(&value)));
647        value
648    }
649}
650
651/// The head the index was built at, for the log line that announces a generation.
652fn head_of(ctx: &Context) -> String {
653    match &ctx.index.repository.git {
654        crate::git::GitState::Available(info) => info.head.clone().unwrap_or_else(|| "-".into()),
655        crate::git::GitState::Unavailable { .. } => "-".into(),
656    }
657}
658
659fn read<T>(lock: &RwLock<T>) -> std::sync::RwLockReadGuard<'_, T> {
660    lock.read().unwrap_or_else(|e| e.into_inner())
661}
662
663fn write<T>(lock: &RwLock<T>) -> std::sync::RwLockWriteGuard<'_, T> {
664    lock.write().unwrap_or_else(|e| e.into_inner())
665}

807    #[test]
808    fn the_stamp_is_cheap_enough_to_take_on_every_request() {
809        // The whole design rests on this: the check runs on the request's own thread,
810        // before the request is answered, and the HTTP p50 this repository records is a
811        // few hundred microseconds. A stamp that cost a millisecond would be the
812        // regression the performance doctrine refuses, and the file set would have to
813        // shrink. The bound is generous — this runs on loaded CI machines — and it still
814        // fails long before the cost could matter.
815        let dir = repo();
816        let watch = Stamp::watching(dir.path()).expect("a work tree");
817        let _warm = watch.take();
818        let rounds = 200;
819        let started = Instant::now();
820        for _ in 0..rounds {
821            let _ = watch.take();
822        }
823        let each = started.elapsed() / rounds;
824        assert!(
825            each < std::time::Duration::from_millis(2),
826            "a stamp took {each:?}, which is too much to take on every request"
827        );
828    }
