# Mission 06: Fast, safe throughput and verified dogfooding

Audit pipeline dependency graph, caches, jobs and merge/release gates. Record actual baseline durations for representative PRs, tests, site publication and deployment; distinguish local, CI, queue and network time. Make only evidence-based improvements: parallelize independent jobs; cache by lockfile/toolchain; reuse compiled Rust binary for behavior tests; build docs/site once per commit where appropriate; make fast deterministic checks blocking and longer suites correctly scoped. Never weaken required coverage/verification to hit a target. Aim for PR feedback under 5 minutes and rapid Pages rollout where feasible, without claiming SLA before measurements. Reuse existing versioning/Elm-style policies, release assets, install smoke tests, source provenance and rollback. Validate actual released artifact/install/docs endpoints and compare their revision/version to source. Enforce evidence freshness after deployment. Drain ready PRs in controlled batches, rebase obsolete worktrees safely without deleting unmerged/unpushed data; fail closed on conflicts. Feed each completed session and release back through Majordomus intents, sessions, evidence, context, `.ai` validation, user-facing surface and claims. Produce final table: acceptance ID, exact proof, test command/result, SHA, pipeline run, live URL/version, remaining blocker. No green checkmarks without observed proof.
