Module tasks 

Source
Expand description

Each task’s delivery economics, folded from every checkout’s ledger (I3376).

The owner’s report of 2026-10-19 asks, for each task, its time, its interventions, its CI reruns, its spend and whether its result was accepted (T3). The ledger already records a task’s steps — task.started, every task.refused, task.finished — and the episodes that carried it, but it is per checkout and untracked, and the one reader that folded it (crate::intent_realization::gather) read only the root checkout’s. This module reads the ledger of every checkout git worktree list reports, with the archives ledger.rotated left beside it, and answers one record per task.

Wall time, refusals and episodes are measured. Interventions, CI reruns, spend and acceptance are not yet observed by anything; each is present on every record as TaskEconomicsFieldStatus::NotObserved with the reason and the issue that will supply it, so later issues fill a field without changing the response type.

use majordomus_cli::economics::tasks::{fold, TaskEconomicsQuery, TaskEconomicsSource};
let line = |ts: &str, event: &str, extra: &str| {
    format!(r#"{{"ts":"{ts}","event":"{event}","head":"h","branch":"b","by":"me","session":"s-1","task_id":"t-1"{extra}}}"#)
};
let text = [
    line("2026-10-21T10:00:00Z", "task.started", r#","issue":"I3376""#),
    line("2026-10-21T10:30:00Z", "task.refused", r#","outcome":"completed","unmet":1"#),
    line("2026-10-21T11:00:00Z", "task.finished", r#","outcome":"completed""#),
]
.join("\n");
let source = TaskEconomicsSource::parse("repo", "ledger.jsonl", &text);
let list = fold(vec![source], &TaskEconomicsQuery::default());
assert_eq!(list.count, 1);
let t = &list.tasks[0];
assert_eq!(t.wall_seconds, Some(3600));
assert_eq!(t.refusals, 1);
assert_eq!(t.issue.as_deref(), Some("I3376"));
