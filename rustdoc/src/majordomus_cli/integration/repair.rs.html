1//! `prs repair`: bring the current master into one named pull request whose only quarrel with
2//! master is over derived files, on a person's request.
3//!
4//! # Why it exists
5//!
6//! `.gitattributes` marks every family of committed generated artifacts `merge=derived`, and
7//! the driver that resolves them is per-clone configuration the forge never has. So the forge
8//! runs its text merge over files whose content is a fingerprint of the merged tree and calls
9//! nearly every pull request conflicting, over a conflict that exists on nobody's machine.
10//! The remedy is rule `project.land-and-publish` clause 2: merge master in locally, where the
11//! driver exists, regenerate, commit, push. The executor does exactly that for the first
12//! refreshable pull request of the queue (`prs drain --refresh`); this is the same act for the
13//! one a person names, whatever lane it waits in. It replaces `scripts/unblock`, the shell
14//! script that performed the gesture outside the integrator.
15//!
16//! # What decides
17//!
18//! Nothing here classifies. [`decide`] reads the assessment the queue built — the relation to
19//! master git decided with the derived attribute ([`super::relation`]), the disposition and
20//! the reasons the classifier gave — and maps it onto three answers:
21//!
22//! - eligible: the relation is `behind`. The head does not contain master, and git's merge
23//!   conflicts on no authored path: whatever the forge calls conflicting is a `merge=derived`
24//!   path, which the regeneration settles;
25//! - nothing to repair: the head already contains master, its work is on master already, or
26//!   a declared successor landed — cleanup is the lane for those;
27//! - refused: a conflict on an authored path (named, file by file: two people wrote two
28//!   things and only they can say which is meant), a relation git could not decide, a base
29//!   that is not the integration base, a fork's head this repository cannot push to, or a
30//!   pull request with auto-merge armed, which the forge would merge on its own the moment a
31//!   new head arrived.
32//!
33//! # What it reads, what it does, and what it never does
34//!
35//! The dry run is the default and it is a read: [`plan`] decides from the queue
36//! [`super::queue_of`] builds out of the last recorded observation — the value `prs status`,
37//! `prs plan` and `prs explain` render — so it reaches no network, takes no lease and writes
38//! nothing to the trail. [`apply`] is the act, and it follows the drain's rules: the caller
39//! holds the base branch's integration lease for the whole of it; it observes the forge
40//! afresh, exactly as a drain step does ([`Integrator::observe`]), and decides again on that;
41//! `repair_selected` and then `repair_attempted` are on the trail before anything reaches the
42//! remote, and `repaired` or `repair_refused` after, so an act interrupted half-way leaves its
43//! attempt behind. The act is the executor's own ([`Integrator::refresh_branch`]): a merge of
44//! the decided master in a scratch worktree of its own, `scripts/derive` on the result, one
45//! commit, and a push that is a fast-forward of the head that was observed, leased on that
46//! head, so a branch somebody pushed to meanwhile is refused and never overwritten. It never
47//! merges anything into master, and never touches a person's checkout.

59/// The pull request a person names: its number, or its head branch.
60#[derive(Debug, Clone, PartialEq, Eq)]
61pub enum RepairTarget {
62    /// The number.
63    Number(u64),
64    /// The head branch of an open pull request of this repository.
65    Branch(String),
66}
67
68impl RepairTarget {
69    /// A number when the word is digits, a branch otherwise: a pull-request number is what a
70    /// person has in front of them when they see the conflict.
71    ///
72    /// ```text
73    /// use crate::integration::repair::RepairTarget;
74    /// assert_eq!(RepairTarget::parse("137"), RepairTarget::Number(137));
75    /// assert_eq!(RepairTarget::parse("feature/x"), RepairTarget::Branch("feature/x".into()));
76    /// ```
77    pub fn parse(word: &str) -> Self {
78        match word.parse::<u64>() {
79            Ok(n) if word.bytes().all(|b| b.is_ascii_digit()) => RepairTarget::Number(n),
80            _ => RepairTarget::Branch(word.to_string()),
81        }
82    }
83
84    /// The open pull request this names in `queue`. A branch name prefers this repository's
85    /// own head over a fork's of the same name.
86    fn find<'q>(&self, queue: &'q IntegrationQueue) -> Option<&'q PullRequestAssessment> {
87        match self {
88            RepairTarget::Number(n) => queue.get(*n),
89            RepairTarget::Branch(b) => queue
90                .assessments
91                .iter()
92                .filter(|a| &a.head_ref == b)
93                .find(|a| !a.reasons.contains(&ReasonCode::ForkHead))
94                .or_else(|| queue.assessments.iter().find(|a| &a.head_ref == b)),
95        }
96    }
97}
98
99impl std::fmt::Display for RepairTarget {
100    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
101        match self {
102            RepairTarget::Number(n) => write!(f, "#{n}"),
103            RepairTarget::Branch(b) => f.write_str(b),
104        }
105    }
106}

108/// Why a pull request is not repaired.
109#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
110#[serde(rename_all = "snake_case", tag = "kind")]
111pub enum RepairRefusal {
112    /// No open pull request is that number, or has that head branch.
113    NotOpen {
114        /// What was named.
115        target: String,
116    },
117    /// It targets another branch than the integration base: the base is not what it lacks.
118    OtherBase {
119        /// The branch it targets.
120        base: String,
121    },
122    /// Its head lives in a fork, which this repository cannot push to.
123    ForkHead,
124    /// The forge has auto-merge armed on it: a new head would be merged by the forge on its
125    /// own, outside the executor.
126    AutoMergeArmed,
127    /// Merging master conflicts on authored paths: the owner's to settle.
128    AuthoredConflict {
129        /// The conflicting authored paths.
130        paths: Vec<String>,
131    },
132    /// Git could not decide what the head is to master.
133    Undecidable {
134        /// Why.
135        reason: String,
136    },
137    /// The act was taken and failed — a merge that conflicted after all, a derive that
138    /// failed, a commit the hooks refused, or a push refused because the branch moved — and
139    /// nothing reached the branch.
140    ActFailed {
141        /// What failed, in the words of the step that failed.
142        reason: String,
143        /// Why, as a class.
144        class: FailureClass,
145    },
146    /// The trail could not record the act first, so it was not taken.
147    TrailUnwritable {
148        /// Why the trail refused it.
149        reason: String,
150    },
151}
152
153impl RepairRefusal {
154    /// The class a refusal is recorded with on the trail.
155    pub fn class(&self) -> FailureClass {
156        match self {
157            RepairRefusal::AuthoredConflict { .. } => FailureClass::Conflict,
158            RepairRefusal::Undecidable { .. } | RepairRefusal::TrailUnwritable { .. } => {
159                FailureClass::Unreadable
160            }
161            RepairRefusal::ActFailed { class, .. } => *class,
162            RepairRefusal::NotOpen { .. }
163            | RepairRefusal::OtherBase { .. }
164            | RepairRefusal::ForkHead
165            | RepairRefusal::AutoMergeArmed => FailureClass::PolicyViolation,
166        }
167    }
168}
169
170impl std::fmt::Display for RepairRefusal {
171    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
172        match self {
173            RepairRefusal::NotOpen { target } => write!(
174                f,
175                "{target} is not an open pull request of this repository: nothing classifies it, so nothing may repair it"
176            ),
177            RepairRefusal::OtherBase { base } => write!(
178                f,
179                "it targets {base}, not the integration base: master is not what it lacks"
180            ),
181            RepairRefusal::ForkHead => f.write_str(
182                "its head lives in a fork this repository cannot push to; the author merges the base in",
183            ),
184            RepairRefusal::AutoMergeArmed => f.write_str(
185                "auto-merge is armed on it: a pushed head would be merged by the forge on its own; a person disarms it first",
186            ),
187            RepairRefusal::AuthoredConflict { paths } => write!(
188                f,
189                "merging master conflicts on {} authored file(s), which are the owner's to settle: {}",
190                paths.len(),
191                paths.join(", ")
192            ),
193            RepairRefusal::Undecidable { reason } => {
194                write!(f, "git could not decide its relation to master: {reason}")
195            }
196            RepairRefusal::ActFailed { reason, .. } => {
197                write!(f, "nothing reached the branch: {reason}")
198            }
199            RepairRefusal::TrailUnwritable { reason } => write!(
200                f,
201                "the act was not taken: the trail could not record it first: {reason}"
202            ),
203        }
204    }
205}

207/// What a repair did, or would do.
208#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
209#[serde(rename_all = "snake_case", tag = "outcome")]
210pub enum RepairOutcome {
211    /// Its head already contains master, or its work is on master already: there is nothing
212    /// to bring in.
213    NothingToRepair {
214        /// Why, for a person.
215        why: String,
216    },
217    /// Dry run: master would be brought in, derived, committed and pushed.
218    WouldRepair,
219    /// Master was brought in and the branch pushed, as a fast-forward leased on the head
220    /// that was observed.
221    Repaired {
222        /// The head pushed.
223        head_after: String,
224    },
225    /// Refused, and why.
226    Refused {
227        /// Why.
228        refusal: RepairRefusal,
229    },
230}

232/// The answer of one `prs repair`.
233#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
234pub struct RepairReport {
235    /// Whether nothing was allowed to change.
236    pub dry_run: bool,
237    /// What the person named.
238    pub target: String,
239    /// The pull request it named, when one is open.
240    pub pr: Option<u64>,
241    /// Its head branch.
242    pub branch: Option<String>,
243    /// The integration base.
244    pub base: String,
245    /// The master commit the decision was taken against.
246    pub master_sha: String,
247    /// The head the decision was taken against.
248    pub head_sha: Option<String>,
249    /// When the forge was observed, for the observation the decision was taken on.
250    pub observed_at: String,
251    /// What git decided the head is to master.
252    pub relation: Option<RelationToMaster>,
253    /// What happened.
254    pub outcome: RepairOutcome,
255    /// What the observation the decision rests on cannot vouch for — the queue's own
256    /// diagnostics, such as an observation older than an hour. A dry run with any exits 10, as
257    /// every other reading of a diagnosed queue does.
258    #[serde(default)]
259    pub diagnostics: Vec<String>,
260}

262/// What the classification says about repairing one pull request.
263#[derive(Debug, Clone, PartialEq, Eq)]
264pub enum RepairDecision {
265    /// Master may be brought in.
266    Eligible(PullRequestAssessment),
267    /// Nothing to bring in, and why.
268    Nothing(PullRequestAssessment, String),
269    /// Refused.
270    Refused(Option<PullRequestAssessment>, RepairRefusal),
271}
272
273impl RepairDecision {
274    fn assessment(&self) -> Option<&PullRequestAssessment> {
275        match self {
276            RepairDecision::Eligible(a) | RepairDecision::Nothing(a, _) => Some(a),
277            RepairDecision::Refused(a, _) => a.as_ref(),
278        }
279    }
280}

282/// Decide from the queue alone — the relation, the disposition and the reasons the
283/// classifier gave. Pure: it reads no file, runs no git and asks no forge.
284pub fn decide(queue: &IntegrationQueue, target: &RepairTarget) -> RepairDecision {
285    let Some(a) = target.find(queue) else {
286        return RepairDecision::Refused(
287            None,
288            RepairRefusal::NotOpen {
289                target: target.to_string(),
290            },
291        );
292    };
293    let refuse = |r| RepairDecision::Refused(Some(a.clone()), r);
294    let nothing = |why: String| RepairDecision::Nothing(a.clone(), why);
295    if a.base_ref != queue.base {
296        return refuse(RepairRefusal::OtherBase {
297            base: a.base_ref.clone(),
298        });
299    }
300    if a.reasons.contains(&ReasonCode::AutoMergeArmed) {
301        return refuse(RepairRefusal::AutoMergeArmed);
302    }
303    match a.disposition {
304        PullRequestDisposition::Redundant => {
305            return nothing(format!(
306                "its work is on {} already; cleanup is the lane for it",
307                queue.base
308            ))
309        }
310        PullRequestDisposition::Superseded => {
311            return nothing(format!(
312                "a successor{} landed and replaces it; cleanup is the lane for it",
313                a.superseded_by
314                    .map(|n| format!(", #{n},"))
315                    .unwrap_or_default()
316            ))
317        }
318        _ => {}
319    }
320    match &a.relation {
321        RelationToMaster::Conflicting { paths } => refuse(RepairRefusal::AuthoredConflict {
322            paths: paths.clone(),
323        }),
324        RelationToMaster::Unknown { reason } => refuse(RepairRefusal::Undecidable {
325            reason: reason.clone(),
326        }),
327        RelationToMaster::Behind { .. } if a.reasons.contains(&ReasonCode::ForkHead) => {
328            refuse(RepairRefusal::ForkHead)
329        }
330        RelationToMaster::Behind { .. } => RepairDecision::Eligible(a.clone()),
331        RelationToMaster::UpToDate { .. } => {
332            nothing(format!("its head already contains {}", queue.base))
333        }
334        RelationToMaster::Contained
335        | RelationToMaster::Superseded
336        | RelationToMaster::PatchIdsUpstream { .. } => nothing(format!(
337            "its work is on {} already; cleanup is the lane for it",
338            queue.base
339        )),
340        RelationToMaster::DerivedOnly { .. } => nothing(
341            "only derived artifacts would change: the authored change appears to be on master \
342             already, which a person confirms (possibly_redundant)"
343                .to_string(),
344        ),
345    }
346}

348/// The report of `decision`, taken on `queue`, before anything is done.
349fn report_of(
350    queue: &IntegrationQueue,
351    target: &RepairTarget,
352    decision: &RepairDecision,
353    dry_run: bool,
354) -> RepairReport {
355    let a = decision.assessment();
356    RepairReport {
357        dry_run,
358        target: target.to_string(),
359        pr: a.map(|a| a.number),
360        branch: a.map(|a| a.head_ref.clone()),
361        base: queue.base.clone(),
362        master_sha: queue.master_sha.clone(),
363        head_sha: a.map(|a| a.evaluated_against.head_sha.clone()),
364        observed_at: queue.observed_at.clone(),
365        relation: a.map(|a| a.relation.clone()),
366        diagnostics: queue.diagnostics.clone(),
367        outcome: match decision {
368            RepairDecision::Eligible(_) => RepairOutcome::WouldRepair,
369            RepairDecision::Nothing(_, why) => RepairOutcome::NothingToRepair { why: why.clone() },
370            RepairDecision::Refused(_, refusal) => RepairOutcome::Refused {
371                refusal: refusal.clone(),
372            },
373        },
374    }
375}

377/// The dry run over a queue already built: what [`apply`] would do on it. Pure.
378pub fn dry_run(queue: &IntegrationQueue, target: &RepairTarget) -> RepairReport {
379    report_of(queue, target, &decide(queue, target), true)
380}

382/// The dry run of this checkout: decided on the queue of the last recorded observation
383/// ([`super::queue_of`]), the read every other non-acting `prs` command makes. It reaches no
384/// network, takes no lease and records nothing; an observation that is absent is the error,
385/// as it is for `prs status`.
386pub fn plan(root: &Path, target: &RepairTarget) -> Result<RepairReport, String> {
387    Ok(dry_run(&super::queue_of(root)?, target))
388}

390/// The act. The caller holds the base branch's integration lease for the whole call: the act
391/// is a push to the forge's remote, and a drain must not race it. The forge is observed
392/// afresh first, as a drain step observes it, and the decision is taken again on that; every
393/// act is on the trail before it reaches the remote. `Err` when the forge could not be
394/// observed, or the trail refused a line recording a refusal or an outcome; an act the trail
395/// could not announce first is not taken and is reported as
396/// [`RepairRefusal::TrailUnwritable`].
397pub fn apply(
398    root: &Path,
399    integrator: &mut dyn Integrator,
400    target: &RepairTarget,
401) -> Result<RepairReport, String> {
402    let queue = integrator.observe()?;
403    let decision = decide(&queue, target);
404    let mut report = report_of(&queue, target, &decision, false);
405    let candidate = match decision {
406        RepairDecision::Nothing(..) => return Ok(report),
407        RepairDecision::Refused(a, refusal) => {
408            let mut e = event(
409                IntegrationAction::RepairRefused,
410                a.as_ref(),
411                refusal.to_string(),
412            );
413            e.class = Some(refusal.class());
414            record(root, e)?;
415            return Ok(report);
416        }
417        RepairDecision::Eligible(a) => a,
418    };
419    let unwritable = |reason| RepairOutcome::Refused {
420        refusal: RepairRefusal::TrailUnwritable { reason },
421    };
422    let selected = event(
423        IntegrationAction::RepairSelected,
424        Some(&candidate),
425        format!("named by a person: {target}"),
426    )
427    .with_evidence(&candidate);
428    if let Err(reason) = record(root, selected) {
429        report.outcome = unwritable(reason);
430        return Ok(report);
431    }
432    // on the trail before anything is pushed: a push the trail cannot name is not made
433    let attempted = event(
434        IntegrationAction::RepairAttempted,
435        Some(&candidate),
436        format!(
437            "master {} into {}, pushed leased on {}",
438            queue.master_sha, candidate.head_ref, candidate.evaluated_against.head_sha
439        ),
440    );
441    if let Err(reason) = record(root, attempted) {
442        report.outcome = unwritable(reason);
443        return Ok(report);
444    }
445    match integrator.refresh_branch(&candidate, &queue.base) {
446        Ok(head_after) => {
447            let mut e = event(
448                IntegrationAction::Repaired,
449                Some(&candidate),
450                format!("new head {head_after}"),
451            );
452            e.master_after = Some(queue.master_sha.clone());
453            e.head_after = Some(head_after.clone());
454            record(root, e)?;
455            report.outcome = RepairOutcome::Repaired { head_after };
456        }
457        Err(reason) => {
458            let refusal = RepairRefusal::ActFailed {
459                class: FailureClass::of_refresh_failure(&reason),
460                reason,
461            };
462            let mut e = event(
463                IntegrationAction::RepairRefused,
464                Some(&candidate),
465                refusal.to_string(),
466            );
467            e.class = Some(refusal.class());
468            record(root, e)?;
469            report.outcome = RepairOutcome::Refused { refusal };
470        }
471    }
472    Ok(report)
