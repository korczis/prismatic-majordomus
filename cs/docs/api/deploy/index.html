HTTP API: deploy

Nasazení (deployments), která tento repozitář deklaruje, čtená z kanonických objektů držených indexem, a zda by fungovala — posuzováno proti registru schopností, který tento proces postavil, a pracovnímu prostoru, v němž sedí. Každá operace je čtení: nasazení se mění důvěryhodným příkazovým řádkem a CI, nikdy přes HTTP a nikdy klientem MCP.

Zda by tato nasazení fungovala

Každé odmítnutí, které si deklarovaná nasazení lokálně vyslouží: trasa health, kterou neregistruje žádná schopnost, balíček nebo binárka, kterou workspace nevytváří, vstup buildu, který se nerozliší, víc běžících strojů, než existuje, hostovaný proces, který by se vázal na loopback. Každé jmenuje soubor, klíč, pozorovanou hodnotu a opravu. Nic zde nekontaktuje providera.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache process (max_entries=2, ttl_seconds=5)
  • Nástroj MCP majordomus_deploy_check

GET /api/v1/deployments/observed deploy.observed

Co bylo nasazeno a kde

Každé nasazení, které forge zaznamenal, do každého prostředí, v němž nějaké má — mimo jiné GitHub Pages — s commitem, refem, tím, kdo je vytvořil, jak skončilo, kde se servíruje a během, který je provedl; každé prostředí popsané jeho nejnovějším nasazením; a každý release, který forge publikoval. Čte se ze záznamu, který zapsal `majordomus served forge`, když se forge naposledy ptal: nic zde nesahá na síť a checkout, který se nikdy neptal, odpoví `observed: false` s tím, co spustit.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache vypnuta
