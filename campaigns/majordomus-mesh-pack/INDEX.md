# Milestone routing

- **M00** [Reconnaissance and baseline](milestones/M00-reconnaissance-and-baseline.md): Identify actual canonical mechanisms before changing architecture.
- **M01** [Canonical artifact registry and upload safety](milestones/M01-canonical-artifact-registry-and-upload-safety.md): Represent uploads as immutable, addressable, provenance-bearing artifacts.
- **M02** [Prompt-pack structural extraction](milestones/M02-prompt-pack-structural-extraction.md): Extract traceable source segments from varied pack layouts.
- **M03** [Intent and project-graph reconciliation](milestones/M03-intent-and-project-graph-reconciliation.md): Turn pack requirements into existing canonical plans rather than shadow tasks.
- **M04** [Revision tracking and impact analysis](milestones/M04-revision-tracking-and-impact-analysis.md): Reconcile new pack revisions without erasing history or corrupting running work.
- **M05** [Durable intent execution controller](milestones/M05-durable-intent-execution-controller.md): Make autonomous continuation runtime-owned, never dependent on a long chat.
- **M06** [Mesh peer cooperation](milestones/M06-mesh-peer-cooperation.md): Use capabilities and leases to allocate parallel work safely.
- **M07** [Session context, handover and resumption](milestones/M07-session-context,-handover-and-resumption.md): Carry minimum sufficient context across agents and machines without transcript worship.
- **M08** [PR drain and continuous integration](milestones/M08-pr-drain-and-continuous-integration.md): Turn completed work into small, policy-compliant merged increments.
- **M09** [Self-update and compatible rollout](milestones/M09-self-update-and-compatible-rollout.md): Upgrade Majordomus and injected projects without tearing down its controller.
- **M10** [CLI MCP REST OpenAPI integration](milestones/M10-cli-mcp-rest-openapi-integration.md): Make every interface a projection of the same canonical state and actions.
- **M11** [Majordomus UI product experience](milestones/M11-majordomus-ui-product-experience.md): Turn the new model into a discoverable mobile-first user workflow.
- **M12** [Governance security and verification](milestones/M12-governance-security-and-verification.md): Make architectural invariants machine-enforced and adversarially tested.
- **M13** [Documentation website and real demonstration](milestones/M13-documentation-website-and-real-demonstration.md): Explain user value with evidence rather than marketing hallucinations.
- **M14** [Dogfood release deploy and measured handoff](milestones/M14-dogfood-release-deploy-and-measured-handoff.md): Use the system to complete its own transformation and prove it.

M00 is mandatory baseline. Subsequent milestones can overlap if dependencies, ownership and safety permit. Each Mxx file has seven bounded issue contracts.
