Constant PROCESS_DIMENSIONS

pub const PROCESS_DIMENSIONS: [&str; 3];
Expand description

The dimensions that describe the process serving a checkout and not the repository: the shared server, its peer board and its mesh runtime. Only a process holding the checkout’s lease decides the last two, so in any other they are unknown by construction, never by a fault of the repository.

use majordomus_cli::capability::builtin::health::PROCESS_DIMENSIONS;
assert!(PROCESS_DIMENSIONS.contains(&"mesh"));
assert!(!PROCESS_DIMENSIONS.contains(&"layer"));
