pub fn applicable<'a>(
    rule_ids: impl IntoIterator<Item = &'a str>,
) -> Vec<&'static str>
Expand description

The checks a repository declaring the rules rule_ids is held to, in CHECKS order: every check where REPOSITORY_RULE is among them, and only what an adopter adopted (its catalogue, adapters, coupling and records) where it is not.

use majordomus_cli::reasoning::check::{applicable, CHECKS};

assert_eq!(applicable(["project.advisors-are-optional"]), CHECKS);
assert_eq!(
    applicable(["majordomus.some-other-rule"]),
    ["catalogue", "adapters", "coupling", "records"]
);
