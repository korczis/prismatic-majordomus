title = "I3072 — A task holding the release seat does not finish completed while landed work has waited past the threshold"
description = "Add a doctrine of its own, enforced by finish with its own validator, policy key and wording, that reads release.currency. It refuses the outcome completed only to the release seat's task. A task is the seat's when a live exclusive claim matching release/seat is held by a mesh session whose provider session is the task's own. The join is derived, never declared. The MCP bridge reads the provider session from the variables the lifecycle adapters declare and hands it to the server at initialize. The board projection carries a digest of it into the mesh session record as provider_session, and start records the same digest in the task record, so no raw session id leaves the machine. Before the field ships, a test shows that an event's signature covers the bytes received, so that a runtime that does not know the field still verifies the event. The seat's task is refused completed when release.currency says overdue, and when the measurement is unknown, naming the count, the wait and the version or why none was decided. A pushed v* tag counts as released only while scripts/ci/release-check reads its run as queued or running, or once that run has succeeded. A failed run, or none past release-check's grace, refuses the seat, and a forge that cannot be read is reported, never counted. Every other finish is told the stance and who holds release/seat, its session and machine, or that the seat is vacant, and is never refused by it. A measurement or seat that cannot be read refuses no other task. A task whose provider session differs from the seat holder's, such as a new session that resumed the seat's handover, is told that release/seat is held by another provider session, so the seat sees why its work was not gated. A task started with no observable provider session is never the seat's. Case 3472 proves each of these, and the intent's criterion the-seat-releases names it instead of case 3470."
