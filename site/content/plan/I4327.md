A session that declares nothing takes no reviews. ReviewAnswered (journal.rs:661-671) gains a fourth answer, `declined`, beside approved, changes_requested and commented, with a note, so that 'not mine' is recorded and is never read as a verdict on the change. For each open review request, mesh state derives its eligible answerers: the live sessions whose mandate covers the request's repository and scope, minus the requesting session, minus sessions of the same task (a builder's own subagents), and minus any session that declined it. mesh state, mesh peers, the brief and /ui/mesh list them, and list the declines apart. mesh doctor and the brief print `WARN review_no_eligible_reviewer <repository> <request>` when the set is empty. The link FEATURES list (mesh/link.rs:63) is unchanged: `reviews` there means that a runtime's link protocol carries review events, and request_review's FeatureUnsupported refusal (mesh/cooperation.rs:4453-4470) keeps that meaning, with wording that no longer suggests the runtime will review."
