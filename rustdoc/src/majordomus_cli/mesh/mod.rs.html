1//! The mesh: how one running Majordomus learns that others exist, and proves which one
2//! it is. ADR 0050 is the decision; this module is the whole implementation, and its
3//! boundaries are the point:
4//!
5//! - **Identity is a key, not an address.** A node is an Ed25519 keypair kept per user
6//!   and machine ([`identity`]); the node id is a digest of the public key. Hostnames,
7//!   IPs, ports and PIDs are runtime attributes and never identity.
8//! - **One protocol** ([`protocol`]): a compact, versioned, bounded, signed envelope,
9//!   the same over multicast, broadcast and rendezvous. Parsing never panics; hostile
10//!   input is a counted refusal.
11//! - **Providers observe, the manager decides** ([`provider`], [`manager`]): a
12//!   discovery mechanism hands raw bytes up and answers for its own health. The manager
13//!   owns the one verification path and the one [`registry`]; adding a mechanism is
14//!   implementing the provider contract, not editing consumers.
15//! - **Discovery creates awareness, not authority** ([`trust`]): a valid unknown node
16//!   is observed and trusted for nothing; even a trusted node gains no execution
17//!   rights — there is no remote execution to gain. The default policy is
18//!   `deny_unknown`, and the mesh itself is off until the repository commits a
19//!   declaration ([`config`]) that says otherwise: the "nothing leaves the machine"
20//!   posture holds by default.
21//! - **Every surface is a projection.** CLI, HTTP, OpenAPI, MCP and the Cockpit read
22//!   [`MeshRuntime`] and the registry; none holds peers of its own.
23//!
24//! Nothing here writes to the repository. The identity file lives under the user's
25//! state directory; the registry lives in process memory and dies with it.
26//!
27//! The whole lifecycle, in memory:
28//!
29//! ```
30//! use majordomus_cli::mesh::{identity::NodeIdentity, protocol};
31//!
32//! // a node proves itself: sign, encode, parse, verify — the one path every
33//! // transport's datagrams take
34//! let node = NodeIdentity::ephemeral().unwrap();
35//! let envelope = protocol::advertise(&node, 1, &["127.0.0.1:8741".into()],
36//!     &["http".into()], &[], "docs");
37//! let bytes = protocol::encode(&envelope).unwrap();
38//! let heard = protocol::parse(&bytes).expect("a fresh signed envelope verifies");
39//! assert_eq!(heard.adv.node_id(), Some(node.public.node_id.clone()));
40//!
41//! // and hostile input is a refusal, never a panic
42//! assert!(protocol::parse(b"garbage").is_err());
43//! ```

74/// Why a mesh operation did not happen. Each variant names the layer that refused, so
75/// a log line places the failure without a backtrace.
76///
77/// ```
78/// use majordomus_cli::mesh::MeshError;
79/// let e = MeshError::Config("an interval of 0 would be a busy loop".into());
80/// assert_eq!(e.to_string(), "config: an interval of 0 would be a busy loop");
81/// ```
82#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
83pub enum MeshError {
84    /// The identity file: unreadable, malformed, or nowhere to keep one.
85    #[error("identity: {0}")]
86    Identity(String),
87    /// The protocol: an envelope that cannot be built or does not fit.
88    #[error("protocol: {0}")]
89    Protocol(String),
90    /// A provider: a socket, a group, an endpoint.
91    #[error("provider: {0}")]
92    Provider(String),
93    /// The declaration: missing, malformed, or a version this executable does not read.
94    #[error("config: {0}")]
95    Config(String),
96}
