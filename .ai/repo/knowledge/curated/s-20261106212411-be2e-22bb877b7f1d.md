# Evidence

- `.github/workflows/release.yml` lines 565-606, "wait for the published metadata to name this release": a pre-release's own tag file (`${url%latest.json}$tag.json`), 60 attempts 15 s apart with `curl --max-time 60`, so about 15 minutes after the publish job pushed gh-pages.
- Run 42251574700 (v1.0.0-alpha.10, 64d28e2d9c5) on 2026-11-06: four of six smoke jobs failed at 17:40-17:42Z with HTTP 404 for `https://majordomus.dev/releases/v1.0.0-alpha.10.json`; the two linux-x86_64 jobs, which ran later, passed; by 18:05Z the file named the tag; one rerun of the failed jobs was green.
