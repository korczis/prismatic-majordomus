Odmítnout adresář vrstvy, který nic nedokumentuje

Adresář přidaný pod vrstvu bez kontextového dokumentu neprojde validací, a to jmenovitě; nic se nevyřeší proti stromu, dokud neřekne, k čemu je, a tatáž hierarchie je čitelná přes MCP i API bez spuštění kontroly.

○zaručeno Znalosti repozitářepokročilýmaintainerreviewerjen pro čtení

Situace

Někdo přidá adresář pod .ai/ — novou sekci, místo pro data, podrozdělení stávající — a nenapíše README.md. Ten den se nic nerozbije. Adresář nepřispívá nic do řetězce, který pracovník rozlišuje, nejmenuje žádný formát pro soubory, které drží, a příští člověk, který tam přistane, přečte jeho předky a zbytek hádá. Ponecháno bez povšimnutí takto vrstva s kontraktem na adresář přechází ve vrstvu s kontraktem na adresář, na který si někdo vzpomněl.

Co spouštíte

  • context validate: celý strom, přičemž missing-contract jmenuje každý adresář, který dluží dokument
  • context resolve <path>: odmítne, dokud je strom rozbitý, místo aby odpovídal z části, která je náhodou v pořádku
  • doctor: tatáž kontrola přes majordomus.context-integrity, kterou spouští pre-commit hook

Scénář

setup: undocumented-directory
given:
  - 'a repository with Majordomus installed, a new section that carries its contract, and one directory below it that carries none'
steps:
  - id: validate
    run: ['context', 'validate']
    note: 'the directory with no document is named, and the one that has its contract is not'
    expect:
      exit: 10
      stdout_contains: ['missing-contract', 'zones/deep']
      stdout_not_contains: ['zones — missing-contract']
  - id: resolve
    run: ['context', 'resolve', '.ai/repo/zones']
    note: 'nothing resolves against a tree that does not validate, not even the part that is correct'
    expect:
      exit: 10
      stdout_contains: ['does not validate']
  - id: doctor
    run: ['doctor']
    note: 'the same finding through the rule majordomus.context-integrity, which the pre-commit hook runs'
    expect:
      exit: 10
      stdout_contains: ['missing-contract']
then:
  - 'a directory of the layer with no context document is a named failure, not a silence'
  - 'the same tree, and what each directory owes, is readable through majordomus_directories and GET /api/v1/directories without running the gate'
  - 'the finding names the directory, so the fix is one file in one place'
  - 'the tree refuses to resolve until it is fixed, so nobody reads a half-documented layer'
  - 'the same tree, and what each directory owes, is readable through majordomus_directories and GET /api/v1/directories without running the gate'

Výsledek

Povinnost zdokumentovat adresář se vynucuje, ne pamatuje. Oprava je jeden soubor: README.md nesoucí schema: context/v1, který říká, k čemu adresář slouží a co do něj patří. Kde jsou adresáře pod kontraktem instancemi druhu, a ne sekcemi — dovednost a její příklady — řídicí kontrakt je vyjme pomocí children.require_contract: false a výjimka putuje se stromem, který popisuje.

Proč to nástroj ví

Řetězec od této stránky ke kódu: případ užití jmenuje příkazy, pravidla a tvrzení; každé pravidlo se dispatchuje z registru a každé tvrzení jmenuje test, který ho dokazuje; scénář výše provedl příkazy. Nic v tomto řetězci není text o záměru.

  • majordomus contextCo potřebuje vědět další worker právě teď, v pořadí podle autority a v rámci rozpočtu.
  • majordomus doctorKontroluje jen governance: je samotný Majordomus zdravý a je každé vynucování, které deklaruje, tady skutečně zapojeno?

Přes MCP se ke stejné vrstvě dostanete přes majordomus_directories (povrch MCP).

Související případy užití

Vypočteno z toho, co sdílejí: tvrzení, pravidla, příkazy, kategorie, aplikace. Tento seznam nikdo neudržuje.

  • Dohledat změnu k dokumentům kontextu, kterých se týkáVypíše dokumenty kontextu s rozsahem, vyřeší, které se vztahují na cestu a proč, a zjistí, kterých dokumentů se změna dotýká, než přistane.
  • Řekněte jednou, k čemu vaše práce slouží, a nechte to říkat každý povrchZaznamenejte provozní způsob selhání jako jeden soubor a nechte na něj odpovídat příkazovou řádku, API, MCP i web, aniž by se kdekoli registroval.
  • Čtěte jen kontext, který se vejde do rozpočtu, a vězte, co se zahodiloSestavte kontext, který worker potřebuje právě teď, v pořadí autority, oříznuté na rozpočet řádků, a podívejte se na každou zahozenou sekci jmenovanou s důvodem.
  • Určit jako data, co patří do AI kontextuPřečtěte si deklarovanou politiku rozsahu repozitáře, zjistěte, které cesty jsou v indexu a které mimo něj, a nechte ji uplatňovat doctor a index znalostí místo pevně zadaného seznamu.
  • Pracovat na větvi v jediném worktree, kam patříZaložit větev bez volby cesty, najít z kteréhokoli checkoutu všechny checkouty repozitáře a přivést zbloudilý domů s nedotčenou necommitnutou prací.
