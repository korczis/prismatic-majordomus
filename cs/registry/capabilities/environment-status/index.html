environment.status

Jeden snímek tohoto checkoutu: identita projektu, identita repozitáře, správa verzí, deklarované toolchainy, co vrstva obsahuje spočítané podle druhu, workflow, která runner popisuje, projekce providerů vůči politice, která je vykresluje, a lokální služby s adresou, kterou zveřejnil běžící server. Každá hodnota nese, odkud pochází.

Schémata

Kanonický vstup a výstup z typů Rustu; schéma nástroje MCP a parametry a odpovědi OpenAPI se odvozují z nich.

input · EnvironmentInput

Co zahrnout do snapshotu.
vlastnosttyppovinnépopis
probe_services boolean ne Kontaktovat lokální adresu, kterou běžící server publikoval, a zjistit, zda odpovídá. Ve výchozím stavu vypnuto: obsluhovaný požadavek by neměl otevírat socket k jinému serveru jménem svého volajícího, a volající je obvykle ten server. výchozí false

output · RepositoryEnvironment

Snímek: čím tento checkout právě teď je.

Každý povrch, který cokoli z toho hlásí, vykresluje tuto hodnotu. Kolekce jsou v zdokumentovaném, stabilním pořadí — druhy a workflow podle jména, služby a poskytovatelé v pořadí, v jakém je deklaruje jejich kanonický zdroj, diagnostika v pořadí nalezení — takže dva snímky téhož repozitáře se serializují shodně až na RepositoryEnvironment::generated_at.

vlastnosttyppovinnépopis
diagnostika array ano Vše, co se pokazilo nebo stojí za zmínku, v pořadí, v jakém to bylo nalezeno.
generated_at string ano Kdy byl pořízen, RFC 3339 v UTC.
vrstva reference ano Co vrstva obsahuje.
projekt reference ano Co projekt je.
provenance array ano Odkud pochází každé pole.
providers array ano Projekce poskytovatelů, které politika deklaruje, v pořadí politiky.
reasoning jedno ze 2 ne Reasoning (ADR 0098): funkční bez ohledu na poradce, platný režim a kolik volitelných poradců lze oslovit. Chybí, když distribuce žádné nedeklaruje.
repozitář reference ano Čím checkout je.
rozlišení reference ano Jak úplně se vyřešilo.
schema string ano Smlouva, kterou se tento dokument řídí, majordomus/repository-environment/v1.
služby array ano Lokální služby v pořadí, v jakém je deklaruje tabulka služeb.
toolchainy array ano Toolchainy, které repozitář deklaruje, seřazené podle id.
vcs reference ano Co říká správa verzí.
workflow reference ano Pracovní postupy, které může člověk spustit.
