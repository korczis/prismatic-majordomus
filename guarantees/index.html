Guaranteed, advisory, planned

What Majordomus actually does today, row by row, with the file that implements it and the test that proves it.

A supervisory tool that overstates itself is the thing it was built to prevent. This page is generated from docs/CLAIMS.yaml; the build fails if any source, implementation or test path in it does not exist, or if a guaranteed claim names no test. A status is what the file declares; the recorded evidence column is what majordomus evidence show derives from the runs actually recorded, and only a supported verdict is coloured as one.
