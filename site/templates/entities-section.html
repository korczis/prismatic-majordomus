Where these come from

{{ meta.count }} objects of kind {{ kind }}, read from the repository's own layer. Nothing on this page is typed into the site: the source class that discovers the files is declared in the repository's knowledge sources, the executable indexes them, and this page, majordomus entity show {{ kind }}/<slug>, the MCP resource majordomus://{{ kind }}/<identity> and the Cockpit route /cockpit/objects/{{ kind }}/<slug> are all projections of that one index.

The references and backlinks each page shows are edges of one graph. A reference is declared in the front matter of the object that makes it; the backlink is that same edge read from the other end, so nothing declares a relationship twice and nothing can declare half of one.
