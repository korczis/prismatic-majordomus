# 05 — LIVE EXECUTION AND MESH SUPERVISION

Audit existing event stream (`/events` if still current), execution ledger, task/session records and mesh protocol. Reuse the actual event transport and persistence; SSE for one-way updates may be sufficient, with WebSocket only for truly bidirectional low-latency sessions. Do not deploy a second pub/sub fabric or clone runtime state into the browser.

Define/fix a typed event envelope with stable `event_id`, monotonic sequence in a stated scope, execution/job ID, actor/peer ID, object references, causation/correlation ID, UTC occurrence timestamp, schema version, event kind, payload, redaction and visibility. Determine whether durable append-only storage exists; if absent implement a minimal retained execution event log with explicit retention/recovery guarantees rather than promise impossible replay. Provide `snapshot + cursor + delta` or reliable resume semantics; handle duplicates, out-of-order delivery, missed cursors, retention gaps, heartbeat, server restart, client sleep and slow consumers. Show reconciliation errors, not silent data loss.

Task lifecycle must distinguish `proposed`, `queued`, `running`, `waiting_approval`, `blocked`, `cancelling`, `cancelled`, `failed`, `completed`, `verified` if these semantics map to existing canonical enums. Do not create conflicting status enums. Never compute '100%' from a number of log lines. Execution can be complete yet evidence unsatisfied.

Mesh view: derive peers, capabilities, topology, health, leases, last seen, assignments, active sessions, locks, scopes, in-flight tasks and logs. Nodes are clickable with identity, workload and supported actions. Interact through authorized capability invocation; preserve trace IDs back to original intent, issue and criterion. Stream bounded output with redaction. Include remote-peer disappearance, split-brain claims, duplicate delivery, task reassignment, worker timeouts and backpressure tests. No magical distributed exactly-once claims.

Add integration tests: two clients watching same execution; browser refresh; worker disappears; events delivered out of order; restart/reconnect; duplicate ack; stale peer; rapid state changes; permission change midstream; huge logs; secret-bearing output; event retention gap. A test must assert derived UI state eventually agrees with authoritative status via resnapshot. Expose live subscription health and diagnostics in UI/doctor.
