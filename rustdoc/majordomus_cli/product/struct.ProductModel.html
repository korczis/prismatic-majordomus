Struct ProductModel

pub struct ProductModel { /* private fields */ }
Expand description

The validated product model and every index derived from it. Immutable: built once from an index and a registry, read many times.

pub fn build( index: &Index, registry: &CapabilityRegistry, why: &Catalogue, web: &Topology, ) -> Self

Build the model from an index, the registry its module references resolve against, the catalogue whose moments it answers, and the topology whose surfaces it names. Deterministic: the same objects produce the same value, and no derivation reads a clock.

Source

pub fn module_area(&self, module: &str) -> Option<&str>

The area a capability module serves, or None for a module no feature with an area names.

Derived when the model is built, from the features that name the module, resolved by the areas’ own weight; the Cockpit’s sidebar groups by it. The derivation is private and this text does not link to it: rustdoc refuses a public link to a private item, and the public fact is the answer rather than the route to it.
