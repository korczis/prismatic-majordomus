1//! Evidence: what actually ran, against which commit, and whether it still proves anything.
2//!
3//! `docs/CLAIMS.yaml` binds a claim to a test with a **path**. A path is a declaration that
4//! a proof exists somewhere; it is not the proof. Until this module, a claim reading
5//!
6//! ```text
7//! status: guaranteed
8//! test:   test/cases/84_distribution_model.sh
9//! ```
10//!
11//! was rendered on the public site as a guarantee on the strength of that file existing.
12//! Nobody could answer, from the repository, whether the case had ever run, against which
13//! revision, with what result, or whether the result still applied. `scripts/generate-site-data
14//! --check` verified that the path resolves — which is a check that the *reference* is not
15//! broken, not that the *claim* is proven.
16//!
17//! # The model
18//!
19//! Three objects, and one derivation over them:
20//!
21//! * a [`TestId`] — the stable identity of a test, derived from the path a claim already
22//!   names, so nothing is entered by hand and no claim has to be migrated;
23//! * an [`Execution`] — one recorded run of one test: its outcome, its duration, the commit
24//!   it ran against, the digest of the test's own source at the time, when, by which runner
25//!   and from where;
26//! * a [`Ledger`] — the latest execution of every test, committed to the repository as
27//!   durable semantic evidence. Not logs: one line's worth of meaning per test.
28//!
29//! and [`report`], which joins the claims of the index with the ledger and decides, per
30//! claim, a [`ProofState`] that the surfaces render and the gate judges.
31//!
32//! # The lifecycle, end to end
33//!
34//! A claim's path becomes an identity, a run becomes an [`Execution`], the ledger keeps the
35//! latest one per test, and the digest is what notices that the test itself has moved since
36//! — without any commit having to change.
37//!
38//! ```
39//! use majordomus_cli::evidence::{digest_of, Execution, Ledger, Origin, Outcome, Runner, TestId};
40//!
41//! // the identity is derived from the path the claim already names; nothing is entered
42//! let id = TestId::of("test/cases/84_distribution_model.sh").unwrap();
43//! assert_eq!(id.as_string(), "suite:84_distribution_model");
44//! assert_eq!(id.reproduce(), "bash test/run.sh 84_distribution_model");
45//!
46//! let repo = tempfile::tempdir().unwrap();
47//! std::fs::create_dir_all(repo.path().join("test/cases")).unwrap();
48//! std::fs::write(repo.path().join(id.source()), "echo ok\n").unwrap();
49//!
50//! let run = Execution {
51//!     test: id.as_string(),
52//!     runner: Runner::Suite,
53//!     source: id.source(),
54//!     outcome: Outcome::parse("ok"),
55//!     seconds: 3,
56//!     commit: "0".repeat(40),
57//!     working_tree: "clean".into(),
58//!     digest: digest_of(b"echo ok\n"),
59//!     at: "2026-09-11T00:00:00Z".into(),
60//!     origin: Origin::Local,
61//!     command: id.reproduce(),
62//!     run: None,
63//! };
64//! assert!(run.outcome.proves());
65//!
66//! // the ledger is a tracked file, so the evidence survives the process that produced it
67//! let mut ledger = Ledger::empty();
68//! ledger.merge([run]);
69//! ledger.save(repo.path()).unwrap();
70//!
71//! let recorded = Ledger::load(repo.path()).unwrap();
72//! let latest = recorded.latest(&id.as_string()).unwrap();
73//! assert_eq!(latest.digest_matches(repo.path()), Some(true));
74//!
75//! // edit the case afterwards and the recorded run is no longer a run of the test that is
76//! // there now — which no diff against a commit would have shown, had the edit been reverted
77//! std::fs::write(repo.path().join(id.source()), "echo something else\n").unwrap();
78//! assert_eq!(latest.digest_matches(repo.path()), Some(false));
79//! ```
80//!
81//! # What "current" means here, exactly
82//!
83//! A passing run three commits ago is not automatically proof of the tree in front of you,
84//! and pretending otherwise is the failure this module exists to prevent. But declaring
85//! every result stale the instant anything anywhere changes is sound and useless — it
86//! would mean no claim is ever proven except in the seconds after a full run.
87//!
88//! So the derivation is conservative and says which of two things it found:
89//!
90//! * [`ProofState::Proven`] — the test passed, and the tree in front of you is byte for
91//!   byte the tree the run measured: the diff against the execution's own commit is empty.
92//!   The ledger's own row is excluded from that diff, because the evidence is about the
93//!   tree rather than part of what the tests measure — without that exclusion `proven`
94//!   would be unreachable by construction, since recording dirties the tree and committing
95//!   the record moves HEAD past the commit the record names.
96//! * [`ProofState::InputsUnchanged`] — the test passed, and **nothing the claim itself
97//!   names** (its source document, its implementation, its test) differs between the
98//!   recorded commit and the working tree. This is *not* proof at HEAD: something the claim
99//!   does not name may have broken it. It is the absence of any known invalidation, and it
100//!   is labelled as that everywhere it is shown.
101//! * [`ProofState::Stale`] — the test passed, and something the claim names has changed
102//!   since. The changed paths are named.
103//!
104//! The distinction is the point. A surface that collapsed the second into the first would
105//! be the green badge whose derivation cannot be inspected.
106//!
107//! # What this is not
108//!
109//! It is not tamper-proof, and it does not pretend to be. The ledger is a tracked file; a
110//! person can edit `"outcome": "pass"` into it, and the diff is what a reviewer sees. What
111//! the recorded digest *does* buy is staleness detection that survives a revert: an
112//! execution whose test source no longer hashes to the recorded digest did not run this
113//! test, whatever the commit says. Cryptographic ceremony against an attacker who can
114//! already commit to the repository would be ceremony with no threat model.
115//!
116//! It is also not the execution control plane. [`crate::execution`] is about capability
117//! executions of a running server — in-flight work, progress, events, gone with the
118//! process. This is about test runs, durable, committed and read long after the process
119//! that produced them exited. Two different subjects that share an English word.
120
121//! # Example
122//!
123//! The vocabulary, without a repository: a test is named by the path a claim writes down,
124//! a result word is a pass only when the runner said so, and the proof states rank.
125//!
126//! ```
127//! use majordomus_cli::evidence::{Outcome, ProofState, Runner, TestId};
128//!
129//! let t = TestId::of("test/cases/07_scope.sh").unwrap();
130//! assert_eq!(t.runner, Runner::Suite);
131//! assert_eq!(t.as_string(), "suite:07_scope");
132//! assert!(Outcome::parse("ok").proves());
133//! assert!(!Outcome::parse("FAIL").proves());
134//! assert!(ProofState::Proven < ProofState::Stale);
135//! ```

152/// Which runner produced a result, and therefore how the test is named and re-run.
153///
154/// The repository has exactly two that a claim may name today. A third would be a variant
155/// here and a branch in [`TestId::of`]; a claim naming something neither runner produces is
156/// reported as [`ProofState::Unrunnable`] rather than silently counted as covered.
157///
158/// ```
159/// use majordomus_cli::evidence::{Runner, TestId};
160///
161/// // which runner owns a test is read off where the test lives, never declared
162/// assert_eq!(TestId::of("test/cases/07_scope.sh").unwrap().runner, Runner::Suite);
163/// assert_eq!(
164///     TestId::of("apps/majordomus-cli/tests/why.rs").unwrap().runner,
165///     Runner::Crate
166/// );
167/// // and a path under neither directory belongs to no runner at all
168/// assert!(TestId::of("test/lib.sh").is_none());
169/// ```
170#[derive(
171    Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, JsonSchema,
172)]
173#[serde(rename_all = "snake_case")]
174#[schemars(rename = "EvidenceRunner")]
175/// # Example
176///
177/// ```
178/// use majordomus_cli::evidence::Runner;
179/// assert_eq!(Runner::Suite.prefix(), "suite");
180/// assert_eq!(Runner::Crate.prefix(), "crate");
181/// ```
182pub enum Runner {
183    /// A behavioural case under `test/cases/`, run by `test/run.sh`.
184    Suite,
185    /// An integration test binary under `apps/majordomus-cli/tests/`, run by `cargo test`.
186    Crate,
187}
188
189impl Runner {
190    /// The prefix this runner's test ids carry, and the half of [`TestId::as_string`] that
191    /// says which runner has to be asked for the proof again.
192    ///
193    /// The two are distinct words on purpose: a case and a test binary may share a name,
194    /// and a ledger keyed on the bare name would let one record overwrite the other's.
195    ///
196    /// ```
197    /// use majordomus_cli::evidence::Runner;
198    /// assert_eq!(Runner::Suite.prefix(), "suite");
199    /// assert_eq!(Runner::Crate.prefix(), "crate");
200    /// assert_ne!(Runner::Suite.prefix(), Runner::Crate.prefix());
201    /// ```
202    pub fn prefix(self) -> &'static str {
203        match self {
204            Runner::Suite => "suite",
205            Runner::Crate => "crate",
206        }
207    }
208}

210/// What a run said about one test.
211///
212/// `NotRun` is deliberately absent: it is the absence of an execution, not an outcome one
213/// had. Encoding it here would let a recorder write "this did not run" and have it counted
214/// among the things that did.
215///
216/// ```
217/// use majordomus_cli::evidence::Outcome;
218///
219/// assert!(Outcome::parse("ok").proves());
220/// assert!(!Outcome::parse("timeout").proves());
221/// // exactly one of the five is evidence of anything; the other four are reasons there
222/// // is none, kept apart because "it declined" and "the harness broke" are different bugs
223/// assert_eq!(Outcome::parse("skipped"), Outcome::Skip);
224/// assert_eq!(Outcome::parse("nonsense"), Outcome::Error);
225/// ```
226#[derive(
227    Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, JsonSchema,
228)]
229#[serde(rename_all = "snake_case")]
230#[schemars(rename = "EvidenceOutcome")]
231/// # Example
232///
233/// ```
234/// use majordomus_cli::evidence::Outcome;
235/// assert!(Outcome::parse("ok").proves());
236/// assert_eq!(Outcome::parse("wat"), Outcome::Error);
237/// ```
238pub enum Outcome {
239    /// It passed.
240    Pass,
241    /// It failed.
242    Fail,
243    /// It declined to run and said so (an unmet precondition the case reports itself).
244    Skip,
245    /// The bound fired before it finished.
246    Timeout,
247    /// The harness could not run it at all.
248    Error,
249}
250
251impl Outcome {
252    /// Did this run prove the behaviour it was about? Only a pass does.
253    ///
254    /// A skip is a test that declined, and a timeout or an error is a test whose verdict
255    /// nobody has; none of the three is a weaker kind of success, and every derivation in
256    /// this module asks this question rather than matching on the variants itself.
257    ///
258    /// ```
259    /// use majordomus_cli::evidence::Outcome;
260    /// assert!(Outcome::Pass.proves());
261    /// assert!(!Outcome::Skip.proves(), "a test that declined to run proved nothing");
262    /// assert!(!Outcome::Timeout.proves());
263    /// assert!(!Outcome::Error.proves());
264    /// ```
265    pub fn proves(self) -> bool {
266        matches!(self, Outcome::Pass)
267    }
268
269    /// The word the runner writes, read back. Anything unrecognised is [`Outcome::Error`]:
270    /// a result nobody can classify is not a pass.
271    ///
272    /// Case and surrounding space are the runner's business, not the ledger's, so both are
273    /// normalised away. The fallback is the whole point: a truncated line, a renamed status
274    /// word or a new runner's vocabulary fails loudly instead of widening into a green.
275    ///
276    /// ```
277    /// use majordomus_cli::evidence::Outcome;
278    /// assert_eq!(Outcome::parse("PASSED"), Outcome::Pass);
279    /// assert_eq!(Outcome::parse("  skip  "), Outcome::Skip);
280    /// // near-misses included: nothing here guesses at what was meant
281    /// assert_eq!(Outcome::parse("okay"), Outcome::Error);
282    /// assert!(!Outcome::parse("").proves());
283    /// ```
284    pub fn parse(word: &str) -> Outcome {
285        match word.trim().to_ascii_lowercase().as_str() {
286            "ok" | "pass" | "passed" => Outcome::Pass,
287            "fail" | "failed" => Outcome::Fail,
288            "skip" | "skipped" => Outcome::Skip,
289            "timeout" => Outcome::Timeout,
290            _ => Outcome::Error,
291        }
292    }
293}

295/// Where a run happened. The canonical model is provider-neutral: a CI adapter records
296/// `Ci`, and nothing here knows or cares which CI it was.
297///
298/// ```
299/// use majordomus_cli::evidence::Origin;
300///
301/// assert_eq!(Origin::parse("CI"), Some(Origin::Ci));
302/// assert_eq!(Origin::parse("local"), Some(Origin::Local));
303/// // naming the provider is the adapter's business; the ledger records the kind of run,
304/// // so a repository that changes CI does not change what its old evidence says
305/// assert!(Origin::parse("github-actions").is_none());
306/// ```
307#[derive(
308    Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, JsonSchema,
309)]
310#[serde(rename_all = "snake_case")]
311#[schemars(rename = "EvidenceOrigin")]
312/// # Example
313///
314/// ```
315/// use majordomus_cli::evidence::Origin;
316/// assert_eq!(Origin::parse("ci"), Some(Origin::Ci));
317/// assert_eq!(Origin::parse("nowhere"), None);
318/// ```
319pub enum Origin {
320    /// Someone ran it on their own machine.
321    Local,
322    /// A continuous-integration run.
323    Ci,
324    /// A release run.
325    Release,
326}
327
328impl Origin {
329    /// Read an origin from the word a recorder was given, or `None` when it names none of
330    /// the three.
331    ///
332    /// The asymmetry with [`Outcome::parse`] is deliberate. An unreadable outcome still has
333    /// to be recorded as something, and the safe something is an error; an unreadable origin
334    /// is a caller passing a word this model does not have, which is worth refusing at the
335    /// boundary rather than recording as a local run nobody made.
336    ///
337    /// ```
338    /// use majordomus_cli::evidence::Origin;
339    /// assert_eq!(Origin::parse(" Release "), Some(Origin::Release));
340    /// assert!(Origin::parse("laptop").is_none());
341    /// ```
342    pub fn parse(word: &str) -> Option<Origin> {
343        match word.trim().to_ascii_lowercase().as_str() {
344            "local" => Some(Origin::Local),
345            "ci" => Some(Origin::Ci),
346            "release" => Some(Origin::Release),
347            _ => None,
348        }
349    }
350}

352/// The stable identity of a test: the runner that owns it and the name that runner knows
353/// it by.
354///
355/// Derived from the path a claim already names, which is what makes the migration from
356/// `test: <path>` deterministic and empty of data entry. `test/cases/84_x.sh` is the case
357/// `test/run.sh` calls `84_x`; `apps/majordomus-cli/tests/why.rs` is the binary `cargo test
358/// --test why` runs. Both spellings already exist in the repository; this only names the
359/// join.
360///
361/// ```
362/// use majordomus_cli::evidence::{Runner, TestId};
363///
364/// let id = TestId::of("test/cases/07_scope.sh").unwrap();
365/// assert_eq!(id, TestId { runner: Runner::Suite, name: "07_scope".into() });
366///
367/// // the identity and the path are two spellings of one thing, so the derivation is
368/// // reversible and no claim in `docs/CLAIMS.yaml` has to be rewritten to carry an id
369/// assert_eq!(TestId::of(&id.source()).unwrap(), id);
370/// ```
371#[derive(Debug, Clone, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, JsonSchema)]
372#[schemars(rename = "EvidenceTestId")]
373/// # Example
374///
375/// ```
376/// use majordomus_cli::evidence::TestId;
377/// let t = TestId::of("apps/majordomus-cli/tests/product.rs").unwrap();
378/// assert_eq!(t.as_string(), "crate:product");
379/// assert_eq!(t.reproduce(), "cargo test --test product");
380/// assert!(TestId::of("lib/nothing.sh").is_none());
381/// ```
382pub struct TestId {
383    /// Which runner owns it.
384    pub runner: Runner,
385    /// The name that runner knows it by: a case's file stem, a test binary's file stem.
386    pub name: String,
387}
388
389impl TestId {
390    /// The canonical string form: `suite:84_distribution_model`, `crate:why`.
391    ///
392    /// This is the ledger's key. Every execution is stored and looked up under it, which is
393    /// why the runner is part of it rather than context a reader is expected to carry.
394    ///
395    /// ```
396    /// use majordomus_cli::evidence::TestId;
397    /// assert_eq!(
398    ///     TestId::of("test/cases/07_scope.sh").unwrap().as_string(),
399    ///     "suite:07_scope"
400    /// );
401    /// assert_eq!(
402    ///     TestId::of("apps/majordomus-cli/tests/why.rs").unwrap().as_string(),
403    ///     "crate:why"
404    /// );
405    /// ```
406    pub fn as_string(&self) -> String {
407        format!("{}:{}", self.runner.prefix(), self.name)
408    }
409
410    /// The test a path names, when a runner in this repository produces it.
411    ///
412    /// `None` is an answer, not a failure: a claim may name a file no runner drives (a
413    /// template, a fixture, a document), and the report says so rather than counting it.
414    ///
415    /// ```
416    /// use majordomus_cli::evidence::{Runner, TestId};
417    /// assert_eq!(
418    ///     TestId::of("test/cases/84_distribution_model.sh").unwrap().as_string(),
419    ///     "suite:84_distribution_model"
420    /// );
421    /// assert_eq!(TestId::of("apps/majordomus-cli/tests/why.rs").unwrap().runner, Runner::Crate);
422    /// assert!(TestId::of("share/install/install.sh.in").is_none());
423    /// assert!(TestId::of("-").is_none());
424    /// ```
425    pub fn of(path: &str) -> Option<TestId> {
426        let path = path.trim().trim_matches(|c| c == '\'' || c == '"');
427        if let Some(rest) = path.strip_prefix("test/cases/") {
428            return TestId::named(Runner::Suite, rest.strip_suffix(".sh")?);
429        }
430        if let Some(rest) = path.strip_prefix("apps/majordomus-cli/tests/") {
431            return TestId::named(Runner::Crate, rest.strip_suffix(".rs")?);
432        }
433        None
434    }
435
436    /// A test named directly, validated by the same rule [`TestId::of`] applies to a path.
437    ///
438    /// The identity form (`suite:84_x`) and the path form (`test/cases/84_x.sh`) name the
439    /// same thing, so they must agree about what a name may be. They did not: the path
440    /// form rejected a name containing a separator and the identity form did not, so
441    /// `suite:../../x` produced the source `test/cases/../../x.sh`. Two parsers for one
442    /// grammar is the one-way check this repository keeps finding; this is the grammar,
443    /// and both forms go through it.
444    ///
445    /// ```
446    /// use majordomus_cli::evidence::{Runner, TestId};
447    /// assert_eq!(TestId::named(Runner::Suite, "84_x").unwrap().as_string(), "suite:84_x");
448    /// assert!(TestId::named(Runner::Suite, "../../x").is_none(), "a name is not a path");
449    /// assert!(TestId::named(Runner::Suite, "").is_none());
450    /// assert!(TestId::named(Runner::Crate, "a/b").is_none());
451    /// assert!(TestId::named(Runner::Suite, ".hidden").is_none());
452    /// ```
453    pub fn named(runner: Runner, name: &str) -> Option<TestId> {
454        if name.is_empty() || name.contains('/') || name.contains('\\') || name.starts_with('.') {
455            return None;
456        }
457        Some(TestId {
458            runner,
459            name: name.to_string(),
460        })
461    }

463    /// The repository-relative path of the test's own source: the file that is hashed into
464    /// [`Execution::digest`], and one of the paths a claim's staleness is measured over.
465    ///
466    /// ```
467    /// use majordomus_cli::evidence::TestId;
468    /// let id = TestId::of("apps/majordomus-cli/tests/why.rs").unwrap();
469    /// assert_eq!(id.source(), "apps/majordomus-cli/tests/why.rs");
470    /// // a case's source is the file the runner executes, not the runner
471    /// assert_eq!(
472    ///     TestId::of("test/cases/07_scope.sh").unwrap().source(),
473    ///     "test/cases/07_scope.sh"
474    /// );
475    /// ```
476    pub fn source(&self) -> String {
477        match self.runner {
478            Runner::Suite => format!("test/cases/{}.sh", self.name),
479            Runner::Crate => format!("apps/majordomus-cli/tests/{}.rs", self.name),
480        }
481    }

483    /// The exact command that runs this one test, for a reader who wants the proof again
484    /// rather than the claim that it exists.
485    ///
486    /// One test, not the suite: a finding a reader can settle in seconds is settled, and
487    /// one that costs a full run is argued about instead.
488    ///
489    /// ```
490    /// use majordomus_cli::evidence::TestId;
491    /// assert_eq!(
492    ///     TestId::of("test/cases/84_distribution_model.sh").unwrap().reproduce(),
493    ///     "bash test/run.sh 84_distribution_model"
494    /// );
495    /// assert_eq!(
496    ///     TestId::of("apps/majordomus-cli/tests/why.rs").unwrap().reproduce(),
497    ///     "cargo test --test why"
498    /// );
499    /// ```
500    pub fn reproduce(&self) -> String {
501        match self.runner {
502            Runner::Suite => format!("bash test/run.sh {}", self.name),
503            Runner::Crate => format!("cargo test --test {}", self.name),
504        }
505    }
506}

508/// One recorded run of one test: the whole of what this repository durably remembers about
509/// it.
510///
511/// Every field is provenance. A result with no commit is an anonymous green, which is the
512/// thing a badge must never be derived from.
513///
514/// ```
515/// use majordomus_cli::evidence::{digest_of, Execution, Origin, Outcome, Runner, TestId};
516///
517/// let id = TestId::of("apps/majordomus-cli/tests/why.rs").unwrap();
518/// let run = Execution {
519///     test: id.as_string(),
520///     runner: Runner::Crate,
521///     source: id.source(),
522///     outcome: Outcome::Pass,
523///     seconds: 12,
524///     commit: "0".repeat(40),
525///     working_tree: "clean".into(),
526///     digest: digest_of(b"fn main() {}"),
527///     at: "2026-09-11T00:00:00Z".into(),
528///     origin: Origin::Ci,
529///     command: id.reproduce(),
530///     run: None,
531/// };
532///
533/// // it is a value in a tracked JSON file, so it has to survive the file unchanged
534/// let back: Execution = serde_json::from_str(&serde_json::to_string(&run).unwrap()).unwrap();
535/// assert_eq!(back, run);
536/// assert_eq!(back.test, "crate:why");
537/// assert_eq!(back.command, "cargo test --test why");
538/// ```
539#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
540#[schemars(rename = "EvidenceExecution")]
541/// # Example
542///
543/// One recorded run, with the provenance the runner did not carry: which commit, which
544/// tree state, the digest of the test's own source, when, and how to run it again.
545///
546/// ```
547/// use majordomus_cli::evidence::{Execution, Origin, Outcome, Runner};
548/// let e = Execution {
549///     test: "suite:07_scope".into(),
550///     runner: Runner::Suite,
551///     source: "test/cases/07_scope.sh".into(),
552///     outcome: Outcome::Pass,
553///     seconds: 3,
554///     commit: "a04b65c9".into(),
555///     working_tree: "clean".into(),
556///     digest: "sha256:00".into(),
557///     at: "2026-09-11T00:00:00Z".into(),
558///     origin: Origin::Local,
559///     command: "bash test/run.sh 07_scope".into(),
560///     run: None,
561/// };
562/// assert!(e.outcome.proves());
563/// ```
564pub struct Execution {
565    /// The test, in [`TestId::as_string`] form.
566    pub test: String,
567    /// Which runner produced it.
568    pub runner: Runner,
569    /// The test's own source, repository-relative.
570    pub source: String,
571    /// What it said.
572    pub outcome: Outcome,
573    /// How long it took, in whole seconds.
574    pub seconds: u64,
575    /// The full commit id the run was made against.
576    pub commit: String,
577    /// `clean`, `dirty` or `unknown`: whether the tree the run measured was the commit.
578    pub working_tree: String,
579    /// `sha256:<hex>` of the test's own source as it was when the run was recorded. An
580    /// execution whose test no longer hashes to this did not run the test that is there now.
581    pub digest: String,
582    /// When it was recorded, RFC 3339, UTC.
583    pub at: String,
584    /// Where the run happened.
585    pub origin: Origin,
586    /// The exact command that runs this one test again.
587    pub command: String,
588    #[serde(default, skip_serializing_if = "Option::is_none")]
589    /// The continuous-integration run the execution was recorded in, when it was recorded in
590    /// one that could name itself. Absent for a local run, and absent from every row recorded
591    /// before runs were named, which is why the ledger's version did not change.
592    pub run: Option<RunRef>,
593}

595/// The continuous-integration run an execution was recorded in: enough to navigate back to
596/// the run that produced it.
597///
598/// [`Origin`] says what kind of run it was and deliberately names no provider. This names the
599/// one run, in the words the provider addressed it with when it happened — its identifier,
600/// its attempt, the workflow and job, and the address a reader follows — because a link built
601/// later from a template would point wherever the template's idea of the provider had drifted
602/// to. Only an adapter constructs it; nothing in the model reads the provider's name.
603///
604/// ```
605/// use majordomus_cli::evidence::RunRef;
606///
607/// let actions = |k: &str| {
608///     let v = match k {
609///         "GITHUB_ACTIONS" => "true",
610///         "GITHUB_SERVER_URL" => "https://github.com",
611///         "GITHUB_REPOSITORY" => "owner/repo",
612///         "GITHUB_RUN_ID" => "42",
613///         "GITHUB_RUN_ATTEMPT" => "2",
614///         "GITHUB_WORKFLOW" => "validate",
615///         "GITHUB_JOB" => "evidence",
616///         _ => return None,
617///     };
618///     Some(v.to_string())
619/// };
620/// let run = RunRef::from_env(actions).unwrap();
621/// assert_eq!(run.id, "42");
622/// assert_eq!(run.attempt, 2);
623/// assert_eq!(run.url, "https://github.com/owner/repo/actions/runs/42/attempts/2");
624///
625/// // outside a run there is nothing to name, and a half-described run is not a run
626/// assert!(RunRef::from_env(|_| None).is_none());
627/// assert!(RunRef::from_env(|k| (k == "GITHUB_ACTIONS").then(|| "true".to_string())).is_none());
628/// ```
629#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
630#[schemars(rename = "EvidenceRun")]
631pub struct RunRef {
632    /// The provider that ran it, as the adapter that recorded it names it.
633    pub provider: String,
634    /// The provider's identifier of the run.
635    pub id: String,
636    /// Which attempt of the run, counted from 1.
637    pub attempt: u32,
638    /// The workflow the run belongs to.
639    pub workflow: String,
640    /// The job within the run that recorded the execution.
641    pub job: String,
642    /// Where a reader finds the run, as the provider addressed it at the time.
643    pub url: String,
644}
645
646impl RunRef {
647    /// The run described by a GitHub Actions environment, read through `var`, or `None` when
648    /// the environment is not one or leaves out any part a reader would need to find it.
649    ///
650    /// The variable reader is a parameter so the adapter can be exercised without mutating
651    /// the process environment, which other threads of a test binary share.
652    ///
653    /// ```
654    /// use majordomus_cli::evidence::RunRef;
655    /// assert!(RunRef::from_env(|k| (k == "GITHUB_RUN_ID").then(|| "1".to_string())).is_none());
656    /// ```
657    pub fn from_env(var: impl Fn(&str) -> Option<String>) -> Option<RunRef> {
658        if var("GITHUB_ACTIONS").as_deref() != Some("true") {
659            return None;
660        }
661        let server = var("GITHUB_SERVER_URL")?;
662        let repository = var("GITHUB_REPOSITORY")?;
663        let id = var("GITHUB_RUN_ID")?;
664        let attempt: u32 = var("GITHUB_RUN_ATTEMPT")
665            .and_then(|a| a.parse().ok())
666            .unwrap_or(1);
667        Some(RunRef {
668            provider: "github_actions".into(),
669            url: format!(
670                "{}/{repository}/actions/runs/{id}/attempts/{attempt}",
671                server.trim_end_matches('/')
672            ),
673            id,
674            attempt,
675            workflow: var("GITHUB_WORKFLOW")?,
676            job: var("GITHUB_JOB")?,
677        })
678    }
679}

689impl Execution {
690    /// Does the test's source still hash to what was recorded?
691    ///
692    /// `None` when the source is not there to hash — which is itself a finding, reported by
693    /// the path checks, not silently read as a match.
694    ///
695    /// This is the staleness check that survives a revert: an edit made and undone around a
696    /// run leaves no diff against any commit, and the recorded digest still says the test
697    /// that ran is not the test that is there.
698    ///
699    /// ```
700    /// use majordomus_cli::evidence::{digest_of, Execution, Origin, Outcome, Runner, TestId};
701    ///
702    /// let repo = tempfile::tempdir().unwrap();
703    /// let id = TestId::of("test/cases/07_scope.sh").unwrap();
704    /// std::fs::create_dir_all(repo.path().join("test/cases")).unwrap();
705    /// std::fs::write(repo.path().join(id.source()), "echo ok\n").unwrap();
706    ///
707    /// let run = Execution {
708    ///     test: id.as_string(),
709    ///     runner: Runner::Suite,
710    ///     source: id.source(),
711    ///     outcome: Outcome::Pass,
712    ///     seconds: 1,
713    ///     commit: "0".repeat(40),
714    ///     working_tree: "clean".into(),
715    ///     digest: digest_of(b"echo ok\n"),
716    ///     at: "2026-09-11T00:00:00Z".into(),
717    ///     origin: Origin::Local,
718    ///     command: id.reproduce(),
719    ///     run: None,
720    /// };
721    /// assert_eq!(run.digest_matches(repo.path()), Some(true));
722    ///
723    /// std::fs::write(repo.path().join(id.source()), "echo something else\n").unwrap();
724    /// assert_eq!(run.digest_matches(repo.path()), Some(false));
725    ///
726    /// // and a source that is gone cannot be compared, which is not the same as agreeing
727    /// std::fs::remove_file(repo.path().join(id.source())).unwrap();
728    /// assert_eq!(run.digest_matches(repo.path()), None);
729    /// ```
730    pub fn digest_matches(&self, root: &Path) -> Option<bool> {
731        let text = std::fs::read(root.join(&self.source)).ok()?;
732        Some(digest_of(&text) == self.digest)
733    }

736/// `sha256:<hex>` of some bytes, the one spelling used in the ledger.
737///
738/// The algorithm is named in the value rather than assumed by the reader, so a ledger
739/// written before a change of algorithm stays readable and says which one produced it.
740///
741/// ```
742/// use majordomus_cli::evidence::digest_of;
743///
744/// let d = digest_of(b"echo ok\n");
745/// assert!(d.starts_with("sha256:"), "{d}");
746/// assert_eq!(d.len(), "sha256:".len() + 64);
747/// assert_eq!(d, digest_of(b"echo ok\n"), "the same bytes hash the same");
748/// assert_ne!(d, digest_of(b"echo ok"), "a trailing newline is a different file");
749/// ```
750pub fn digest_of(bytes: &[u8]) -> String {
751    use sha2::{Digest, Sha256};
752    let mut h = Sha256::new();
753    h.update(bytes);
754    format!("sha256:{:x}", h.finalize())
755}

757/// What the repository can say about one claim's proof, right now.
758///
759/// Ordered from strongest to weakest, so a summary that sorts by this reads as a ranking.
760///
761/// ```
762/// use majordomus_cli::evidence::ProofState;
763///
764/// let mut states = vec![ProofState::NotRun, ProofState::Stale, ProofState::Proven];
765/// states.sort();
766/// assert_eq!(
767///     states,
768///     vec![ProofState::Proven, ProofState::Stale, ProofState::NotRun]
769/// );
770///
771/// // the two strongest are deliberately not one state: `inputs unchanged` is the absence
772/// // of a known invalidation, and collapsing it into `proven` is the unaccountable badge
773/// assert_ne!(ProofState::Proven, ProofState::InputsUnchanged);
774/// assert!(ProofState::Proven < ProofState::InputsUnchanged);
775/// assert!(ProofState::InputsUnchanged.passing());
776/// ```
777#[derive(
778    Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, JsonSchema,
779)]
780#[serde(rename_all = "snake_case")]
781/// # Example
782///
783/// ```
784/// use majordomus_cli::evidence::ProofState;
785/// assert!(ProofState::Proven.passing());
786/// assert!(!ProofState::NotRun.passing());
787/// assert!(!ProofState::InputsUnchanged.meaning().is_empty());
788/// ```
789pub enum ProofState {
790    /// A passing run, and nothing has changed since it — the diff against the execution's
791    /// own commit is empty but for the ledger. Proof of the tree in front of you.
792    Proven,
793    /// A passing run, and nothing this claim names has changed since. Not proof at HEAD:
794    /// something the claim does not name may have broken it.
795    InputsUnchanged,
796    /// A passing run, but something this claim names has changed since. The proof is older
797    /// than its subject.
798    Stale,
799    /// The latest run of this claim's test did not pass.
800    Failing,
801    /// The claim names a test a runner owns, and no run of it has ever been recorded.
802    NotRun,
803    /// The claim names a path no runner in this repository drives. Nothing can record it,
804    /// so nothing can prove it this way.
805    Unrunnable,
806    /// The claim names no test at all. Correct for a `planned` or `rejected` claim, and a
807    /// defect for any other.
808    NoTest,
809}
810
811impl ProofState {
812    /// The word every surface prints for this state, and the key the report's totals are
813    /// counted under.
814    ///
815    /// One spelling, defined here, so that the badge, the terminal rendering and the JSON
816    /// cannot disagree about what they are showing the same reader.
817    ///
818    /// ```
819    /// use majordomus_cli::evidence::ProofState;
820    /// assert_eq!(ProofState::Proven.label(), "proven");
821    /// assert_eq!(ProofState::InputsUnchanged.label(), "inputs unchanged");
822    /// assert_ne!(ProofState::Proven.label(), ProofState::InputsUnchanged.label());
823    /// ```
824    pub fn label(self) -> &'static str {
825        match self {
826            ProofState::Proven => "proven",
827            ProofState::InputsUnchanged => "inputs unchanged",
828            ProofState::Stale => "stale",
829            ProofState::Failing => "failing",
830            ProofState::NotRun => "not run",
831            ProofState::Unrunnable => "unrunnable",
832            ProofState::NoTest => "no test",
833        }
834    }
835
836    /// One sentence: what the state means, for the reader who clicked the badge. This is
837    /// the derivation, in words, and it lives here so that every surface says the same
838    /// thing rather than each inventing its own gloss.
839    ///
840    /// The sentence for [`ProofState::InputsUnchanged`] is the one that has to be carried
841    /// everywhere, because it is the state a surface is tempted to render as a plain green.
842    ///
843    /// ```
844    /// use majordomus_cli::evidence::ProofState;
845    ///
846    /// let m = ProofState::InputsUnchanged.meaning();
847    /// assert!(m.contains("not proof against the current commit"), "{m}");
848    /// assert_ne!(m, ProofState::Proven.meaning());
849    /// ```
850    pub fn meaning(self) -> &'static str {
851        match self {
852            ProofState::Proven => {
853                "A passing run, and nothing in the repository has changed since it — the tree \
854                 in front of you is the tree the run measured."
855            }
856            ProofState::InputsUnchanged => {
857                "A passing run, and nothing this claim names has changed since it. This is the \
858                 absence of a known invalidation, not proof against the current commit: a change \
859                 the claim does not name could have broken it."
860            }
861            ProofState::Stale => {
862                "A passing run, but a file this claim names has changed since. The proof is older \
863                 than what it is about."
864            }
865            ProofState::Failing => {
866                "The most recent recorded run of this claim's test did not pass."
867            }
868            ProofState::NotRun => {
869                "The claim names a test, and no run of that test has ever been recorded."
870            }
871            ProofState::Unrunnable => {
872                "The claim names a path that no runner in this repository drives, so no execution \
873                 of it can ever be recorded."
874            }
875            ProofState::NoTest => "The claim names no test.",
876        }
877    }
878
879    /// Does this state carry a passing execution behind it, of any freshness?
880    ///
881    /// Freshness and outcome are two questions, and this answers only the second. A count
882    /// of passing claims is honest; a count that called them all proven would not be.
883    ///
884    /// ```
885    /// use majordomus_cli::evidence::ProofState;
886    /// assert!(ProofState::Proven.passing());
887    /// assert!(ProofState::Stale.passing(), "a pass older than its subject is still a pass");
888    /// assert!(!ProofState::Failing.passing());
889    /// assert!(!ProofState::NotRun.passing());
890    /// assert!(!ProofState::Unrunnable.passing());
891    /// ```
892    pub fn passing(self) -> bool {
893        matches!(
894            self,
895            ProofState::Proven | ProofState::InputsUnchanged | ProofState::Stale
896        )
897    }
898}

900/// What a state may still be once the tree the run measured is taken into account.
901///
902/// `proven` is "a passing run recorded against this exact commit with a clean tree"
903/// (ADR 0041), and docs/EVIDENCE.md says why the tree is half of that: "A dirty tree is
904/// recorded as `dirty` for exactly this reason: it is the one case where the commit does
905/// not describe what ran." A run measured against a tree that was not its commit is
906/// therefore capped at `inputs_unchanged`: a pass, joined to a commit, with no claim that
907/// the commit is what it saw. A weaker state is never strengthened here, and `unknown` —
908/// git could not be asked — is treated as not clean, because not knowing is not proof.
909///
910/// ```
911/// use majordomus_cli::evidence::{capped_by_working_tree, ProofState};
912///
913/// // a clean tree changes nothing
914/// assert_eq!(
915///     capped_by_working_tree(ProofState::Proven, "clean"),
916///     ProofState::Proven
917/// );
918/// // a dirty one costs the strongest state, and only that one
919/// assert_eq!(
920///     capped_by_working_tree(ProofState::Proven, "dirty"),
921///     ProofState::InputsUnchanged
922/// );
923/// assert_eq!(
924///     capped_by_working_tree(ProofState::Proven, "unknown"),
925///     ProofState::InputsUnchanged
926/// );
927/// assert_eq!(
928///     capped_by_working_tree(ProofState::Stale, "dirty"),
929///     ProofState::Stale
930/// );
931/// ```
932pub fn capped_by_working_tree(state: ProofState, working_tree: &str) -> ProofState {
933    match (state, working_tree) {
934        (ProofState::Proven, t) if t != "clean" => ProofState::InputsUnchanged,
935        (s, _) => s,
936    }
937}

1108pub struct LedgerSummary {
1109    /// Where it lives, repository-relative.
1110    pub path: String,
1111    /// Whether the ledger holds at least one execution.
1112    ///
1113    /// Not whether the file exists. A ledger file holding nothing and no ledger file at
1114    /// all are the same answer to the only question a reader is asking — has anything
1115    /// been recorded — and both make every claim read `not_run`. [`Ledger::present`]
1116    /// answers the filesystem question, and nothing derives a proof state from it.

1119    pub executions: usize,
1120    /// The newest `at` in it, when it holds any.
1121    #[serde(skip_serializing_if = "Option::is_none")]
1122    pub newest: Option<String>,

1124    /// included, for the reason [`ClaimProof::changed`] is.
1125    pub commits: Vec<String>,
1126}

1128/// Whether the report could see its whole subject.
1129///
1130/// A verdict over a matrix the index silently shrank is the failure this repository met
1131/// four times in one day: an object is excluded, every projection of the smaller index is a
1132/// faithful projection, and each check prints a true statement about the half it can see.
1133/// A freshness check answers "was this generated from this tree" and cannot answer "did the
1134/// generator see everything in it", so the answer has to carry its own denominator.
1135///
1136/// ```
1137/// use majordomus_cli::evidence::Subject;
1138/// let whole = Subject { examined: 149, complete: true, excluded: vec![] };
1139/// assert!(whole.complete);
1140///
1141/// let partial = Subject {
1142///     examined: 148,
1143///     complete: false,
1144///     excluded: vec!["docs/CLAIMS.yaml: unknown_key".into()],
1145/// };
1146/// assert!(!partial.complete, "a shrunken index must not report a clean verdict");
1147/// ```
1148#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
1149#[schemars(rename = "EvidenceSubject")]
1150pub struct Subject {
1151    /// How many claims the index held, and this report therefore examined.
1152    pub examined: usize,
1153    /// Whether the index that produced them carried no error diagnostic. When this is
1154    /// false, every count and every absence below is about a smaller world than the
1155    /// repository, and no verdict over it means what it says.
1156    pub complete: bool,
1157    /// The diagnostics that excluded something, when any did: `<path>: <code>`.
1158    pub excluded: Vec<String>,
1159}

1161/// The whole joined picture: every claim of the matrix against every execution recorded.
1162///
1163/// What the capability answers, what the gate judges and what the site renders are this one
1164/// value; the totals and the findings are derived from the claims, never counted twice.
1165///
1166/// ```
1167/// use majordomus_cli::evidence::{EvidenceReport, Finding, Ledger, ProofState, Subject};
1168///
1169/// let mut report = EvidenceReport {
1170///     head: None,
1171///     working_tree: "unknown".into(),
1172///     ledger: Ledger::empty().summary(),
1173///     subject: Subject { examined: 0, complete: true, excluded: vec![] },
1174///     claims: vec![],
1175///     totals: Default::default(),
1176///     findings: vec![],
1177/// };
1178/// assert!(report.satisfied(), "nothing claimed, so nothing unsupported");
1179///
1180/// // and the same report over a subject it could not wholly read is not a pass
1181/// let mut partial = report.clone();
1182/// partial.subject.complete = false;
1183/// assert!(!partial.satisfied(), "an absent answer is not a clean one");
1184///
1185/// report.findings.push(Finding {
1186///     claim: "scope-integrity".into(),
1187///     status: "guaranteed".into(),
1188///     state: ProofState::Failing,
1189///     reason: "the claim guarantees a behaviour whose test most recently failed".into(),
1190///     reproduce: None,
1191/// });
1192/// // one unsupported guarantee is enough: the gate is not a proportion
1193/// assert!(!report.satisfied());
1194/// ```
1195#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
1196/// # Example
1197///
1198/// The whole matrix joined to the ledger. `satisfied` is true when no claim declares a
1199/// guarantee the recorded evidence does not support.
1200///
1201/// ```
1202/// use majordomus_cli::evidence::{report, EvidenceReport, Ledger};
1203/// use majordomus_cli::synthetic::SyntheticRepository;
1204/// let repo = SyntheticRepository::small().unwrap();
1205/// let ledger = Ledger::load(repo.root()).unwrap();
1206/// let r: EvidenceReport = report(&repo.index().unwrap(), &ledger);
1207/// assert!(r.satisfied(), "no claim, so no unsupported guarantee");
1208/// ```
1209pub struct EvidenceReport {
1210    /// The commit the report was derived against.
1211    #[serde(skip_serializing_if = "Option::is_none")]
1212    pub head: Option<String>,
1213    /// `clean`, `dirty` or `unknown`.
1214    pub working_tree: String,
1215    /// The ledger this was joined against.
1216    pub ledger: LedgerSummary,
1217    /// What the report could reach. Read this before reading the tallies: they are counts
1218    /// over the claims the index held, and an index that dropped a file holds fewer.
1219    pub subject: Subject,
1220    /// Every claim, in the matrix's own order.
1221    pub claims: Vec<ClaimProof>,
1222    /// How many claims are in each state.
1223    pub totals: BTreeMap<String, usize>,
1224    /// Claims whose declared status the evidence does not support.
1225    pub findings: Vec<Finding>,
1226}
1227
1228impl EvidenceReport {
1229    /// Does the evidence support every claim that declares a guarantee?
1230    ///
1231    /// False when the index was incomplete, whatever the findings say. An empty finding
1232    /// list over a matrix that lost entries is not a pass — it is the absence of an
1233    /// answer, and the two must never be spelled the same way.
1234    ///
1235    /// ```
1236    /// # use majordomus_cli::evidence::{EvidenceReport, LedgerSummary, Subject};
1237    /// # use std::collections::BTreeMap;
1238    /// let mut r = EvidenceReport {
1239    ///     head: None,
1240    ///     working_tree: "clean".into(),
1241    ///     ledger: LedgerSummary {
1242    ///         path: ".ai/repo/evidence/ledger.json".into(),
1243    ///         present: false,
1244    ///         executions: 0,
1245    ///         newest: None,
1246    ///         commits: vec![],
1247    ///     },
1248    ///     subject: Subject { examined: 0, complete: true, excluded: vec![] },
1249    ///     claims: vec![],
1250    ///     totals: BTreeMap::new(),
1251    ///     findings: vec![],
1252    /// };
1253    /// assert!(r.satisfied(), "no findings over a whole subject is a pass");
1254    ///
1255    /// r.subject.complete = false;
1256    /// assert!(!r.satisfied(), "no findings over a partial subject is not a pass");
1257    /// ```
1258    pub fn satisfied(&self) -> bool {
1259        self.subject.complete && self.findings.is_empty()
1260    }
1261}

1275/// Read one metadata field, treating the matrix's `'-'` placeholder as absence — which is
1276/// what it means, and what every reader of this file has to agree on.
1277fn field(meta: &Value, key: &str) -> Option<String> {
1278    let v = meta.get(key)?.as_str()?.trim().trim_matches('\'');
1279    if v.is_empty() || v == "-" {
1280        None
1281    } else {
1282        Some(v.to_string())
1283    }
1284}

1286/// Every claim the index holds, in the order the index holds them, which is the matrix's.
1287fn claims_of(index: &Index) -> Vec<IndexedClaim> {
1288    index
1289        .objects
1290        .iter()
1291        .filter(|o| o.kind == "claim")
1292        .map(|o| IndexedClaim {
1293            id: o.identity.clone(),
1294            claim: field(&o.metadata, "claim")
1295                .or_else(|| o.title.clone())
1296                .unwrap_or_else(|| o.identity.clone()),
1297            status: field(&o.metadata, "status").unwrap_or_else(|| "unknown".into()),
1298            source: field(&o.metadata, "source"),
1299            implementation: field(&o.metadata, "implementation"),
1300            test: field(&o.metadata, "test"),
1301        })
1302        .collect()
1303}

1305/// Every path that differs between `commit` and the working tree — committed since, staged,
1306/// or merely edited. One subprocess per distinct commit in the ledger, which in practice is
1307/// one.
1308///
1309/// `None` when git could not answer, which the caller must not read as "nothing changed":
1310/// an unanswerable comparison is why [`ProofState`] has to be able to say it does not know.
1311///
1312/// Shared with the preflight (`environment::preflight`), whose verdict about recorded test
1313/// runs must mean what `proven` means here and nothing looser.
1314pub(crate) fn changed_since(root: &Path, commit: &str) -> Option<BTreeSet<String>> {
1315    let git = |args: &[&str]| -> Option<Vec<String>> {
1316        let out = crate::git::read_only(root).args(args).output().ok()?;
1317        if !out.status.success() {
1318            return None;
1319        }
1320        Some(
1321            String::from_utf8_lossy(&out.stdout)
1322                .lines()
1323                .map(|l| l.trim().to_string())
1324                .filter(|l| !l.is_empty())
1325                .collect(),
1326        )
1327    };
1328    // Tracked differences, and then the files that are there but git is not tracking.
1329    // `git diff` never lists an untracked file, so a tree whose only difference from the
1330    // recorded commit is a new source file would compare equal — and `proven` would say
1331    // "the tree in front of you is the tree the run measured" about a tree carrying code
1332    // the run never saw. Ignored files stay ignored: `--exclude-standard` is what makes
1333    // this the set a person would call "new here" rather than every build artifact.
1334    let mut changed: BTreeSet<String> = git(&["diff", "--name-only", commit, "--"])?
1335        .into_iter()
1336        .collect();
1337    changed.extend(git(&["ls-files", "--others", "--exclude-standard"])?);
1338    Some(changed)
1339}

1341/// Join the claims of the index with the executions of the ledger and decide, per claim,
1342/// what the repository can honestly say.
1343///
1344/// The git comparison is done once per distinct recorded commit and shared by every claim
1345/// that recorded against it.
1346///
1347/// Claims come from the index and nothing else; executions come from the ledger and nothing
1348/// else. A claim the ledger has never heard of is [`ProofState::NotRun`], and if it declares
1349/// a guarantee, that is a finding — the file existing was never the proof.
1350///
1351/// ```
1352/// use majordomus_cli::evidence::{self, Ledger, ProofState};
1353/// use majordomus_cli::git::GitState;
1354/// use majordomus_cli::index::{Index, RepositoryInfo, State};
1355/// use majordomus_cli::{Object, Provenance};
1356///
1357/// let repo = tempfile::tempdir().unwrap();
1358/// let claim = Object {
1359///     kind: "claim".into(),
1360///     identity: "scope-integrity".into(),
1361///     uri: "majordomus://claim/scope-integrity".into(),
1362///     title: None,
1363///     description: None,
1364///     metadata: serde_json::json!({
1365///         "claim": "a commit outside the task's scope is refused",
1366///         "status": "guaranteed",
1367///         "source": "docs/SCOPE.md",
1368///         "test": "test/cases/07_scope.sh",
1369///     }),
1370///     body: String::new(),
1371///     content: String::new(),
1372///     media_type: "application/yaml",
1373///     provenance: Provenance {
1374///         path: "docs/CLAIMS.yaml".into(),
1375///         directory: "docs".into(),
1376///         source_class: "claim".into(),
1377///         section: None,
1378///         bytes: 0,
1379///         member: Some("claims.0".into()),
1380///     },
1381/// };
1382/// let index = Index {
1383///     repository: RepositoryInfo {
1384///         root: repo.path().display().to_string(),
1385///         layer_schema: "ai-repository/v1".into(),
1386///         sections: Default::default(),
1387///         git: GitState::Unavailable { reason: "doc".into() },
1388///         discovery: "filesystem".into(),
1389///         source_classes: vec![],
1390///         kind_sources: vec![],
1391///         scope_origin: majordomus_cli::scope::Origin::Distribution,
1392///         scope_path: String::new(),
1393///     },
1394///     objects: vec![claim],
1395///     diagnostics: vec![],
1396///     state: State::Ok,
1397///     fingerprint: String::new(),
1398///     scoped: Default::default(),
1399///     distribution: None,
1400///     providers: Default::default(),
1401///     share: None,
1402/// };
1403///
1404/// let report = evidence::report(&index, &Ledger::empty());
1405/// let proof = &report.claims[0];
1406/// assert_eq!(proof.test.as_deref(), Some("suite:07_scope"), "the id came from the path");
1407/// assert_eq!(proof.state, ProofState::NotRun);
1408/// assert_eq!(report.totals.get("not run"), Some(&1));
1409///
1410/// // a guarantee with nothing recorded behind it is a finding, and the reader is told
1411/// // exactly what would settle it
1412/// assert!(!report.satisfied());
1413/// assert_eq!(report.findings[0].claim, "scope-integrity");
1414/// assert_eq!(
1415///     report.findings[0].reproduce.as_deref(),
1416///     Some("bash test/run.sh 07_scope")
1417/// );
1418/// ```
1419pub fn report(index: &Index, ledger: &Ledger) -> EvidenceReport {
1420    let root = PathBuf::from(&index.repository.root);
1421    let git = crate::git::inspect(&root);
1422    // Reported so a reader knows what the report was derived against; the proof states
1423    // are decided by the diff against each execution's own commit, never by HEAD.
1424    let (head, working_tree) = match &git {
1425        crate::git::GitState::Available(i) => (i.head.clone(), i.working_tree.clone()),
1426        crate::git::GitState::Unavailable { .. } => (None, "unknown".to_string()),
1427    };
1428
1429    // one comparison per commit the ledger names, not one per claim
1430    let mut diffs: BTreeMap<String, Option<BTreeSet<String>>> = BTreeMap::new();
1431    for e in &ledger.executions {
1432        diffs
1433            .entry(e.commit.clone())
1434            .or_insert_with(|| changed_since(&root, &e.commit));
1435    }
1436
1437    let mut claims = Vec::new();
1438    let mut totals: BTreeMap<String, usize> = BTreeMap::new();
1439    let mut findings = Vec::new();
1440
1441    for c in claims_of(index) {
1442        let test_id = c.test.as_deref().and_then(TestId::of);
1443        let execution = test_id
1444            .as_ref()
1445            .and_then(|t| ledger.latest(&t.as_string()))
1446            .cloned();
1447
1448        let (state, changed) = match (&c.test, &test_id, &execution) {
1449            (None, _, _) => (ProofState::NoTest, Vec::new()),
1450            (Some(_), None, _) => (ProofState::Unrunnable, Vec::new()),
1451            (Some(_), Some(_), None) => (ProofState::NotRun, Vec::new()),
1452            (Some(_), Some(t), Some(e)) => {
1453                if !e.outcome.proves() {
1454                    (ProofState::Failing, Vec::new())
1455                } else {
1456                    // what this claim names, and nothing else: the derivation is explicit
1457                    // about its own reach, and a surface can repeat it
1458                    let inputs: Vec<String> =
1459                        [c.source.clone(), c.implementation.clone(), Some(t.source())]
1460                            .into_iter()
1461                            .flatten()
1462                            .collect();
1463                    match diffs.get(&e.commit).and_then(|d| d.as_ref()) {
1464                        // git could not compare: not knowing is not proof
1465                        None => (ProofState::Stale, Vec::new()),
1466                        Some(d) => {
1467                            // The ledger is evidence *about* the tree, not part of what the
1468                            // tests measure, so its own row does not age the proof it
1469                            // records. Without this exclusion `proven` is unreachable by
1470                            // construction: recording dirties the tree, and committing the
1471                            // record moves HEAD past the commit the record names.
1472                            let changed_at_all: Vec<&String> =
1473                                d.iter().filter(|p| p.as_str() != LEDGER_PATH).collect();
1474                            let changed: Vec<String> =
1475                                inputs.iter().filter(|p| d.contains(*p)).cloned().collect();
1476                            // A test whose source no longer hashes to what ran did not run
1477                            // in the form it is in now, whatever the diff says — an edit
1478                            // made and reverted around the run leaves no diff and is still
1479                            // not the thing that was measured.
1480                            let test_moved = e.digest_matches(&root) == Some(false);
1481                            if test_moved && changed.is_empty() {
1482                                (ProofState::Stale, vec![t.source()])
1483                            } else if !changed.is_empty() {
1484                                (ProofState::Stale, changed)
1485                            } else if changed_at_all.is_empty() {
1486                                // The diff says the commit is the tree in front of us; the
1487                                // execution's own `working_tree` says whether that commit
1488                                // was the tree the run measured. Both, or it is not proven.
1489                                (
1490                                    capped_by_working_tree(ProofState::Proven, &e.working_tree),
1491                                    Vec::new(),
1492                                )
1493                            } else {
1494                                (ProofState::InputsUnchanged, Vec::new())
1495                            }
1496                        }
1497                    }
1498                }
1499            }
1500        };
1501
1502        *totals.entry(state.label().to_string()).or_insert(0) += 1;
1503
1504        if let Some(reason) = unsupported(&c.status, state) {
1505            findings.push(Finding {
1506                claim: c.id.clone(),
1507                status: c.status.clone(),
1508                state,
1509                reason,
1510                reproduce: test_id.as_ref().map(TestId::reproduce),
1511            });
1512        }
1513
1514        claims.push(ClaimProof {
1515            id: c.id,
1516            claim: c.claim,
1517            status: c.status,
1518            source: c.source,
1519            implementation: c.implementation,
1520            test_path: c.test,
1521            test: test_id.as_ref().map(TestId::as_string),
1522            state,
1523            meaning: state.meaning().to_string(),
1524            execution,
1525            changed,
1526            reproduce: test_id.as_ref().map(TestId::reproduce),
1527        });
1528    }
1529
1530    // What the index could not read is what this report cannot be a verdict over. An
1531    // excluded file takes its objects out of the index, and every count below is then a
1532    // count over what survived.
1533    let excluded: Vec<String> = index
1534        .diagnostics
1535        .iter()
1536        .filter(|d| d.severity == crate::Severity::Error)
1537        .map(|d| match &d.path {
1538            Some(p) => format!("{p}: {}", d.code),
1539            None => d.code.clone(),
1540        })
1541        .collect();
1542    let subject = Subject {
1543        examined: claims.len(),
1544        complete: excluded.is_empty(),
1545        excluded,
1546    };
1547
1548    EvidenceReport {
1549        head,
1550        working_tree,
1551        ledger: ledger.summary(),
1552        subject,
1553        claims,
1554        totals,
1555        findings,
1556    }
1557}

1559/// Does a claim's declared status survive the evidence found for it? `Some(reason)` when it
1560/// does not.
1561///
1562/// Only `guaranteed` is judged. `advisory` states that enforcement is not observable from
1563/// outside, `planned` states that nothing implements it and `rejected` that nothing will;
1564/// demanding a current proof of those would be demanding proof of a thing the claim already
1565/// says is not there.
1566///
1567/// Three states pass and three do not, and [`ProofState::Stale`] is the line between them.
1568/// A stale run is a pass — [`ProofState::passing`] says so, and the summary keeps it apart
1569/// from a failure for good reason — but it is a pass of a subject that has since moved: the
1570/// claim's own implementation or its test changed after the run offered as its proof.
1571/// Accepting it here made the gate accept, as support for a guarantee, a measurement of
1572/// something else. What is left is [`ProofState::InputsUnchanged`], weaker than `proven`
1573/// but at least a pass of *this* subject, and that is the floor.
1574fn unsupported(status: &str, state: ProofState) -> Option<String> {
1575    if status != "guaranteed" {
1576        return None;
1577    }
1578    match state {
1579        ProofState::Proven | ProofState::InputsUnchanged => None,
1580        ProofState::Stale => Some(
1581            "the claim guarantees a behaviour whose only recorded run is older than what it is \
1582             about: the implementation or the test changed after that run, so the pass measured \
1583             a subject this claim no longer names"
1584                .into(),
1585        ),
1586        ProofState::Failing => {
1587            Some("the claim guarantees a behaviour whose test most recently failed".into())
1588        }
1589        ProofState::NotRun => Some(
1590            "the claim guarantees a behaviour and names a test, and no run of that test has ever \
1591             been recorded"
1592                .into(),
1593        ),
1594        ProofState::Unrunnable => Some(
1595            "the claim guarantees a behaviour and names a path no runner drives, so no execution \
1596             of it can be recorded"
1597                .into(),
1598        ),
1599        ProofState::NoTest => {
1600            Some("the claim guarantees a behaviour and names no test at all".into())
1601        }
1602    }
1603}

1745    /// `proven` is a passing run recorded against this exact commit *with a clean tree*
1746    /// (ADR 0041). The tree the run measured is recorded per execution, so a run made on a

1750    fn a_run_recorded_on_a_dirty_tree_is_never_proven() {

1753            capped_by_working_tree(ProofState::Proven, "clean"),
1754            ProofState::Proven
1755        );
1756        // negative: the commit did not describe what ran, so it is not proof of the commit
1757        for tree in ["dirty", "unknown", ""] {

1768            ProofState::Failing,
1769            ProofState::NotRun,
1770            ProofState::Unrunnable,
1771            ProofState::NoTest,
