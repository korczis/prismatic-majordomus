Coordination

Every worker declares the paths it will touch, sees who else is working and where, and hears about a collision before it is committed.

The failure it answers

Agents collide. Parallel workers edit the same paths, or build the same thing twice, without knowing about each other.

Several workers on one repository at once: the scope a task claims, the board every attached session announces itself on, the worktree each branch lives in, the plan whose status is derived rather than stored, the machines that share one repository, and the models and advisors a worker is routed to. A claim is information and a collision is reported; what refuses a change is the task's own scope, at check and at finish.

Not in this domain: what the work must satisfy, which is governance; and when it counts as finished, which is completion.

Each feature names this domain in its own file; the domain lists none of them. A feature added with this domain is on this page at the next build, and one removed is gone.

The failure modes its features answer

Operational moments from the Why catalogue that name a rule, a command, a capability or a claim of a feature in this domain. Nothing here was assigned.

  • →re-explained the same context to a brand-new session
  • →found two agents fixing the same bug in two branches
  • →watched the strongest model, at maximum effort, rename a variable
  • →accepted "done" because the model said so, and paid for it the next morning
  • →found a task "in progress" that nobody had touched for three weeks
  • →read three roadmaps for one project and believed none of them
Every failure mode it answers (17)
  • One worker undoing another worker's change
  • A worktree nobody can decide to delete
  • Finished work that never reached the trunk
  • Two sessions in one checkout, standing on each other
  • A change that no plan ever asked for
  • The issue says done and the repository disagrees
  • Nobody can reconstruct where the milestone actually is
  • A cheap worker deciding something expensive
  • Nobody can say why that worker was chosen
  • Spend that cannot be tied to anything accepted
  • A result nobody can reproduce, including its author
