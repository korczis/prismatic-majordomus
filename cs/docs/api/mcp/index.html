HTTP API: mcp

MCP projekce tohoto registru popsaná jako jedna typovaná hodnota: kdo odpovídá na `initialize` a s jakými verzemi protokolu, transporty a kolik relací každý drží, co z protokolu se poskytuje a co ne, každý nástroj s efektem a nápovědami, z nichž se odvozují jeho anotace, nástroje, které zapisují do repozitáře, zdroje a stav konfigurace každého deklarovaného klienta v tomto repozitáři. Nic z toho není vlastní seznam: nástroje jsou z registru, efekt je klasifikace schopnosti, klienti jsou provideři distribuce.

mcp

MCP projekce tohoto registru popsaná jako jedna typovaná hodnota: kdo odpovídá na `initialize` a s jakými verzemi protokolu, transporty a kolik relací každý drží, co z protokolu se poskytuje a co ne, každý nástroj s efektem a nápovědami, z nichž se odvozují jeho anotace, nástroje, které zapisují do repozitáře, zdroje a stav konfigurace každého deklarovaného klienta v tomto repozitáři. GET /api/v1/mcp mcp.projection

Projekce MCP tohoto registru

Kdo odpovídá na `initialize` a s jakými verzemi protokolu; transporty a relace připojené přes každý; obsluhované metody a to, že prompty a notifikace ne; každý nástroj (nebo jen ty s jedním efektem) s jeho schopností, efektem a nápovědami, z nichž se odvozují jeho anotace; nástroje, které zapisují do repozitáře; zdroje; a zda každý klient, kterého distribuce deklaruje, má zde konfiguraci, která spouští server tohoto repozitáře. Čte registr a jeden soubor na deklarovaného klienta; nic nezapisuje.

  • query
  • experimentální
  • vyžaduje se měření výkonu
  • cache vypnuta
  • Nástroj MCP majordomus_mcp
  • Zdroj MCP {"name": "mcp", "uri": "majordomus://mcp"}

Parametry dotazu

názevtyppovinnépopispříklady
účinek ExecutionEffect | null ne Vypíše jen nástroje s tímto efektem: `read`, `process_state` nebo `repository_mutation`. Když chybí, vypíše každý nástroj. writers: "repository_mutation"

Vyzkoušejte

Port je ten, který server zalogoval; 8741 je ten, o který žádá jako první. Hodnoty jsou první příklad operace.

curl -s "http://127.0.0.1:8741/api/v1/mcp?effect=repository_mutation"

Testováno v apps/majordomus-cli/tests/http_serve.rs, který přehrává routu s těmito hodnotami proti serveru na skutečném socketu.

Schémata

Komponenty, které používají jen operace tohoto tagu. Každý řádek je pole daného typu, jeho doc komentář je popis; typ vlastněný jinou stránkou na ni odkazuje.

ExecutionHints

object
Co smí volající o volání předpokládat před jeho provedením: čtyři fakta, která MCP nazývá anotacemi nástroje, držená jednou na modelu, aby je žádná projekce neuváděla zvlášť.

Klasifikováno pomocí ExecutionPolicy::hints, nikdy deklarováno.

use majordomus_cli::capability::{CapabilityKind, ExecutionPolicy, Hints};
let read: Hints = ExecutionPolicy::classify(CapabilityKind::Query).hints();
assert_eq!(
    serde_json::to_value(read).unwrap(),
    serde_json::json!({ "read_only": true, "destructive": false, "idempotent": true, "open_world": false })
);
vlastnosttyppovinnépopis
read_only boolean ano
Volání nic nemění, nikde.
destruktivní boolean ano
Volání může přepsat nebo odstranit něco, co přežije tento proces.
idempotentní boolean ano
Druhé shodné volání nezmění nic, co nezměnilo první.
open_world boolean ano
Volání sahá za tento stroj. Žádný handler tohoto spustitelného souboru to nedělá: pozorování forge a rozhovor s advisorem jsou příkazy, které spouští člověk, ne schopnosti.

Používá McpProjection

McpClientStanding

"wired" | "foreign" | "absent"
Jak je na tom konfigurace klienta vázaná na projekt v tomto repozitáři.

use majordomus_cli::capability::builtin::mcp::McpClientStanding;
// the words a caller reads, as they are written on every surface
assert_eq!(serde_json::to_value(McpClientStanding::Wired).unwrap(), "wired");
assert_eq!(serde_json::to_value(McpClientStanding::Foreign).unwrap(), "foreign");
assert_eq!(serde_json::to_value(McpClientStanding::Absent).unwrap(), "absent");
  • wiredSoubor existuje a jmenuje launcher: tento klient spouští server tohoto repozitáře.
  • foreignSoubor existuje a nejmenuje launcher: klient ho přečte a spustí něco jiného, nebo nic.
  • absentSoubor neexistuje: tento klient zde nespustí žádný server, dokud nebude zapsán.

use majordomus_cli::capability::builtin::mcp::McpProjection;
let p: McpProjection = serde_json::from_value(serde_json::json!({
    "server": { "name": "majordomus", "title": "Majordomus", "version": "0.14.0" },
    "protocol_versions": ["2025-06-18"],
    "transports": [{ "id": "stdio", "reached_by": "majordomus mcp", "attached": 0 }],
    "serving": { "methods": ["initialize"], "tools": true, "resources": true, "prompts": false, "notifications": false },
    "tool_count": 2,
    "tools": [],
    "effects": [{ "effect": "read", "tools": 1 }, { "effect": "repository_mutation", "tools": 1 }],
    "writers": ["majordomus_plan_transition"],
    "resources": { "builtin": 1, "objects": 0, "template": "majordomus://<kind>/<identity>" },
    "launcher_in_repository": false,
    "clients": [],
    "findings": [],
})).unwrap();
// the count is of every tool, whatever the `effect` filter narrowed `tools` to
