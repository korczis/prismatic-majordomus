an-inference-names-its-source-and-budget — Every inference a decision rests on names its model and source, stays inside a declared budget, counts independent sources rather than answers, and is never reached from a hook path

Each consultation is attributable, and independence is counted by a defined source. Peer critique reviews the evidence. A spent budget decides locally and says so, and consultation usage is economics data with its class. The pack's routing levels are documented as the existing plan outcomes. Hook closures are checked to reach no model. Reuse holds only while its evidence holds, and a poisoned answer stays data.

Problem

majordomus reasoning plans, consults, records and settles disagreement by experiment, but six gaps remain. A consultation records no model (apps/majordomus-cli/src/reasoning/record.rs:414-460). Selection counts one adapter as one source (policy.rs:355-358) while the conclusion counts distinct advisor ids (store.rs:789-793), so two peers through the one mesh-review adapter count as two independent reviews. A mesh peer is asked a subject line without the evidence (scripts/lib/advisors/mesh-review.mjs:31-35). Reuse has no validity window (store.rs:446-497). The only budget is an advisor count (policy.rs:341), and advisor usage never reaches economics. Nothing refuses a hook path that reaches a model.

Outcome

Each consultation is attributable, and independence is counted by a defined source. Peer critique reviews the evidence. A spent budget decides locally and says so, and consultation usage is economics data with its class. The pack's routing levels are documented as the existing plan outcomes. Hook closures are checked to reach no model. Reuse holds only while its evidence holds, and a poisoned answer stays data.

Current state

Verified by code and tests: six reasoning capabilities (capability/builtin/reasoning.rs:563-668); zero advisors in CI; offline and local fallback; circuit breaker, timeout and rate limit; disagreement settled by evidence (cases 730-736). Also verified: mesh trust, partition conflict, reconnect and expiry (mesh_cooperation.rs:474,494,716; mesh/state.rs:962).
