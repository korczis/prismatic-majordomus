A second install changes nothing; mesh hub status says whether the unit is written as rendered, loaded, running and answering, and how many runtimes the hub is linked with; mesh hub uninstall stops it and removes the unit. The hub started that way registers with every declared hub and keeps its links across restarts on its own.
