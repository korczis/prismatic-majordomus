The test report: the suite’s own results, rendered.

The evidence is what the runs already write — test/run.sh’s TSV report for the behavioural cases and cargo test’s summary lines for the crate — and this module parses, joins and renders it. It decides nothing about what passed: a case that failed is a case the runner said failed, and a report that disagreed with the runner would be worse than no report.
