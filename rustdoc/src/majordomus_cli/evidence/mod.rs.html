1//! Evidence: what actually ran, against which commit, and whether it still proves anything.
2//!
3//! `docs/CLAIMS.yaml` binds a claim to a test with a **path**. A path is a declaration that
4//! a proof exists somewhere; it is not the proof. Until this module, a claim reading
5//!
6//! ```text
7//! status: guaranteed
8//! test:   test/cases/84_distribution_model.sh
9//! ```
10//!
11//! was rendered on the public site as a guarantee on the strength of that file existing.
12//! Nobody could answer, from the repository, whether the case had ever run, against which
13//! revision, with what result, or whether the result still applied. `scripts/generate-site-data
14//! --check` verified that the path resolves — which is a check that the *reference* is not
15//! broken, not that the *claim* is proven.
16//!
17//! # The model
18//!
19//! Three objects, and one derivation over them:
20//!
21//! * a [`TestId`] — the stable identity of a test, derived from the path a claim already
22//!   names, so nothing is entered by hand and no claim has to be migrated;
23//! * an [`Execution`] — one recorded run of one test: its outcome, its duration, the commit
24//!   it ran against, the digest of the test's own source at the time, when, by which runner
25//!   and from where;
26//! * a [`Ledger`] — the latest execution of every test, committed to the repository as
27//!   durable semantic evidence. Not logs: one line's worth of meaning per test.
28//!
29//! and [`report`], which joins the claims of the index with the ledger and decides, per
30//! claim, a [`ProofState`] that the surfaces render and the gate judges.
31//!
32//! # The lifecycle, end to end
33//!
34//! A claim's path becomes an identity, a run becomes an [`Execution`], the ledger keeps the
35//! latest one per test, and the digest is what notices that the test itself has moved since
36//! — without any commit having to change.
37//!
38//! ```
39//! use majordomus_cli::evidence::{digest_of, Execution, Ledger, Origin, Outcome, Runner, TestId};
40//!
41//! // the identity is derived from the path the claim already names; nothing is entered
42//! let id = TestId::of("test/cases/84_distribution_model.sh").unwrap();
43//! assert_eq!(id.as_string(), "suite:84_distribution_model");
44//! assert_eq!(id.reproduce(), "bash test/run.sh 84_distribution_model");
45//!
46//! let repo = tempfile::tempdir().unwrap();
47//! std::fs::create_dir_all(repo.path().join("test/cases")).unwrap();
48//! std::fs::write(repo.path().join(id.source()), "echo ok\n").unwrap();
49//!
50//! let run = Execution {
51//!     test: id.as_string(),
52//!     runner: Runner::Suite,
53//!     source: id.source(),
54//!     outcome: Outcome::parse("ok"),
55//!     seconds: 3,
56//!     commit: "0".repeat(40),
57//!     working_tree: "clean".into(),
58//!     digest: digest_of(b"echo ok\n"),
59//!     at: "2026-09-11T00:00:00Z".into(),
60//!     origin: Origin::Local,
61//!     command: id.reproduce(),
62//!     run: None,
63//! };
64//! assert!(run.outcome.proves());
65//!
66//! // the ledger is a tracked file, so the evidence survives the process that produced it
67//! let mut ledger = Ledger::empty();
68//! ledger.merge([run]);
69//! ledger.save(repo.path()).unwrap();
70//!
71//! let recorded = Ledger::load(repo.path()).unwrap();
72//! let latest = recorded.latest(&id.as_string()).unwrap();
73//! assert_eq!(latest.digest_matches(repo.path()), Some(true));
74//!
75//! // edit the case afterwards and the recorded run is no longer a run of the test that is
76//! // there now — which no diff against a commit would have shown, had the edit been reverted
77//! std::fs::write(repo.path().join(id.source()), "echo something else\n").unwrap();
78//! assert_eq!(latest.digest_matches(repo.path()), Some(false));
79//! ```
80//!
81//! # What "current" means here, exactly
82//!
83//! A passing run three commits ago is not automatically proof of the tree in front of you,
84//! and pretending otherwise is the failure this module exists to prevent. But declaring
85//! every result stale the instant anything anywhere changes is sound and useless — it
86//! would mean no claim is ever proven except in the seconds after a full run.
87//!
88//! So the derivation is conservative and says which of two things it found:
89//!
90//! * [`ProofState::Proven`] — the test passed, and the tree in front of you is byte for
91//!   byte the tree the run measured: the diff against the execution's own commit is empty.
92//!   The ledger's own row is excluded from that diff, because the evidence is about the
93//!   tree rather than part of what the tests measure — without that exclusion `proven`
94//!   would be unreachable by construction, since recording dirties the tree and committing
95//!   the record moves HEAD past the commit the record names.
96//! * [`ProofState::InputsUnchanged`] — the test passed, and **nothing the claim itself
97//!   names** (its source document, its implementation, its test) differs between the
98//!   recorded commit and the working tree. This is *not* proof at HEAD: something the claim
99//!   does not name may have broken it. It is the absence of any known invalidation, and it
100//!   is labelled as that everywhere it is shown.
101//! * [`ProofState::Stale`] — the test passed, and something the claim names has changed
102//!   since. The changed paths are named.
103//!
104//! The distinction is the point. A surface that collapsed the second into the first would
105//! be the green badge whose derivation cannot be inspected.
106//!
107//! # What this is not
108//!
109//! It is not tamper-proof, and it does not pretend to be. The ledger is a tracked file; a
110//! person can edit `"outcome": "pass"` into it, and the diff is what a reviewer sees. What
111//! the recorded digest *does* buy is staleness detection that survives a revert: an
112//! execution whose test source no longer hashes to the recorded digest did not run this
113//! test, whatever the commit says. Cryptographic ceremony against an attacker who can
114//! already commit to the repository would be ceremony with no threat model.
115//!
116//! It is also not the execution control plane. [`crate::execution`] is about capability
117//! executions of a running server — in-flight work, progress, events, gone with the
118//! process. This is about test runs, durable, committed and read long after the process
119//! that produced them exited. Two different subjects that share an English word.
120
121//! # Example
122//!
123//! The vocabulary, without a repository: a test is named by the path a claim writes down,
124//! a result word is a pass only when the runner said so, and the proof states rank.
125//!
126//! ```
127//! use majordomus_cli::evidence::{Outcome, ProofState, Runner, TestId};
128//!
129//! let t = TestId::of("test/cases/07_scope.sh").unwrap();
130//! assert_eq!(t.runner, Runner::Suite);
131//! assert_eq!(t.as_string(), "suite:07_scope");
132//! assert!(Outcome::parse("ok").proves());
133//! assert!(!Outcome::parse("FAIL").proves());
134//! assert!(ProofState::Proven < ProofState::Stale);
135//! ```

158/// Which runner produced a result, and therefore how the test is named and re-run.
159///
160/// The repository has exactly two that a claim may name today. A third would be a variant
161/// here and a branch in [`TestId::of`]; a claim naming something neither runner produces is
162/// reported as [`ProofState::Unrunnable`] rather than silently counted as covered.
163///
164/// ```
165/// use majordomus_cli::evidence::{Runner, TestId};
166///
167/// // which runner owns a test is read off where the test lives, never declared
168/// assert_eq!(TestId::of("test/cases/07_scope.sh").unwrap().runner, Runner::Suite);
169/// assert_eq!(
170///     TestId::of("apps/majordomus-cli/tests/why.rs").unwrap().runner,
171///     Runner::Crate
172/// );
173/// // and a path under neither directory belongs to no runner at all
174/// assert!(TestId::of("test/lib.sh").is_none());
175/// ```
176#[derive(
177    Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, JsonSchema,
178)]
179#[serde(rename_all = "snake_case")]
180#[schemars(rename = "EvidenceRunner")]
181/// # Example
182///
183/// ```
184/// use majordomus_cli::evidence::Runner;
185/// assert_eq!(Runner::Suite.prefix(), "suite");
186/// assert_eq!(Runner::Crate.prefix(), "crate");
187/// ```
188pub enum Runner {
189    /// A behavioural case under `test/cases/`, run by `test/run.sh`.
190    Suite,
191    /// An integration test binary under `apps/majordomus-cli/tests/`, run by `cargo test`.
192    Crate,
193}
194
195impl Runner {
196    /// The prefix this runner's test ids carry, and the half of [`TestId::as_string`] that
197    /// says which runner has to be asked for the proof again.
198    ///
199    /// The two are distinct words on purpose: a case and a test binary may share a name,
200    /// and a ledger keyed on the bare name would let one record overwrite the other's.
201    ///
202    /// ```
203    /// use majordomus_cli::evidence::Runner;
204    /// assert_eq!(Runner::Suite.prefix(), "suite");
205    /// assert_eq!(Runner::Crate.prefix(), "crate");
206    /// assert_ne!(Runner::Suite.prefix(), Runner::Crate.prefix());
207    /// ```
208    pub fn prefix(self) -> &'static str {
209        match self {
210            Runner::Suite => "suite",
211            Runner::Crate => "crate",
212        }
213    }
214}

216/// What a run said about one test.
217///
218/// `NotRun` is deliberately absent: it is the absence of an execution, not an outcome one
219/// had. Encoding it here would let a recorder write "this did not run" and have it counted
220/// among the things that did.
221///
222/// ```
223/// use majordomus_cli::evidence::Outcome;
224///
225/// assert!(Outcome::parse("ok").proves());
226/// assert!(!Outcome::parse("timeout").proves());
227/// // exactly one of the five is evidence of anything; the other four are reasons there
228/// // is none, kept apart because "it declined" and "the harness broke" are different bugs
229/// assert_eq!(Outcome::parse("skipped"), Outcome::Skip);
230/// assert_eq!(Outcome::parse("nonsense"), Outcome::Error);
231/// ```
232#[derive(
233    Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, JsonSchema,
234)]
235#[serde(rename_all = "snake_case")]
236#[schemars(rename = "EvidenceOutcome")]
237/// # Example
238///
239/// ```
240/// use majordomus_cli::evidence::Outcome;
241/// assert!(Outcome::parse("ok").proves());
242/// assert_eq!(Outcome::parse("wat"), Outcome::Error);
243/// ```
244pub enum Outcome {
245    /// It passed.
246    Pass,
247    /// It failed.
248    Fail,
249    /// It declined to run and said so (an unmet precondition the case reports itself).
250    Skip,
251    /// The bound fired before it finished.
252    Timeout,
253    /// The harness could not run it at all.
254    Error,
255}
256
257impl Outcome {
258    /// Did this run prove the behaviour it was about? Only a pass does.
259    ///
260    /// A skip is a test that declined, and a timeout or an error is a test whose verdict
261    /// nobody has; none of the three is a weaker kind of success, and every derivation in
262    /// this module asks this question rather than matching on the variants itself.
263    ///
264    /// ```
265    /// use majordomus_cli::evidence::Outcome;
266    /// assert!(Outcome::Pass.proves());
267    /// assert!(!Outcome::Skip.proves(), "a test that declined to run proved nothing");
268    /// assert!(!Outcome::Timeout.proves());
269    /// assert!(!Outcome::Error.proves());
270    /// ```
271    pub fn proves(self) -> bool {
272        matches!(self, Outcome::Pass)
273    }
274
275    /// The word the runner writes, read back. Anything unrecognised is [`Outcome::Error`]:
276    /// a result nobody can classify is not a pass.
277    ///
278    /// Case and surrounding space are the runner's business, not the ledger's, so both are
279    /// normalised away. The fallback is the whole point: a truncated line, a renamed status
280    /// word or a new runner's vocabulary fails loudly instead of widening into a green.
281    ///
282    /// ```
283    /// use majordomus_cli::evidence::Outcome;
284    /// assert_eq!(Outcome::parse("PASSED"), Outcome::Pass);
285    /// assert_eq!(Outcome::parse("  skip  "), Outcome::Skip);
286    /// // near-misses included: nothing here guesses at what was meant
287    /// assert_eq!(Outcome::parse("okay"), Outcome::Error);
288    /// assert!(!Outcome::parse("").proves());
289    /// ```
290    pub fn parse(word: &str) -> Outcome {
291        match word.trim().to_ascii_lowercase().as_str() {
292            "ok" | "pass" | "passed" => Outcome::Pass,
293            "fail" | "failed" => Outcome::Fail,
294            "skip" | "skipped" => Outcome::Skip,
295            "timeout" => Outcome::Timeout,
296            _ => Outcome::Error,
297        }
298    }
299}

301/// Where a run happened. The canonical model is provider-neutral: a CI adapter records
302/// `Ci`, and nothing here knows or cares which CI it was.
303///
304/// ```
305/// use majordomus_cli::evidence::Origin;
306///
307/// assert_eq!(Origin::parse("CI"), Some(Origin::Ci));
308/// assert_eq!(Origin::parse("local"), Some(Origin::Local));
309/// // naming the provider is the adapter's business; the ledger records the kind of run,
310/// // so a repository that changes CI does not change what its old evidence says
311/// assert!(Origin::parse("github-actions").is_none());
312/// ```
313#[derive(
314    Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, JsonSchema,
315)]
316#[serde(rename_all = "snake_case")]
317#[schemars(rename = "EvidenceOrigin")]
318/// # Example
319///
320/// ```
321/// use majordomus_cli::evidence::Origin;
322/// assert_eq!(Origin::parse("ci"), Some(Origin::Ci));
323/// assert_eq!(Origin::parse("nowhere"), None);
324/// ```
325pub enum Origin {
326    /// Someone ran it on their own machine.
327    Local,
328    /// A continuous-integration run.
329    Ci,
330    /// A release run.
331    Release,
332}
333
334impl Origin {
335    /// Read an origin from the word a recorder was given, or `None` when it names none of
336    /// the three.
337    ///
338    /// The asymmetry with [`Outcome::parse`] is deliberate. An unreadable outcome still has
339    /// to be recorded as something, and the safe something is an error; an unreadable origin
340    /// is a caller passing a word this model does not have, which is worth refusing at the
341    /// boundary rather than recording as a local run nobody made.
342    ///
343    /// ```
344    /// use majordomus_cli::evidence::Origin;
345    /// assert_eq!(Origin::parse(" Release "), Some(Origin::Release));
346    /// assert!(Origin::parse("laptop").is_none());
347    /// ```
348    pub fn parse(word: &str) -> Option<Origin> {
349        match word.trim().to_ascii_lowercase().as_str() {
350            "local" => Some(Origin::Local),
351            "ci" => Some(Origin::Ci),
352            "release" => Some(Origin::Release),
353            _ => None,
354        }
355    }
356}

358/// The stable identity of a test: the runner that owns it and the name that runner knows
359/// it by.
360///
361/// Derived from the path a claim already names, which is what makes the migration from
362/// `test: <path>` deterministic and empty of data entry. `test/cases/84_x.sh` is the case
363/// `test/run.sh` calls `84_x`; `apps/majordomus-cli/tests/why.rs` is the binary `cargo test
364/// --test why` runs. Both spellings already exist in the repository; this only names the
365/// join.
366///
367/// ```
368/// use majordomus_cli::evidence::{Runner, TestId};
369///
370/// let id = TestId::of("test/cases/07_scope.sh").unwrap();
371/// assert_eq!(id, TestId { runner: Runner::Suite, name: "07_scope".into() });
372///
373/// // the identity and the path are two spellings of one thing, so the derivation is
374/// // reversible and no claim in `docs/CLAIMS.yaml` has to be rewritten to carry an id
375/// assert_eq!(TestId::of(&id.source()).unwrap(), id);
376/// ```
377#[derive(Debug, Clone, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, JsonSchema)]
378#[schemars(rename = "EvidenceTestId")]
379/// # Example
380///
381/// ```
382/// use majordomus_cli::evidence::TestId;
383/// let t = TestId::of("apps/majordomus-cli/tests/product.rs").unwrap();
384/// assert_eq!(t.as_string(), "crate:product");
385/// assert_eq!(t.reproduce(), "cargo test --test product");
386/// assert!(TestId::of("lib/nothing.sh").is_none());
387/// ```
388pub struct TestId {
389    /// Which runner owns it.
390    pub runner: Runner,
391    /// The name that runner knows it by: a case's file stem, a test binary's file stem.
392    pub name: String,
393}
394
395impl TestId {
396    /// The canonical string form: `suite:84_distribution_model`, `crate:why`.
397    ///
398    /// This is the ledger's key. Every execution is stored and looked up under it, which is
399    /// why the runner is part of it rather than context a reader is expected to carry.
400    ///
401    /// ```
402    /// use majordomus_cli::evidence::TestId;
403    /// assert_eq!(
404    ///     TestId::of("test/cases/07_scope.sh").unwrap().as_string(),
405    ///     "suite:07_scope"
406    /// );
407    /// assert_eq!(
408    ///     TestId::of("apps/majordomus-cli/tests/why.rs").unwrap().as_string(),
409    ///     "crate:why"
410    /// );
411    /// ```
412    pub fn as_string(&self) -> String {
413        format!("{}:{}", self.runner.prefix(), self.name)
414    }
415
416    /// The test a path names, when a runner in this repository produces it.
417    ///
418    /// `None` is an answer, not a failure: a claim may name a file no runner drives (a
419    /// template, a fixture, a document), and the report says so rather than counting it.
420    ///
421    /// ```
422    /// use majordomus_cli::evidence::{Runner, TestId};
423    /// assert_eq!(
424    ///     TestId::of("test/cases/84_distribution_model.sh").unwrap().as_string(),
425    ///     "suite:84_distribution_model"
426    /// );
427    /// assert_eq!(TestId::of("apps/majordomus-cli/tests/why.rs").unwrap().runner, Runner::Crate);
428    /// assert!(TestId::of("share/install/install.sh.in").is_none());
429    /// assert!(TestId::of("-").is_none());
430    /// ```
431    pub fn of(path: &str) -> Option<TestId> {
432        let path = path.trim().trim_matches(|c| c == '\'' || c == '"');
433        if let Some(rest) = path.strip_prefix("test/cases/") {
434            return TestId::named(Runner::Suite, rest.strip_suffix(".sh")?);
435        }
436        if let Some(rest) = path.strip_prefix("apps/majordomus-cli/tests/") {
437            return TestId::named(Runner::Crate, rest.strip_suffix(".rs")?);
438        }
439        None
440    }
441
442    /// A test named directly, validated by the same rule [`TestId::of`] applies to a path.
443    ///
444    /// The identity form (`suite:84_x`) and the path form (`test/cases/84_x.sh`) name the
445    /// same thing, so they must agree about what a name may be. They did not: the path
446    /// form rejected a name containing a separator and the identity form did not, so
447    /// `suite:../../x` produced the source `test/cases/../../x.sh`. Two parsers for one
448    /// grammar is the one-way check this repository keeps finding; this is the grammar,
449    /// and both forms go through it.
450    ///
451    /// ```
452    /// use majordomus_cli::evidence::{Runner, TestId};
453    /// assert_eq!(TestId::named(Runner::Suite, "84_x").unwrap().as_string(), "suite:84_x");
454    /// assert!(TestId::named(Runner::Suite, "../../x").is_none(), "a name is not a path");
455    /// assert!(TestId::named(Runner::Suite, "").is_none());
456    /// assert!(TestId::named(Runner::Crate, "a/b").is_none());
457    /// assert!(TestId::named(Runner::Suite, ".hidden").is_none());
458    /// ```
459    pub fn named(runner: Runner, name: &str) -> Option<TestId> {
460        if name.is_empty() || name.contains('/') || name.contains('\\') || name.starts_with('.') {
461            return None;
462        }
463        Some(TestId {
464            runner,
465            name: name.to_string(),
466        })
467    }

469    /// The repository-relative path of the test's own source: the file that is hashed into
470    /// [`Execution::digest`], and one of the paths a claim's staleness is measured over.
471    ///
472    /// ```
473    /// use majordomus_cli::evidence::TestId;
474    /// let id = TestId::of("apps/majordomus-cli/tests/why.rs").unwrap();
475    /// assert_eq!(id.source(), "apps/majordomus-cli/tests/why.rs");
476    /// // a case's source is the file the runner executes, not the runner
477    /// assert_eq!(
478    ///     TestId::of("test/cases/07_scope.sh").unwrap().source(),
479    ///     "test/cases/07_scope.sh"
480    /// );
481    /// ```
482    pub fn source(&self) -> String {
483        match self.runner {
484            Runner::Suite => format!("test/cases/{}.sh", self.name),
485            Runner::Crate => format!("apps/majordomus-cli/tests/{}.rs", self.name),
486        }
487    }

489    /// The exact command that runs this one test, for a reader who wants the proof again
490    /// rather than the claim that it exists.
491    ///
492    /// One test, not the suite: a finding a reader can settle in seconds is settled, and
493    /// one that costs a full run is argued about instead.
494    ///
495    /// ```
496    /// use majordomus_cli::evidence::TestId;
497    /// assert_eq!(
498    ///     TestId::of("test/cases/84_distribution_model.sh").unwrap().reproduce(),
499    ///     "bash test/run.sh 84_distribution_model"
500    /// );
501    /// assert_eq!(
502    ///     TestId::of("apps/majordomus-cli/tests/why.rs").unwrap().reproduce(),
503    ///     "cargo test --test why"
504    /// );
505    /// ```
506    pub fn reproduce(&self) -> String {
507        match self.runner {
508            Runner::Suite => format!("bash test/run.sh {}", self.name),
509            Runner::Crate => format!("cargo test --test {}", self.name),
510        }
511    }
512}

514/// One recorded run of one test: the whole of what this repository durably remembers about
515/// it.
516///
517/// Every field is provenance. A result with no commit is an anonymous green, which is the
518/// thing a badge must never be derived from.
519///
520/// ```
521/// use majordomus_cli::evidence::{digest_of, Execution, Origin, Outcome, Runner, TestId};
522///
523/// let id = TestId::of("apps/majordomus-cli/tests/why.rs").unwrap();
524/// let run = Execution {
525///     test: id.as_string(),
526///     runner: Runner::Crate,
527///     source: id.source(),
528///     outcome: Outcome::Pass,
529///     seconds: 12,
530///     commit: "0".repeat(40),
531///     working_tree: "clean".into(),
532///     digest: digest_of(b"fn main() {}"),
533///     at: "2026-09-11T00:00:00Z".into(),
534///     origin: Origin::Ci,
535///     command: id.reproduce(),
536///     run: None,
537/// };
538///
539/// // it is a value in a tracked JSON file, so it has to survive the file unchanged
540/// let back: Execution = serde_json::from_str(&serde_json::to_string(&run).unwrap()).unwrap();
541/// assert_eq!(back, run);
542/// assert_eq!(back.test, "crate:why");
543/// assert_eq!(back.command, "cargo test --test why");
544/// ```
545#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
546#[schemars(rename = "EvidenceExecution")]
547/// # Example
548///
549/// One recorded run, with the provenance the runner did not carry: which commit, which
550/// tree state, the digest of the test's own source, when, and how to run it again.
551///
552/// ```
553/// use majordomus_cli::evidence::{Execution, Origin, Outcome, Runner};
554/// let e = Execution {
555///     test: "suite:07_scope".into(),
556///     runner: Runner::Suite,
557///     source: "test/cases/07_scope.sh".into(),
558///     outcome: Outcome::Pass,
559///     seconds: 3,
560///     commit: "a04b65c9".into(),
561///     working_tree: "clean".into(),
562///     digest: "sha256:00".into(),
563///     at: "2026-09-11T00:00:00Z".into(),
564///     origin: Origin::Local,
565///     command: "bash test/run.sh 07_scope".into(),
566///     run: None,
567/// };
568/// assert!(e.outcome.proves());
569/// ```
570pub struct Execution {

601/// The continuous-integration run an execution was recorded in: enough to navigate back to
602/// the run that produced it.
603///
604/// [`Origin`] says what kind of run it was and deliberately names no provider. This names the
605/// one run, in the words the provider addressed it with when it happened — its identifier,
606/// its attempt, the workflow and job, and the address a reader follows — because a link built
607/// later from a template would point wherever the template's idea of the provider had drifted
608/// to. Only an adapter constructs it; nothing in the model reads the provider's name.
609///
610/// ```
611/// use majordomus_cli::evidence::RunRef;
612///
613/// let actions = |k: &str| {
614///     let v = match k {
615///         "GITHUB_ACTIONS" => "true",
616///         "GITHUB_SERVER_URL" => "https://github.com",
617///         "GITHUB_REPOSITORY" => "owner/repo",
618///         "GITHUB_RUN_ID" => "42",
619///         "GITHUB_RUN_ATTEMPT" => "2",
620///         "GITHUB_WORKFLOW" => "validate",
621///         "GITHUB_JOB" => "evidence",
622///         _ => return None,
623///     };
624///     Some(v.to_string())
625/// };
626/// let run = RunRef::from_env(actions).unwrap();
627/// assert_eq!(run.id, "42");
628/// assert_eq!(run.attempt, 2);
629/// assert_eq!(run.url, "https://github.com/owner/repo/actions/runs/42/attempts/2");
630///
631/// // outside a run there is nothing to name, and a half-described run is not a run
632/// assert!(RunRef::from_env(|_| None).is_none());
633/// assert!(RunRef::from_env(|k| (k == "GITHUB_ACTIONS").then(|| "true".to_string())).is_none());
634/// ```
635#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
636#[schemars(rename = "EvidenceRun")]
637pub struct RunRef {
638    /// The provider that ran it, as the adapter that recorded it names it.
639    pub provider: String,
640    /// The provider's identifier of the run.
641    pub id: String,
642    /// Which attempt of the run, counted from 1.
643    pub attempt: u32,
644    /// The workflow the run belongs to.
645    pub workflow: String,
646    /// The job within the run that recorded the execution.
647    pub job: String,
648    /// Where a reader finds the run, as the provider addressed it at the time.
649    pub url: String,
650}

652impl RunRef {
653    /// The run described by a GitHub Actions environment, read through `var`, or `None` when
654    /// the environment is not one or leaves out any part a reader would need to find it.
655    ///
656    /// The variable reader is a parameter so the adapter can be exercised without mutating
657    /// the process environment, which other threads of a test binary share.
658    ///
659    /// ```
660    /// use majordomus_cli::evidence::RunRef;
661    /// assert!(RunRef::from_env(|k| (k == "GITHUB_RUN_ID").then(|| "1".to_string())).is_none());
662    /// ```
663    pub fn from_env(var: impl Fn(&str) -> Option<String>) -> Option<RunRef> {
664        if var("GITHUB_ACTIONS").as_deref() != Some("true") {
665            return None;
666        }
667        let server = var("GITHUB_SERVER_URL")?;
668        let repository = var("GITHUB_REPOSITORY")?;
669        let id = var("GITHUB_RUN_ID")?;
670        let attempt: u32 = var("GITHUB_RUN_ATTEMPT")
671            .and_then(|a| a.parse().ok())
672            .unwrap_or(1);
673        Some(RunRef {
674            provider: "github_actions".into(),
675            url: format!(
676                "{}/{repository}/actions/runs/{id}/attempts/{attempt}",
677                server.trim_end_matches('/')
678            ),
679            id,
680            attempt,
681            workflow: var("GITHUB_WORKFLOW")?,
682            job: var("GITHUB_JOB")?,
683        })
684    }

696    /// Does the test's source still hash to what was recorded?
697    ///
698    /// `None` when the source is not there to hash — which is itself a finding, reported by
699    /// the path checks, not silently read as a match.
700    ///
701    /// This is the staleness check that survives a revert: an edit made and undone around a
702    /// run leaves no diff against any commit, and the recorded digest still says the test
703    /// that ran is not the test that is there.
704    ///
705    /// ```
706    /// use majordomus_cli::evidence::{digest_of, Execution, Origin, Outcome, Runner, TestId};
707    ///
708    /// let repo = tempfile::tempdir().unwrap();
709    /// let id = TestId::of("test/cases/07_scope.sh").unwrap();
710    /// std::fs::create_dir_all(repo.path().join("test/cases")).unwrap();
711    /// std::fs::write(repo.path().join(id.source()), "echo ok\n").unwrap();
712    ///
713    /// let run = Execution {
714    ///     test: id.as_string(),
715    ///     runner: Runner::Suite,
716    ///     source: id.source(),
717    ///     outcome: Outcome::Pass,
718    ///     seconds: 1,
719    ///     commit: "0".repeat(40),
720    ///     working_tree: "clean".into(),
721    ///     digest: digest_of(b"echo ok\n"),
722    ///     at: "2026-09-11T00:00:00Z".into(),
723    ///     origin: Origin::Local,
724    ///     command: id.reproduce(),
725    ///     run: None,
726    /// };
727    /// assert_eq!(run.digest_matches(repo.path()), Some(true));
728    ///
729    /// std::fs::write(repo.path().join(id.source()), "echo something else\n").unwrap();
730    /// assert_eq!(run.digest_matches(repo.path()), Some(false));
731    ///
732    /// // and a source that is gone cannot be compared, which is not the same as agreeing
733    /// std::fs::remove_file(repo.path().join(id.source())).unwrap();
734    /// assert_eq!(run.digest_matches(repo.path()), None);
735    /// ```
736    pub fn digest_matches(&self, root: &Path) -> Option<bool> {
737        let text = std::fs::read(root.join(&self.source)).ok()?;
738        Some(digest_of(&text) == self.digest)
739    }

742/// `sha256:<hex>` of some bytes, the one spelling used in the ledger.
743///
744/// The algorithm is named in the value rather than assumed by the reader, so a ledger
745/// written before a change of algorithm stays readable and says which one produced it.
746///
747/// ```
748/// use majordomus_cli::evidence::digest_of;
749///
750/// let d = digest_of(b"echo ok\n");
751/// assert!(d.starts_with("sha256:"), "{d}");
752/// assert_eq!(d.len(), "sha256:".len() + 64);
753/// assert_eq!(d, digest_of(b"echo ok\n"), "the same bytes hash the same");
754/// assert_ne!(d, digest_of(b"echo ok"), "a trailing newline is a different file");
755/// ```
756pub fn digest_of(bytes: &[u8]) -> String {
757    use sha2::{Digest, Sha256};
758    let mut h = Sha256::new();
759    h.update(bytes);
760    format!("sha256:{:x}", h.finalize())
761}

763/// What the repository can say about one claim's proof, right now.
764///
765/// Ordered from strongest to weakest, so a summary that sorts by this reads as a ranking.
766///
767/// ```
768/// use majordomus_cli::evidence::ProofState;
769///
770/// let mut states = vec![ProofState::NotRun, ProofState::Stale, ProofState::Proven];
771/// states.sort();
772/// assert_eq!(
773///     states,
774///     vec![ProofState::Proven, ProofState::Stale, ProofState::NotRun]
775/// );
776///
777/// // the two strongest are deliberately not one state: `inputs unchanged` is the absence
778/// // of a known invalidation, and collapsing it into `proven` is the unaccountable badge
779/// assert_ne!(ProofState::Proven, ProofState::InputsUnchanged);
780/// assert!(ProofState::Proven < ProofState::InputsUnchanged);
781/// assert!(ProofState::InputsUnchanged.passing());
782/// ```
783#[derive(
784    Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, JsonSchema,
785)]
786#[serde(rename_all = "snake_case")]
787/// # Example
788///
789/// ```
790/// use majordomus_cli::evidence::ProofState;
791/// assert!(ProofState::Proven.passing());
792/// assert!(!ProofState::NotRun.passing());
793/// assert!(!ProofState::InputsUnchanged.meaning().is_empty());
794/// ```
795pub enum ProofState {
796    /// A passing run, and nothing has changed since it — the diff against the execution's
797    /// own commit is empty but for the ledger. Proof of the tree in front of you.
798    Proven,
799    /// A passing run, and nothing this claim names has changed since. Not proof at HEAD:
800    /// something the claim does not name may have broken it.
801    InputsUnchanged,
802    /// A passing run, but something this claim names has changed since. The proof is older
803    /// than its subject.
804    Stale,
805    /// The latest run of this claim's test did not pass.
806    Failing,
807    /// The claim names a test a runner owns, and no run of it has ever been recorded.
808    NotRun,
809    /// The claim names a path no runner in this repository drives. Nothing can record it,
810    /// so nothing can prove it this way.
811    Unrunnable,
812    /// The claim names no test at all. Correct for a `planned` or `rejected` claim, and a
813    /// defect for any other.
814    NoTest,
815}
816
817impl ProofState {
818    /// The word every surface prints for this state, and the key the report's totals are
819    /// counted under.
820    ///
821    /// One spelling, defined here, so that the badge, the terminal rendering and the JSON
822    /// cannot disagree about what they are showing the same reader.
823    ///
824    /// ```
825    /// use majordomus_cli::evidence::ProofState;
826    /// assert_eq!(ProofState::Proven.label(), "proven");
827    /// assert_eq!(ProofState::InputsUnchanged.label(), "inputs unchanged");
828    /// assert_ne!(ProofState::Proven.label(), ProofState::InputsUnchanged.label());
829    /// ```
830    pub fn label(self) -> &'static str {
831        match self {
832            ProofState::Proven => "proven",
833            ProofState::InputsUnchanged => "inputs unchanged",
834            ProofState::Stale => "stale",
835            ProofState::Failing => "failing",
836            ProofState::NotRun => "not run",
837            ProofState::Unrunnable => "unrunnable",
838            ProofState::NoTest => "no test",
839        }
840    }
841
842    /// The design-token word for this state: its serialised name with `_` written as `-`.
843    ///
844    /// A surface that colours a state asks for its token and nothing else, so the mapping
845    /// from a state to a design token is this one spelling rather than a table in each
846    /// renderer.
847    ///
848    /// ```
849    /// use majordomus_cli::evidence::ProofState;
850    /// assert_eq!(ProofState::Proven.token(), "proven");
851    /// assert_eq!(ProofState::InputsUnchanged.token(), "inputs-unchanged");
852    /// assert_eq!(ProofState::NoTest.token(), "no-test");
853    /// ```
854    pub fn token(self) -> &'static str {
855        match self {
856            ProofState::Proven => "proven",
857            ProofState::InputsUnchanged => "inputs-unchanged",
858            ProofState::Stale => "stale",
859            ProofState::Failing => "failing",
860            ProofState::NotRun => "not-run",
861            ProofState::Unrunnable => "unrunnable",
862            ProofState::NoTest => "no-test",
863        }
864    }
865
866    /// One sentence: what the state means, for the reader who clicked the badge. This is
867    /// the derivation, in words, and it lives here so that every surface says the same
868    /// thing rather than each inventing its own gloss.
869    ///
870    /// The sentence for [`ProofState::InputsUnchanged`] is the one that has to be carried
871    /// everywhere, because it is the state a surface is tempted to render as a plain green.
872    ///
873    /// ```
874    /// use majordomus_cli::evidence::ProofState;
875    ///
876    /// let m = ProofState::InputsUnchanged.meaning();
877    /// assert!(m.contains("not proof against the current commit"), "{m}");
878    /// assert_ne!(m, ProofState::Proven.meaning());
879    /// ```
880    pub fn meaning(self) -> &'static str {
881        match self {
882            ProofState::Proven => {
883                "A passing run, and nothing in the repository has changed since it — the tree \
884                 in front of you is the tree the run measured."
885            }
886            ProofState::InputsUnchanged => {
887                "A passing run, and nothing this claim names has changed since it. This is the \
888                 absence of a known invalidation, not proof against the current commit: a change \
889                 the claim does not name could have broken it."
890            }
891            ProofState::Stale => {
892                "A passing run, but a file this claim names has changed since. The proof is older \
893                 than what it is about."
894            }
895            ProofState::Failing => {
896                "The most recent recorded run of this claim's test did not pass."
897            }
898            ProofState::NotRun => {
899                "The claim names a test, and no run of that test has ever been recorded."
900            }
901            ProofState::Unrunnable => {
902                "The claim names a path that no runner in this repository drives, so no execution \
903                 of it can ever be recorded."
904            }
905            ProofState::NoTest => "The claim names no test.",
906        }
907    }
908
909    /// Does this state carry a passing execution behind it, of any freshness?
910    ///
911    /// Freshness and outcome are two questions, and this answers only the second. A count
912    /// of passing claims is honest; a count that called them all proven would not be.
913    ///
914    /// ```
915    /// use majordomus_cli::evidence::ProofState;
916    /// assert!(ProofState::Proven.passing());
917    /// assert!(ProofState::Stale.passing(), "a pass older than its subject is still a pass");
918    /// assert!(!ProofState::Failing.passing());
919    /// assert!(!ProofState::NotRun.passing());
920    /// assert!(!ProofState::Unrunnable.passing());
921    /// ```
922    pub fn passing(self) -> bool {
923        matches!(
924            self,
925            ProofState::Proven | ProofState::InputsUnchanged | ProofState::Stale
926        )
927    }
928}

930/// What a state may still be once the tree the run measured is taken into account.
931///
932/// `proven` is "a passing run recorded against this exact commit with a clean tree"
933/// (ADR 0041), and docs/EVIDENCE.md says why the tree is half of that: "A dirty tree is
934/// recorded as `dirty` for exactly this reason: it is the one case where the commit does
935/// not describe what ran." A run measured against a tree that was not its commit is
936/// therefore capped at `inputs_unchanged`: a pass, joined to a commit, with no claim that
937/// the commit is what it saw. A weaker state is never strengthened here, and `unknown` —
938/// git could not be asked — is treated as not clean, because not knowing is not proof.
939///
940/// ```
941/// use majordomus_cli::evidence::{capped_by_working_tree, ProofState};
942///
943/// // a clean tree changes nothing
944/// assert_eq!(
945///     capped_by_working_tree(ProofState::Proven, "clean"),
946///     ProofState::Proven
947/// );
948/// // a dirty one costs the strongest state, and only that one
949/// assert_eq!(
950///     capped_by_working_tree(ProofState::Proven, "dirty"),
951///     ProofState::InputsUnchanged
952/// );
953/// assert_eq!(
954///     capped_by_working_tree(ProofState::Proven, "unknown"),
955///     ProofState::InputsUnchanged
956/// );
957/// assert_eq!(
958///     capped_by_working_tree(ProofState::Stale, "dirty"),
959///     ProofState::Stale
960/// );
961/// ```
962pub fn capped_by_working_tree(state: ProofState, working_tree: &str) -> ProofState {
963    match (state, working_tree) {
964        (ProofState::Proven, t) if t != "clean" => ProofState::InputsUnchanged,
965        (s, _) => s,
966    }
967}

1199/// What a report was judged at: the revision, its tree, and the runs the checkout holds that

1223    pub revision: String,

1236///
1237/// What the capability answers, what the gate judges and what the site renders are this one
1238/// value; the totals and the findings are derived from the claims, never counted twice.

1241/// use majordomus_cli::evidence::{

1278///

1365/// Read one metadata field, treating the matrix's `'-'` placeholder as absence — which is
1366/// what it means, and what every reader of this file has to agree on.
1367fn field(meta: &Value, key: &str) -> Option<String> {
1368    let v = meta.get(key)?.as_str()?.trim().trim_matches('\'');
1369    if v.is_empty() || v == "-" {
1370        None
1371    } else {
1372        Some(v.to_string())
1373    }
1374}

1376/// Every claim the index holds, in the order the index holds them, which is the matrix's.

1378    index
1379        .objects
1380        .iter()
1381        .filter(|o| o.kind == "claim")
1382        .map(|o| IndexedClaim {
1383            id: o.identity.clone(),
1384            claim: field(&o.metadata, "claim")
1385                .or_else(|| o.title.clone())
1386                .unwrap_or_else(|| o.identity.clone()),
1387            status: field(&o.metadata, "status").unwrap_or_else(|| "unknown".into()),
1388            source: field(&o.metadata, "source"),
1389            implementation: field(&o.metadata, "implementation"),
1390            test: field(&o.metadata, "test"),

1392        .collect()

1395/// Every path that differs between `commit` and the working tree — committed since, staged,
1396/// or merely edited. One subprocess per distinct commit in the ledger, which in practice is
1397/// one.
1398///
1399/// `None` when git could not answer, which the caller must not read as "nothing changed":
1400/// an unanswerable comparison is why [`ProofState`] has to be able to say it does not know.
1401///
1402/// Shared with the preflight (`environment::preflight`), whose verdict about recorded test
1403/// runs must mean what `proven` means here and nothing looser.
1404pub(crate) fn changed_since(root: &Path, commit: &str) -> Option<BTreeSet<String>> {
1405    let git = |args: &[&str]| -> Option<Vec<String>> {
1406        let out = crate::git::read_only(root).args(args).output().ok()?;
1407        if !out.status.success() {
1408            return None;
1409        }
1410        Some(
1411            String::from_utf8_lossy(&out.stdout)
1412                .lines()
1413                .map(|l| l.trim().to_string())
1414                .filter(|l| !l.is_empty())
1415                .collect(),
1416        )
1417    };
1418    // Tracked differences, and then the files that are there but git is not tracking.
1419    // `git diff` never lists an untracked file, so a tree whose only difference from the
1420    // recorded commit is a new source file would compare equal — and `proven` would say
1421    // "the tree in front of you is the tree the run measured" about a tree carrying code
1422    // the run never saw. Ignored files stay ignored: `--exclude-standard` is what makes
1423    // this the set a person would call "new here" rather than every build artifact.
1424    let mut changed: BTreeSet<String> = git(&["diff", "--name-only", commit, "--"])?
1425        .into_iter()
1426        .collect();
1427    changed.extend(git(&["ls-files", "--others", "--exclude-standard"])?);
1428    Some(changed)
1429}

1514/// The same join, judged at a named revision: the working tree, or the checked-out commit
1515/// as committed.
1516///
1517/// The caller supplies what is read for that revision, so this stays one derivation for both:
1518/// for [`Presented::WorkingTree`], [`Ledger::load`] and no uncommitted executions — the
1519/// working ledger is itself the authority there; for a presented commit, [`ledger_at`] that
1520/// commit and [`uncommitted`] against it. Each claim's state, changed paths and detail come
1521/// from [`freshness()`] alone. For a presented commit, a clean failing run of the same test
1522/// that the checkout holds uncommitted, recorded between the evidence and the presented
1523/// commit, then caps the verdict at `stale` through [`weakened_by`]; it never decides one.
1524///
1525/// ```
1526/// use majordomus_cli::evidence::{report_at, Ledger, Presented};
1527/// use majordomus_cli::synthetic::SyntheticRepository;
1528///
1529/// let repo = SyntheticRepository::small().unwrap();
1530/// let ledger = Ledger::load(repo.root()).unwrap();
1531/// let r = report_at(&repo.index().unwrap(), &ledger, &Presented::WorkingTree, &[]);
1532/// assert_eq!(r.presented.revision, "working_tree");
1533/// assert!(r.presented.uncommitted.is_empty(), "the working ledger is the authority here");
1534/// ```
1535pub fn report_at(
1536    index: &Index,
1537    ledger: &Ledger,
1538    presented: &Presented,
1539    uncommitted: &[Execution],
1540) -> EvidenceReport {
1541    let root = PathBuf::from(&index.repository.root);
1542    let git = crate::git::inspect(&root);
1543    // Reported so a reader knows what the report was derived against; the proof states
1544    // are decided by each execution's own commit against the presented revision.
1545    let (head, working_tree) = match &git {
1546        crate::git::GitState::Available(i) => (i.head.clone(), i.working_tree.clone()),
1547        crate::git::GitState::Unavailable { .. } => (None, "unknown".to_string()),
1548    };
1549
1550    // one comparison per commit the ledger names, not one per claim
1551    let mut comparisons: BTreeMap<String, Comparison> = BTreeMap::new();
1552    for e in &ledger.executions {
1553        comparisons
1554            .entry(e.commit.clone())
1555            .or_insert_with(|| compare(&root, &e.commit, presented));
1556    }
1557    // and one containment per pair of commits the monotone rule asks about
1558    let mut containments: BTreeMap<(String, String), crate::git::Containment> = BTreeMap::new();
1559    let mut contains = |descendant: &str, ancestor: &str| {
1560        *containments
1561            .entry((descendant.to_string(), ancestor.to_string()))
1562            .or_insert_with(|| crate::git::contains(&root, descendant, ancestor))
1563    };
1564
1565    let mut claims = Vec::new();
1566    let mut totals: BTreeMap<String, usize> = BTreeMap::new();
1567    let mut findings = Vec::new();
1568
1569    for c in claims_of(index) {
1570        let test_id = c.test.as_deref().and_then(TestId::of);
1571        let execution = test_id
1572            .as_ref()
1573            .and_then(|t| ledger.latest(&t.as_string()))
1574            .cloned();
1575
1576        let recorded = match (&c.test, &test_id, &execution) {
1577            (None, _, _) => Recorded::NoTest,
1578            (Some(_), None, _) => Recorded::Unrunnable,
1579            (Some(_), Some(_), None) => Recorded::NotRun,
1580            (Some(_), Some(_), Some(e)) => Recorded::Ran(e),
1581        };
1582        let test_source = test_id.as_ref().map(TestId::source).unwrap_or_default();
1583        // what this claim names, and nothing else: the derivation is explicit about its own
1584        // reach, and a surface can repeat it
1585        let inputs: Vec<String> = [
1586            c.source.clone(),
1587            c.implementation.clone(),
1588            test_id.as_ref().map(TestId::source),
1589        ]
1590        .into_iter()
1591        .flatten()
1592        .collect();
1593        // A test whose source no longer hashes to what ran did not run in the form it is in
1594        // now, whatever the diff says — an edit made and reverted around the run leaves no
1595        // diff and is still not the thing that was measured. A presented commit is HEAD, so
1596        // the checkout's sources are the commit's whenever its tree is clean.
1597        let test_moved = execution
1598            .as_ref()
1599            .is_some_and(|e| e.outcome.proves() && e.digest_matches(&root) == Some(false));
1600        let mut judgement = freshness(
1601            recorded,
1602            Some(&inputs),
1603            &test_source,
1604            test_moved,
1605            execution.as_ref().and_then(|e| comparisons.get(&e.commit)),
1606            presented.tree(),
1607        );
1608
1609        // The monotone rule, over the one supplementary source a presented commit has: the
1610        // run of the same test the checkout holds and the commit's ledger does not.
1611        if let (Some(p), Some(e), Some(t)) = (presented.commit(), &execution, &test_id) {
1612            let key = t.as_string();
1613            if judgement.state < ProofState::Stale {
1614                if let Some(u) = uncommitted.iter().find(|u| u.test == key) {
1615                    let record = Supplementary {
1616                        execution: u,
1617                        named: UNCOMMITTED_RUN,
1618                        after_evidence: contains(&u.commit, &e.commit),
1619                        in_presented: contains(p, &u.commit),
1620                    };
1621                    judgement = weakened_by(judgement, &[record]);
1622                }
1623            }
1624        }
1625        let Judgement {
1626            state,
1627            changed,
1628            detail,
1629        } = judgement;
1630
1631        *totals.entry(state.label().to_string()).or_insert(0) += 1;
1632
1633        if let Some(reason) = unsupported(&c.status, state, detail.as_deref()) {
1634            findings.push(Finding {
1635                claim: c.id.clone(),
1636                status: c.status.clone(),
1637                state,
1638                reason,
1639                reproduce: test_id.as_ref().map(TestId::reproduce),
1640            });
1641        }
1642
1643        claims.push(ClaimProof {
1644            id: c.id,
1645            claim: c.claim,
1646            status: c.status,
1647            source: c.source,
1648            implementation: c.implementation,
1649            test_path: c.test,
1650            test: test_id.as_ref().map(TestId::as_string),
1651            state,
1652            meaning: state.meaning().to_string(),
1653            execution,
1654            changed,
1655            detail,
1656            reproduce: test_id.as_ref().map(TestId::reproduce),
1657        });
1658    }
1659
1660    // What the index could not read is what this report cannot be a verdict over. An
1661    // excluded file takes its objects out of the index, and every count below is then a
1662    // count over what survived.
1663    let excluded: Vec<String> = index
1664        .diagnostics
1665        .iter()
1666        .filter(|d| d.severity == crate::Severity::Error)
1667        .map(|d| match &d.path {
1668            Some(p) => format!("{p}: {}", d.code),
1669            None => d.code.clone(),
1670        })
1671        .collect();
1672    let subject = Subject {
1673        examined: claims.len(),
1674        complete: excluded.is_empty(),
1675        excluded,
1676    };
1677
1678    let presented = match presented.commit() {
1679        None => PresentedRevision {
1680            revision: "working_tree".to_string(),
1681            tree: TreeState::parse(&working_tree),
1682            uncommitted: Vec::new(),
1683        },
1684        Some(commit) => PresentedRevision {
1685            revision: commit.to_string(),
1686            tree: presented.tree(),
1687            uncommitted: uncommitted
1688                .iter()
1689                .map(|e| e.test.clone())
1690                .collect::<BTreeSet<_>>()
1691                .into_iter()

1708/// Does a claim's declared status survive the evidence found for it? `Some(reason)` when it
1709/// does not.
1710///
1711/// Only `guaranteed` is judged. `advisory` states that enforcement is not observable from
1712/// outside, `planned` states that nothing implements it and `rejected` that nothing will;
1713/// demanding a current proof of those would be demanding proof of a thing the claim already
1714/// says is not there.
1715///
1716/// Three states pass and three do not, and [`ProofState::Stale`] is the line between them.
1717/// A stale run is a pass — [`ProofState::passing`] says so, and the summary keeps it apart
1718/// from a failure for good reason — but it is a pass of a subject that has since moved: the
1719/// claim's own implementation or its test changed after the run offered as its proof.
1720/// Accepting it here made the gate accept, as support for a guarantee, a measurement of
1721/// something else. What is left is [`ProofState::InputsUnchanged`], weaker than `proven`
1722/// but at least a pass of *this* subject, and that is the floor.
1723///
1724/// The reason reads the judgement's detail where the state alone would mislead: a test that
1725/// declined to run is `not_run` and was not "never recorded", and a pass the presented
1726/// revision does not contain is `stale` without anything the claim names having changed.
1727fn unsupported(status: &str, state: ProofState, detail: Option<&str>) -> Option<String> {
1728    if status != "guaranteed" {
1729        return None;
1730    }
1731    match (state, detail) {
1732        (ProofState::Proven | ProofState::InputsUnchanged, _) => None,
1733        (ProofState::Stale, None) => Some(
1734            "the claim guarantees a behaviour whose only recorded run is older than what it is \
1735             about: the implementation or the test changed after that run, so the pass measured \
1736             a subject this claim no longer names"
1737                .into(),
1738        ),
1739        (ProofState::Stale, Some(d)) => Some(format!(
1740            "the claim guarantees a behaviour whose recorded pass proves nothing at the presented \
1741             revision: {d}"
1742        )),
1743        (ProofState::Failing, None | Some("failed")) => {
1744            Some("the claim guarantees a behaviour whose test most recently failed".into())
1745        }
1746        (ProofState::Failing, Some(d)) => Some(format!(
1747            "the claim guarantees a behaviour whose latest run did not pass: {d}"
1748        )),
1749        (ProofState::NotRun, None) => Some(
1750            "the claim guarantees a behaviour and names a test, and no run of that test has ever \
1751             been recorded"
1752                .into(),
1753        ),
1754        (ProofState::NotRun, Some(_)) => {
1755            Some("the claim guarantees a behaviour whose test declined to run".into())
1756        }
1757        (ProofState::Unrunnable, _) => Some(
1758            "the claim guarantees a behaviour and names a path no runner drives, so no execution \
1759             of it can be recorded"
1760                .into(),
1761        ),
1762        (ProofState::NoTest, _) => {
1763            Some("the claim guarantees a behaviour and names no test at all".into())
1764        }
1765    }
1766}
