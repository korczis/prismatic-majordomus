Vyhodnotí smlouvu o dokončení a odmítne výsledek, pokud je jakýkoli její řádek nesplněn.

Vyhodnotí smlouvu o dokončení a odmítne výsledek, pokud je jakýkoli její řádek nesplněn.

Reference

Vyhodnotit kontrakt dokončení. Odmítnout, pokud není splněn.

Čte: politiku, profil, current.yaml, git, knihu. Zapisuje: při úspěchu výsledek current.yaml nastavený na zadanou hodnotu, jeden řádek knihy task.finished nesoucí vyhodnocený kontrolní seznam a výsledek ověření a kopii --note pod state/completed/<id>.md, pokud je zadána.

Argumenty: --outcome completed|partial|blocked|no_match|failed povinný. --verify-command "<cmd>" spustí vlastní ověření projektu v kořeni repozitáře a zaznamená jeho návratový kód, dobu trvání, příkaz a id git stromu pracovního stromu, nad kterým běželo. Strom se čte před během i po něm: pokud se změnil, zatímco příkaz běžel — druhý worker ve stejném checkoutu, člověk ukládající soubor, příkaz přepisující sledované soubory — běh nepopisuje ani jeden stav a řádek selže; spusťte jej znovu, až se strom ustálí. --note <file> dodá poznámku o dokončení; jinak se použije nejnovější předávka, která tuto úlohu jmenuje. --check vyhodnotí rozsah a stav bez zápisu a skončí s 0, když není aktivní žádná úloha nebo je úloha už dokončená, takže pre-push hook nikdy nezablokuje repozitář, ve kterém není co vynucovat.

Požadavky profilu se vyhodnocují i pro completed: regression_test_required projde, když se dotčená cesta jeví jako test (test/, spec/, _test., .spec.); decision_record_required projde, když decisions.md obsahuje Task: <id>. Kontrola regrese je záměrně hrubá a říká to ve své zprávě.

Kontrakt pro completed:

scope respected        touched files within claimed paths
verification ran       --verify-command exited 0, recorded
state updated          current.yaml is at HEAD or advanced, not diverged
no open blockers       open-questions.md has no unresolved entry for this task
note present           newest handover or completion note has required sections

Každý řádek smlouvy se vyhodnotí a vypíše, ať projde, nebo ne, aby odmítnutí řeklo přesně, co chybí. partial a blocked vyžadují poznámku s # Next Action; no_match a failed vyžadují # Reason; všechny čtyři přeskakují řádek ověření a blocked přeskakuje řádek blokátorů. Když selže kterýkoli řádek, nic se nezapíše. Dokončení již dokončené úlohy se odmítne (15).

$ majordomus finish --outcome completed --verify-command "make test"
OK   scope         12 files, all within lib/auth
OK   verification  make test — exit 0, 41s
OK   state         exact (head 9b1e2d4)
FAIL blockers      open-questions.md: "token refresh window — needs product decision" unresolved  [reproduce: grep -n 'unresolved' .ai/local/state/open-questions.md]
OK   note          handover 20260903T201455Z--main--9b1e2d4--c0ffee.md
finish: refused, 1 unmet
blocking doctrines:
- majordomus.blocker-resolution
$ echo $?
10

Smlouva není seznam uvnitř finish. Je to sada doktrín, jejichž enforced_by jmenuje finish, vybraná verification.finish_requires tohoto repozitáře. Požadavek v politice, který nedefinuje žádná doktrína, se hlásí a odmítá, místo aby se ignoroval. Viz DOCTRINE.md.
