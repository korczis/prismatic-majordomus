**Execute against actual current repository.** First inspect canonical conventions and reconcile existing intent/milestone/issue/PR. Every issue must deliver a small vertical slice: typed source → projection → SSR → optional JS enhancement → tests → documented behavior → .ai enforcement when architectural → merged/released only when eligible.
