HTTP API: brief

What surrounds one working session, in one line and in a few: its episode and task, the peers of every board, the mesh, the integration queue and the derive queue, each section asked of its owner once and saying whether it could be read. The answer a session reports on itself from without being asked, and the one a provider mod shows as its status line (ADR 0136). Writes nothing.

brief

What surrounds one working session, in one line and in a few: its episode and task, the peers of every board, the mesh, the integration queue and the derive queue, each section asked of its owner once and saying whether it could be read. The answer a session reports on itself from without being asked, and the one a provider mod shows as its status line (ADR 0136). Writes nothing.

GET /api/v1/brief brief.session

The session brief

One line and a few: this session's episode and task (the one the given provider session owns, else the pointer's), the peers of every board with the boards that could not be read named, the mesh's links and what its journal addresses to this runtime, the integration queue as `majordomus prs brief` says it, and the machine's derive lock. Composed by the server holding this checkout's lease, which holds the board and the mesh: the command line asks it and composes the brief itself only when none answers, saying so; a superseded server says its own board is unreachable by the repository's gather. Carries the reporting interval the policy declares (`session.brief_interval_minutes`) and the keep-awake text a session is told at its start. Writes nothing.

  • behaviorally_verified
  • benchmark required
  • cache disabled
  • MCP tool majordomus_brief

Query parameters

nametyperequireddescriptionexamples
session string no The provider's own session identity (Claude Code's session id): the brief names the open episode that session owns. Absent, the episode the pointer resolves to. default: "00000000-0000-0000-0000-000000000000"
checkouts Checkouts no Which checkouts the peers section covers: `repository` (every board, the default) or `this`. default: "this"
local boolean no Compose in the process that answers and never ask the checkout's leaseholder: what a forwarded request says, so that it is never forwarded again. default: true

Try it

The port is whatever the server logged; 8741 is the one it asks for first. The values are the operation's first example.

curl -s "http://127.0.0.1:8741/api/v1/brief?session=00000000-0000-0000-0000-000000000000&checkouts=this&local=true"

Tested by apps/majordomus-cli/tests/http_serve.rs, which replays the route with these values against a server on a real socket.

Responses

statusbodymeaning
200 SessionBrief The session brief: the result.
400 ErrorBody invalid_input: The input does not fit the schema: a parameter of the wrong type, an unknown one, or a value the capability rejects.
404 ErrorBody not_found: The input names something the repository does not hold.
500 ErrorBody internal: The capability failed for a reason of its own; the message names it.
default ErrorBody Any other failure the transport reports: 405 method_not_allowed for another method on this path, 400 invalid_input for a body that is not a JSON object.

BriefSectionState

"read" | "partial" | "unread" | "undeclared"
Whether a section of the brief could be read.
  • readIts owner answered in full.
  • partialIts owner answered, and part of what it covers could not be asked; the summary says which.
  • unreadIts owner did not answer; the summary says why.
  • undeclaredThe repository declares nothing for it (no derive lock, a mesh switched off).
