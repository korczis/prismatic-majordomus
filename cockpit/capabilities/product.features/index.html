product.features

The features

What it is

Every product feature this repository declares, narrowed by any of the facets the model derives — featured, area, domain, module, command, surface, text — with the interfaces each is exposed through, the counts behind it and what is guaranteed about it, none of which its file states. The default is the stable set; pass status=any for the drafts too.

query
A query. It reads and changes nothing.

Only the features the homepage shows.

Only features of this status. Absent means the stable ones; pass `any` for everything the model holds.

Only features serving this operational area.

Only features filed under this product domain.

Only features made of this capability module.

Only features made of this shell command.

Only features exposed through this surface: `cli`, `api`, `mcp`, `cockpit`, `docs`.

Case-insensitive text, matched against the identity, the titles, the headline, the summary, the tags and the body.
