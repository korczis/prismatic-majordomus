Integrations

One repository.Every interface.

The same repository state reaches the command line, the HTTP API under /api/v1/, Swagger UI, the Cockpit, MCP and this site. Each capability is declared once: its HTTP route, OpenAPI operation and MCP tool are built from that declaration, and the command line is checked against it.
