How far a checkout is from the remote trunk: the one measurement behind project.a-checkout-serves-the-current-trunk.

On 2026-10-16 the primary checkout of this repository was 779 commits behind origin/master, and its shared server answered every session’s plan questions from that tree; the local master, which worktree create then used as a base, was as far behind. Nothing said so. This module says so: the checkout’s HEAD and the local trunk branch, each counted against the remote-tracking trunk, judged against the thresholds the policy declares under checkout.trunk_distance, and rendered by worktree status, by the shared server’s server.status, by the MCP initialize instructions and by doctor.

Everything is read from git on every call and nothing is fetched: the answer is “as of the last fetch”, and the time of that fetch is part of it. A remote trunk that cannot be named is unmeasured, a distance with no declared threshold is unjudged — neither is ever reported as current, and no threshold is invented here (ADR 0167 records the cooperation model that asks for an always-current checkout; this module is its measurement, not its restatement).

The measurement’s life, from git’s count to the word every surface shows:

use majordomus_cli::worktree::trunk::{judge, parse_left_right, TrunkStanding, TrunkThresholds};

// `git rev-list --left-right --count HEAD...origin/master` on the primary of 2026-10-16
let d = parse_left_right("0\t779").unwrap();
let declared: TrunkThresholds =
    serde_json::from_str(r#"{"warn_behind": 50, "fail_behind": 300}"#).unwrap();
let standing = judge(Some(d.behind), declared);
assert_eq!(standing, TrunkStanding::Stale);
assert_eq!(standing.as_str(), "stale");
// nothing declared: the same distance is reported, never judged current
assert_eq!(judge(Some(d.behind), TrunkThresholds::default()), TrunkStanding::Unjudged);

distance
How far the commits revs hold are from remote_trunk: the trunk’s commits none of them reaches (behind), and the first one’s commits the trunk lacks (ahead).

Judge a distance behind the remote trunk against the declared thresholds. Pure: every branch of the decision is a test.
measure
Measure the work tree worktree of a discovered repository against the remote trunk, judged by thresholds. Never fetches and writes nothing.
measure_checkout
Measure the checkout holding path with the thresholds its own policy declares. A path git cannot place in a repository is unmeasured, with git’s reason.
parse_left_right
Read rev-list --left-right --count output: the left side is ahead, the right behind.
remote_trunk_of
The remote-tracking ref of the trunk, short (origin/master): the trunk’s configured upstream, else the remote whose HEAD names the trunk, else the first remote that has a branch of the trunk’s name. None when no remote carries it.
