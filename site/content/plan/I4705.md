title = "I4705 — Every source reference in a tracked document resolves, checked by one capability, and a document declared live refuses a commit that leaves one of its references dangling"
description = "A read-only capability refs (CLI `majordomus refs check|index|impact`, MCP majordomus_refs_check, GET /api/v1/refs) reads the source references in tracked Markdown and judges each against the tree. A reference is an inline code span whose first segment is a tracked top-level entry, in one of the forms `path`, `path/`, `path:Symbol` or `path:line[-line]`, or a pathspec in a front-matter `tracks:` list. A file must be tracked. A directory must hold tracked files. A symbol must occur as a whole word in its file. A line must exist in the file, and a line reference whose document also quotes the cited text is judged against that text. A pathspec must match at least one file. `check` names each dangling reference with its document and line and exits 10. `index` answers the reverse index from each cited file to the documents that cite it. `impact <rev-range>` names the documents citing a file the range changed. The policy key `references.live` declares the documents, such as a capability matrix or a status table, whose references must always resolve. The derive step and the pre-commit doctor refuse a change that leaves one of them dangling, while any other document is reported only. A document whose front matter says `status: superseded` or `deprecated` is history and is not judged. The resolver is the one I4583 uses for outbound drafts, not a second one."
