description = "Slice S2 of milestone one-frame-one-kit-one-library-per-job. Vendor Flowbite JS from the npm flowbite 4.0.2 package.json already pins, built by scripts/cockpit-assets and scripts/site-build into the served tree and checked against the /ui and /cockpit CSP. Delete the collapse and dropdown of site/nav.js; move tabs, modal, drawer and tooltip (site/kit.js, site/search.js, the Cockpit palette, the graph detail panes) onto Flowbite's data attributes and its initialisers, re-run after a fragment swap. ADR 0230 (Flowbite Pro is adapted onto Tailwind 4) is proposed; this slice builds on it and asks the owner to accept it through the ADR process. The owner's order of 2026-11-07 does not name ADR 0230 and is not read as accepting it. Initialise per fragment: Flowbite's initDropdowns and its siblings construct a new instance for every matching element of the whole document, and the constructor binds listeners before the instance registry refuses a duplicate (node_modules/flowbite/dist/flowbite.js:6804-6820, 7026, 8336-8345), so re-running initFlowbite after a swap binds every existing toggle twice; a swapped fragment's elements are instantiated alone through the component constructors. Flowbite's Dropdown and Collapse have no Escape handling or focus return (only Drawer, Modal and Tooltip handle Escape, flowbite.js:6455, 7375, 8173), which site/nav.js:5-8 does today; the keyboard behaviour is kept by a core extension that drives Flowbite's instance API, never by reading the data attributes. The tab half of I3793 (one tab control on every surface) is delivered here as Flowbite tabs; I3793 keeps the copy control."
