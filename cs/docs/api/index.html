Majordomus

v1.0.0-alpha.10 OpenAPI 3.1.0MIT

Projekce AI vrstvy repozitáře: každé pravidlo, prompt, relace a projektový záznam pod .ai/, schopnosti, které je čtou, a deklarované příkazy, které je mění, zpřístupněné přes MCP, HTTP a příkazovou řádku z jednoho registru.

Jeden registr, každé rozhraní je projekce. Každá zdejší operace je schopnost registru a nic se nedeklaruje jen pro HTTP. operationId je kanonické id schopnosti; táž schopnost odpovídá jako nástroj MCP, který jmenuje x-majordomus-mcp, a jako příkaz, který jmenuje x-majordomus-cli, kde to její expozice říká, jedním executorem s jednou cache. Změna popisu nebo vstupního typu schopnosti se při příštím startu projeví v tomto dokumentu, schématu MCP, příkazové řádce a generované referenci; nic se neupravuje ručně.

Loopback, bez autentizace a explicitní v tom, co zapisuje. První majordomus mcp v repozitáři naváže tento server vedle své stdio relace a zaloguje URL; majordomus serve ho naváže samotný. Naslouchá na 127.0.0.1 a nežádá o žádné přihlašovací údaje: kdo se dostane k socketu, může číst vrstvu a spouštět každý příkaz, který zpřístupňuje. Operace, která mění sledovaný soubor, deklaruje efekt repository_mutation v x-majordomus-effect; vždy je to POST a nikdy ne nástroj MCP jen pro čtení, a každá další operace čte. GET / je domovská stránka a vypisuje každý povrch; /swagger je Swagger UI nad tímto dokumentem; /docs/ je vlastní dokumentace tohoto repozitáře; /mcp je MCP přes HTTP pro druhého klienta.

Binding. GET binds every top-level property of the capability's input as a query parameter, coerced by the schema's type (integers, numbers and booleans are parsed, everything else is text); POST binds the input as the JSON body. An unknown parameter is an invalid input, not ignored. Every failure is one JSON body, { "error": { "code", "message" } }: 400 invalid_input, 403 forbidden (a caller beyond loopback asking for anything but a read or a signed mesh message), 404 not_found, 409 conflict and 422 refused (a command's alone), 500 internal; 405 method_not_allowed names a path that exists under another method.

Příklady jsou případy měření výkonu. Každý příklad v tomto dokumentu je jedním z vlastních případů měření schopnosti, vstupem, který měření časují a testy přehrávají proti skutečnému socketu: operace bez příkladu je operace bez případu a spustitelný soubor se v tom stavu nezkompiluje. x-majordomus-benchmark a x-majordomus-cache nesou politiky; x-majordomus-stability a x-majordomus-provenance říkají, jak daleko je schopnost dokázána a kde byla deklarována.

Generováno, commitnuto, kontrolováno. Tento dokument se vykresluje z registru při každém požadavku a commituje jako docs/generated/openapi.json; majordomus generate --check jej odvodí znovu a zastaralou kopii odmítne a CI tuto kontrolu spouští při každém pushi, takže commitnutý dokument, obsluhovaný dokument a reference na webu jsou týž dokument.

Chyby

Každé selhání je jedno tělo JSON, {"error": {"code", "message"}} (ErrorBody). Stav jmenuje třídu; zpráva je pro člověka.

statuskódkdy
400invalid_inputVstup neodpovídá schématu: parametr špatného typu, neznámý parametr nebo hodnota, kterou schopnost odmítá.
404not_foundVstup jmenuje něco, co repozitář neobsahuje.
409conflictThe command contradicts what the server already holds, such as an idempotency key sent again with a different input; the message names what the key already started.
422odmítnutoPříkaz byl pochopen a odmítnut z důvodu, který uvádí zpráva.
500interníSchopnost selhala z vlastního důvodu; zpráva ho jmenuje.

  • convergence

    Zda je každá jednotka práce v tomto repozitáři někde, kde ji může najít jiný worker. Holding je cokoli, co může práci držet — pracovní strom s necommitnutými soubory, větev s commity, stash — a každý nese dispozici přečtenou z gitu: integrated (trunk na něj dosáhne), published (dosáhne na něj remote-tracking ref), local_only (commitnuto na tomto disku a nikde jinde) nebo uncommitted. Poslední dvě jsou ohrožené: jsou neviditelné pro každého jiného workera a worker, který skončí, není rollback. Měří se offline, jen z tohoto checkoutu; zda pro větev existuje pull request, je otázka na forge a tady se neklade.

  • rules

    Co tento repozitář odmítá a co dokáže pro každé odmítnutí skutečně ukázat. Pravidlo deklaruje třídu — blocking, kde kontrola práci odmítne, nebo advisory, kde se očekává, že si ho čtenář přečetl — a blok vynucování, který pojmenovává buď validátor, jejž volá dispatcher, nebo případy chování, které ho dokazují. Tento modul tuto deklaraci spojuje se stromem a s knihou zaznamenaných běhů a hlásí pro každé pravidlo, zda to, co pojmenovává, existuje, zda ho vlastní nějaký runner, zda byl někdy spuštěn, zda běh prošel a zda je běh starší než to, čeho se týká. Blokující pravidlo, jehož důkaz chybí, visí v prázdnu nebo selhává, je nález, protože pravidlo, které nikdo nedokáže prokázat, je pravidlo, které nikdo nevynucuje.
