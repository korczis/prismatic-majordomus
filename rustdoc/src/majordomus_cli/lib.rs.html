1//! Majordomus control-plane CLI.
2//!
3//! The library half of the executable. Dependencies flow inward toward the domain model:
4//!
5//! ```text
6//! cli / commands  ->  mcp (surface, protocol, stdio)  ->  index / model
7//!                     discovery, metadata, repository, git  ->  model, error
8//! ```
9//!
10//! Nothing below `commands` knows about clap; nothing below `mcp` knows about JSON-RPC; and
11//! the model knows nothing about either.

108/// Whether the tree [`COMMIT`] names carried uncommitted changes when this executable was
109/// built: `Some(true)` or `Some(false)` when the build knew, `None` when it did not — a
110/// commit handed in through `MAJORDOMUS_BUILD_COMMIT` without `MAJORDOMUS_BUILD_DIRTY`, or
111/// a build outside a work tree. It covers the crate's directory as the build script last saw
112/// it; [`build_identity::identify`] is the decision and holds its table.
113///
114/// Read with `option_env!`: a build-script output that predates the flag (a target directory
115/// shared across checkouts reuses one) must still compile, and what it did not record is
116/// unknown rather than a build failure.
117pub const DIRTY: Option<bool> = match option_env!("MAJORDOMUS_DIRTY") {
118    Some(v) => match v.as_bytes() {
119        b"true" => Some(true),
120        b"false" => Some(false),
121        _ => None,
122    },
123    None => None,
124};

126/// The generation this executable was built from: the digest `generation::crate_generation`
127/// takes over the crate sources, compiled in by `build.rs`, or `unknown` when the build
128/// could not read them.
129///
130/// [`VERSION`] says what this executable calls itself; this says what it *is*. Two builds
131/// of `majordomus-cli 0.4.0` from different revisions of the crate carry different models
132/// and derive a repository differently, and only this tells them apart — which is why
133/// `majordomus generate` compares it against the tree it is asked to derive rather than
134/// comparing versions.
135pub const GENERATION: &str = env!("MAJORDOMUS_GENERATION");
