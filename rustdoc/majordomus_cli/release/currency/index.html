Whether the trunk is released: how much landed work it holds past the last release, since when, and at which version (I3070).

The cooperation model’s fourth rule says the release seat releases whenever the trunk holds landed work past the last tag (project.the-cooperation-model-is-the-owners-word), and the owner’s order of 2026-10-19 asks for a measured version after every session and milestone. Neither was measured. The trunk could hold a day of landed work past the last release while every check, the brief, doctor and the delivery screen stayed green. This module is the one measurement: release.currency answers it, and every surface that shows it reads that answer.

Three readings make it, each of git as it is when asked:

  • The release. The newer of two: the release the layer records (super::compat::last_release), and the newest version tag the trunk contains. A tag is pushed before its record lands, so a tag newer than every record is a release that has happened and is not recorded yet.
  • The landed work. Every commit the trunk holds past that release, except merges and release commits (chore(release)): what the next release would ship.
  • How long it has waited. A landing is a commit of the trunk’s first-parent history: a merge of a branch or a top, or a commit made on the trunk itself. The work has waited since the oldest landing that brought anything but release commits arrived on the trunk: when this clone’s remote-tracking trunk first held it, from that ref’s reflog. A top is composed for hours before it is pushed, so its commit time says when it was made, not when it landed. Where the reflog does not show the landing arrive, the commit time is used as what it is, an upper bound on the wait, and alone it never makes the work overdue (LandedAt).

The answer reads refs and the clock, so it is a runtime read and is never committed. A committed derivation that read refs would go stale with every tag.

use majordomus_cli::release::currency::{measure, Currency, Stance, OVERDUE_AFTER};
use std::time::{Duration, SystemTime};

// a directory with no trunk is not measured, and the answer says why
let nowhere = tempfile::tempdir().unwrap();
let answer: Currency = measure(nowhere.path(), &[], SystemTime::now());
assert_eq!(answer.stance, Stance::Unknown);

// on a trunk, the stance follows the landed work and how long it has waited
assert_eq!(Stance::of(0, OVERDUE_AFTER), Stance::Current);
assert_eq!(Stance::of(3, Duration::from_secs(600)), Stance::Owed);
assert_eq!(Stance::of(3, OVERDUE_AFTER), Stance::Overdue);

How long landed work may wait past the last release before it is overdue: six hours, the release seat’s word (I3070). That is longer than a session, and shorter than the day of landed work the owner’s order closes.

Functions§

decide_next
Decide the version the public contract requires for the landed work, where it can be measured: the release the trunk is measured from must be recorded, because the contract is measured from a recorded release (ADR 0051), and this checkout must be at the trunk, because the contract is this tree’s. Otherwise next_unmeasured says which of the two it is not. Nothing is decided when nothing has landed.
measure
Measure the trunk of the repository at root against its last release, as of now. Git is read as it is, the remote-tracking trunk as of the last fetch. The version the contract requires is not decided here (decide_next), because that reads the last release’s registry, and the brief and doctor do not need it.
