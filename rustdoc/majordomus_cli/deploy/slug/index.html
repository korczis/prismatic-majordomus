Module slug 

Source
Expand description

The tree a provider receives, assembled from the deployment object at one commit (ADR 0219, decisions 3 and 4).

What is pushed to a provider is never the repository: not its history, not the checkout-local half, not a file the object does not name. It is built from three things, all read at one commit, and a fourth when the object declares one (ADR 0223):

  • the object’s build.inputs, except the package directory the executable is compiled from (render::runtime_inputs), read from git rather than from the working tree, so a file edited and not committed never reaches a provider;
  • the provider’s generated files (deploy/<provider>/), moved to the slug’s root where the provider reads them, each held to what the object renders at that commit and the hooks made executable;
  • the executable built at that same commit, installed at render::slug_executable, and the provider’s buildpack line (render::buildpack);
  • when the object declares build.site, the site the canonical pipeline built at that same commit (scripts/site-build --serve), carried at the declared path. Its surface.json says which commit it was built from, and a site built from any other commit is refused: a slug stays a function of one commit.

Beside them the slug carries one record, SOURCE_FILE, naming the deployment, the commit, the executable’s digest and the provider, so a person reading the slug can tell what it was assembled from without asking anyone.

The assembler writes only into a directory outside the checkout, absent or empty, and never into the repository: the only process it starts is git, read-only (crate::git::read_only). Pushing the result is a workflow’s work (.github/workflows/provider.yml), with a credential this module never sees.

use majordomus_cli::deploy::slug::{BUILDPACKS_FILE, SOURCE_FILE, SOURCE_SCHEMA};

// the record and the buildpack list sit beside the provider files, at fixed places
assert_eq!(SOURCE_FILE, ".majordomus/SOURCE.json");
assert_eq!(BUILDPACKS_FILE, ".buildpacks");
assert!(SOURCE_SCHEMA.ends_with("/v1"));
