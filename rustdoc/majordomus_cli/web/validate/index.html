Validation: the invariants a topology must satisfy before anything serves or publishes it.

A collision here is an error, never an ordering accident: two surfaces claiming one path is refused at the point it is discovered rather than resolved by whichever router happened to insert its route first. Every finding names the surface, the value, where the value came from and what to do about it, because a convention-heavy system that reports “invalid topology” is a system nobody can maintain.
