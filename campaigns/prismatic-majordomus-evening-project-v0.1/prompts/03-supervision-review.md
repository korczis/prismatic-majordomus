# Prompt 03 — Supervisory Review

For policy, context, state, coordination, budget, verification, handover, maintenance, and termination classify behavior as documented / represented / deterministically validated / enforced / measurable. Do not call documentation enforcement. Improve only lightweight high-value gaps. Explicitly separate guaranteed from advisory behavior. Add behavioral tests for deterministic guarantees. Reject servers, daemons, databases, MCP, background monitoring, and model invocation.
