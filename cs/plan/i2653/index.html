I2653 — Každý diagram na webu je jeden interaktivní, odkazovatelný prohlížeč, jehož odkazy uzlů se odvozují, a odvozenou tabulku lze nakreslit jako graf

Zařídit, aby každý diagram Mermaid, který web publikuje, šel přibližovat, posouvat, zobrazit na celou obrazovku, stáhnout a adresovat fragmentem (#diagram-<name>, a #diagram-<name>:<node> pro jeden uzel), přičemž uzel, který jmenuje pravidlo, rozhodnutí, příkaz, schopnost, úkol, milník nebo dokument, je s stránkou toho objektu spojen buildem, ne autorem diagramu; a nechat tabulku, kterou web už vykresluje z odvozených dat, nakreslit jako interaktivní graf Apache ECharts jejím deklarováním, bez druhé kopie čísel.

✓HOTOVO vlna 0 · p2 · profil implementation · bezpečné souběžně

Cíl

Zařídit, aby každý diagram Mermaid, který web publikuje, šel přibližovat, posouvat, zobrazit na celou obrazovku, stáhnout a adresovat fragmentem (#diagram-<name>, a #diagram-<name>:<node> pro jeden uzel), přičemž uzel, který jmenuje pravidlo, rozhodnutí, příkaz, schopnost, úkol, milník nebo dokument, je s stránkou toho objektu spojen buildem, ne autorem diagramu; a nechat tabulku, kterou web už vykresluje z odvozených dat, nakreslit jako interaktivní graf Apache ECharts jejím deklarováním, bez druhé kopie čísel.

Proč

ADR 0152. site/diagrams.js inicializoval Mermaid a nic víc: široký graf závislostí byl vodorovný posuvník, žádný diagram neměl adresu a uzel, který byl úkolem nebo pravidlem, byl text. Pravidlo project.a-diagram-is-drawn-not-typed říká, že zpracovatelný diagram je to, co umožňuje odkazování a kontrolu; nic to nevyužívalo. Web nekreslil žádný graf, ačkoli ADR 0135 jmenuje ECharts jako knihovnu pro měřené řady.

Aktuální stav

Každý <pre class=\"mermaid\"> se vykreslí v přirozené šířce uvnitř posouvatelného boxu. Nemá id, ovládací prvky ani odkazy. Runtime Mermaidu (nejtěžší soubor na webu) se načítá blokujícím tagem script. Čísla, která generátor odvozuje (úkoly na milník a stav, percentily měření výkonu), jsou jen tabulky.

Cílový stav

scripts/lib/diagrams.mjs pojmenuje každý diagram po buildu (výslovný data-diagram, jinak nadpis, pod kterým leží), vypíše jeho uzly a vedle něj zapíše odkazy, které odvodil z site/data/generated; site/diagrams.js z každého udělá stejný prohlížeč; scripts/ci/link-check řeší fragment uzlu proti deklarovaným uzlům diagramu; site/charts.js kreslí každý <figure data-chart> z tabulky uvnitř, přičemž vendorovaný build ECharts se stahuje, až když se graf blíží k viewportu; docs/DIAGRAMS.md je příručka.

Mimo rozsah

  • Domovská stránka: její příběh a rozpočet bajtů jsou deklarovány (site/data/homepage.toml) a podle rozhodnutí nenese žádný diagram; I2655 se na to ptá samostatně
  • Cockpit a majordomus ui: vykreslují vlastní grafy; sdílení tohoto prohlížeče s nimi je I2656
  • Vpisování odkazů do zdroje diagramu direktivou click v Mermaidu: odkaz se odvozuje z identity, nebo neexistuje

Závislosti

Žádné. Tento úkol je kořenem grafu.

Co na tom čeká

  • I2654○PŘIPRAVENO Graf je k své tabulce držen kontrolou a tabulky, které jsou měřenými řadami, se kreslí
  • I2655○PŘIPRAVENO Úvodní stránka rozhoduje, zda nese odvozený údaj, v mezích deklarovaného příběhu a rozpočtu
  • I2656○PŘIPRAVENO Prohlížeč diagramů slouží Cockpitu a majordomus ui a uzel, který je souborem repozitáře, odkazuje na svůj zdroj

Kritéria přijetí

  • Každý <pre class=\"mermaid\"> sestaveného webu nese jedinečné id diagram-<name>, seznam svých uzlů a tabindex=0; build, který by na stránce publikoval dva diagramy s jedním id, se odmítne
  • Uzel, jehož id nebo popisek je identitou objektu, pro který web má stránku, je vypsán vedle diagramu jako odkaz na tu stránku a scripts/ci/link-check vyřeší každý takový odkaz
  • Odkaz na #diagram-<name>:<node> je odmítnut scripts/ci/link-check, když diagram tento uzel nedeklaruje
  • V prohlížeči prohlížeč diagramů přibližuje, posouvá a resetuje z lišty nástrojů i z klávesnice, kopíruje svůj vlastní odkaz a otevře diagram a uzel, které fragment pojmenovává
  • <figure data-chart> se kreslí z tabulky uvnitř a tabulka na stránce zůstává
  • Ratchet ručně kreslených diagramů zůstává na diagrams=0
