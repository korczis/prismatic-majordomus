why.list

The catalogue

What it is

Every operational moment this repository holds, narrowed by any of the facets the catalogue itself reports, with the audiences, the areas, the derived filters and the counts. The default is the public catalogue; pass status=any for the drafts too.

A query. It reads and changes nothing.

Only moments this audience recognises.

Only moments in this operational area.

Only moments carrying this tag.

Only moments of this severity.

Only moments of this frequency.

Only moments at this stage of work.

Only moments naming this capability of the executable.

Only moments naming this command.

Only moments the homepage features.

Only moments of this status. Absent means the public ones (`stable`); pass `any` for everything the catalogue holds.

Case-insensitive text, matched against the identity, the titles, the hook, the summary, the tags, the aliases, the signals, the examples and the body.
