Start a session from a rendered framing, not a pasted transcript

List the prompt assets the repository ships, render one against the durable state, and read the context it embeds.

verified Sessions and handoverbasicagentread-only

Situation

Every new session starts with the same paragraph somebody types from memory, and the repository state it describes is whatever that person last remembered.

Outcome

The framing is a versioned file under .ai/repo/prompts/; rendering it embeds the assembled context, so the session starts from durable state and a budget, not from a paste.

The scenario

Executed against the real tool, in a repository prepared by installed, every time this site is generated. What follows is not a description of what should happen; it is what happened.

given

  • ·Majordomus installed; the skeleton ships its prompt assets

when

  1. 1majordomus prompt list
  2. 2majordomus prompt show nosuch
  3. 3majordomus context

then

  • ·a prompt is rendered against a closed set of state tokens
  • ·the context inside it is the same one `context` prints

Why the tool knows this

The chain from this page to the code: the use case names commands, rules and claims; each rule is dispatched from the registry and each claim names the test that proves it; the scenario above executed the commands. Nothing in this chain is prose about intent.

  • majordomus promptList, show and render the repository's own prompt assets, substituting known tokens only.
  • majordomus contextWhat the next worker needs to know now, in authority order and within a budget.

The rules that make it hold

  • blockingPrompt integrityEvery repository-local prompt asset renders, and every token in it is one the renderer knows.
  • blockingContext budgetThe always-loaded projection stays within its line budget, every reference in it resolves, it states no count that will go stale, and the assembled context fits the builder's own budget.

Guarantees exercised

  • guaranteedEvery repository-local prompt asset renders, and an unknown token is a failure
  • advisoryA profile declares which context a worker should load and no more
  • guaranteedThe context a worker is given is assembled from durable state in authority order, and what a profile excludes is excluded
  • guaranteedA repository-local prompt renders against a closed set of state tokens, and an unknown token is an error
