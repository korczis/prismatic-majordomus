HTTP API: skills

Každá dovednost, kterou vrstva definuje jako prokázanou schopnost: zda ji pojmenovává test a kniha důkazů drží aktuální úspěšný běh tohoto testu, zda web promítá její stránku, zda ji drží doktrína a kontrola v CI a zda ji vyvolává workflow, prompt, profil, šablona providera, recept nebo CI workflow. Všechny čtyři se odvozují při každém čtení a žádná se nepíše ručně; aktivní dovednost, kterou nepojmenovává žádný test nebo ji nic nevyvolává, je sirotek.

na této stránce

  • skills.status

  • skills.verify

skills

Každá dovednost, kterou vrstva definuje jako prokázanou schopnost: zda ji pojmenovává test a kniha důkazů drží aktuální úspěšný běh tohoto testu, zda web promítá její stránku, zda ji drží doktrína a kontrola v CI a zda ji vyvolává workflow, prompt, profil, šablona providera, recept nebo CI workflow. Všechny čtyři se odvozují při každém čtení a žádná se nepíše ručně; aktivní dovednost, kterou nepojmenovává žádný test nebo ji nic nevyvolává, je sirotek.

GET /api/v1/skills skills.status

Každá dovednost s odvozeným postavením

Každá dovednost, kterou index drží, každá s testy, které ji jmenují, a stavem důkazů jejich posledních běhů, její projekcí stránky, doktrínou a kontrolami, které ji drží, každým vyvoláním, které na ni odkazuje, a postavením, které z toho vyplývá: proven, partial, orphan, invalid nebo not_required pro dovednost ve stavu konceptu či zastaralou.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache vypnuta
  • nástroj MCP majordomus_skills
  • Zdroj MCP {"name": "skills", "uri": "majordomus://skills"}
  • $ skills status

Žádné parametry.

GET /api/v1/skills/explain skills.explain

Jedna dovednost se vším, co o ní bylo odvozeno

Jedna dovednost celá: její autorská identita, stav a značka původu, každý test, který ji jmenuje, se stavem posledního zaznamenaného běhu a příkazem, který ho reprodukuje, její stránka, doktrína a kontroly, každé vyvolání podle cesty a řádku, její postavení a zjištění o ní. Samotný soubor zůstává na `majordomus://skill/<id>`.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache vypnuta
  • MCP nástroj majordomus_skill_explain
  • $ skills explain

SkillEvidence

"proven" | "inputs_unchanged" | "stale" | "failing" | "not_run" | "unrunnable" | "untested"
Co kniha důkazů může říci o testech dovednosti jako celku: nejslabší stav testů, které ji jmenují, nebo untested, když ji nejmenuje žádný.

use majordomus_cli::skill::SkillEvidence;
assert!(SkillEvidence::Proven.current());
assert!(SkillEvidence::InputsUnchanged.current());
assert!(!SkillEvidence::Stale.current());
assert!(SkillEvidence::Proven < SkillEvidence::Untested);
  • provenKaždý test pojmenování má úspěšný běh a od té doby se změnil jen ledger.
  • inputs_unchangedKaždý test pojmenování prošel a od té doby se nezměnil ani test, ani dovednost.
  • staleÚspěšný běh existuje a test nebo dovednost se od té doby změnily.
  • failingPoslední zaznamenaný běh testu pojmenování neprošel.
  • not_runTest jmenuje dovednost a žádný její běh nebyl nikdy zaznamenán.
  • unrunnableTest pojmenuje dovednost podle cesty, kterou žádný runner neprovádí.
  • untestedŽádný test dovednost nepojmenovává.

Používá SkillStatus

SkillStanding

"proven" | "partial" | "orphan" | "invalid" | "not_required"
Kde dovednost stojí, odvozeno ze čtyř faktů.

use majordomus_cli::skill::SkillStanding;
assert_eq!(SkillStanding::Orphan.label(), "orphan");
  • provenAktivní a otestováno s aktuálními důkazy, zdokumentováno, vynucováno a používáno.
  • partialAktivní, pojmenovaný testem a vyvolávaný, s alespoň jedním dluhem, který jmenuje varování.
  • orphanAktivní a žádný test ho nepojmenovává, nebo ho nic nevyvolává.
  • invalidJeho soubor nesplňuje smlouvu dovednosti; i ten, který index zcela odmítl, je zde uveden, aby se výpis nikdy tiše nezkracoval.
  • not_requiredDraft nebo zastaralé: nic se nedluží.
