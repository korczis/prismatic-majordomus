1//! The context compiler: what a development session should be given, derived from the
2//! repository rather than composed by hand.
3//!
4//! # What this is for
5//!
6//! A session that is handed a large hand-written prompt is handed somebody's memory of the
7//! repository; a session that reads the repository from scratch on every request pays for
8//! discovery it has already paid for. This module is the third option: given an issue, a
9//! milestone, a free-text intent, some paths, or nothing at all, it derives the set of
10//! canonical objects that bear on the work, says why each one is in the set, says what it
11//! left out and why, and reports what the whole thing cost against a budget.
12//!
13//! # It is not a second context system
14//!
15//! `majordomus context` already assembles what a worker needs *now*: git, the active task,
16//! its profile, the directory contracts over its scope, the open questions, the decisions,
17//! the newest checkpoint, the most relevant handover, recent history — in authority order,
18//! within a line budget, printing what it dropped. That command is the session briefing and
19//! it stays the authority for it. What it cannot do is answer *about a piece of work* rather
20//! than about the present moment, and its output is text: its own JSON projection carries
21//! `sections[]` of `{id, lines, text}`, which is the assembled prose, not the selection.
22//!
23//! So this module keeps the same authority order — [`Tier`] is that order applied to
24//! objects instead of to sections — and changes three things:
25//!
26//! - **The unit is an object, not a section.** Every entry carries the canonical
27//!   identifier, the index's own provenance, the selector that reached it, the reason, the
28//!   confidence, the version and the cost. Nothing is flattened to text here; rendering a
29//!   prompt is a projection of this value and lives downstream of it.
30//! - **It is keyed on the work.** An issue, a milestone, an intent or a path, not only the
31//!   session that happens to be open.
32//! - **It deduplicates and explains.** The same ADR reached by four paths is one entry with
33//!   four recorded discoveries, and the answer says which paths those were.
34//!
35//! It also reuses rather than reimplements: the local records come from `continuity.state`,
36//! the typed relations from [`crate::graph::COMPOSED`] — the repository's own dependency
37//! graph, where every reference the layer declares is already resolved — and the objects
38//! from the index. There is no second relation table, no glob and no walk of the tree.
39//!
40//! One request reads source, and only when it says so: with `source_ranges`, the Rust files
41//! git tracks under the work's paths are parsed into one range per definition
42//! ([`source`]), bounded in files, bytes and ranges and guarded by the repository scope.
43//! Those ranges are candidates like any other, so the same budget spends them in the same
44//! order, and the answer says what reading the files whole would have cost instead.
45//!
46//! # The performance contract
47//!
48//! Nothing here is built when a [`crate::capability::Context`] is composed. The compiler
49//! runs inside its handler, over values already in memory, for the reason
50//! [`crate::plan`] states about the plan: "`App::load` has a stated budget and
51//! 200 project records have no business inside it." Deriving the composed graph over this
52//! repository is milliseconds; building the index is seconds, and it is built once per
53//! process. The answer carries the index fingerprint, so an answer is valid exactly as long
54//! as the index it was computed from, and a caller can tell two trees apart without asking.
55//!
56//! # A call, end to end
57//!
58//! The whole module is three functions over one input type. [`compile`] answers *what
59//! should this session be given*, [`explain`] answers *why is this one thing in or out of
60//! that*, and [`policy`] answers *by what rules* — the last needing no request at all,
61//! because the rules do not depend on what is being asked about.
62//!
63//! The request below names nothing, which is the smallest legitimate one: the governance
64//! applies to every session whether or not anybody asked for it, so the answer is not empty.
65//!
66//! ```
67//! use majordomus_cli::devcontext::{compile, explain, policy, CompileInput, ExplainInput};
68//! use majordomus_cli::devcontext::{Standing, Tier};
69//! use majordomus_cli::synthetic::SyntheticRepository;
70//!
71//! let repo = SyntheticRepository::small().unwrap();
72//! let ctx = repo.context().unwrap();
73//!
74//! // what should a session here be given, with nothing asked for?
75//! let compiled = compile(&ctx, CompileInput::default()).unwrap();
76//! assert!(
77//!     compiled.selected.iter().any(|e| e.kind == "policy"),
78//!     "the governance applies without being asked for",
79//! );
80//! assert_eq!(compiled.budget.tiers.len(), Tier::ORDER.len());
81//!
82//! // and why is that entry in it? — judged under the same request, so "excluded for
83//! // budget" is a statement about a budget the caller can see
84//! let first = compiled.selected[0].uri.clone();
85//! let why = explain(&ctx, ExplainInput { uri: first.clone(), request: CompileInput::default() })
86//!     .unwrap();
87//! assert_eq!(why.standing, Standing::Selected);
88//! assert_eq!(why.uri, first);
89//! assert!(why.entry.is_some() && !why.detail.is_empty());
90//!
91//! // something the index does not hold is `unknown`, not an error
92//! let absent = explain(
93//!     &ctx,
94//!     ExplainInput { uri: "majordomus://rule/nothing-like-this@1".into(), ..Default::default() },
95//! )
96//! .unwrap();
97//! assert_eq!(absent.standing, Standing::Unknown);
98//!
99//! // by what rules? — readable without a request, because they do not depend on one
100//! let rules = policy(&ctx).unwrap();
101//! assert_eq!(rules.tiers.len(), Tier::ORDER.len());
102//! assert!(rules.edges.iter().any(|e| e.refused), "and it says what it will not follow");
103//! ```

130/// What to compile a context about.
131///
132/// Every field is optional. A request that names nothing still gets an answer: the
133/// governance the layer applies to everything, and what the last session left — which is
134/// the smallest true context there is.
135///
136/// The seeds are additive, not alternative: `issue`, `milestone`, `uris`, `paths` and
137/// `intent` all contribute, and naming several is the normal case rather than a conflict.
138/// `intent` is the only one the compiler infers from, which is why every entry it produces
139/// carries [`Selector::IntentMatch`] and a confidence below one.
140///
141/// `deny_unknown_fields` is deliberate. This is the input of a served capability, so a
142/// misspelled field is a request that does not mean what its author thought; refusing it is
143/// the difference between a typo and a silently smaller answer.
144///
145/// ```
146/// use majordomus_cli::devcontext::CompileInput;
147/// use serde_json::json;
148///
149/// // the smallest legitimate request, which is not the same as no request
150/// let nothing: CompileInput = serde_json::from_value(json!({})).unwrap();
151/// assert_eq!(nothing, CompileInput::default());
152/// assert!(nothing.issue.is_none() && nothing.paths.is_empty());
153///
154/// // the seeds combine rather than compete
155/// let both: CompileInput = serde_json::from_value(json!({
156///     "issue": "I0301",
157///     "paths": ["apps/majordomus-cli/src"],
158///     "intent": "explain the budget",
159///     "budget_tokens": 4_000,
160/// })).unwrap();
161/// assert_eq!(both.issue.as_deref(), Some("I0301"));
162/// assert_eq!(both.paths, ["apps/majordomus-cli/src"]);
163/// assert_eq!(both.budget_tokens, Some(4_000));
164///
165/// // and a misspelled field is refused rather than quietly ignored
166/// let typo = serde_json::from_value::<CompileInput>(json!({"max_dept": 2}));
167/// assert!(typo.is_err(), "a typo must not become a smaller answer");
168/// ```
169#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize, JsonSchema)]
170#[serde(deny_unknown_fields)]
171pub struct CompileInput {
172    /// An issue id (`I0301`) or its canonical identifier. Its milestone, its dependencies,
173    /// its declared scope and the decisions over that scope follow from it.
174    #[serde(default, skip_serializing_if = "Option::is_none")]
175    pub issue: Option<String>,
176    /// A milestone id or slug, or its canonical identifier.
177    #[serde(default, skip_serializing_if = "Option::is_none")]
178    pub milestone: Option<String>,
179    /// What the session is trying to do, in words. The only input the compiler infers
180    /// from, and every entry it produces says so and carries a confidence below one.
181    #[serde(default, skip_serializing_if = "Option::is_none")]
182    pub intent: Option<String>,
183    /// Repository-relative paths the work touches, added to whatever the seeds declare.
184    #[serde(default, skip_serializing_if = "Vec::is_empty")]
185    pub paths: Vec<String>,
186    /// Canonical identifiers to seed with directly, for a request about something that is
187    /// neither an issue nor a milestone.
188    #[serde(default, skip_serializing_if = "Vec::is_empty")]
189    pub uris: Vec<String>,
190    /// The ceiling in estimated tokens; [`DEFAULT_BUDGET_TOKENS`] when absent.
191    #[serde(default, skip_serializing_if = "Option::is_none")]
192    pub budget_tokens: Option<u64>,
193    /// How far from a seed the walk goes; [`DEFAULT_MAX_DEPTH`] when absent.
194    #[serde(default, skip_serializing_if = "Option::is_none")]
195    pub max_depth: Option<usize>,
196    /// Relevance below which an entry is reported rather than given; [`DEFAULT_FLOOR`]
197    /// when absent.
198    #[serde(default, skip_serializing_if = "Option::is_none")]
199    pub floor: Option<f64>,
200    /// Every blocking rule of the layer, not only the ones the work reaches. Honest and
201    /// usually over budget: the answer then says `over_budget` rather than dropping what it
202    /// may not drop.
203    #[serde(default, skip_serializing_if = "Option::is_none")]
204    pub all_blocking_rules: Option<bool>,
205    /// Outline the Rust source under the work's paths into ranges, one candidate per
206    /// definition, spent by the same budget beside the layer's objects ([`source`]).
207    ///
208    /// Off unless asked for: it reads files the index does not hold, and an answer every
209    /// existing caller already depends on — `economics measure` counts the files a context
210    /// names — does not change under it.
211    #[serde(default, skip_serializing_if = "Option::is_none")]
212    pub source_ranges: Option<bool>,
213}

272/// What one identifier's standing in a compiled context is.
273/// Where one identifier stands with respect to a compiled context.
274///
275/// The pair to be careful about is `NotReached` and `Unknown`, because they look alike in a
276/// rendering and mean opposite things. `NotReached` says the index holds the object and this
277/// request did not reach it — the request is what to change, and raising the depth or the
278/// budget may well bring it in. `Unknown` says the index holds nothing under that
279/// identifier: the request is fine and the identifier is wrong, or the object is not in
280/// this repository. Collapsing the two would send a reader to tune a request that was never
281/// the problem.
282///
283/// `Deduplicated` is the third one worth naming: the thing is *in* the answer, under another
284/// identifier, which is neither in nor out.
285///
286/// ```
287/// use majordomus_cli::devcontext::Standing;
288///
289/// // in the answer, one way or another
290/// let present = [Standing::Selected, Standing::Deduplicated];
291/// // reached and not given, so the request is what to change
292/// let request_bound = [Standing::Excluded, Standing::NotReached];
293/// for s in present {
294///     assert!(!request_bound.contains(&s));
295/// }
296///
297/// // the two that must not be confused: one is the request's fault, one is not
298/// assert_eq!(Standing::NotReached.as_str(), "not_reached");
299/// assert_ne!(Standing::NotReached, Standing::Unknown);
300/// assert_eq!(
301///     serde_json::to_value(Standing::NotReached).unwrap(),
302///     serde_json::json!(Standing::NotReached.as_str()),
303/// );
304/// ```
305#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
306#[serde(rename_all = "snake_case")]
307// `worktree` already answers with a `Standing` about a branch, and the OpenAPI document has
308// one component namespace: two enums under one name would be one component defined twice.
309#[schemars(rename = "DevContextStanding")]
310pub enum Standing {
311    /// In the answer.
312    Selected,
313    /// Reached and not given; the exclusion says why.
314    Excluded,
315    /// Folded into another identifier, or dropped for one.
316    Deduplicated,
317    /// The index holds it and this request never reached it.
318    NotReached,
319    /// The index holds nothing under that identifier.
320    Unknown,
321}
322
323impl Standing {
324    /// The word this standing is reported under.
325    ///
326    /// ```
327    /// use majordomus_cli::devcontext::Standing;
328    /// assert_eq!(Standing::NotReached.as_str(), "not_reached");
329    /// ```
330    pub fn as_str(self) -> &'static str {
331        match self {
332            Standing::Selected => "selected",
333            Standing::Excluded => "excluded",
334            Standing::Deduplicated => "deduplicated",
335            Standing::NotReached => "not_reached",
336            Standing::Unknown => "unknown",
337        }
338    }

341/// The input of `devcontext.explain`: one identifier, and the request to judge it under.
342///
343/// The request is not optional context for the question — it is half of the question.
344/// "Why is this ADR not in my context" has no answer in the abstract: it is in or out of a
345/// *particular* compiled answer, and "excluded for budget" is only actionable when the
346/// budget it did not fit in is known. So the same fields `compile` takes are `flatten`ed in
347/// here, which also means the wire form is one flat object rather than a nested `request`,
348/// and the command line can share its flags.
349///
350/// ```
351/// use majordomus_cli::devcontext::ExplainInput;
352/// use serde_json::json;
353///
354/// // flattened: the request's fields sit beside `uri`, not under it
355/// let input: ExplainInput = serde_json::from_value(json!({
356///     "uri": "majordomus://adr/0052",
357///     "budget_tokens": 2_000,
358///     "max_depth": 1,
359/// })).unwrap();
360/// assert_eq!(input.uri, "majordomus://adr/0052");
361/// assert_eq!(input.request.budget_tokens, Some(2_000));
362/// assert_eq!(input.request.max_depth, Some(1));
363///
364/// // and the identifier alone is a complete question, judged under the default request
365/// let bare: ExplainInput = serde_json::from_value(json!({"uri": "majordomus://adr/0052"}))
366///     .unwrap();
367/// assert_eq!(bare.request, Default::default());
368/// ```
369#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize, JsonSchema)]
370#[serde(deny_unknown_fields)]
371pub struct ExplainInput {
372    /// The canonical identifier to explain.
373    pub uri: String,
374    /// The request it would be compiled under; the same fields as `devcontext.compile`.
375    #[serde(default, flatten)]
376    pub request: CompileInput,
377}

408/// Why one identifier is, or is not, in a compiled context.
409///
410/// `standing` says which of the five cases this is, and the three optional fields are the
411/// evidence for it: at most one of `entry`, `excluded` and `deduplicated` is populated, and
412/// which one is determined by the standing rather than independent of it. `detail` is the
413/// same answer in words, so the value is legible without a reader matching them up.
414///
415/// `budget` is always present, including when the answer is `unknown`, and that is the
416/// point of carrying it: the commonest reason to ask this question is an entry that did not
417/// fit, and an explanation that said "excluded for budget" without the budget would need a
418/// second call to act on.
419///
420/// ```
421/// use majordomus_cli::devcontext::{compile, explain, CompileInput, ExplainInput};
422/// use majordomus_cli::devcontext::{Explanation, Standing};
423/// use majordomus_cli::synthetic::SyntheticRepository;
424///
425/// let repo = SyntheticRepository::small().unwrap();
426/// let ctx = repo.context().unwrap();
427/// let compiled = compile(&ctx, CompileInput::default()).unwrap();
428/// let selected = compiled.selected[0].uri.clone();
429///
430/// // something in the answer: the entry is the evidence, and the other two are empty
431/// let e: Explanation =
432///     explain(&ctx, ExplainInput { uri: selected.clone(), ..Default::default() }).unwrap();
433/// assert_eq!(e.standing, Standing::Selected);
434/// assert_eq!(e.entry.as_ref().unwrap().uri, selected);
435/// assert!(e.excluded.is_none() && e.deduplicated.is_none());
436/// assert!(!e.detail.is_empty(), "the standing always reads as a sentence too");
437///
438/// // something this repository does not hold: an answer, not an error — and the budget
439/// // the judgement was made under is carried even here
440/// let absent: Explanation = explain(
441///     &ctx,
442///     ExplainInput { uri: "majordomus://adr/9999".into(), ..Default::default() },
443/// )
444/// .unwrap();
445/// assert_eq!(absent.standing, Standing::Unknown);
446/// assert!(absent.entry.is_none());
447/// assert_eq!(absent.budget.limit_tokens, compiled.budget.limit_tokens);
448/// ```
449#[derive(Debug, Clone, PartialEq, Serialize, Deserialize, JsonSchema)]
450pub struct Explanation {
451    /// What was asked about.
452    pub uri: String,
453    /// Where it stands.
454    pub standing: Standing,
455    /// The same, in words.
456    pub detail: String,
457    /// The entry, when it is in the answer.
458    #[serde(default, skip_serializing_if = "Option::is_none")]
459    pub entry: Option<ContextEntry>,
460    /// The exclusion, when it was reached and not given.
461    #[serde(default, skip_serializing_if = "Option::is_none")]
462    pub excluded: Option<Excluded>,
463    /// The collapse it was part of, when it was folded or dropped for another.
464    #[serde(default, skip_serializing_if = "Option::is_none")]
465    pub deduplicated: Option<Deduplicated>,
466    /// The budget the judgement was made under, so that "excluded for budget" can be acted
467    /// on without a second call.
468    pub budget: Budget,
469}

471/// One tier, as the policy reports it: its place in the spend order, what it is for, and
472/// which kinds of object land in it.
473///
474/// `position` is 1-based and exists because the wire form has no inherent order a consumer
475/// can rely on — the [`Tier`] enum's `Ord` is a Rust fact, not a JSON one — so the rank is
476/// made explicit for the readers that are not this crate. `kinds` is the inverse of
477/// [`tier_for_kind`], published so that a caller can see where a kind will land without
478/// compiling an answer and looking.
479///
480/// ```
481/// use majordomus_cli::devcontext::{policy, tier_for_kind, Tier, TierRule};
482/// use majordomus_cli::synthetic::SyntheticRepository;
483///
484/// let repo = SyntheticRepository::small().unwrap();
485/// let ctx = repo.context().unwrap();
486/// let rules = policy(&ctx).unwrap();
487///
488/// // the first tier spent is the one that is never dropped, at position 1
489/// let first: &TierRule = &rules.tiers[0];
490/// assert_eq!(first.tier, Tier::Task);
491/// assert_eq!(first.position, 1, "1-based, so the order survives serialisation");
492///
493/// // every tier is reported, in the order the budget spends in, and explains itself
494/// assert_eq!(rules.tiers.len(), Tier::ORDER.len());
495/// for (i, r) in rules.tiers.iter().enumerate() {
496///     assert_eq!(r.position, i + 1);
497///     assert_eq!(r.meaning, r.tier.meaning());
498/// }
499///
500/// // and every kind is listed under the tier the classifier puts it in, exactly once —
501/// // so the published table and the function behind it cannot disagree
502/// let mut listed = 0usize;
503/// for r in &rules.tiers {
504///     for kind in &r.kinds {
505///         assert_eq!(tier_for_kind(kind), r.tier, "{kind} is listed under the wrong tier");
506///         listed += 1;
507///     }
508/// }
509/// let mut all: Vec<&str> = rules.tiers.iter().flat_map(|r| &r.kinds).map(String::as_str).collect();
510/// all.sort();
511/// all.dedup();
512/// assert_eq!(all.len(), listed, "a kind is listed under one tier only");
513/// ```
514#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
515pub struct TierRule {
516    /// The tier.
517    pub tier: Tier,
518    /// Its position in the order the budget spends in; 1 is spent first.
519    pub position: usize,
520    /// What it is for.
521    pub meaning: String,
522    /// The kinds of object that land in it.
523    pub kinds: Vec<String>,
524}

526/// One edge of the composed graph, and what the compiler does with it.
527///
528/// Every edge kind the graph declares gets a row, followed or not, which is the property
529/// that makes this projection worth reading: an edge added to the graph and not to the
530/// traversal table appears here as `refused` with a reason saying the compiler has no rule
531/// for it, rather than being silently unfollowed. A table that only listed the edges it
532/// followed could not tell you what it was ignoring.
533///
534/// `forward` and `reverse` are absent rather than zero when the edge is not followed that
535/// way, so "not followed" is one representation and not two. `means` is the graph's own
536/// account of the relation; `reason` is this compiler's account of why it is or is not
537/// context, in both directions.
538///
539/// ```
540/// use majordomus_cli::devcontext::{edge_policy, policy, EdgeRule};
541/// use majordomus_cli::synthetic::SyntheticRepository;
542///
543/// let repo = SyntheticRepository::small().unwrap();
544/// let ctx = repo.context().unwrap();
545/// let rules = policy(&ctx).unwrap();
546///
547/// // one row per edge kind the graph declares, followed or refused
548/// let edges: &[EdgeRule] = &rules.edges;
549/// assert!(!edges.is_empty(), "the graph declares edges");
550/// for e in edges {
551///     // the row always says what the relation is and what was decided about it
552///     assert!(!e.means.is_empty() && !e.reason.is_empty(), "{}", e.edge);
553///
554///     if e.refused {
555///         // not followed in either direction, and absent rather than zero
556///         assert!(e.forward.is_none() && e.reverse.is_none(), "{}", e.edge);
557///         assert!(edge_policy(&e.edge).is_none(), "{} is refused and in the table", e.edge);
558///     } else {
559///         // followed at least one way, at a weight the table declares
560///         assert!(e.forward.is_some() || e.reverse.is_some(), "{}", e.edge);
561///         let p = edge_policy(&e.edge).expect("a followed edge has a policy");
562///         assert_eq!(e.forward, (p.forward > 0.0).then_some(p.forward));
563///         assert_eq!(e.reverse, (p.reverse > 0.0).then_some(p.reverse));
564///     }
565/// }
566/// ```
567#[derive(Debug, Clone, PartialEq, Serialize, Deserialize, JsonSchema)]
568pub struct EdgeRule {
569    /// The edge kind, as the composed graph names it.
570    pub edge: String,
571    /// What the graph asserts by it.
572    pub means: String,
573    /// The relevance multiplier when followed source to target; absent when refused.
574    #[serde(default, skip_serializing_if = "Option::is_none")]
575    pub forward: Option<f64>,
576    /// The multiplier when followed target to source; absent when refused.
577    #[serde(default, skip_serializing_if = "Option::is_none")]
578    pub reverse: Option<f64>,
579    /// Why the target is context for the source, or why the edge is refused.
580    pub reason: String,
581    /// True when the compiler will not follow it in either direction.
582    pub refused: bool,
583}

585/// One selector, and whether what it produces was declared or inferred.
586///
587/// Two fields, and the second is the whole reason the projection exists: a caller consuming
588/// a compiled context needs to know which selectors it can trust as repository fact, and
589/// deriving that from the answer would mean inferring it from confidence values. Published
590/// here, it is a rule rather than a pattern a reader noticed.
591///
592/// ```
593/// use majordomus_cli::devcontext::{policy, Selector, SelectorRule};
594/// use majordomus_cli::synthetic::SyntheticRepository;
595///
596/// let repo = SyntheticRepository::small().unwrap();
597/// let ctx = repo.context().unwrap();
598/// let rules = policy(&ctx).unwrap();
599///
600/// // every selector is published, and each row agrees with the selector it names
601/// let selectors: &[SelectorRule] = &rules.selectors;
602/// assert_eq!(selectors.len(), Selector::ALL.len());
603/// for r in selectors {
604///     assert_eq!(r.declared, r.selector.declared());
605/// }
606///
607/// // and the inferring one is named, so the guessed half of an answer can be found
608/// let inferred: Vec<Selector> =
609///     selectors.iter().filter(|r| !r.declared).map(|r| r.selector).collect();
610/// assert_eq!(inferred, [Selector::IntentMatch]);
611/// ```
612#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
613pub struct SelectorRule {
614    /// The selector.
615    pub selector: Selector,
616    /// Declared by the repository, or inferred by the compiler.
617    pub declared: bool,
618}

620/// The compiler's own rules, so that a caller reads the decision instead of inferring it
621/// from an answer.
622///
623/// This is the answer to "why did I get that", asked once rather than reverse-engineered
624/// from every context. It is a projection of the tables and constants this module is built
625/// from — [`Tier::ORDER`], [`select::EDGES`], [`Selector::ALL`] and the four defaults
626/// — and holds no numbers of its own, so the published rules and the code that applies them
627/// cannot drift apart.
628///
629/// The defaults are here because they are what a request gets when it says nothing, and a
630/// caller tuning a request needs to know what it is tuning away from.
631///
632/// ```
633/// use majordomus_cli::devcontext::{policy, CompilerPolicy, Selector, Tier};
634/// use majordomus_cli::devcontext::{BYTES_PER_TOKEN, DEFAULT_BUDGET_TOKENS};
635/// use majordomus_cli::devcontext::{DEFAULT_FLOOR, DEFAULT_MAX_DEPTH};
636/// use majordomus_cli::graph;
637/// use majordomus_cli::synthetic::SyntheticRepository;
638///
639/// let repo = SyntheticRepository::small().unwrap();
640/// let ctx = repo.context().unwrap();
641/// let rules: CompilerPolicy = policy(&ctx).unwrap();
642///
643/// // it names the graph it reads relations from, rather than leaving it to be guessed
644/// assert_eq!(rules.schema, 1);
645/// assert_eq!(rules.graph, graph::COMPOSED);
646///
647/// // the three tables are complete
648/// assert_eq!(rules.tiers.len(), Tier::ORDER.len());
649/// assert_eq!(rules.selectors.len(), Selector::ALL.len());
650/// assert!(!rules.edges.is_empty());
651///
652/// // and the published defaults are the constants a silent request actually gets
653/// assert_eq!(rules.default_budget_tokens, DEFAULT_BUDGET_TOKENS);
654/// assert_eq!(rules.default_max_depth, DEFAULT_MAX_DEPTH);
655/// assert_eq!(rules.default_floor, DEFAULT_FLOOR);
656/// assert_eq!(rules.bytes_per_token, BYTES_PER_TOKEN);
657/// ```
658#[derive(Debug, Clone, PartialEq, Serialize, Deserialize, JsonSchema)]
659pub struct CompilerPolicy {
660    /// The format of this answer.
661    pub schema: u64,
662    /// The graph the relations are read from.
663    pub graph: String,
664    /// The tiers, in the order the budget spends in.
665    pub tiers: Vec<TierRule>,
666    /// Every edge kind the composed graph has, followed or refused.
667    pub edges: Vec<EdgeRule>,
668    /// The selectors, and which of them infer.
669    pub selectors: Vec<SelectorRule>,
670    /// The default ceiling in estimated tokens.
671    pub default_budget_tokens: u64,
672    /// The default depth limit.
673    pub default_max_depth: usize,
674    /// The default relevance floor.
675    pub default_floor: f64,
676    /// Bytes per estimated token.
677    pub bytes_per_token: u64,
678}

682fn normalise(path: &str) -> Result<String, CapabilityError> {
683    let p = path.trim().trim_start_matches("./").trim_end_matches('/');
684    if p.is_empty() {
685        return Err(CapabilityError::InvalidInput(
686            "an empty path is not a scope".into(),
687        ));
688    }
689    if p.starts_with('/') || p.split('/').any(|s| s == "..") {
690        return Err(CapabilityError::InvalidInput(format!(
691            "'{path}' is not repository-relative; a path outside the repository is not context"
692        )));
693    }
694    Ok(p.to_string())
695}

697/// Resolve one short name to the canonical identifier of an object of `kind`.
698fn resolve_seed(
699    ctx: &Context,
700    kind: &str,
701    named: &str,
702    field: &str,
703) -> Result<Seed, CapabilityError> {
704    let named = named.trim();
705    if named.is_empty() {
706        return Err(CapabilityError::InvalidInput(format!(
707            "{field}: name one, or leave it out"
708        )));
709    }
710    let hit = ctx.index.objects.iter().find(|o| {
711        o.kind == kind
712            && (o.uri == named
713                || o.identity == named
714                || o.metadata.get("slug").and_then(|v| v.as_str()) == Some(named))
715    });
716    match hit {
717        Some(o) => Ok(Seed {
718            uri: o.uri.clone(),
719            kind: o.kind.clone(),
720            from: field.to_string(),
721            resolved: (o.identity != named).then(|| o.identity.clone()),
722        }),
723        None => Err(CapabilityError::NotFound(format!(
724            "no {kind} '{named}' in this repository; `objects.list` with kind `{kind}` names every one"
725        ))),
726    }
727}

729/// Compile a context. The one entry point; every projection calls this.
730///
731/// The whole call runs over values the process already holds — the index and the composed
732/// graph derived from it — so it reads no file and walks no tree, which is what lets it sit
733/// inside a handler rather than at load time.
734///
735/// It fails only on a request that cannot mean anything: a budget of zero, a relevance floor
736/// outside 0..=1, a path that is not repository-relative, or a named seed this repository
737/// does not hold. Everything else is an answer. In particular a request that names nothing
738/// is valid and does not produce an empty context — the governance applies to every session
739/// whether or not it was asked for.
740///
741/// The budget is a ceiling on what the compiler *chooses*, not on what it must keep: seeds,
742/// the policy and the scope are never dropped, so an answer can come back over budget and
743/// says so rather than omitting the thing it was compiled about.
744///
745/// ```
746/// use majordomus_cli::capability::CapabilityError;
747/// use majordomus_cli::devcontext::{compile, CompileInput, Tier};
748/// use majordomus_cli::synthetic::SyntheticRepository;
749///
750/// let repo = SyntheticRepository::small().unwrap();
751/// let ctx = repo.context().unwrap();
752///
753/// // the governance arrives without being asked for, and cannot be dropped
754/// let c = compile(&ctx, CompileInput::default()).unwrap();
755/// let required: Vec<&str> = c
756///     .selected
757///     .iter()
758///     .filter(|e| e.required)
759///     .map(|e| e.kind.as_str())
760///     .collect();
761/// assert!(required.contains(&"policy"), "what every session is held to: {required:?}");
762/// assert!(c.selected.iter().all(|e| e.tier >= Tier::Task));
763///
764/// // a tiny ceiling still keeps what may not be dropped, and says it went over
765/// let squeezed = compile(
766///     &ctx,
767///     CompileInput { budget_tokens: Some(1), ..Default::default() },
768/// )
769/// .unwrap();
770/// assert!(squeezed.selected.iter().any(|e| e.required));
771/// assert!(squeezed.budget.over_budget);
772/// assert_eq!(squeezed.budget.limit_tokens, 1);
773///
774/// // and the refusals are requests that could not mean anything
775/// assert!(matches!(
776///     compile(&ctx, CompileInput { budget_tokens: Some(0), ..Default::default() }),
777///     Err(CapabilityError::InvalidInput(_)),
778/// ));
779/// assert!(matches!(
780///     compile(&ctx, CompileInput { floor: Some(1.5), ..Default::default() }),
781///     Err(CapabilityError::InvalidInput(_)),
782/// ));
783/// assert!(matches!(
784///     compile(&ctx, CompileInput { paths: vec!["/etc".into()], ..Default::default() }),
785///     Err(CapabilityError::InvalidInput(_)),
786/// ));
787/// assert!(matches!(
788///     compile(&ctx, CompileInput { issue: Some("I9999".into()), ..Default::default() }),
789///     Err(CapabilityError::NotFound(_)),
790/// ));
791/// ```
792pub fn compile(ctx: &Context, input: CompileInput) -> Result<CompiledContext, CapabilityError> {
793    let index = ctx.index.as_ref();
794    let limit = input.budget_tokens.unwrap_or(DEFAULT_BUDGET_TOKENS);
795    if limit == 0 {
796        return Err(CapabilityError::InvalidInput(
797            "a budget of zero tokens buys nothing; leave it out for the default".into(),
798        ));
799    }
800    let max_depth = input.max_depth.unwrap_or(DEFAULT_MAX_DEPTH);
801    let floor = input.floor.unwrap_or(DEFAULT_FLOOR);
802    if !(0.0..=1.0).contains(&floor) {
803        return Err(CapabilityError::InvalidInput(format!(
804            "the relevance floor is between 0 and 1; got {floor}"
805        )));
806    }
807
808    // ---- the seeds
809    let mut seeds: Vec<Seed> = Vec::new();
810    if let Some(named) = &input.issue {
811        seeds.push(resolve_seed(ctx, "issue", named, "issue")?);
812    }
813    if let Some(named) = &input.milestone {
814        seeds.push(resolve_seed(ctx, "milestone", named, "milestone")?);
815    }
816    for uri in &input.uris {
817        let o = index
818            .objects
819            .iter()
820            .find(|o| o.uri == *uri)
821            .ok_or_else(|| {
822                CapabilityError::NotFound(format!("the index holds nothing under `{uri}`"))
823            })?;
824        seeds.push(Seed {
825            uri: o.uri.clone(),
826            kind: o.kind.clone(),
827            from: "uris".into(),
828            resolved: None,
829        });
830    }
831    let mut requested_paths = BTreeSet::new();
832    for p in &input.paths {
833        let p = normalise(p)?;
834        requested_paths.insert(p.clone());
835        seeds.push(Seed {
836            uri: p.clone(),
837            kind: "path".into(),
838            from: "paths".into(),
839            resolved: None,
840        });
841    }
842    if let Some(intent) = &input.intent {
843        if !intent.trim().is_empty() {
844            seeds.push(Seed {
845                uri: intent.trim().to_string(),
846                kind: "intent".into(),
847                from: "intent".into(),
848                resolved: None,
849            });
850        }
851    }
852
853    let object_seeds: BTreeSet<String> = seeds
854        .iter()
855        .filter(|s| s.kind != "path" && s.kind != "intent")
856        .map(|s| s.uri.clone())
857        .collect();
858
859    let terms = input
860        .intent
861        .as_deref()
862        .map(intent_terms)
863        .unwrap_or_default();
864
865    // whole: a selection over a prefix would miss every object sorted past MAX_NODES
866    let graph = crate::graph::composed_complete(&ctx.registry, index);
867
868    let request = select::Request {
869        seeds: object_seeds.iter().cloned().collect(),
870        paths: requested_paths,
871        terms,
872        max_depth,
873        floor,
874        all_blocking_rules: input.all_blocking_rules.unwrap_or(false),
875        branch: match &index.repository.git {
876            crate::git::GitState::Available(info) => info.branch.as_deref(),
877            _ => None,
878        },
879    };
880    let mut selection = select::select(ctx, &graph, &request);
881
882    // the Rust source under the effective paths, one candidate per definition, spent by the
883    // same budget in the same order as everything else (`source` is the one reader of files)
884    let paths = std::mem::take(&mut selection.paths);
885    let outlined = if input.source_ranges.unwrap_or(false) {
886        source::offer(ctx, &mut selection, &paths, &request.terms)
887    } else {
888        source::Outlined::default()
889    };
890
891    // what stands in for what, from the graph's own edges rather than from a second read
892    let mut supersedes: BTreeMap<String, Vec<String>> = BTreeMap::new();
893    for e in &graph.edges {
894        if e.kind == "supersedes" {
895            supersedes
896                .entry(e.source.clone())
897                .or_default()
898                .push(e.target.clone());
899        }
900    }
901
902    let (spend, diagnostics) = budget::spend(index, selection, &object_seeds, limit, &supersedes);
903    let sources = source_coverage(outlined, &spend.selected);
904
905    // the commits the layer itself names, gathered from what was selected
906    let mut commits = Vec::new();
907    for entry in &spend.selected {
908        let Some(i) = index.objects.iter().position(|o| o.uri == entry.uri) else {
909            continue;
910        };
911        let Some(evidence) = index.objects[i]
912            .metadata
913            .get("evidence")
914            .and_then(|v| v.as_array())
915        else {
916            continue;
917        };
918        for e in evidence {
919            let Some(commit) = e.get("commit").and_then(|v| v.as_str()) else {
920                continue;
921            };
922            commits.push(CommitReference {
923                commit: commit.to_string(),
924                named_by: entry.uri.clone(),
925                covers: e.get("covers").and_then(|v| v.as_str()).map(str::to_string),
926            });
927        }
928    }
929    // One BTreeSet folds the repeats — a commit named twice by the same record is one fact
930    // — and the canonical order is what the answer is read in.
931    let mut commits: Vec<CommitReference> = commits
932        .into_iter()
933        .collect::<BTreeSet<_>>()
934        .into_iter()
935        .collect();
936    crate::order::canonical(&mut commits);
937
938    let git = match &index.repository.git {
939        crate::git::GitState::Available(info) => GitContext {
940            branch: info.branch.clone(),
941            head: info.head.clone(),
942            working_tree: info.working_tree.clone(),
943            commits,
944        },
945        crate::git::GitState::Unavailable { reason } => GitContext {
946            branch: None,
947            head: None,
948            working_tree: format!("unavailable: {reason}"),
949            commits,
950        },
951    };
952
953    Ok(CompiledContext {
954        schema: 1,
955        fingerprint: index.fingerprint.clone(),
956        git,
957        seeds,
958        selected: spend.selected,
959        excluded: spend.excluded,
960        deduplicated: spend.deduplicated,
961        conflicts: spend.conflicts,
962        budget: spend.budget,
963        diagnostics,
964        sources,
965    })
966}

968/// What the budget made of the ranges [`source::offer`] put in: per file, how many were
969/// selected, what they cost, and what that saved against reading the file whole.
970fn source_coverage(outlined: source::Outlined, selected: &[ContextEntry]) -> SourceCoverage {
971    let mut spent: BTreeMap<&str, (usize, u64)> = BTreeMap::new();
972    for e in selected.iter().filter(|e| e.kind == source::KIND) {
973        let slot = spent.entry(e.provenance.path.as_str()).or_default();
974        slot.0 += 1;
975        slot.1 += e.cost_tokens;
976    }
977    let mut files = outlined.files;
978    for f in &mut files {
979        let (n, tokens) = spent.get(f.path.as_str()).copied().unwrap_or_default();
980        f.selected = n;
981        f.selected_tokens = tokens;
982        f.saved_tokens = if n == 0 {
983            0
984        } else {
985            f.whole_tokens.saturating_sub(tokens)
986        };
987    }
988    let read_any = !files.is_empty() || !outlined.unread.is_empty();
989    SourceCoverage {
990        parser: if read_any {
991            source::PARSER.into()
992        } else {
993            String::new()
994        },
995        files,
996        unread: outlined.unread,
997        unparsed: outlined.unparsed,
998        truncated: outlined.truncated,
999    }
1000}

1002/// Why one identifier is or is not in the context a request compiles to.
1003///
1004/// It compiles the request and then looks the identifier up in the result, which is the
1005/// only honest way to answer the question: the standing of a thing is a property of a
1006/// particular answer, not of the thing. The cost is one compile per question, and the
1007/// benefit is that "excluded for budget" is measured against the budget the reply carries
1008/// rather than one inferred afterwards.
1009///
1010/// An identifier this repository does not hold is [`Standing::Unknown`] — an answer, not an
1011/// error — because "the index holds nothing under that name" is exactly the fact the caller
1012/// asked for. The only refusal is an empty identifier, which is not a question.
1013///
1014/// ```
1015/// use majordomus_cli::capability::CapabilityError;
1016/// use majordomus_cli::devcontext::{compile, explain, CompileInput, ExplainInput, Standing};
1017/// use majordomus_cli::synthetic::SyntheticRepository;
1018///
1019/// let repo = SyntheticRepository::small().unwrap();
1020/// let ctx = repo.context().unwrap();
1021///
1022/// // the standing is about one compiled answer, so it moves with the request
1023/// let generous = compile(&ctx, CompileInput::default()).unwrap();
1024/// let uri = generous.selected.last().unwrap().uri.clone();
1025/// let selected = explain(&ctx, ExplainInput { uri: uri.clone(), ..Default::default() }).unwrap();
1026/// assert_eq!(selected.standing, Standing::Selected);
1027/// assert_eq!(selected.entry.as_ref().unwrap().uri, uri);
1028///
1029/// // an identifier nothing answers: reported as unknown rather than refused
1030/// let unknown = explain(
1031///     &ctx,
1032///     ExplainInput { uri: "majordomus://rule/nothing-like-this@1".into(), ..Default::default() },
1033/// )
1034/// .unwrap();
1035/// assert_eq!(unknown.standing, Standing::Unknown);
1036/// assert!(!unknown.detail.is_empty(), "it says so in words too");
1037///
1038/// // and the one thing that is not a question
1039/// assert!(matches!(
1040///     explain(&ctx, ExplainInput { uri: "   ".into(), ..Default::default() }),
1041///     Err(CapabilityError::InvalidInput(_)),
1042/// ));
1043/// ```
1044pub fn explain(ctx: &Context, input: ExplainInput) -> Result<Explanation, CapabilityError> {
1045    let uri = input.uri.trim().to_string();
1046    if uri.is_empty() {
1047        return Err(CapabilityError::InvalidInput(
1048            "name the canonical identifier to explain".into(),
1049        ));
1050    }
1051    let compiled = compile(ctx, input.request)?;
1052    if let Some(entry) = compiled.selected.iter().find(|e| e.uri == uri) {
1053        let ways: Vec<String> = entry
1054            .discovered_by
1055            .iter()
1056            .map(|d| format!("{}: {}", d.selector.as_str(), d.reason))
1057            .collect();
1058        return Ok(Explanation {
1059            uri,
1060            standing: Standing::Selected,
1061            detail: format!(
1062                "in the {} tier at relevance {} and confidence {}, costing {} token(s); reached by {} path(s) — {}",
1063                entry.tier.as_str(),
1064                entry.relevance,
1065                entry.confidence,
1066                entry.cost_tokens,
1067                entry.discovered_by.len(),
1068                ways.join("; ")
1069            ),
1070            entry: Some(entry.clone()),
1071            excluded: None,
1072            deduplicated: None,
1073            budget: compiled.budget,
1074        });
1075    }
1076    if let Some(x) = compiled.excluded.iter().find(|e| e.uri == uri) {
1077        return Ok(Explanation {
1078            uri,
1079            standing: Standing::Excluded,
1080            detail: format!(
1081                "reached and not given: {} — {}",
1082                x.reason.as_str(),
1083                x.detail
1084            ),
1085            entry: None,
1086            excluded: Some(x.clone()),
1087            deduplicated: None,
1088            budget: compiled.budget,
1089        });
1090    }
1091    if let Some(d) = compiled
1092        .deduplicated
1093        .iter()
1094        .find(|d| d.dropped.contains(&uri))
1095    {
1096        return Ok(Explanation {
1097            uri,
1098            standing: Standing::Deduplicated,
1099            detail: format!("folded into `{}` by {}: {}", d.kept, d.key, d.detail),
1100            entry: None,
1101            excluded: None,
1102            deduplicated: Some(d.clone()),
1103            budget: compiled.budget,
1104        });
1105    }
1106    let known = ctx.index.objects.iter().any(|o| o.uri == uri);
1107    Ok(Explanation {
1108        uri: uri.clone(),
1109        standing: if known {
1110            Standing::NotReached
1111        } else {
1112            Standing::Unknown
1113        },
1114        detail: if known {
1115            format!("the index holds `{uri}` and no selector of this request reached it: no seed names it, no followed edge leads to it, no declared path contains it, and it is not governance")
1116        } else if uri.starts_with(source::SCHEME) {
1117            format!("`{uri}` is a source range, which the index does not hold: a range is offered only when the request sets `source_ranges` and the span is a definition in the file as it is now, so either the request did not ask for ranges or the file has moved under it")
1118        } else {
1119            format!("the index holds nothing under `{uri}`")
1120        },
1121        entry: None,
1122        excluded: None,
1123        deduplicated: None,
1124        budget: compiled.budget,
1125    })
1126}

1128/// The compiler's rules: the tiers, every edge of the composed graph and what is done with
1129/// it, the selectors, and the defaults.
1130///
1131/// It takes no request, because the rules do not depend on what is being asked about. It
1132/// does take a context, and for one reason: the edge rows are enumerated from the graph
1133/// *this* repository derives, so an edge kind the graph gains shows up here as unjudged
1134/// rather than going quietly unfollowed. The answer is therefore a function of the
1135/// repository's graph and this module's tables, and of nothing else.
1136///
1137/// Pure over those two: the same tree gives the same answer every time, which is what makes
1138/// it safe to publish beside the compiled contexts it explains.
1139///
1140/// ```
1141/// use majordomus_cli::devcontext::{policy, Selector, Tier};
1142/// use majordomus_cli::synthetic::SyntheticRepository;
1143///
1144/// let repo = SyntheticRepository::small().unwrap();
1145/// let ctx = repo.context().unwrap();
1146///
1147/// let rules = policy(&ctx).unwrap();
1148/// assert_eq!(rules.tiers.len(), Tier::ORDER.len());
1149/// assert_eq!(rules.selectors.len(), Selector::ALL.len());
1150///
1151/// // every edge the graph declares is judged, one way or the other, with a reason
1152/// for e in &rules.edges {
1153///     assert!(!e.reason.is_empty(), "{} was neither followed nor explained", e.edge);
1154///     assert_eq!(e.refused, e.forward.is_none() && e.reverse.is_none());
1155/// }
1156///
1157/// // and asking twice over one tree gives one answer
1158/// let again = policy(&ctx).unwrap();
1159/// assert_eq!(again, rules);
1160/// ```
1161pub fn policy(ctx: &Context) -> Result<CompilerPolicy, CapabilityError> {
1162    let graph = crate::graph::composed_complete(&ctx.registry, ctx.index.as_ref());
1163    let mut kinds: BTreeMap<Tier, Vec<String>> = BTreeMap::new();
1164    for kind in graph.node_kinds.keys() {
1165        kinds
1166            .entry(tier_for_kind(kind))
1167            .or_default()
1168            .push(kind.clone());
1169    }
1170    let tiers = Tier::ORDER
1171        .iter()
1172        .enumerate()
1173        .map(|(i, t)| TierRule {
1174            tier: *t,
1175            position: i + 1,
1176            meaning: t.meaning().to_string(),
1177            kinds: kinds.get(t).cloned().unwrap_or_default(),
1178        })
1179        .collect();
1180
1181    // every edge the graph declares, judged: the table says which are followed, and the
1182    // refusals say why. An edge the graph gains and this table does not name is reported
1183    // as unjudged rather than silently unfollowed.
1184    let mut edges: Vec<EdgeRule> = Vec::new();
1185    for (edge, means) in &graph.edge_kinds {
1186        match edge_policy(edge) {
1187            Some(p) => edges.push(EdgeRule {
1188                edge: edge.clone(),
1189                means: means.clone(),
1190                forward: (p.forward > 0.0).then_some(p.forward),
1191                reverse: (p.reverse > 0.0).then_some(p.reverse),
1192                reason: format!("{}; reversed: {}", p.forward_reason, p.reverse_reason),
1193                refused: false,
1194            }),
1195            None => {
1196                let why = select::REFUSED
1197                    .iter()
1198                    .find(|(k, _)| k == edge)
1199                    .map(|(_, w)| (*w).to_string())
1200                    .unwrap_or_else(|| {
1201                        "the graph declares it and the compiler has no rule for it; it is not followed".into()
1202                    });
1203                edges.push(EdgeRule {
1204                    edge: edge.clone(),
1205                    means: means.clone(),
1206                    forward: None,
1207                    reverse: None,
1208                    reason: why,
1209                    refused: true,
1210                });
1211            }
1212        }
1213    }
1214
1215    Ok(CompilerPolicy {
1216        schema: 1,
1217        graph: crate::graph::COMPOSED.to_string(),
1218        tiers,
1219        edges,
1220        selectors: Selector::ALL
1221            .iter()
1222            .map(|s| SelectorRule {
1223                selector: *s,
1224                declared: s.declared(),
1225            })
1226            .collect(),
1227        default_budget_tokens: DEFAULT_BUDGET_TOKENS,
1228        default_max_depth: DEFAULT_MAX_DEPTH,
1229        default_floor: DEFAULT_FLOOR,
1230        bytes_per_token: BYTES_PER_TOKEN,
1231    })
1232}
