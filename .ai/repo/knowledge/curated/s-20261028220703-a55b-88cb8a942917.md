# a commit message that names an issue id carried only by an open pull request is refused as commit.unresolved_reference until that pull request lands; the message names the pull request instead, and the id once it is on master

Observed as friction about apps/majordomus-cli/src/commit/verdict.rs in episode s-20261028220703-a55b.

# Evidence

- `file:docs/COMMIT.md`

# Evidence

Measured on 2026-10-28. The commit of the rule project.ui-uses-flowbite-pro named I4316, an id
no branch on the remote carries, and the commit-msg hook refused it:

    error    commit.unresolved_reference        the message names I4316, which this repository's layer does not hold

The same message, naming the pull request (#2642) in place of the id, was accepted
(commit 0022a5bb7df, pull request #2644). The finding is documented in docs/COMMIT.md, whose
table now says what to name instead.
