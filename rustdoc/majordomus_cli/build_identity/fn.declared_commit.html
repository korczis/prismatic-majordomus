pub fn declared_commit(

Expand description

The commit the build was handed: MAJORDOMUS_BUILD_COMMIT when it names one (neither empty nor unknown), else a hosting provider’s SOURCE_VERSION when that is a full 40-hex commit (the Heroku-compatible variable Gigalixir sets to the pushed commit, ADR 0219), else whatever MAJORDOMUS_BUILD_COMMIT held, which identify then judges exactly as before. A SOURCE_VERSION that is not a commit (a branch name, a short sha) is ignored rather than compiled in as one (I3820).

use majordomus_cli::build_identity::declared_commit;

let sha = "0123456789abcdef0123456789abcdef01234567";
// a provider build hands only SOURCE_VERSION: it is the commit
assert_eq!(declared_commit(None, Some(sha)), Some(sha.to_string()));
// a branch name is not a commit and is never compiled in as one
assert_eq!(declared_commit(None, Some("master")), None);
