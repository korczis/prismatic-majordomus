pub const EXAMPLES: &[CommandExamples];
Expand description

Every documented example of the native command line.

This is the canonical declaration: docs/generated/cli.md, docs/generated/cli.json, the site dataset and every page under /docs/cli/ render these entries, and apps/majordomus-cli/tests/cli_examples.rs runs them against the built executable in a disposable repository. Adding a command without adding its example does not pass cli::validate, and therefore does not pass the crate’s tests or CI.
