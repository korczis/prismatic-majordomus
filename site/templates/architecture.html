What is guaranteed about this site

  • Derivation is proven, not asserted. A behavioural test changes one canonical value in a throwaway copy of the repository, regenerates, and fails if the output did not change.
  • Claims cannot outrun the code. Every capability sentence names a file and a test, and the build fails if either has gone.
  • Nothing is fetched at runtime. No page asks the network for content; the site works offline once built.
  • The manifest is public. The footer carries the version, commit and hash of the canonical inputs this build came from.
