The edit guard (I2735): before a provider’s tool writes a file of this checkout, is the path claimed?

A session reaches the mesh at its start (I2734), a task’s scope is claimed there by start (I2288), and a task completed off the mesh is refused (I2289). None of that stops a worker from editing a file nobody claimed: the claim was a convention until the edit itself asked for one. This is the asking. It answers one question — may this session write this path now — from four facts, each read without building the index, because it runs before every edit a provider makes:

  1. the policy switch session.edits_require_claim, off unless a repository turns it on;
  2. whether the repository declares its mesh enabled — a repository without a mesh has no claims to be covered by;
  3. the active task’s scope, which start has claimed on the mesh as task-<id>;
  4. the live claims the mesh holds for the session doing the writing.

What it cannot decide it lets through and says why: an unreadable policy, no server to ask, a mesh state that does not parse. Refusing an edit because a probe failed would make a checkout nobody can serve a checkout nobody can edit, which is worse than the edit it would have stopped; I2289 still refuses the completion of such work.

One edit, from the path a provider names to the verdict it reads:

use std::path::Path;
use majordomus_cli::guard::{judge_facts, relative_to, ClaimSource, EditFacts};

// a provider is about to write this file of the checkout at /work/repo
let root = Path::new("/work/repo");
let asked = "/work/repo/docs/MESH.md";
let rel = relative_to(root, asked);
assert_eq!(rel.as_deref(), Some("docs/MESH.md"));

// the facts gathered for it: the policy asks for a claim, the mesh is on, a task claims lib
let scope = vec!["lib".to_string()];
let facts = EditFacts {
    required: Ok(true),
    mesh_enabled: true,
    task: Some(("t-1", &scope[..])),
    session: Some("claude-code-s1"),
    claims: ClaimSource::Claims(vec![]),
};
let verdict = judge_facts(asked, rel.as_deref(), facts);
assert!(!verdict.allowed, "neither the task nor a claim of the session covers docs");
assert!(verdict.remedy.unwrap().contains("majordomus start"));
