Module enrol 

Source
Expand description

Enrolment: add one machine’s public key to a mesh declaration’s trust.allow.

The declaration is a tracked file a person reads and reviews, with comments that say why each machine is there, so enrolment edits its text rather than re-rendering it: the comments, the order and every other key stay as they were, and the new key arrives as one list item under a comment naming the machine — the shape this repository’s own declaration keeps by hand. The result is parsed back as a declaration before anything is returned, so an edit that would leave the file unreadable, or the key unlisted, is a refusal and never a written file.

use majordomus_cli::mesh::enrol::enrol;

// the declaration `majordomus init` seeds: enabled, deny_unknown, nobody listed
let seeded = "schema: mesh/v1\nkind: mesh-declaration\nid: mesh\nenabled: true\n\
    trust:\n  policy: deny_unknown\n  allow: []\n";
let first = "11".repeat(32);
let second = "22".repeat(32);
// one machine enrols, then another: each key once, in the order they joined
let one = enrol(seeded, &first, "11111111 — first").unwrap().unwrap();
let two = enrol(&one, &second, "22222222 — second").unwrap().unwrap();
assert!(two.find(&first).unwrap() < two.find(&second).unwrap());
assert_eq!(enrol(&two, &first, "first again").unwrap(), None);

Functions§

enrol
text with key listed in trust.allow under a # label comment, or None when the key is already listed. A missing trust: block or allow: key is added; an empty allow: [] becomes a block list. Refused when the result would not parse as a declaration or would not list the key.
