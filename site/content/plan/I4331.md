description = "Before it writes, pack build checks its output directory with `git check-ignore`. That is the default <root>/tmp/packs/<repo>-<profile>-<commit12> (apps/majordomus-cli/src/pack/mod.rs:1189-1220) or the --out path. When the directory lies inside the work tree and is not ignored, pack build refuses and writes nothing. The refusal names the path and three remedies: ignore tmp/ in .gitignore, ignore it locally in .git/info/exclude (no commit needed), or pass --out with an ignored directory. On success, the output line names the path written and says that it is ignored. pack.verify keeps its rule that a pack is verified where it was built, inside the repository (inside(), apps/majordomus-cli/src/capability/builtin/pack.rs:115-133). That is why the fix is a refusal and not a new default outside the work tree. Writing under .git/ does not work either: in a linked worktree .git is a file, and the common git directory lies outside the work tree, where inside() refuses it."
