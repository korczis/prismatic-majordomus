pub fn load(root: &Path) -> Result<ProofPlan, Vec<EconomicsFinding>>
Expand description

Read and validate the plan under root, fail-closed: the plan when no finding stands, every finding otherwise. An absent file is the finding no_plan, never an empty valid plan. The kinds, each with its own detail:

  • no_plan, plan_unreadable, schema_unknown, no_tests: the file as a whole.
  • test_malformed: a test or its protocol does not have the declared shape.
  • test_duplicate, dimension_unknown, claim_unknown, settles_nothing, instrument_unknown, instrument_unplanned: a test’s own fields.
  • decision_unknown, digest_mismatch, registered_at_invalid, version_unchanged: a protocol.
  • paired_suite_unknown, paired_registration_absent, paired_registration_mismatch: a paired protocol whose suite or registration digest does not resolve.
  • trials_invalid, window_invalid: a trials or window decision that cannot decide.
  • claims_unreadable, suite_unreadable, suite_duplicate: an input the checks read, or two suite files that declare one id.
  • plan_is_freshness_input: a suite’s freshness inputs could select the plan file, read as git ls-files reads a pathspec list, with its wildcards and magic.
use majordomus_cli::economics::proof::{load, PLAN};
let dir = tempfile::tempdir().unwrap();
let plan = dir.path().join(PLAN);
std::fs::create_dir_all(plan.parent().unwrap()).unwrap();
std::fs::write(&plan, "schema: proof-plan/v0\ntests: []\n").unwrap();
let kinds: Vec<String> = load(dir.path()).unwrap_err().into_iter().map(|f| f.kind).collect();
assert_eq!(kinds, ["schema_unknown", "no_tests"]);
