Rozhraní MCP

Nástroje a zdroje, které spustitelný soubor poskytuje klientu MCP, transporty, sdílený server a co o tom všem rozhoduje.

Registr Spustitelný soubor Moduly Schopnosti Příkazová řádka MCP HTTP API Artefakty Měření výkonu

Klient MCP vidí registr jako nástroje a zdroje. Každý nástroj je schopnost s expozicí mcp.tool; každá vestavěná schopnost s expozicí jako zdroj odpovídá na svém URI; každý objekt vrstvy je jedním dalším zdrojem. Není zde uvedeno nic, co registr nedrží.

Jak se klient dostane k serveru — majordomus mcp přes stdio, jeden sdílený server na repozitář s MCP přes HTTP, lease, peeři, co server odmítá — je dokument o MCP; odolnost sdíleného serveru je doktrína.
