Capabilities

Every executable capability: its schemas, exposures, policies, provenance, and the claims and tests that speak about it.

Registry The executable Modules Capabilities Command line MCP HTTP API Benchmarks

capabilities Capabilities

  • capabilities.describe One capability by canonical id: its kind, schemas, provenance, stability, exposures, benchmark and cache policy. query behaviorally_verified mcp http cli
  • capabilities.list Every capability of this executable and this repository, summarised: kind, module, stability, provenance, the projections it declares, its benchmark and cache policy; the schemas are answered by capabilities.describe. query behaviorally_verified mcp http cli cached

objects Objects

  • objects.get One object by URI (majordomus://<kind>/<identity>): metadata, provenance and content; a URI a query projects (majordomus://repository) answers that query as a JSON document. The same resolution serves the MCP resource read. query behaviorally_verified mcp http
  • objects.list List the declarative objects of the repository's AI layer, optionally by kind or tag. query behaviorally_verified mcp http
  • objects.search Case-insensitive substring search over identities, titles, descriptions and content. query behaviorally_verified mcp http cached

peers Peers

  • peers.announce Tell the other peers of this shared server what the calling session is doing and which paths it expects to touch. Changes this process's memory only; the repository is never written. Needs an MCP session: over plain HTTP there is no caller. command behaviorally_verified mcp http
  • peers.list Every client attached to this shared server: id, the client's own name and version from its initialize, transport, when it attached, when it was last seen, and what it announced. In-memory, gone with the process. query behaviorally_verified mcp http

perf Performance

  • perf.counters The counters of this process: repository scans, index and registry builds, schema generations, projection builds, executions, handler invocations, cache hits, misses and evictions, and the phase timings, as they stand now. query behaviorally_verified mcp http

repository Repository

  • repository.info The repository root, layer sections, git state, discovery mode, kinds present, every diagnostic, and the capability registry counted. query behaviorally_verified mcp http
  • repository.scope The scope declaration as read, where it came from (the repository's own or the distribution's default), and every tracked file tallied against it: how many are in, how many are out for each reason, and which. query behaviorally_verified mcp http cli
  • repository.scope_classify Whether a repository-relative path is in or out of the scope, the reason when it is out, and the pattern or limit that decided; an existing file is judged by name, then size, then content. query behaviorally_verified mcp http cli
