description = "`majordomus plan evidence <id> --covers <token> ... --commit <rev>` writes the named commit into the entry's commit: instead of HEAD. The revision is resolved with `git rev-parse --verify <rev>^{commit}` to its full 40-hex name, and is accepted only when the trunk's remote-tracking branch (mj_git_trunk_ref, lib/common.sh:540-549) reaches it, judged by mj_commit_in_history (lib/common.sh:761-769) against that ref. A commit the trunk does not reach is refused with exit 15 and a message naming the commit and the trunk ref. A clone that cannot decide (shallow, or the object is missing: mj_commit_in_history returns 2) and a repository with no known trunk (no refs/remotes/<remote>/HEAD) are refused with a message that says which, never recorded unjudged. The ledger event plan_evidence carries the recorded commit and whether it was named or taken from HEAD. Without --commit nothing changes: the entry records HEAD, as today. So any number of evidence entries for already-landed work can be recorded on one branch, in one pull request, each naming the trunk commit that landed its work."
