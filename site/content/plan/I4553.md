description = "ReviewRequestInput and EventBody::ReviewRequested (apps/majordomus-cli/src/mesh/journal.rs) gain an optional `session` addressee, read with serde(default) so that a runtime written before the change reads a request without it, as it reads one without a body. The Written answer of mesh.review.request, and of mesh.review.answer for the requester, carries a `route` resolved from the board row's PeerAddress (apps/majordomus-cli/src/peers.rs): `{via: provider-socket, to: uds:<socket>}` when the row names a provider and a socket, `{unavailable: <why>}` otherwise. The requesting worker wakes the addressee with its own provider's messaging tool, carrying the review key; the addressee reads the request once by that key and answers it with mesh.review.answer, whose route wakes the requester, who reads the answer once. Majordomus sends nothing to the socket and never reads the provider's messaging token (peers.rs: the address is where to knock, not the key). `share/providers.yaml` gains a `messaging` cell in its `offers` block: `socket` for claude-code, with its citation, and `none` for every other provider. Optionally, scripts/lib/advisors/mesh-review.mjs follows the existing /events stream for its requester instead of reading mesh state every two seconds."
