Majordomus API

OpenAPI 3.1.0

201 operací; Swagger UI na /swagger.

GET/api/v1/repository

Stav repozitáře a indexu. Kořen repozitáře, sekce vrstvy, stav gitu, režim objevování, přítomné druhy, každá diagnostika a spočítaný registr schopností.

GET/api/v1/rules

Každé pravidlo proti důkazu, který pro něj existuje. Celý korpus pravidel spojený se stromem a účetní knihou: u každého pravidla jeho třída, režim vynucování, validátor a případy, které jmenuje, zda…

GET/api/v1/environment

Prostředí repozitáře. Jeden snapshot tohoto checkoutu: identita projektu, identita repozitáře, správa verzí, deklarované toolchainy, co vrstva drží, sečteno podle…

GET/api/v1/search

Hledání objektů. Vyhledávání podřetězce bez ohledu na velikost písmen v identitách, názvech, popisech a obsahu.

POST/api/v1/plan/transition

Posunout jeden úkol životním cyklem. Zaznamenat, že provádění úkolu začalo (`start`), že implementace je hotová a důkazy chybí (`verify`), nebo že je dokonče…
