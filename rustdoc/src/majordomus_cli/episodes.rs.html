1//! Episodes: the execution episode of a client that has no provider hooks, drawn by the
2//! MCP connection itself (ADR 0103).
3//!
4//! # The defect this exists for
5//!
6//! Majordomus draws the episode boundary below the model, so that the episode which
7//! mattered — the one that ended in a crash, a compaction, or somebody closing the window —
8//! is recorded whether or not a model remembered to record it. Until this module that was
9//! wired for exactly one provider. Claude Code fires `SessionStart` and `SessionEnd`, a
10//! shim runs `capture session`, and the repository gets an episode. Every other client got
11//! nothing at all, and the repository's claim to draw the boundary below the model was a
12//! claim about one vendor.
13//!
14//! A client with no hooks still has a boundary, and this server is standing on it: the
15//! client speaks `initialize`, makes calls, and goes. That is an episode. The connection is
16//! the event source, the peer board already tracks attach, activity and detach, and the
17//! repository's own `majordomus capture session` already opens and closes episodes for a
18//! provider that names its session. Nothing new needs inventing; the three had to be joined.
19//!
20//! # A peer is not an episode
21//!
22//! They are deliberately separate types and the distinction has cost real time here. A peer
23//! id (`p1`, `p2`, ...) is *this process's* name for *this connection*, handed out in
24//! attachment order and reused by the next server. It is not a worker identity: a session
25//! that reconnects comes back as a different peer, and on 2026-09-09 a session in this
26//! repository announced, was re-established under a new id, and was invisible to eight
27//! others for three hours because everybody had been treating the id as durable.
28//!
29//! So an episode is keyed by an **external identity** the client supplies — its own
30//! conversation id, thread id, whatever it durably calls itself — and the peer holding it is
31//! a field that changes. The invariants:
32//!
33//! * a connection holds **zero or one** episode: `initialize` alone opens nothing, and a
34//!   client that never calls `episodes.attach` is a peer and not a worker with a record;
35//! * a client that reconnects **re-associates** with its own episode by external identity,
36//!   under whatever peer id it now has;
37//! * an episode outlives the connection that opened it, for a bounded grace, because a
38//!   dropped socket is not the end of somebody's work — it is the most ordinary thing that
39//!   happens to one.
40//!
41//! # What is honestly not here
42//!
43//! Raw prompt capture. An MCP server is handed `initialize`, tool calls and notifications;
44//! the person's prompt is never among them, in any version of the protocol. Prompt capture
45//! stays provider-specific, `share/providers.yaml` declares `prompts: none` for the generic
46//! provider with that reasoning written down, and no surface implies otherwise.
47//!
48//! # The lifecycle, end to end
49//!
50//! A client attaches under its own name, its connection drops, it comes back as a different
51//! peer under the same name and gets the same episode, and then it says it is done:
52//!
53//! ```
54//! use majordomus_cli::episodes::{CloseReason, ConnectionEpisodeState, EpisodeBoard};
55//! use majordomus_cli::peers::{PeerBoard, Transport};
56//!
57//! let peers = PeerBoard::new();
58//! let board = EpisodeBoard::new(); // records nothing in a repository
59//! let first = peers.attach(Transport::Http);
60//! let (opened, resumed) = board.attach(&first, "thread-7", "generic");
61//! assert!(!resumed);
62//!
63//! board.detach(&first); // the socket went; the work did not
64//! assert_eq!(board.list()[0].state, ConnectionEpisodeState::Detached);
65//!
66//! let second = peers.attach(Transport::Http); // a new peer id, the same worker
67//! let (again, resumed) = board.attach(&second, "thread-7", "generic");
68//! assert!(resumed);
69//! assert_eq!((again.opened_at.as_str(), again.attachments), (opened.opened_at.as_str(), 2));
70//!
71//! let closed = board.close("thread-7", CloseReason::Detach).unwrap();
72//! assert_eq!(closed.external_id, "thread-7");
73//! assert!(board.list().is_empty());
74//! ```

87/// How long an episode whose connection has gone is kept before it is closed.
88///
89/// Longer than the transport's own idle timeout on purpose. `http::mcp::SESSION_IDLE_TIMEOUT`
90/// decides when a *connection* is forgotten — ninety seconds, which is right for a socket —
91/// and a client that is restarted, rebuilt or resumed takes longer than that to come back.
92/// Closing the episode at the same moment as the connection would publish a record saying
93/// the work ended, for work that resumed four minutes later under a new peer id, which is
94/// precisely the fiction this whole subsystem exists to avoid.
95pub const REATTACH_GRACE: Duration = Duration::from_secs(15 * 60);

97/// Why an episode was closed. Reported to the repository as the end event's `reason`, where
98/// `share/providers.yaml`'s deliberate-end list decides whether the record says `closed` or
99/// `interrupted` — the same table the provider hooks are read through, so a connection
100/// episode and a hook episode cannot disagree about what "ended deliberately" means.
101///
102/// The serialised word and [`CloseReason::as_str`] are one vocabulary:
103///
104/// ```
105/// use majordomus_cli::episodes::CloseReason;
106/// for reason in [CloseReason::Detach, CloseReason::Shutdown, CloseReason::Expired] {
107///     let json = serde_json::to_string(&reason).unwrap();
108///     assert_eq!(json, format!("\"{}\"", reason.as_str()));
109/// }
110/// ```
111#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
112#[serde(rename_all = "snake_case")]
113pub enum CloseReason {
114    /// The client said so: `episodes.detach`, or `DELETE /mcp`. A deliberate end.
115    Detach,
116    /// The server is stopping and every episode goes with it. Deliberate: nothing was cut
117    /// short by this, the machine was.
118    Shutdown,
119    /// The connection went and did not come back inside [`REATTACH_GRACE`]. Not deliberate,
120    /// and the record says `interrupted`, because calling a crashed episode complete is the
121    /// worse of the two mistakes.
122    Expired,
123}
124
125impl CloseReason {
126    /// The word sent to the repository's end event, as its `reason`. Only `expired` is
127    /// outside the deliberate-end list, so only it records the episode as interrupted.
128    ///
129    /// ```
130    /// use majordomus_cli::episodes::CloseReason;
131    /// assert_eq!(CloseReason::Detach.as_str(), "detach");
132    /// assert_eq!(CloseReason::Expired.as_str(), "expired");
133    /// ```
134    pub fn as_str(self) -> &'static str {
135        match self {
136            CloseReason::Detach => "detach",
137            CloseReason::Shutdown => "shutdown",
138            CloseReason::Expired => "expired",
139        }
140    }
141}

143/// Where an episode stands: held by a live connection, or waiting for its client to come
144/// back. There is no closed state, because a closed episode leaves the board; what survives
145/// it is the repository's own record.
146///
147/// ```
148/// use majordomus_cli::episodes::{ConnectionEpisodeState, EpisodeBoard};
149/// use majordomus_cli::peers::{PeerBoard, Transport};
150/// let peer = PeerBoard::new().attach(Transport::Stdio);
151/// let board = EpisodeBoard::new();
152/// assert_eq!(board.attach(&peer, "w", "generic").0.state, ConnectionEpisodeState::Open);
153/// assert_eq!(board.detach(&peer)[0].state, ConnectionEpisodeState::Detached);
154/// assert_eq!(serde_json::to_string(&ConnectionEpisodeState::Detached).unwrap(), "\"detached\"");
155/// ```
156#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
157#[serde(rename_all = "snake_case")]
158pub enum ConnectionEpisodeState {
159    /// A connection holds it and the client is speaking.
160    Open,
161    /// The connection has gone; the episode is kept for [`REATTACH_GRACE`] so the client
162    /// can come back to it. This is the state a crash lands in, and the one a reconnect
163    /// recovers from.
164    Detached,
165}

167/// One episode: what the client calls itself, which connection holds it now, and what the
168/// repository did about it.
169///
170/// ```
171/// use majordomus_cli::episodes::{ConnectionEpisode, EpisodeBoard};
172/// use majordomus_cli::peers::{PeerBoard, Transport};
173/// let peer = PeerBoard::new().attach(Transport::Http);
174/// let (episode, _) = EpisodeBoard::new().attach(&peer, "conv-42", "generic");
175/// let episode: ConnectionEpisode = episode;
176/// assert_eq!((episode.external_id.as_str(), episode.provider.as_str()), ("conv-42", "generic"));
177/// assert_eq!(episode.peer.as_ref(), Some(&peer));
178/// // never empty: a board with no repository behind it says so
179/// assert!(episode.repository.contains("without a driver"));
180/// ```
181#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
182pub struct ConnectionEpisode {
183    /// The client's own durable name for this piece of work, and the key everything here is
184    /// addressed by. Never a peer id: see the module documentation.
185    pub external_id: String,
186    /// The provider id this episode is recorded under, as `share/providers.yaml` names one.
187    pub provider: String,
188    /// The connection holding it, when one does. `None` while detached — which is a state
189    /// an episode is *supposed* to reach and come back from, not a fault.
190    #[serde(skip_serializing_if = "Option::is_none")]
191    pub peer: Option<PeerId>,
192    /// When it was first opened, RFC 3339, UTC. Unchanged by a re-attach: the episode is
193    /// the work, and the work did not restart because a socket did.
194    pub opened_at: String,
195    /// Seconds since the client last spoke on it, through any connection.
196    pub last_activity_seconds_ago: u64,
197    /// How many times a connection has taken it over, the first attach included.
198    pub attachments: u32,
199    /// Open, or detached and waiting for its client.
200    pub state: ConnectionEpisodeState,
201    /// What the repository's own episode command reported, verbatim — the record it opened,
202    /// or the reason it could not. Never interpreted here, and never empty: a subsystem
203    /// that silently does nothing is the failure mode this field exists to make visible.
204    pub repository: String,
205}

207/// The episodes of one server.
208///
209/// In memory, like the peer board, and for a narrower reason: what survives the process is
210/// the repository's own record, written by the same command a provider hook runs. This board
211/// holds only the association between a live connection and that record, which is a fact
212/// about now and stops being true when the process does.
213///
214/// ```
215/// use majordomus_cli::episodes::EpisodeBoard;
216/// use majordomus_cli::peers::{PeerBoard, Transport};
217/// let peers = PeerBoard::new();
218/// let (a, b) = (peers.attach(Transport::Stdio), peers.attach(Transport::Http));
219/// let board = EpisodeBoard::default();
220/// board.attach(&b, "zeta", "generic");
221/// board.attach(&a, "alpha", "generic");
222/// // listed by external identity, never by peer or attachment order
223/// let ids: Vec<String> = board.list().into_iter().map(|e| e.external_id).collect();
224/// assert_eq!(ids, ["alpha", "zeta"]);
225/// assert_eq!(board.close_all().len(), 2);
226/// ```
227pub struct EpisodeBoard {
228    episodes: Mutex<BTreeMap<String, Entry>>,
229    /// How the repository's episode boundary is driven. Injected so that the unit suites can
230    /// drive the board without a repository and the real server drives the real command.
231    driver: Box<dyn EpisodeDriver>,
232}

240/// What opens and closes the repository's own episode.
241///
242/// One trait with one real implementation, because the alternative was for this module to
243/// learn how a session record is written — and a second writer of the record the provider
244/// hooks already write is exactly the repeated semantic definition this repository refuses
245/// (ADR 0004). [`ToolDriver`] runs `majordomus capture session`, the same command, with the
246/// same payload shape, through the same adapter resolution.
247///
248/// A driver of one's own is how a board is driven without a repository; what it returns is
249/// what the episode's `repository` field carries:
250///
251/// ```
252/// use majordomus_cli::episodes::{CloseReason, EpisodeBoard, EpisodeDriver};
253/// use majordomus_cli::peers::{PeerBoard, Transport};
254///
255/// struct Echo;
256/// impl EpisodeDriver for Echo {
257///     fn open(&self, provider: &str, id: &str) -> String { format!("opened {provider} {id}") }
258///     fn close(&self, _: &str, id: &str, reason: CloseReason) -> String {
259///         format!("closed {id} ({})", reason.as_str())
260///     }
261/// }
262///
263/// let board = EpisodeBoard::with_driver(Box::new(Echo));
264/// let peer = PeerBoard::new().attach(Transport::Stdio);
265/// assert_eq!(board.attach(&peer, "t1", "generic").0.repository, "opened generic t1");
266/// assert_eq!(board.close("t1", CloseReason::Shutdown).unwrap().repository, "closed t1 (shutdown)");
267/// ```
268pub trait EpisodeDriver: Send + Sync {
269    /// Open the episode for `external_id` under `provider`. Returns what to record in
270    /// [`ConnectionEpisode::repository`] — a description of what happened, successful or not.
271    /// It is called once per episode, on the first attach; a resume does not call it again.
272    ///
273    /// ```
274    /// use majordomus_cli::episodes::{EpisodeDriver, NullDriver};
275    /// let said = NullDriver.open("generic", "t1");
276    /// assert!(said.starts_with("no repository episode"), "a driver never answers blank");
277    /// ```
278    fn open(&self, provider: &str, external_id: &str) -> String;
279    /// Close it, with the reason the record is to carry. Returns what the repository did,
280    /// which replaces the episode's `repository` field on the way out.
281    ///
282    /// ```
283    /// use majordomus_cli::episodes::{CloseReason, EpisodeDriver, NullDriver};
284    /// let said = NullDriver.close("generic", "t1", CloseReason::Expired);
285    /// assert!(said.contains("without a driver"));
286    /// ```
287    fn close(&self, provider: &str, external_id: &str, reason: CloseReason) -> String;
288}

290/// The driver that runs the repository's own `majordomus capture session`.
291///
292/// It finds the tool the way a provider hook's shim does and in the same order — the
293/// repository's `bin/majordomus`, an installation under `.majordomus/`, then whatever is on
294/// the path — because a second resolution order would be a second answer to "which tool is
295/// this repository's", and the shims are the ones that have been right about it for months.
296///
297/// When no tool is found it records nothing and says why, in the episode's own field:
298///
299/// ```
300/// use majordomus_cli::episodes::{EpisodeDriver, ToolDriver};
301/// let empty = std::env::temp_dir().join("mj-tooldriver-doctest-no-tool");
302/// std::env::remove_var("PATH"); // nor any majordomus on the path
303/// let said = ToolDriver::new(&empty).open("generic", "t1");
304/// assert!(said.starts_with("no episode was recorded"), "{said}");
305/// ```
306#[derive(Debug, Clone)]
307pub struct ToolDriver {
308    root: PathBuf,
309}
310
311impl ToolDriver {
312    /// A driver for the repository at `root`. Nothing is resolved or run here: the tool is
313    /// looked for on every event, so a `bin/majordomus` built after the server started is the
314    /// one used.
315    ///
316    /// ```
317    /// use majordomus_cli::episodes::ToolDriver;
318    /// let driver = ToolDriver::new("/srv/repo");
319    /// assert!(format!("{driver:?}").contains("/srv/repo"));
320    /// ```
321    pub fn new(root: impl Into<PathBuf>) -> Self {
322        ToolDriver { root: root.into() }
323    }
324
325    /// The shell tool, resolved as `.claude/hooks/majordomus-session-start` resolves it.
326    fn tool(&self) -> Option<PathBuf> {
327        for candidate in ["bin/majordomus", ".majordomus/bin/majordomus"] {
328            let p = self.root.join(candidate);
329            if is_executable(&p) {
330                return Some(p);
331            }
332        }
333        which("majordomus")
334    }
335
336    fn run(&self, provider: &str, event: &str, payload: &str) -> String {
337        self.run_tool(self.tool(), provider, event, payload)
338    }
339
340    /// Run `tool`'s `capture session` with `payload` on stdin, or say that there is no tool.
341    fn run_tool(
342        &self,
343        tool: Option<PathBuf>,
344        provider: &str,
345        event: &str,
346        payload: &str,
347    ) -> String {
348        let Some(tool) = tool else {
349            return format!(
350                "no episode was recorded: neither bin/majordomus nor .majordomus/bin/majordomus is executable under {} and none is on the path",
351                self.root.display()
352            );
353        };
354        // The payload goes in on stdin exactly as a provider's own event does, so the one
355        // reader in lib/capture.sh parses both. Writing it with a pipe rather than an
356        // argument is not decoration: `capture session` reads the episode key out of the
357        // payload, and a key that arrived as an argument would be a second way in.
358        let mut child = match Command::new(&tool)
359            .arg("--repo")
360            .arg(&self.root)
361            .args([
362                "capture",
363                "session",
364                "--provider",
365                provider,
366                "--event",
367                event,
368            ])
369            .current_dir(&self.root)
370            .stdin(std::process::Stdio::piped())
371            .stdout(std::process::Stdio::piped())
372            .stderr(std::process::Stdio::piped())
373            .spawn()
374        {
375            Ok(c) => c,
376            Err(e) => {
377                return format!(
378                    "no episode was recorded: {} did not start: {e}",
379                    tool.display()
380                )
381            }
382        };
383        // stdin was asked for as a pipe, so it is there; it is closed when the write is done,
384        // and a tool that exited without reading it has answered all the same
385        let _ = child.stdin.take().map(|mut stdin| {
386            use std::io::Write;
387            stdin.write_all(payload.as_bytes())
388        });
389        reported(event, &tool, child.wait_with_output())
390    }
391}

393/// What a finished `capture session` run says happened: its last line on stderr, or, when it
394/// said nothing or could not be waited for, a sentence that says so and names the tool.
395fn reported(event: &str, tool: &Path, finished: std::io::Result<std::process::Output>) -> String {
396    match finished {
397        // `capture session` writes nothing to stdout by contract and reports what it did
398        // on stderr, because on a start event its stdout would be loaded into a model's
399        // context. Its last line is the one that says what happened.
400        Ok(out) => {
401            let text = String::from_utf8_lossy(&out.stderr);
402            let last = text
403                .lines()
404                .rev()
405                .find(|l| !l.trim().is_empty())
406                .unwrap_or("");
407            if last.is_empty() {
408                format!(
409                    "`capture session --event {event}` exited {} and said nothing",
410                    out.status
411                )
412            } else {
413                last.trim().to_string()
414            }
415        }
416        Err(e) => format!(
417            "no episode was recorded: {} did not finish: {e}",
418            tool.display()
419        ),
420    }
421}

423impl EpisodeDriver for ToolDriver {
424    fn open(&self, provider: &str, external_id: &str) -> String {
425        self.run(
426            provider,
427            "start",
428            &format!(
429                "{{\"session_id\":{},\"source\":\"attach\"}}\n",
430                json_string(external_id)
431            ),
432        )
433    }
434
435    fn close(&self, provider: &str, external_id: &str, reason: CloseReason) -> String {
436        self.run(
437            provider,
438            "end",
439            &format!(
440                "{{\"session_id\":{},\"reason\":\"{}\"}}\n",
441                json_string(external_id),
442                reason.as_str()
443            ),
444        )
445    }
446}

543    /// Open an episode for `external_id`, or take an existing one over.
544    ///
545    /// The whole point is in the second half. A client that comes back — after a crash, a
546    /// rebuild, a dropped socket, a client restart — names itself the same way and gets the
547    /// same episode, with a new peer holding it and `attachments` one higher. Nothing is
548    /// re-opened, no second record is written, and the ledger lines on either side of the
549    /// gap belong to one episode, which is what makes the record of it true.
550    ///
551    /// Returns the episode and whether it was resumed rather than opened.
552    ///
553    /// ```
554    /// use majordomus_cli::episodes::EpisodeBoard;
555    /// use majordomus_cli::peers::{PeerBoard, Transport};
556    /// let peers = PeerBoard::new();
557    /// let board = EpisodeBoard::new();
558    /// let (p1, p2) = (peers.attach(Transport::Stdio), peers.attach(Transport::Http));
559    /// assert!(!board.attach(&p1, "work", "generic").1, "first: opened");
560    /// let (episode, resumed) = board.attach(&p2, "work", "generic");
561    /// assert!(resumed, "same identity, another peer: resumed");
562    /// assert_eq!((episode.attachments, episode.peer.as_ref()), (2, Some(&p2)));
563    /// assert_eq!(board.list().len(), 1, "one episode, not two");
564    /// ```
565    pub fn attach(
566        &self,
567        peer: &PeerId,
568        external_id: &str,
569        provider: &str,
570    ) -> (ConnectionEpisode, bool) {
571        let mut episodes = self.lock();
572        // A connection holds zero or one episode. A peer attaching to a second external
573        // identity is not a second worker, it is the same connection changing its mind —
574        // the first is released (and left detached, recoverable) rather than held by a peer
575        // that has stopped speaking for it.
576        for entry in episodes.values_mut().filter(|e| {
577            e.episode.peer.as_ref() == Some(peer) && e.episode.external_id != external_id
578        }) {
579            entry.episode.peer = None;
580            entry.episode.state = ConnectionEpisodeState::Detached;
581            entry.detached_since = Some(Instant::now());
582        }
583
584        if let Some(entry) = episodes.get_mut(external_id) {
585            entry.episode.peer = Some(peer.clone());
586            entry.episode.state = ConnectionEpisodeState::Open;
587            entry.episode.attachments = entry.episode.attachments.saturating_add(1);
588            entry.detached_since = None;
589            entry.last_activity = Instant::now();
590            entry.episode.last_activity_seconds_ago = 0;
591            return (entry.episode.clone(), true);
592        }
593
594        // The driver runs while the map is locked, which is deliberate and not an oversight:
595        // two connections racing to attach under one external identity must produce one
596        // episode, and releasing the lock across the subprocess is how they would produce
597        // two. The cost is one attach at a time per server, which is the correct price.
598        //
599        // It is re-entrant across processes and safe to be. `capture session --event start`
600        // runs `serve ensure`, which probes this very server over HTTP from a child process
601        // — so an attach handled on the stdio thread is answered by the HTTP listener's
602        // thread, and one handled by the HTTP endpoint is answered by another of its
603        // workers. Nothing on that path touches this mutex, so the probe cannot wait on the
604        // attach that started it. `test/cases/200_generic_mcp_episode.sh` exercises both
605        // directions — a stdio client that is the server, and a client bridged to somebody
606        // else's — because an argument about threads is worth exactly as much as the run
607        // that confirms it.
608        let repository = self.driver.open(provider, external_id);
609        let episode = ConnectionEpisode {
610            external_id: external_id.to_string(),
611            provider: provider.to_string(),
612            peer: Some(peer.clone()),
613            opened_at: crate::peers::rfc3339(SystemTime::now()),
614            last_activity_seconds_ago: 0,
615            attachments: 1,
616            state: ConnectionEpisodeState::Open,
617            repository,
618        };
619        episodes.insert(
620            external_id.to_string(),
621            Entry {
622                episode: episode.clone(),
623                last_activity: Instant::now(),
624                detached_since: None,
625            },
626        );
627        (episode, false)
628    }
629
630    /// The client spoke. Every message on a connection holding an episode is a heartbeat for
631    /// it, so a working client never has its episode reaped and no client has to send
632    /// anything it would not otherwise send.
633    ///
634    /// ```
635    /// use std::time::Duration;
636    /// use majordomus_cli::episodes::EpisodeBoard;
637    /// use majordomus_cli::peers::{PeerBoard, Transport};
638    /// let peer = PeerBoard::new().attach(Transport::Http);
639    /// let board = EpisodeBoard::new();
640    /// board.attach(&peer, "busy", "generic");
641    /// board.touch(&peer);
642    /// assert_eq!(board.list()[0].last_activity_seconds_ago, 0);
643    /// assert!(board.reap(Duration::ZERO).is_empty(), "a held episode is never reaped");
644    /// ```
645    pub fn touch(&self, peer: &PeerId) {
646        let mut episodes = self.lock();
647        for entry in episodes.values_mut() {
648            if entry.episode.peer.as_ref() == Some(peer) {
649                entry.last_activity = Instant::now();
650            }
651        }
652    }
653
654    /// The connection went. The episode is **not** closed: it is detached, and the client
655    /// can come back to it by name for [`REATTACH_GRACE`].
656    ///
657    /// This is the difference between a lifecycle and a session counter. Closing here would
658    /// publish a record saying the work ended every time a socket dropped, and the work
659    /// almost never ends when a socket drops.
660    ///
661    /// ```
662    /// use majordomus_cli::episodes::{ConnectionEpisodeState, EpisodeBoard};
663    /// use majordomus_cli::peers::{PeerBoard, Transport};
664    /// let peer = PeerBoard::new().attach(Transport::Http);
665    /// let board = EpisodeBoard::new();
666    /// board.attach(&peer, "kept", "generic");
667    /// let detached = board.detach(&peer);
668    /// assert_eq!(detached.len(), 1);
669    /// assert!(detached[0].peer.is_none());
670    /// assert_eq!(board.list()[0].state, ConnectionEpisodeState::Detached, "still on the board");
671    /// assert!(board.detach(&peer).is_empty(), "nothing is held twice");
672    /// ```
673    pub fn detach(&self, peer: &PeerId) -> Vec<ConnectionEpisode> {
674        let mut episodes = self.lock();
675        let mut out = Vec::new();
676        for entry in episodes.values_mut() {
677            if entry.episode.peer.as_ref() == Some(peer) {
678                entry.episode.peer = None;
679                entry.episode.state = ConnectionEpisodeState::Detached;
680                entry.detached_since = Some(Instant::now());
681                out.push(entry.episode.clone());
682            }
683        }
684        out
685    }

687    /// Close one episode deliberately, by name: the client said it was done.
688    ///
689    /// ```
690    /// use majordomus_cli::episodes::{CloseReason, EpisodeBoard};
691    /// use majordomus_cli::peers::{PeerBoard, Transport};
692    /// let peer = PeerBoard::new().attach(Transport::Stdio);
693    /// let board = EpisodeBoard::new();
694    /// board.attach(&peer, "done", "generic");
695    /// let closed = board.close("done", CloseReason::Detach).expect("it was open");
696    /// assert!(closed.peer.is_none());
697    /// assert!(board.close("done", CloseReason::Detach).is_none(), "closed once only");
698    /// assert!(board.of_peer(&peer).is_none());
699    /// ```
700    pub fn close(&self, external_id: &str, reason: CloseReason) -> Option<ConnectionEpisode> {
701        let mut episodes = self.lock();
702        let entry = episodes.remove(external_id)?;
703        let mut episode = entry.episode;
704        episode.repository = self
705            .driver
706            .close(&episode.provider, &episode.external_id, reason);
707        episode.peer = None;
708        episode.state = ConnectionEpisodeState::Detached;
709        Some(episode)
710    }

712    /// Close every episode detached longer than `grace`. The reaper, and the answer to the
713    /// client that never comes back. Returns what it closed, each as
714    /// [`CloseReason::Expired`], which the record reads as interrupted.
715    ///
716    /// ```
717    /// use std::time::Duration;
718    /// use majordomus_cli::episodes::EpisodeBoard;
719    /// use majordomus_cli::peers::{PeerBoard, Transport};
720    /// let peer = PeerBoard::new().attach(Transport::Http);
721    /// let board = EpisodeBoard::new();
722    /// board.attach(&peer, "gone", "generic");
723    /// board.detach(&peer);
724    /// assert!(board.reap(Duration::from_secs(3600)).is_empty(), "inside the grace it waits");
725    /// assert_eq!(board.reap(Duration::ZERO).len(), 1);
726    /// assert!(board.list().is_empty());
727    /// ```
728    pub fn reap(&self, grace: Duration) -> Vec<ConnectionEpisode> {
729        let expired: Vec<String> = {
730            let episodes = self.lock();
731            episodes
732                .values()
733                .filter(|e| e.detached_since.is_some_and(|t| t.elapsed() > grace))
734                .map(|e| e.episode.external_id.clone())
735                .collect()
736        };
737        expired
738            .into_iter()
739            .filter_map(|id| self.close(&id, CloseReason::Expired))
740            .collect()
741    }
742
743    /// Close every episode: the server is stopping.
744    ///
745    /// An episode left open by a server that has gone is an episode nothing will ever close,
746    /// and the repository would carry it as open for ever — the failure ADR 0041 names on
747    /// the hook side, reached here by a different road.
748    ///
749    /// ```
750    /// use majordomus_cli::episodes::EpisodeBoard;
751    /// use majordomus_cli::peers::{PeerBoard, Transport};
752    /// let peers = PeerBoard::new();
753    /// let board = EpisodeBoard::new();
754    /// board.attach(&peers.attach(Transport::Stdio), "held", "generic");
755    /// let detached = peers.attach(Transport::Http);
756    /// board.attach(&detached, "waiting", "generic");
757    /// board.detach(&detached);
758    /// assert_eq!(board.close_all().len(), 2, "held and detached alike");
759    /// assert!(board.list().is_empty());
760    /// ```
761    pub fn close_all(&self) -> Vec<ConnectionEpisode> {
762        let ids: Vec<String> = self.lock().keys().cloned().collect();
763        ids.into_iter()
764            .filter_map(|id| self.close(&id, CloseReason::Shutdown))
765            .collect()
766    }

768    /// Every episode this server holds, open and detached, in external-identity order, each
769    /// with its idle time measured now rather than when it was last written.
770    ///
771    /// ```
772    /// use majordomus_cli::episodes::{ConnectionEpisodeState, EpisodeBoard};
773    /// use majordomus_cli::peers::{PeerBoard, Transport};
774    /// let peers = PeerBoard::new();
775    /// let board = EpisodeBoard::new();
776    /// let p = peers.attach(Transport::Stdio);
777    /// board.attach(&p, "b", "generic");
778    /// board.detach(&p);
779    /// board.attach(&peers.attach(Transport::Http), "a", "generic");
780    /// let states: Vec<_> = board.list().into_iter().map(|e| (e.external_id, e.state)).collect();
781    /// assert_eq!(states, [("a".to_string(), ConnectionEpisodeState::Open),
782    ///                     ("b".to_string(), ConnectionEpisodeState::Detached)]);
783    /// ```
784    pub fn list(&self) -> Vec<ConnectionEpisode> {
785        let episodes = self.lock();
786        episodes
787            .values()
788            .map(|e| {
789                let mut episode = e.episode.clone();
790                episode.last_activity_seconds_ago = e.last_activity.elapsed().as_secs();
791                episode
792            })
793            .collect()
794    }

796    /// The episode a connection holds, if it holds one. A connection that only initialised
797    /// holds none, and neither does one whose episode was detached from it.
798    ///
799    /// ```
800    /// use majordomus_cli::episodes::EpisodeBoard;
801    /// use majordomus_cli::peers::{PeerBoard, Transport};
802    /// let peer = PeerBoard::new().attach(Transport::Http);
803    /// let board = EpisodeBoard::new();
804    /// assert!(board.of_peer(&peer).is_none(), "a peer is not a worker until it attaches");
805    /// board.attach(&peer, "mine", "generic");
806    /// assert_eq!(board.of_peer(&peer).map(|e| e.external_id).as_deref(), Some("mine"));
807    /// ```
808    pub fn of_peer(&self, peer: &PeerId) -> Option<ConnectionEpisode> {
809        self.list()
810            .into_iter()
811            .find(|e| e.peer.as_ref() == Some(peer))
812    }
813
814    fn lock(&self) -> std::sync::MutexGuard<'_, BTreeMap<String, Entry>> {
815        self.episodes.lock().unwrap_or_else(|e| e.into_inner())
816    }
817}

842/// One JSON string, escaped. The payload is this tool's own and the identity in it came from
843/// a client, so it is escaped rather than trusted: a quote in an external identity that
844/// reached a shell's stdin unescaped would be a payload of somebody else's making.
845fn json_string(s: &str) -> String {
846    let mut out = String::with_capacity(s.len() + 2);
847    out.push('"');
848    for c in s.chars() {
849        match c {
850            '"' => out.push_str("\\\""),
851            '\\' => out.push_str("\\\\"),
852            '\n' => out.push_str("\\n"),
853            '\r' => out.push_str("\\r"),
854            '\t' => out.push_str("\\t"),
855            c if (c as u32) < 0x20 => out.push_str(&format!("\\u{:04x}", c as u32)),
856            c => out.push(c),
857        }
858    }
859    out.push('"');
860    out
861}
