Module release 

Source
Expand description

The release module: the changelog, the version, and the compatibility analysis behind it — all three derived.

Three capabilities, all read-only, all answered by crate::release — the same code the command line renders, the generated document is written from, and the site page shows. Neither reads a file somebody maintains: the changelog composes the layer’s own release records, decisions and the repository’s commits, and the version report reads the one place the version is authored and says whether the projection the shell tool prints is current.

Raising the version is not here. It writes tracked files, which makes it a repository mutation, and the exposure policy keeps repository mutations off every machine surface — so release bump is a command and nothing more, and this module is the read half.
