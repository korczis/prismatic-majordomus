Každá funkce proti každému rozhraní

Matice oběma směry: každá funkce proti příkazové řádce, HTTP API, MCP, Cockpitu a dokumentaci a každý modul schopnosti, veřejný příkaz a druh objektu proti funkcím, které ho jmenují. Každá značka je odvozená; mezera se ukáže.

Každá značka je odvozená. Funkce je na rozhraní, protože tam je promítnut schopnostní modul, shellový příkaz nebo druh objektu, který pojmenovává — cesta příkazové řádky, HTTP route, nástroj nebo zdroj MCP, oblast Cockpitu, dokument. Neříká to žádná stránka ani soubor.
