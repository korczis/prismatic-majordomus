Určit jako data, co patří do AI kontextu

Přečtěte deklarovanou politiku rozsahu repozitáře, zjistěte, které cesty jsou v indexu a které mimo něj, a nechte doctor a znalostní index aplikovat ji místo pevně zakódovaného seznamu.

○zaručeno Znalosti repozitářepokročilýmaintainerzapisuje stav

Situace

Klient AI indexuje, co najde: výstupy buildu, lokální adresář stavu, vendorovanou binárku, dump dat. Kontext se plní šumem a někdy i tajným údajem. Každý nástroj má vlastní seznam ignorovaných a žádný z nich není vlastním prohlášením repozitáře o tom, na čem záleží.

Co spouštíte

  • doctor: politika rozsahu existuje a lze ji zpracovat
  • knowledge sources, knowledge nodes --scope shared: co index objeví po uplatnění politiky
  • přes MCP: majordomus_scope čte politiku, majordomus_scope_classify odpovídá za jednu cestu

Scénář

setup: installed-wired
given:
  - 'installed, and the two enforcements the policy declares are actually in place as hooks'
steps:
  - id: declared
    run: ['doctor']
    note: 'the scope file is present and well-formed; init seeded it'
    expect:
      exit: 0
      stdout_contains: ['^OK   layout      .ai/repo/scope.yaml', 'doctor: 0 failure']
  - id: sources
    run: ['knowledge', 'sources']
    note: 'the source classes and the files each discovers, after the scope policy is applied'
    expect:
      exit: 0
      stdout_contains: ['^policy +shared', '^scope +shared']
  - id: nodes
    run: ['knowledge', 'nodes', '--scope', 'shared']
    note: 'the shared objects only: nothing under .ai/local/ is a node'
    expect:
      exit: 0
      stdout_contains: ['shared']
      stdout_not_contains: ['operational']
then:
  - 'what is in and out of the context is one file in the layer, with a schema'
  - 'build outputs, local state, binaries and secrets are out by declaration, not by luck'
  - 'the MCP server classifies a path with the same data'

Výsledek

Co patří do kontextu AI, se deklaruje jednou ve vrstvě, kontroluje se a uplatňuje ho shodně shellový nástroj i server. Klient, který to respektuje, indexuje repozitář, ne stroj.

Scénář

Provedeno proti skutečnému nástroji v repozitáři připraveném pomocí installed-wired, při každém generování tohoto webu. To, co následuje, není popis toho, co by se mělo stát; je to to, co se stalo.
