Architecture

One repository.Many interfaces.

Majordomus discovers a repository once, reads it into typed models, and derives its interfaces from them: the HTTP API and its OpenAPI description, Swagger UI, MCP, the Cockpit's generic pages and this site. The command line is declared a second time, in clap, and checked against the registry.

Repository

The tracked tree is the source of truth

prismatic-majordomus/

  • .ai/the layer: policy, rules, ADRs, skills
  • apps/the Rust executable and its capabilities
  • bin/the entry points
  • lib/the shell tool
  • share/kinds, schemas, the design
  • docs/manuals and generated documents
  • test/the cases
  • site/this website and the data derived for it

Key principles

  • One declarationMCP, HTTP and OpenAPI are built from it; the CLI is checked against it
  • Discoveredenumerated through sources.yaml, never registered by hand
  • Typedan object that does not validate is a diagnostic
  • Deterministicthe OpenAPI document: maps sorted, no timestamp
  • Provenanceevery field names where it came from
  • Checkeda hand edit of a derived file is refused or reported

Discovery

Enumeration governed by a declaration

  • The rootthe executable finds the repository
  • The manifest.ai/manifest.yaml names the layer
  • Kinds and schemasshare/kinds.yaml and share/schemas/
  • Sourcessources.yaml classes, read from the git index
  • Diagnosticsa file that does not validate is excluded and named
2

Canonical model

Typed, with provenance

Resolved in full or fast; both produce the same type, and a value nothing resolved is absent, never zero.
