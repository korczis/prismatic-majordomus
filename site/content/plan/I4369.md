title = "I4369 — A record renamed with `replaces:` keeps its GitHub issue or milestone, and an issue whose record was renamed without one stays unmanaged, names the commit that removed its record, and is never closed or reused"
description = "The issue and milestone schemas gain a key `replaces`, a list of former ids, with share/allow/issue.txt and share/allow/milestone.txt regenerated by `majordomus generate`. plan validate, in both engines (lib/project.awk and apps/majordomus-cli/src/plan.rs, compared by case 99), refuses a `replaces` entry that names a record still present, or a former id claimed by two records. scripts/github-sync, and so the forge command that packages it (I4370), resolves an issue projected for a replaced id as the replacing record's issue: it moves the identity marker to the replacing record and retitles the issue, so one GitHub number survives the rename, and --check reports the replacing record `behind`, not `missing`, and the old issue not `unmanaged`. A milestone, which github-sync finds by its `<id> — ` title prefix (github-sync:277), is found by a replaced id's prefix the same way and retitled, so its number and its issues' assignment survive. When both the old and the new id already have an issue, --apply closes the old one as not planned with the comment 'superseded by #<n>', and from then on --check does not report it unmanaged. Without `replaces:`, nothing new is invented: the old issue stays `unmanaged` (github-sync:1121-1130), --check exits 11 on it (:1138), and --apply never closes it, never reuses its number and never rewrites its marker. The unmanaged finding gains one fact when git history holds the record (`git log --diff-filter=D` on its path): the commit that removed it, so a forgotten `replaces:` is told apart from an id that was never a record here; where the history cannot be read (a shallow clone) the finding says so instead of reading as never a record. `next --kind issue` (I4357) counts replaced ids as taken, and the identifier landing check refuses a new record whose id a `replaces` entry names."
