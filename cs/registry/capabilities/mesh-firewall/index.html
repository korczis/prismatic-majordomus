mesh.firewall

Jaký příchozí provoz deklarace implikuje, že tento stroj musí přijmout — port multicastové skupiny, port broadcastu, je-li povoleným záložním řešením, každý deklarovaný port hubu, jehož adresa je adresou tohoto stroje, a vlastní port serveru, když naslouchá mimo loopback — z privátních sítí, které deklarace jmenuje; jakou frontu firewallu tento host provozuje (ufw, nftables, aplikační firewall macOS); příkazy, které plán tam povolí; co o plánu nyní říká sám firewall (present, missing, inactive nebo bez root nepozorovatelný); a co jádro za posledních pět minut zalogovalo jako zahozené směrem k těmto portům. Selže, když je pozorováno chybějící pravidlo nebo byl zalogován drop. Čte hosta; nic nemění.

output · FirewallReport

Celý report: plán, backend, příkazy, slovo firewallu a jádra, s jednou větou verdiktu a jedním ok. To, co odpovídá mesh.firewall a co čte kontrola firewall doctoru.

use majordomus_cli::mesh::firewall::{report, FirewallReport, BLOCK_WINDOW_SECONDS};

let r: FirewallReport = report(None, &[], None);
assert!(r.ok && r.commands.is_empty());
assert_eq!(r.window_seconds, BLOCK_WINDOW_SECONDS);
assert_eq!(r.platform, std::env::consts::OS);
vlastnosttyppovinnépopis
backend reference ano Nalezená čelní vrstva firewallu.
blocked_recently object | null ne Zahození, která kernel zaznamenal směrem k portům plánu v rámci okna, po portech; chybí, když se log nepodařilo přečíst.
commands array ano Příkazy, které ho na tomto backendu připouštějí; to, co spouští apply.
spustitelný soubor string | null ne Spustitelný soubor, jako který server běží, což je to, co firewall macOS připouští.
pozorování reference ano Vlastní slovo firewallu o plánu.
ok boolean ano Zda hostitel mesh připouští, pokud to lze pozorovat: nic nechybí a nic není zaznamenáno jako zahozené.
plan reference ano Co z deklarace vyplývá, že musí tento hostitel připustit.
platforma string ano Platforma (linux, macos, …).
verdikt string ano Věta, kterou člověk čte.
window_seconds integer ano Okno, které blocked_recently pokrývá, v sekundách.
