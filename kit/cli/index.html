CLI

One command linefor the whole layer.

A capability that claims a command answers there through the same executor the HTTP API and the MCP tools ask; the clap tree is checked against the registry in both directions. The task lifecycle, start, check and finish, belongs to the shell tool, the other program that answers to majordomus.

  • Instant overview

    majordomus env: the project, version control, the toolchains, the layer and the local services.

  • A documented reference

    202 commands and 204 examples, generated from apps/majordomus-cli/src/cli.rs.

  • Shell integration

    majordomus completion answers a shell from the command graph.

  • Built for automation

    Machine-readable output where a command takes --format json or --json.

Consistent everywhere

The same capability on the command line, over HTTP and as an MCP tool.

  • Deterministicthe same input projects the same bytes
  • Checkeda projection that disagrees fails the build

  • Generatedthe reference is rendered from the clap tree
