Princip

Z repozitářena každý povrch.

Majordomus zjistí, co repozitář deklaruje, z toho sestaví jeden typovaný index a registr schopností a z něj promítá každé rozhraní: HTTP API popsané OpenAPI, MCP, Cockpit a tento web a příkazovou řádku kontrolovanou proti registru. Jeden model, mnoho projekcí.
