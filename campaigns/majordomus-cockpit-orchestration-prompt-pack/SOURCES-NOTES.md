# Source Notes

This pack was derived from two supplied project texts:

1. The "dynamic CLI banner" design, whose key architectural invariant is a typed canonical repository/environment representation feeding CLI JSON, API, OpenAPI/Swagger, MCP and Cockpit rather than duplicating values in `.envrc` or frontend code.
2. The "canonical deterministic ordering" implementation prompt, which formalizes Majordomus-wide requirements for inferred/derived metadata, deterministic ordering, zero consumer registration, cross-surface contracts, rules/doctrines, validation, migration and E2E testing.

The runtime orchestration requirements supplied with this pack extend the same architecture to context compilation, model routing, switching, escalation, provenance and cross-model handover.
