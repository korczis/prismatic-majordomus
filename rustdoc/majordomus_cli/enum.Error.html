Transport(Error)

§

Refused

A subsystem refused an operation and carries its own message and exit code. The message is the subsystem’s, complete, and is printed as it is: rephrasing an actionable refusal into a generic one is how a person loses the corrective command.

Fields

§code: u8

The exit code the subsystem’s own contract assigns.

§reason: String

What failed, why, what was involved, and what to run instead.

§

Protocol

A protocol frame could not be encoded, or an internal answer could not be produced.

Fields

§reason: String

What is wrong.

§

Registry

The violations, in id order.

§

Http

Fields

§reason: String

What is wrong.

Lease

Fields

§reason: String

What is wrong.

DeploymentNotFound

Fields

§

InvalidDeployment

A deployment object exists and cannot be read as one.

Fields

§reason: String

What is wrong, with the file, the key, the value and the correction.

§

CapabilityNotFound

No capability has this id.

Fields

§id: String

The id asked for.

§

NotFound

A caller named something this repository does not hold. Not the caller’s fault in the sense an internal error is: the request was well formed and the thing is absent, which is the missing-artifact code and not the internal one.

Fields

§reason: String

What was asked for and where the caller can see what exists.

§

InvalidPolicy

The policy file does not parse, or does not carry what the projections need.

Fields

§path: PathBuf

The policy file.

§reason: String

What is wrong.

§

InvalidProjection

A declared provider projection cannot be produced.

Fields

§target: String

The declared target.

§reason: String

What is wrong.

§

InvalidSurface

A web surface’s declaration cannot be read, or the topology it would join is not valid.

Fields

§surface: String

The surface’s id, or the declaration’s path when the id is what is wrong.

§reason: String

What is wrong, and what to do about it.

§

InvalidDistribution

The distribution model cannot be read, or it breaks an invariant of its own contract.

Fields

§path: String

Where the model was read from.

§reason: String

What is wrong, and what to do about it.

§

InvalidRelease

A release record cannot be read, or it disagrees with the distribution model.

Fields

§path: String

Where the record was read from.

§reason: String

What is wrong, and what to do about it.

§

InvalidDesign

The design declaration, or a projection rendered from it, is inconsistent: a role naming no palette entry, a state word filed under two meanings, a value the CSS parser would drop in silence. Nothing is written.

Fields

§path: String

The declaration, or the projection that could not be rendered.

§reason: String

What is wrong.

§

InvalidSource

A Rust source file of the crate under inspection cannot be read or parsed, so the quality inventory would be built over less than the whole crate. Reported rather than skipped: a partial inventory that looked clean would be the one result this subsystem must never produce.

Fields

§path: String

The file, crate-relative when it is inside the crate.

§reason: String

What is wrong, and what to do about it.

§

UnresolvedRelation

The layer names something this repository does not hold, so the graph composed from it would carry a reference to nothing. Nothing is written: a published graph whose reference resolves to no node is a naming defect a reader cannot see, and every regeneration would reproduce it.

Fields

§findings: Vec<String>

One line per finding: the file, the key, what was named, and the correction.

§

Stale

generate --check found committed projections that differ from the registry, or are missing.

Fields

§files: Vec<String>

Each stale file with (differs) or (missing).
