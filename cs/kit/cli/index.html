CLI

Jedna příkazová řádkapro celou vrstvu.

Schopnost, která si nárokuje příkaz, tam odpovídá přes stejný exekutor, na který se ptají HTTP API a nástroje MCP; strom clap se kontroluje proti registru v obou směrech. Životní cyklus úlohy, start, check a finish, patří shellovému nástroji, druhému programu, který odpovídá majordomu.

  • Zdokumentovaná reference
