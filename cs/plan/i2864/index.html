I2864 — The site generator reads no output of a later derive stage

scripts/generate-site-data (derive stage B) takes the editors projection's skill files from a source stage A has already written, not from docs/generated/artifacts.json, which stage C rewrites after it. No stage then reads another stage's later output, as scripts/derive's header already claims.

!ZRUŠENO vlna 0 · p2 · implementační profil · bezpečné paralelně

Součást derived-data-integrity — Commitnuté odvození popisuje něco, čeho může být projekcí.

Cíl

scripts/generate-site-data (derive stage B) takes the editors projection's skill files from a source stage A has already written, not from docs/generated/artifacts.json, which stage C rewrites after it. No stage then reads another stage's later output, as scripts/derive's header already claims.

Proč

Found on 2026-10-21 while closing I2847. scripts/generate-site-data reads docs/generated/artifacts.json (the .claude/skills/*/SKILL.md rows of the editors projection) to list the skills an agent reads by name. scripts/derive's header says stage C writes that manifest after stage B, and that 'no stage reads its own output; stage C's outputs are read by nothing but the site build'. So stage B reads the manifest the previous derive left. Declaring it an input (the first cut of I2847) moved the fingerprint on every derive, and the commit was refused as stale. I2847 therefore exempts it, and the ordering defect is left open here.

Aktuální stav

Stage B reads docs/generated/artifacts.json, which stage C writes after it. A derive that adds or removes a skill shows the change on the site only one derive later.

Cílový stav

Stage B lists the editors projection's skill files from stage A's output, or from the projection's own declaration, never from the manifest stage C writes. Case 3246 then drops docs/generated/artifacts.json from its exemptions, and a single derive after adding a skill shows it.

Důkazy

Nic nezaznamenáno. Za každým tokenem výše musí stát příkaz nebo artefakt, než lze tento úkol dokončit; vyprávění se odmítá.

Zpráva o dokončení

Cancelled 2026-10-21 before any code was written: the premise is wrong. scripts/derive runs the same `majordomus generate --repo <root> --strict` (every target) in stage A and in stage C, so docs/generated/artifacts.json is written by stage A, before scripts/generate-site-data runs, and only rewritten by stage C. The rows stage B reads from it are the editors projection's skill files (.claude/skills/*/SKILL.md, their kind and source), stage A's output and a function of .ai/repo/skills/*/SKILL.md, which the generator already declares as inputs. So stage B reads current data. What was real is that the whole file's hash changes when stage C rewrites it, which is why I2847 keeps the file out of the input fingerprint; case 3246's exemption now says so.
