title = "I4668 — doctor names every heavy process group that no session, claim, run record or declared service accounts for, with the inbound SSH peer that started it, and the owner pauses one through a governed command"
description = "One capability sweeps the local process table and groups heavy work by process group. A group is heavy when its summed CPU or resident memory stays above a policy threshold (machine.heavy_process: cpu_percent, rss_mib, sustained_seconds, min_members) for the declared interval. Each heavy group is attributed from facts only, in this order: a live session's process tree (the provider registry who.rs already reads), a mesh claim or board row that records the pid or group, an offload run record or the owner variables in the environment, and a declared service (machine.services of I4622 once it exists). A group none of them accounts for is unattributed. When its parent chain reaches an SSH server's per-connection process, the report names the inbound peer address and port, the remote user and the connection's start time. Otherwise it names the chain up to init. `majordomus mesh who --unattributed` lists every unattributed heavy group with its process group, leader, member count, summed CPU and memory, start time, chain and peer. doctor reports one WARN that counts them and names that command. `majordomus machine pause <pgid> --because <text>` sends SIGSTOP to the group, and `machine resume <pgid>` sends SIGCONT. Each one is refused unless an owner approval names that group and its leader's start time. Each one writes a ledger line with the attribution, the approval and the reason. Nothing is killed, and no file or permission is changed."
