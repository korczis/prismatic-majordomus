HTTP API: economics

Co spotřebuje programovací relace s nainstalovaným Majordomus a bez něj, ze zaznamenaných běhů: spárované kontrolní a ošetřené relace posuzované týmiž skrytými akceptačními testy, využití providera tak, jak je ohlásil, a každé číslo označené třídou měření (observed, counted, derived, estimated, counterfactual). Jedna kalkulačka; každý povrch je její projekce a verdikt říká jen to, co dovoluje pravidlo publikace metodiky.

  • economics.check

GET /api/v1/economics economics.summary

Shrnutí ekonomiky tokenů

Každá metrika benchmarku ekonomiky s hodnotou, třídou měření, velikostí vzorku, rozdělením a bootstrapovým intervalem; každá dvojice běhů s jejím stavem (valid, control failed, treatment failed, incomparable, ...); výsledky podle segmentů; stav důkazů každé sady (current, stale, incompatible); a jediné tvrzení, které pravidlo publikace dovoluje. Snížení kontextu a snížení celkových tokenů jsou samostatné metriky a nikdy se neslučují.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache procesu (max_entries=8, ttl_seconds=5)
  • Nástroj MCP majordomus_economics
  • zdroj MCP {"name": "economics", "uri": "majordomus://economics"}
  • $ economics summary

assert!(report.ok && report.findings.is_empty(), "an empty repository claims nothing");

assert_eq!(serde_json::from_value::<EconomicsCheckReport>(json).unwrap(), report);

Používá economics.check

EconomicsClass

"observed" | "counted" | "derived" | "estimated" | "counterfactual"
Jak číslo vzniklo. Třídy jsou seřazeny od nejsilnější po nejslabší a hodnota vypočtená z několika vstupů není nikdy silnější než nejslabší z nich.

use majordomus_cli::economics::model::EconomicsClass;
assert_eq!(serde_json::to_value(EconomicsClass::Counterfactual).unwrap(), "counterfactual");
let parsed: EconomicsClass = serde_json::from_value("observed".into()).unwrap();
assert!(parsed < EconomicsClass::Estimated, "a stronger class sorts first");
  • observedVráceno poskytovatelem nebo jeho harness za běhu a zaznamenáno beze změny.
  • countedVypočteno deterministicky z bajtů na disku pojmenovaným, připnutým tokenizérem.
  • derivedAritmetika nad pozorovanými nebo spočtenými hodnotami.
  • estimatedČíslo, které zastupuje takové, které nikdo neměřil. Nikdy se neporovnává, nikdy nepublikuje.
  • counterfactualČemu by mechanismus zabránil, modelováno, ne pozorováno.

object
Odpověď economics.explain: jedna metrika a vše, na čem stojí.

Repozitář, který nedeklaruje metodiku měření výkonu, nic nemě­ří, takže nemá metriku k vysvětlení: odpovídá se mu tak, jak odpovídá economics.summary — present: false, tvrzení proč, žádná metrika a žádné číslo — a neodmítá se, protože repozitář, který sám sebe neměří, není chybný požadavek. Používá economics.explain

EconomicsFinding

object
Jedna věc, kterou kontrola odmítá. detail jmenuje nápravu, takže se podle nálezu dá jednat bez čtení metodiky. Nález o tvrzení nebo souboru, ne o řádku, nenese line a jeho JSON klíč vynechává. Druhy:

  • unsupported_quantity: číslo napsané do ručně psané prózy vedle slovníku ekonomiky.
  • claim_unsupported: vazba na tvrzení, která neplatí — vázané tvrzení chybí v docs/CLAIMS.yaml, nebo je guaranteed, zatímco jeho metrika nestojí tam, kde vazba říká, nebo jeho důkazy nejsou aktuální.
  • claim_unbound: tvrzení guaranteed říká, že tokeny, kontext nebo cena klesají, a žádná vazba ho nespojuje s metrikou.
  • claim_duplicate: jedno id tvrzení se v docs/CLAIMS.yaml vyskytuje více než jednou.
  • declarations_unreadable: deklarace měření výkonu nelze přečíst, takže nelze ukázat, že platí jakákoli vazba.
  • claims_unreadable: docs/CLAIMS.yaml existuje a nelze ho přečíst ani parsovat.
  • scan_failed: próza nešla vypsat nebo se soubor v ní nedal přečíst, takže nelze říct, že je čistá.
use majordomus_cli::economics::claims::EconomicsFinding;
let finding = EconomicsFinding {
    kind: "claim_unsupported".into(),
    path: "docs/CLAIMS.yaml".into(),
    line: None,
    detail: "set the claim to planned, or record the evidence".into(),
};
let json = serde_json::to_value(&finding).unwrap();
assert!(json.get("line").is_none(), "no line, no key");
assert_eq!(serde_json::from_value::<EconomicsFinding>(json).unwrap(), finding);

druh string ano unsupported_quantity, claim_unsupported, claim_unbound, claim_duplicate, declarations_unreadable, claims_unreadable nebo scan_failed.
path string ano Cesta relativní k repozitáři.
řádek integer | null ne Řádek od 1, když se nález týká řádku.
