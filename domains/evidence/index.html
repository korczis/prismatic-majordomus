Evidence

A claim names the test that settles it, a recorded run is judged against the commit it ran at, and a claim with no recorded run says so.

The failure it answers

Claims outrun proof. The documentation says one thing, the runtime does another, and nobody can show which is true.

What shows that a statement about the product is true: claims joined to the executions recorded for their tests, use cases the tool runs against itself, measurements of speed and of token cost that are recorded rather than typed, and the provenance of every record. A run against this commit is never reported as the same thing as a run whose inputs merely have not changed.

Not in this domain: the verdict on one task, which is completion; and the rules a claim is about, which is governance.

The failure modes its features answer

Operational moments from the Why catalogue that name a rule, a command, a capability or a claim of a feature in this domain. Nothing here was assigned.

  • →re-explained the same context to a brand-new session
  • →opened CLAUDE.md and AGENTS.md and found two different rulebooks for one repository
  • →found a task "in progress" that nobody had touched for three weeks
  • →asked what the workers did last night and had only transcripts to grep
  • →found five worktrees and could not say which of them still mattered
  • →found finished work on a branch that nobody ever merged
Every failure mode it answers (19)
  • The policy changed and its four copies did not
  • A change that no plan ever asked for
  • Nobody can reconstruct where the milestone actually is
  • A capability the documentation promises and nothing proves
  • The interface changed and its contract document did not
  • The documented command that no longer works
  • Green tests over stale generated files
  • Nobody can say why that worker was chosen
  • Spend that cannot be tied to anything accepted
  • A failure that was seen once and never again
  • A public page promising something nothing tests
  • A result nobody can reproduce, including its author
  • A change whose provenance cannot be reconstructed
