# the session start opens a mesh session as <provider>-<provider session> (mj_capture_mesh_join, lib/capture.sh) and exports no variable naming it, so nothing a session's own processes run can name the mesh session they work for except the provider's session variable or MAJORDOMUS_OWNER_SESSION, the pair mesh who reads (apps/majordomus-cli/src/mesh/who.rs). I4561 (feat/a-ledger-line-names-its-writer, in flight) writes it into every ledger line from that pair.
