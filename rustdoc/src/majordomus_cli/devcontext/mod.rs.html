1//! The context compiler: what a development session should be given, derived from the
2//! repository rather than composed by hand.
3//!
4//! # What this is for
5//!
6//! A session that is handed a large hand-written prompt is handed somebody's memory of the
7//! repository; a session that reads the repository from scratch on every request pays for
8//! discovery it has already paid for. This module is the third option: given an issue, a
9//! milestone, a free-text intent, some paths, or nothing at all, it derives the set of
10//! canonical objects that bear on the work, says why each one is in the set, says what it
11//! left out and why, and reports what the whole thing cost against a budget.
12//!
13//! # It is not a second context system
14//!
15//! `majordomus context` already assembles what a worker needs *now*: git, the active task,
16//! its profile, the directory contracts over its scope, the open questions, the decisions,
17//! the newest checkpoint, the most relevant handover, recent history — in authority order,
18//! within a line budget, printing what it dropped. That command is the session briefing and
19//! it stays the authority for it. What it cannot do is answer *about a piece of work* rather
20//! than about the present moment, and its output is text: its own JSON projection carries
21//! `sections[]` of `{id, lines, text}`, which is the assembled prose, not the selection.
22//!
23//! So this module keeps the same authority order — [`Tier`] is that order applied to
24//! objects instead of to sections — and changes three things:
25//!
26//! - **The unit is an object, not a section.** Every entry carries the canonical
27//!   identifier, the index's own provenance, the selector that reached it, the reason, the
28//!   confidence, the version and the cost. Nothing is flattened to text here; rendering a
29//!   prompt is a projection of this value and lives downstream of it.
30//! - **It is keyed on the work.** An issue, a milestone, an intent or a path, not only the
31//!   session that happens to be open.
32//! - **It deduplicates and explains.** The same ADR reached by four paths is one entry with
33//!   four recorded discoveries, and the answer says which paths those were.
34//!
35//! It also reuses rather than reimplements: the local records come from `continuity.state`,
36//! the typed relations from [`crate::graph::COMPOSED`] — the repository's own dependency
37//! graph, where every reference the layer declares is already resolved — and the objects
38//! from the index. There is no second relation table, no glob and no walk of the tree.
39//!
40//! # The performance contract
41//!
42//! Nothing here is built when a [`crate::capability::Context`] is composed. The compiler
43//! runs inside its handler, over values already in memory, for the reason
44//! [`crate::plan`] states about the plan: "`App::load` has a stated budget and
45//! 200 project records have no business inside it." Deriving the composed graph over this
46//! repository is milliseconds; building the index is seconds, and it is built once per
47//! process. The answer carries the index fingerprint, so an answer is valid exactly as long
48//! as the index it was computed from, and a caller can tell two trees apart without asking.
49//!
50//! # A call, end to end
51//!
52//! The whole module is three functions over one input type. [`compile`] answers *what
53//! should this session be given*, [`explain`] answers *why is this one thing in or out of
54//! that*, and [`policy`] answers *by what rules* — the last needing no request at all,
55//! because the rules do not depend on what is being asked about.
56//!
57//! The request below names nothing, which is the smallest legitimate one: the governance
58//! applies to every session whether or not anybody asked for it, so the answer is not empty.
59//!
60//! ```
61//! use majordomus_cli::devcontext::{compile, explain, policy, CompileInput, ExplainInput};
62//! use majordomus_cli::devcontext::{Standing, Tier};
63//! use majordomus_cli::synthetic::SyntheticRepository;
64//!
65//! let repo = SyntheticRepository::small().unwrap();
66//! let ctx = repo.context().unwrap();
67//!
68//! // what should a session here be given, with nothing asked for?
69//! let compiled = compile(&ctx, CompileInput::default()).unwrap();
70//! assert!(
71//!     compiled.selected.iter().any(|e| e.kind == "policy"),
72//!     "the governance applies without being asked for",
73//! );
74//! assert_eq!(compiled.budget.tiers.len(), Tier::ORDER.len());
75//!
76//! // and why is that entry in it? — judged under the same request, so "excluded for
77//! // budget" is a statement about a budget the caller can see
78//! let first = compiled.selected[0].uri.clone();
79//! let why = explain(&ctx, ExplainInput { uri: first.clone(), request: CompileInput::default() })
80//!     .unwrap();
81//! assert_eq!(why.standing, Standing::Selected);
82//! assert_eq!(why.uri, first);
83//! assert!(why.entry.is_some() && !why.detail.is_empty());
84//!
85//! // something the index does not hold is `unknown`, not an error
86//! let absent = explain(
87//!     &ctx,
88//!     ExplainInput { uri: "majordomus://rule/nothing-like-this@1".into(), ..Default::default() },
89//! )
90//! .unwrap();
91//! assert_eq!(absent.standing, Standing::Unknown);
92//!
93//! // by what rules? — readable without a request, because they do not depend on one
94//! let rules = policy(&ctx).unwrap();
95//! assert_eq!(rules.tiers.len(), Tier::ORDER.len());
96//! assert!(rules.edges.iter().any(|e| e.refused), "and it says what it will not follow");
97//! ```

122/// What to compile a context about.
123///
124/// Every field is optional. A request that names nothing still gets an answer: the
125/// governance the layer applies to everything, and what the last session left — which is
126/// the smallest true context there is.
127///
128/// The seeds are additive, not alternative: `issue`, `milestone`, `uris`, `paths` and
129/// `intent` all contribute, and naming several is the normal case rather than a conflict.
130/// `intent` is the only one the compiler infers from, which is why every entry it produces
131/// carries [`Selector::IntentMatch`] and a confidence below one.
132///
133/// `deny_unknown_fields` is deliberate. This is the input of a served capability, so a
134/// misspelled field is a request that does not mean what its author thought; refusing it is
135/// the difference between a typo and a silently smaller answer.
136///
137/// ```
138/// use majordomus_cli::devcontext::CompileInput;
139/// use serde_json::json;
140///
141/// // the smallest legitimate request, which is not the same as no request
142/// let nothing: CompileInput = serde_json::from_value(json!({})).unwrap();
143/// assert_eq!(nothing, CompileInput::default());
144/// assert!(nothing.issue.is_none() && nothing.paths.is_empty());
145///
146/// // the seeds combine rather than compete
147/// let both: CompileInput = serde_json::from_value(json!({
148///     "issue": "I0301",
149///     "paths": ["apps/majordomus-cli/src"],
150///     "intent": "explain the budget",
151///     "budget_tokens": 4_000,
152/// })).unwrap();
153/// assert_eq!(both.issue.as_deref(), Some("I0301"));
154/// assert_eq!(both.paths, ["apps/majordomus-cli/src"]);
155/// assert_eq!(both.budget_tokens, Some(4_000));
156///
157/// // and a misspelled field is refused rather than quietly ignored
158/// let typo = serde_json::from_value::<CompileInput>(json!({"max_dept": 2}));
159/// assert!(typo.is_err(), "a typo must not become a smaller answer");
160/// ```
161#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize, JsonSchema)]
162#[serde(deny_unknown_fields)]
163pub struct CompileInput {
164    /// An issue id (`I0301`) or its canonical identifier. Its milestone, its dependencies,
165    /// its declared scope and the decisions over that scope follow from it.
166    #[serde(default, skip_serializing_if = "Option::is_none")]
167    pub issue: Option<String>,
168    /// A milestone id or slug, or its canonical identifier.
169    #[serde(default, skip_serializing_if = "Option::is_none")]
170    pub milestone: Option<String>,
171    /// What the session is trying to do, in words. The only input the compiler infers
172    /// from, and every entry it produces says so and carries a confidence below one.
173    #[serde(default, skip_serializing_if = "Option::is_none")]
174    pub intent: Option<String>,
175    /// Repository-relative paths the work touches, added to whatever the seeds declare.
176    #[serde(default, skip_serializing_if = "Vec::is_empty")]
177    pub paths: Vec<String>,
178    /// Canonical identifiers to seed with directly, for a request about something that is
179    /// neither an issue nor a milestone.
180    #[serde(default, skip_serializing_if = "Vec::is_empty")]
181    pub uris: Vec<String>,
182    /// The ceiling in estimated tokens; [`DEFAULT_BUDGET_TOKENS`] when absent.
183    #[serde(default, skip_serializing_if = "Option::is_none")]
184    pub budget_tokens: Option<u64>,
185    /// How far from a seed the walk goes; [`DEFAULT_MAX_DEPTH`] when absent.
186    #[serde(default, skip_serializing_if = "Option::is_none")]
187    pub max_depth: Option<usize>,
188    /// Relevance below which an entry is reported rather than given; [`DEFAULT_FLOOR`]
189    /// when absent.
190    #[serde(default, skip_serializing_if = "Option::is_none")]
191    pub floor: Option<f64>,
192    /// Every blocking rule of the layer, not only the ones the work reaches. Honest and
193    /// usually over budget: the answer then says `over_budget` rather than dropping what it
194    /// may not drop.
195    #[serde(default, skip_serializing_if = "Option::is_none")]
196    pub all_blocking_rules: Option<bool>,
197}

242/// What one identifier's standing in a compiled context is.
243/// Where one identifier stands with respect to a compiled context.
244///
245/// The pair to be careful about is `NotReached` and `Unknown`, because they look alike in a
246/// rendering and mean opposite things. `NotReached` says the index holds the object and this
247/// request did not reach it — the request is what to change, and raising the depth or the
248/// budget may well bring it in. `Unknown` says the index holds nothing under that
249/// identifier: the request is fine and the identifier is wrong, or the object is not in
250/// this repository. Collapsing the two would send a reader to tune a request that was never
251/// the problem.
252///
253/// `Deduplicated` is the third one worth naming: the thing is *in* the answer, under another
254/// identifier, which is neither in nor out.
255///
256/// ```
257/// use majordomus_cli::devcontext::Standing;
258///
259/// // in the answer, one way or another
260/// let present = [Standing::Selected, Standing::Deduplicated];
261/// // reached and not given, so the request is what to change
262/// let request_bound = [Standing::Excluded, Standing::NotReached];
263/// for s in present {
264///     assert!(!request_bound.contains(&s));
265/// }
266///
267/// // the two that must not be confused: one is the request's fault, one is not
268/// assert_eq!(Standing::NotReached.as_str(), "not_reached");
269/// assert_ne!(Standing::NotReached, Standing::Unknown);
270/// assert_eq!(
271///     serde_json::to_value(Standing::NotReached).unwrap(),
272///     serde_json::json!(Standing::NotReached.as_str()),
273/// );
274/// ```
275#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
276#[serde(rename_all = "snake_case")]
277// `worktree` already answers with a `Standing` about a branch, and the OpenAPI document has
278// one component namespace: two enums under one name would be one component defined twice.
279#[schemars(rename = "DevContextStanding")]
280pub enum Standing {
281    /// In the answer.
282    Selected,
283    /// Reached and not given; the exclusion says why.
284    Excluded,
285    /// Folded into another identifier, or dropped for one.
286    Deduplicated,
287    /// The index holds it and this request never reached it.
288    NotReached,
289    /// The index holds nothing under that identifier.
290    Unknown,
291}

293impl Standing {
294    /// The word this standing is reported under.
295    ///
296    /// ```
297    /// use majordomus_cli::devcontext::Standing;
298    /// assert_eq!(Standing::NotReached.as_str(), "not_reached");
299    /// ```
300    pub fn as_str(self) -> &'static str {
301        match self {
302            Standing::Selected => "selected",
303            Standing::Excluded => "excluded",
304            Standing::Deduplicated => "deduplicated",

311/// The input of `devcontext.explain`: one identifier, and the request to judge it under.
312///
313/// The request is not optional context for the question — it is half of the question.
314/// "Why is this ADR not in my context" has no answer in the abstract: it is in or out of a
315/// *particular* compiled answer, and "excluded for budget" is only actionable when the
316/// budget it did not fit in is known. So the same fields `compile` takes are `flatten`ed in
317/// here, which also means the wire form is one flat object rather than a nested `request`,
318/// and the command line can share its flags.
319///
320/// ```
321/// use majordomus_cli::devcontext::ExplainInput;
322/// use serde_json::json;
323///
324/// // flattened: the request's fields sit beside `uri`, not under it
325/// let input: ExplainInput = serde_json::from_value(json!({
326///     "uri": "majordomus://adr/0052",
327///     "budget_tokens": 2_000,

330/// assert_eq!(input.uri, "majordomus://adr/0052");
331/// assert_eq!(input.request.budget_tokens, Some(2_000));

334/// // and the identifier alone is a complete question, judged under the default request

343    pub uri: String,
344    /// The request it would be compiled under; the same fields as `devcontext.compile`.
345    #[serde(default, flatten)]
346    pub request: CompileInput,
347}

378/// Why one identifier is, or is not, in a compiled context.
379///
380/// `standing` says which of the five cases this is, and the three optional fields are the
381/// evidence for it: at most one of `entry`, `excluded` and `deduplicated` is populated, and
382/// which one is determined by the standing rather than independent of it. `detail` is the
383/// same answer in words, so the value is legible without a reader matching them up.
384///
385/// `budget` is always present, including when the answer is `unknown`, and that is the
386/// point of carrying it: the commonest reason to ask this question is an entry that did not
387/// fit, and an explanation that said "excluded for budget" without the budget would need a
388/// second call to act on.
389///
390/// ```
391/// use majordomus_cli::devcontext::{compile, explain, CompileInput, ExplainInput};
392/// use majordomus_cli::devcontext::{Explanation, Standing};
393/// use majordomus_cli::synthetic::SyntheticRepository;
394///
395/// let repo = SyntheticRepository::small().unwrap();
396/// let ctx = repo.context().unwrap();
397/// let compiled = compile(&ctx, CompileInput::default()).unwrap();
398/// let selected = compiled.selected[0].uri.clone();
399///
400/// // something in the answer: the entry is the evidence, and the other two are empty
401/// let e: Explanation =
402///     explain(&ctx, ExplainInput { uri: selected.clone(), ..Default::default() }).unwrap();
403/// assert_eq!(e.standing, Standing::Selected);
404/// assert_eq!(e.entry.as_ref().unwrap().uri, selected);
405/// assert!(e.excluded.is_none() && e.deduplicated.is_none());
406/// assert!(!e.detail.is_empty(), "the standing always reads as a sentence too");
407///
408/// // something this repository does not hold: an answer, not an error — and the budget
409/// // the judgement was made under is carried even here
410/// let absent: Explanation = explain(
411///     &ctx,
412///     ExplainInput { uri: "majordomus://adr/9999".into(), ..Default::default() },
413/// )
414/// .unwrap();
415/// assert_eq!(absent.standing, Standing::Unknown);
416/// assert!(absent.entry.is_none());
417/// assert_eq!(absent.budget.limit_tokens, compiled.budget.limit_tokens);
418/// ```
419#[derive(Debug, Clone, PartialEq, Serialize, Deserialize, JsonSchema)]
420pub struct Explanation {
421    /// What was asked about.
422    pub uri: String,
423    /// Where it stands.
424    pub standing: Standing,
425    /// The same, in words.
426    pub detail: String,
427    /// The entry, when it is in the answer.
428    #[serde(default, skip_serializing_if = "Option::is_none")]
429    pub entry: Option<ContextEntry>,
430    /// The exclusion, when it was reached and not given.
431    #[serde(default, skip_serializing_if = "Option::is_none")]
432    pub excluded: Option<Excluded>,
433    /// The collapse it was part of, when it was folded or dropped for another.
434    #[serde(default, skip_serializing_if = "Option::is_none")]
435    pub deduplicated: Option<Deduplicated>,
436    /// The budget the judgement was made under, so that "excluded for budget" can be acted
437    /// on without a second call.
438    pub budget: Budget,
439}

441/// One tier, as the policy reports it: its place in the spend order, what it is for, and
442/// which kinds of object land in it.
443///
444/// `position` is 1-based and exists because the wire form has no inherent order a consumer
445/// can rely on — the [`Tier`] enum's `Ord` is a Rust fact, not a JSON one — so the rank is
446/// made explicit for the readers that are not this crate. `kinds` is the inverse of
447/// [`tier_for_kind`], published so that a caller can see where a kind will land without
448/// compiling an answer and looking.
449///
450/// ```
451/// use majordomus_cli::devcontext::{policy, tier_for_kind, Tier, TierRule};
452/// use majordomus_cli::synthetic::SyntheticRepository;
453///
454/// let repo = SyntheticRepository::small().unwrap();
455/// let ctx = repo.context().unwrap();
456/// let rules = policy(&ctx).unwrap();
457///
458/// // the first tier spent is the one that is never dropped, at position 1
459/// let first: &TierRule = &rules.tiers[0];
460/// assert_eq!(first.tier, Tier::Task);
461/// assert_eq!(first.position, 1, "1-based, so the order survives serialisation");
462///
463/// // every tier is reported, in the order the budget spends in, and explains itself
464/// assert_eq!(rules.tiers.len(), Tier::ORDER.len());
465/// for (i, r) in rules.tiers.iter().enumerate() {
466///     assert_eq!(r.position, i + 1);
467///     assert_eq!(r.meaning, r.tier.meaning());
468/// }
469///
470/// // and every kind is listed under the tier the classifier puts it in, exactly once —
471/// // so the published table and the function behind it cannot disagree
472/// let mut listed = 0usize;
473/// for r in &rules.tiers {
474///     for kind in &r.kinds {
475///         assert_eq!(tier_for_kind(kind), r.tier, "{kind} is listed under the wrong tier");
476///         listed += 1;
477///     }
478/// }
479/// let mut all: Vec<&str> = rules.tiers.iter().flat_map(|r| &r.kinds).map(String::as_str).collect();
480/// all.sort();
481/// all.dedup();
482/// assert_eq!(all.len(), listed, "a kind is listed under one tier only");
483/// ```
484#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
485pub struct TierRule {
486    /// The tier.
487    pub tier: Tier,
488    /// Its position in the order the budget spends in; 1 is spent first.
489    pub position: usize,
490    /// What it is for.
491    pub meaning: String,
492    /// The kinds of object that land in it.
493    pub kinds: Vec<String>,
494}

496/// One edge of the composed graph, and what the compiler does with it.
497///
498/// Every edge kind the graph declares gets a row, followed or not, which is the property
499/// that makes this projection worth reading: an edge added to the graph and not to the
500/// traversal table appears here as `refused` with a reason saying the compiler has no rule
501/// for it, rather than being silently unfollowed. A table that only listed the edges it
502/// followed could not tell you what it was ignoring.
503///
504/// `forward` and `reverse` are absent rather than zero when the edge is not followed that
505/// way, so "not followed" is one representation and not two. `means` is the graph's own
506/// account of the relation; `reason` is this compiler's account of why it is or is not
507/// context, in both directions.
508///
509/// ```
510/// use majordomus_cli::devcontext::{edge_policy, policy, EdgeRule};
511/// use majordomus_cli::synthetic::SyntheticRepository;
512///
513/// let repo = SyntheticRepository::small().unwrap();
514/// let ctx = repo.context().unwrap();
515/// let rules = policy(&ctx).unwrap();
516///
517/// // one row per edge kind the graph declares, followed or refused
518/// let edges: &[EdgeRule] = &rules.edges;
519/// assert!(!edges.is_empty(), "the graph declares edges");
520/// for e in edges {
521///     // the row always says what the relation is and what was decided about it
522///     assert!(!e.means.is_empty() && !e.reason.is_empty(), "{}", e.edge);
523///
524///     if e.refused {
525///         // not followed in either direction, and absent rather than zero
526///         assert!(e.forward.is_none() && e.reverse.is_none(), "{}", e.edge);
527///         assert!(edge_policy(&e.edge).is_none(), "{} is refused and in the table", e.edge);
528///     } else {
529///         // followed at least one way, at a weight the table declares
530///         assert!(e.forward.is_some() || e.reverse.is_some(), "{}", e.edge);
531///         let p = edge_policy(&e.edge).expect("a followed edge has a policy");
532///         assert_eq!(e.forward, (p.forward > 0.0).then_some(p.forward));
533///         assert_eq!(e.reverse, (p.reverse > 0.0).then_some(p.reverse));
534///     }
535/// }
536/// ```
537#[derive(Debug, Clone, PartialEq, Serialize, Deserialize, JsonSchema)]
538pub struct EdgeRule {
539    /// The edge kind, as the composed graph names it.
540    pub edge: String,
541    /// What the graph asserts by it.
542    pub means: String,
543    /// The relevance multiplier when followed source to target; absent when refused.
544    #[serde(default, skip_serializing_if = "Option::is_none")]
545    pub forward: Option<f64>,
546    /// The multiplier when followed target to source; absent when refused.
547    #[serde(default, skip_serializing_if = "Option::is_none")]
548    pub reverse: Option<f64>,
549    /// Why the target is context for the source, or why the edge is refused.
550    pub reason: String,
551    /// True when the compiler will not follow it in either direction.
552    pub refused: bool,
553}

555/// One selector, and whether what it produces was declared or inferred.
556///
557/// Two fields, and the second is the whole reason the projection exists: a caller consuming
558/// a compiled context needs to know which selectors it can trust as repository fact, and
559/// deriving that from the answer would mean inferring it from confidence values. Published
560/// here, it is a rule rather than a pattern a reader noticed.
561///
562/// ```
563/// use majordomus_cli::devcontext::{policy, Selector, SelectorRule};
564/// use majordomus_cli::synthetic::SyntheticRepository;
565///
566/// let repo = SyntheticRepository::small().unwrap();
567/// let ctx = repo.context().unwrap();
568/// let rules = policy(&ctx).unwrap();
569///
570/// // every selector is published, and each row agrees with the selector it names
571/// let selectors: &[SelectorRule] = &rules.selectors;
572/// assert_eq!(selectors.len(), Selector::ALL.len());
573/// for r in selectors {
574///     assert_eq!(r.declared, r.selector.declared());
575/// }
576///
577/// // and the inferring one is named, so the guessed half of an answer can be found
578/// let inferred: Vec<Selector> =
579///     selectors.iter().filter(|r| !r.declared).map(|r| r.selector).collect();
580/// assert_eq!(inferred, [Selector::IntentMatch]);
581/// ```
582#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
583pub struct SelectorRule {
584    /// The selector.
585    pub selector: Selector,
586    /// Declared by the repository, or inferred by the compiler.
587    pub declared: bool,
588}

590/// The compiler's own rules, so that a caller reads the decision instead of inferring it
591/// from an answer.
592///
593/// This is the answer to "why did I get that", asked once rather than reverse-engineered
594/// from every context. It is a projection of the tables and constants this module is built
595/// from — [`Tier::ORDER`], [`select::EDGES`], [`Selector::ALL`] and the four defaults
596/// — and holds no numbers of its own, so the published rules and the code that applies them
597/// cannot drift apart.
598///
599/// The defaults are here because they are what a request gets when it says nothing, and a
600/// caller tuning a request needs to know what it is tuning away from.
601///
602/// ```
603/// use majordomus_cli::devcontext::{policy, CompilerPolicy, Selector, Tier};
604/// use majordomus_cli::devcontext::{BYTES_PER_TOKEN, DEFAULT_BUDGET_TOKENS};
605/// use majordomus_cli::devcontext::{DEFAULT_FLOOR, DEFAULT_MAX_DEPTH};
606/// use majordomus_cli::graph;
607/// use majordomus_cli::synthetic::SyntheticRepository;
608///
609/// let repo = SyntheticRepository::small().unwrap();
610/// let ctx = repo.context().unwrap();
611/// let rules: CompilerPolicy = policy(&ctx).unwrap();
612///
613/// // it names the graph it reads relations from, rather than leaving it to be guessed
614/// assert_eq!(rules.schema, 1);
615/// assert_eq!(rules.graph, graph::COMPOSED);
616///
617/// // the three tables are complete
618/// assert_eq!(rules.tiers.len(), Tier::ORDER.len());
619/// assert_eq!(rules.selectors.len(), Selector::ALL.len());
620/// assert!(!rules.edges.is_empty());
621///
622/// // and the published defaults are the constants a silent request actually gets
623/// assert_eq!(rules.default_budget_tokens, DEFAULT_BUDGET_TOKENS);
624/// assert_eq!(rules.default_max_depth, DEFAULT_MAX_DEPTH);
625/// assert_eq!(rules.default_floor, DEFAULT_FLOOR);
626/// assert_eq!(rules.bytes_per_token, BYTES_PER_TOKEN);
627/// ```
628#[derive(Debug, Clone, PartialEq, Serialize, Deserialize, JsonSchema)]
629pub struct CompilerPolicy {
630    /// The format of this answer.
631    pub schema: u64,
632    /// The graph the relations are read from.
633    pub graph: String,
634    /// The tiers, in the order the budget spends in.
635    pub tiers: Vec<TierRule>,
636    /// Every edge kind the composed graph has, followed or refused.
637    pub edges: Vec<EdgeRule>,
638    /// The selectors, and which of them infer.
639    pub selectors: Vec<SelectorRule>,
640    /// The default ceiling in estimated tokens.
641    pub default_budget_tokens: u64,
642    /// The default depth limit.
643    pub default_max_depth: usize,
644    /// The default relevance floor.
645    pub default_floor: f64,
646    /// Bytes per estimated token.
647    pub bytes_per_token: u64,
648}

652fn normalise(path: &str) -> Result<String, CapabilityError> {
653    let p = path.trim().trim_start_matches("./").trim_end_matches('/');
654    if p.is_empty() {
655        return Err(CapabilityError::InvalidInput(
656            "an empty path is not a scope".into(),
657        ));
658    }
659    if p.starts_with('/') || p.split('/').any(|s| s == "..") {
660        return Err(CapabilityError::InvalidInput(format!(
661            "'{path}' is not repository-relative; a path outside the repository is not context"
662        )));
663    }
664    Ok(p.to_string())
665}

667/// Resolve one short name to the canonical identifier of an object of `kind`.
668fn resolve_seed(
669    ctx: &Context,
670    kind: &str,
671    named: &str,
672    field: &str,
673) -> Result<Seed, CapabilityError> {
674    let named = named.trim();
675    if named.is_empty() {
676        return Err(CapabilityError::InvalidInput(format!(
677            "{field}: name one, or leave it out"
678        )));
679    }
680    let hit = ctx.index.objects.iter().find(|o| {
681        o.kind == kind
682            && (o.uri == named
683                || o.identity == named
684                || o.metadata.get("slug").and_then(|v| v.as_str()) == Some(named))
685    });
686    match hit {
687        Some(o) => Ok(Seed {
688            uri: o.uri.clone(),
689            kind: o.kind.clone(),
690            from: field.to_string(),
691            resolved: (o.identity != named).then(|| o.identity.clone()),
692        }),
693        None => Err(CapabilityError::NotFound(format!(
694            "no {kind} '{named}' in this repository; `objects.list` with kind `{kind}` names every one"
695        ))),
696    }
697}

699/// Compile a context. The one entry point; every projection calls this.
700///
701/// The whole call runs over values the process already holds — the index and the composed
702/// graph derived from it — so it reads no file and walks no tree, which is what lets it sit
703/// inside a handler rather than at load time.
704///
705/// It fails only on a request that cannot mean anything: a budget of zero, a relevance floor
706/// outside 0..=1, a path that is not repository-relative, or a named seed this repository
707/// does not hold. Everything else is an answer. In particular a request that names nothing
708/// is valid and does not produce an empty context — the governance applies to every session
709/// whether or not it was asked for.
710///
711/// The budget is a ceiling on what the compiler *chooses*, not on what it must keep: seeds,
712/// the policy and the scope are never dropped, so an answer can come back over budget and
713/// says so rather than omitting the thing it was compiled about.
714///
715/// ```
716/// use majordomus_cli::capability::CapabilityError;
717/// use majordomus_cli::devcontext::{compile, CompileInput, Tier};
718/// use majordomus_cli::synthetic::SyntheticRepository;
719///
720/// let repo = SyntheticRepository::small().unwrap();
721/// let ctx = repo.context().unwrap();
722///
723/// // the governance arrives without being asked for, and cannot be dropped
724/// let c = compile(&ctx, CompileInput::default()).unwrap();
725/// let required: Vec<&str> = c
726///     .selected
727///     .iter()
728///     .filter(|e| e.required)
729///     .map(|e| e.kind.as_str())
730///     .collect();
731/// assert!(required.contains(&"policy"), "what every session is held to: {required:?}");
732/// assert!(c.selected.iter().all(|e| e.tier >= Tier::Task));
733///
734/// // a tiny ceiling still keeps what may not be dropped, and says it went over
735/// let squeezed = compile(
736///     &ctx,
737///     CompileInput { budget_tokens: Some(1), ..Default::default() },
738/// )
739/// .unwrap();
740/// assert!(squeezed.selected.iter().any(|e| e.required));
741/// assert!(squeezed.budget.over_budget);
742/// assert_eq!(squeezed.budget.limit_tokens, 1);
743///
744/// // and the refusals are requests that could not mean anything
745/// assert!(matches!(
746///     compile(&ctx, CompileInput { budget_tokens: Some(0), ..Default::default() }),
747///     Err(CapabilityError::InvalidInput(_)),
748/// ));
749/// assert!(matches!(
750///     compile(&ctx, CompileInput { floor: Some(1.5), ..Default::default() }),
751///     Err(CapabilityError::InvalidInput(_)),
752/// ));
753/// assert!(matches!(
754///     compile(&ctx, CompileInput { paths: vec!["/etc".into()], ..Default::default() }),
755///     Err(CapabilityError::InvalidInput(_)),
756/// ));
757/// assert!(matches!(
758///     compile(&ctx, CompileInput { issue: Some("I9999".into()), ..Default::default() }),
759///     Err(CapabilityError::NotFound(_)),
760/// ));
761/// ```
762pub fn compile(ctx: &Context, input: CompileInput) -> Result<CompiledContext, CapabilityError> {
763    let index = ctx.index.as_ref();
764    let limit = input.budget_tokens.unwrap_or(DEFAULT_BUDGET_TOKENS);
765    if limit == 0 {
766        return Err(CapabilityError::InvalidInput(
767            "a budget of zero tokens buys nothing; leave it out for the default".into(),
768        ));
769    }
770    let max_depth = input.max_depth.unwrap_or(DEFAULT_MAX_DEPTH);
771    let floor = input.floor.unwrap_or(DEFAULT_FLOOR);
772    if !(0.0..=1.0).contains(&floor) {
773        return Err(CapabilityError::InvalidInput(format!(
774            "the relevance floor is between 0 and 1; got {floor}"
775        )));
776    }
777
778    // ---- the seeds
779    let mut seeds: Vec<Seed> = Vec::new();
780    if let Some(named) = &input.issue {
781        seeds.push(resolve_seed(ctx, "issue", named, "issue")?);
782    }
783    if let Some(named) = &input.milestone {
784        seeds.push(resolve_seed(ctx, "milestone", named, "milestone")?);
785    }
786    for uri in &input.uris {
787        let o = index
788            .objects
789            .iter()
790            .find(|o| o.uri == *uri)
791            .ok_or_else(|| {
792                CapabilityError::NotFound(format!("the index holds nothing under `{uri}`"))
793            })?;
794        seeds.push(Seed {
795            uri: o.uri.clone(),
796            kind: o.kind.clone(),
797            from: "uris".into(),
798            resolved: None,
799        });
800    }
801    let mut requested_paths = BTreeSet::new();
802    for p in &input.paths {
803        let p = normalise(p)?;
804        requested_paths.insert(p.clone());
805        seeds.push(Seed {
806            uri: p.clone(),
807            kind: "path".into(),
808            from: "paths".into(),
809            resolved: None,
810        });
811    }
812    if let Some(intent) = &input.intent {
813        if !intent.trim().is_empty() {
814            seeds.push(Seed {
815                uri: intent.trim().to_string(),
816                kind: "intent".into(),
817                from: "intent".into(),
818                resolved: None,
819            });
820        }
821    }
822
823    let object_seeds: BTreeSet<String> = seeds
824        .iter()
825        .filter(|s| s.kind != "path" && s.kind != "intent")
826        .map(|s| s.uri.clone())
827        .collect();
828
829    let terms = input
830        .intent
831        .as_deref()
832        .map(intent_terms)
833        .unwrap_or_default();
834
835    let graph =
836        crate::graph::derive(crate::graph::COMPOSED, &ctx.registry, index).ok_or_else(|| {
837            CapabilityError::Internal("the composed graph is no longer derived".into())
838        })?;
839
840    let request = select::Request {
841        seeds: object_seeds.iter().cloned().collect(),
842        paths: requested_paths,
843        terms,
844        max_depth,
845        floor,
846        all_blocking_rules: input.all_blocking_rules.unwrap_or(false),
847        branch: match &index.repository.git {
848            crate::git::GitState::Available(info) => info.branch.as_deref(),
849            _ => None,
850        },
851    };
852    let selection = select::select(ctx, &graph, &request);
853
854    // what stands in for what, from the graph's own edges rather than from a second read
855    let mut supersedes: BTreeMap<String, Vec<String>> = BTreeMap::new();
856    for e in &graph.edges {
857        if e.kind == "supersedes" {
858            supersedes
859                .entry(e.source.clone())
860                .or_default()
861                .push(e.target.clone());
862        }
863    }
864
865    let (spend, diagnostics) = budget::spend(index, selection, &object_seeds, limit, &supersedes);
866
867    // the commits the layer itself names, gathered from what was selected
868    let mut commits = Vec::new();
869    for entry in &spend.selected {
870        let Some(i) = index.objects.iter().position(|o| o.uri == entry.uri) else {
871            continue;
872        };
873        let Some(evidence) = index.objects[i]
874            .metadata
875            .get("evidence")
876            .and_then(|v| v.as_array())
877        else {
878            continue;
879        };
880        for e in evidence {
881            let Some(commit) = e.get("commit").and_then(|v| v.as_str()) else {
882                continue;
883            };
884            commits.push(CommitReference {
885                commit: commit.to_string(),
886                named_by: entry.uri.clone(),
887                covers: e.get("covers").and_then(|v| v.as_str()).map(str::to_string),
888            });
889        }
890    }
891    // One BTreeSet folds the repeats — a commit named twice by the same record is one fact
892    // — and the canonical order is what the answer is read in.
893    let mut commits: Vec<CommitReference> = commits
894        .into_iter()
895        .collect::<BTreeSet<_>>()
896        .into_iter()
897        .collect();
898    crate::order::canonical(&mut commits);
899
900    let git = match &index.repository.git {
901        crate::git::GitState::Available(info) => GitContext {
902            branch: info.branch.clone(),
903            head: info.head.clone(),
904            working_tree: info.working_tree.clone(),
905            commits,
906        },
907        crate::git::GitState::Unavailable { reason } => GitContext {
908            branch: None,
909            head: None,
910            working_tree: format!("unavailable: {reason}"),
911            commits,
912        },
913    };
914
915    Ok(CompiledContext {
916        schema: 1,
917        fingerprint: index.fingerprint.clone(),
918        git,
919        seeds,
920        selected: spend.selected,
921        excluded: spend.excluded,
922        deduplicated: spend.deduplicated,
923        conflicts: spend.conflicts,
924        budget: spend.budget,
925        diagnostics,
926    })
927}

929/// Why one identifier is or is not in the context a request compiles to.
930///
931/// It compiles the request and then looks the identifier up in the result, which is the
932/// only honest way to answer the question: the standing of a thing is a property of a
933/// particular answer, not of the thing. The cost is one compile per question, and the
934/// benefit is that "excluded for budget" is measured against the budget the reply carries
935/// rather than one inferred afterwards.
936///
937/// An identifier this repository does not hold is [`Standing::Unknown`] — an answer, not an
938/// error — because "the index holds nothing under that name" is exactly the fact the caller
939/// asked for. The only refusal is an empty identifier, which is not a question.
940///
941/// ```
942/// use majordomus_cli::capability::CapabilityError;
943/// use majordomus_cli::devcontext::{compile, explain, CompileInput, ExplainInput, Standing};
944/// use majordomus_cli::synthetic::SyntheticRepository;
945///
946/// let repo = SyntheticRepository::small().unwrap();
947/// let ctx = repo.context().unwrap();
948///
949/// // the standing is about one compiled answer, so it moves with the request
950/// let generous = compile(&ctx, CompileInput::default()).unwrap();
951/// let uri = generous.selected.last().unwrap().uri.clone();
952/// let selected = explain(&ctx, ExplainInput { uri: uri.clone(), ..Default::default() }).unwrap();
953/// assert_eq!(selected.standing, Standing::Selected);
954/// assert_eq!(selected.entry.as_ref().unwrap().uri, uri);
955///
956/// // an identifier nothing answers: reported as unknown rather than refused
957/// let unknown = explain(
958///     &ctx,
959///     ExplainInput { uri: "majordomus://rule/nothing-like-this@1".into(), ..Default::default() },
960/// )
961/// .unwrap();
962/// assert_eq!(unknown.standing, Standing::Unknown);
963/// assert!(!unknown.detail.is_empty(), "it says so in words too");
964///
965/// // and the one thing that is not a question
966/// assert!(matches!(
967///     explain(&ctx, ExplainInput { uri: "   ".into(), ..Default::default() }),
968///     Err(CapabilityError::InvalidInput(_)),
969/// ));
970/// ```
971pub fn explain(ctx: &Context, input: ExplainInput) -> Result<Explanation, CapabilityError> {
972    let uri = input.uri.trim().to_string();
973    if uri.is_empty() {
974        return Err(CapabilityError::InvalidInput(
975            "name the canonical identifier to explain".into(),
976        ));
977    }
978    let compiled = compile(ctx, input.request)?;
979    if let Some(entry) = compiled.selected.iter().find(|e| e.uri == uri) {
980        let ways: Vec<String> = entry
981            .discovered_by
982            .iter()
983            .map(|d| format!("{}: {}", d.selector.as_str(), d.reason))
984            .collect();
985        return Ok(Explanation {
986            uri,
987            standing: Standing::Selected,
988            detail: format!(
989                "in the {} tier at relevance {} and confidence {}, costing {} token(s); reached by {} path(s) — {}",
990                entry.tier.as_str(),
991                entry.relevance,
992                entry.confidence,
993                entry.cost_tokens,
994                entry.discovered_by.len(),
995                ways.join("; ")
996            ),
997            entry: Some(entry.clone()),
998            excluded: None,
999            deduplicated: None,
1000            budget: compiled.budget,
1001        });
1002    }
1003    if let Some(x) = compiled.excluded.iter().find(|e| e.uri == uri) {
1004        return Ok(Explanation {
1005            uri,
1006            standing: Standing::Excluded,
1007            detail: format!(
1008                "reached and not given: {} — {}",
1009                x.reason.as_str(),
1010                x.detail
1011            ),
1012            entry: None,
1013            excluded: Some(x.clone()),
1014            deduplicated: None,
1015            budget: compiled.budget,
1016        });
1017    }
1018    if let Some(d) = compiled
1019        .deduplicated
1020        .iter()
1021        .find(|d| d.dropped.contains(&uri))
1022    {
1023        return Ok(Explanation {
1024            uri,
1025            standing: Standing::Deduplicated,
1026            detail: format!("folded into `{}` by {}: {}", d.kept, d.key, d.detail),
1027            entry: None,
1028            excluded: None,
1029            deduplicated: Some(d.clone()),
1030            budget: compiled.budget,
1031        });
1032    }
1033    let known = ctx.index.objects.iter().any(|o| o.uri == uri);
1034    Ok(Explanation {
1035        uri: uri.clone(),
1036        standing: if known {
1037            Standing::NotReached
1038        } else {
1039            Standing::Unknown
1040        },
1041        detail: if known {
1042            format!("the index holds `{uri}` and no selector of this request reached it: no seed names it, no followed edge leads to it, no declared path contains it, and it is not governance")
1043        } else {
1044            format!("the index holds nothing under `{uri}`")
1045        },
1046        entry: None,
1047        excluded: None,
1048        deduplicated: None,
1049        budget: compiled.budget,
1050    })
1051}

1053/// The compiler's rules: the tiers, every edge of the composed graph and what is done with
1054/// it, the selectors, and the defaults.
1055///
1056/// It takes no request, because the rules do not depend on what is being asked about. It
1057/// does take a context, and for one reason: the edge rows are enumerated from the graph
1058/// *this* repository derives, so an edge kind the graph gains shows up here as unjudged
1059/// rather than going quietly unfollowed. The answer is therefore a function of the
1060/// repository's graph and this module's tables, and of nothing else.
1061///
1062/// Pure over those two: the same tree gives the same answer every time, which is what makes
1063/// it safe to publish beside the compiled contexts it explains.
1064///
1065/// ```
1066/// use majordomus_cli::devcontext::{policy, Selector, Tier};
1067/// use majordomus_cli::synthetic::SyntheticRepository;
1068///
1069/// let repo = SyntheticRepository::small().unwrap();
1070/// let ctx = repo.context().unwrap();
1071///
1072/// let rules = policy(&ctx).unwrap();
1073/// assert_eq!(rules.tiers.len(), Tier::ORDER.len());
1074/// assert_eq!(rules.selectors.len(), Selector::ALL.len());
1075///
1076/// // every edge the graph declares is judged, one way or the other, with a reason
1077/// for e in &rules.edges {
1078///     assert!(!e.reason.is_empty(), "{} was neither followed nor explained", e.edge);
1079///     assert_eq!(e.refused, e.forward.is_none() && e.reverse.is_none());
1080/// }
1081///
1082/// // and asking twice over one tree gives one answer
1083/// let again = policy(&ctx).unwrap();
1084/// assert_eq!(again, rules);
1085/// ```
1086pub fn policy(ctx: &Context) -> Result<CompilerPolicy, CapabilityError> {
1087    let graph = crate::graph::derive(crate::graph::COMPOSED, &ctx.registry, ctx.index.as_ref())
1088        .ok_or_else(|| {
1089            CapabilityError::Internal("the composed graph is no longer derived".into())
1090        })?;
1091    let mut kinds: BTreeMap<Tier, Vec<String>> = BTreeMap::new();
1092    for kind in graph.node_kinds.keys() {
1093        kinds
1094            .entry(tier_for_kind(kind))
1095            .or_default()
1096            .push(kind.clone());
1097    }
1098    let tiers = Tier::ORDER
1099        .iter()
1100        .enumerate()
1101        .map(|(i, t)| TierRule {
1102            tier: *t,
1103            position: i + 1,
1104            meaning: t.meaning().to_string(),
1105            kinds: kinds.get(t).cloned().unwrap_or_default(),
1106        })
1107        .collect();
1108
1109    // every edge the graph declares, judged: the table says which are followed, and the
1110    // refusals say why. An edge the graph gains and this table does not name is reported
1111    // as unjudged rather than silently unfollowed.
1112    let mut edges: Vec<EdgeRule> = Vec::new();
1113    for (edge, means) in &graph.edge_kinds {
1114        match edge_policy(edge) {
1115            Some(p) => edges.push(EdgeRule {
1116                edge: edge.clone(),
1117                means: means.clone(),
1118                forward: (p.forward > 0.0).then_some(p.forward),
1119                reverse: (p.reverse > 0.0).then_some(p.reverse),
1120                reason: format!("{}; reversed: {}", p.forward_reason, p.reverse_reason),
1121                refused: false,
1122            }),
1123            None => {
1124                let why = select::REFUSED
1125                    .iter()
1126                    .find(|(k, _)| k == edge)
1127                    .map(|(_, w)| (*w).to_string())
1128                    .unwrap_or_else(|| {
1129                        "the graph declares it and the compiler has no rule for it; it is not followed".into()
1130                    });
1131                edges.push(EdgeRule {
1132                    edge: edge.clone(),
1133                    means: means.clone(),
1134                    forward: None,
1135                    reverse: None,
1136                    reason: why,
1137                    refused: true,
1138                });
1139            }
1140        }
1141    }
1142
1143    Ok(CompilerPolicy {
1144        schema: 1,
1145        graph: crate::graph::COMPOSED.to_string(),
1146        tiers,
1147        edges,
1148        selectors: Selector::ALL
1149            .iter()
1150            .map(|s| SelectorRule {
1151                selector: *s,
1152                declared: s.declared(),
1153            })
1154            .collect(),
1155        default_budget_tokens: DEFAULT_BUDGET_TOKENS,
1156        default_max_depth: DEFAULT_MAX_DEPTH,
1157        default_floor: DEFAULT_FLOOR,
1158        bytes_per_token: BYTES_PER_TOKEN,
1159    })
1160}

1162/// A repository with a plan in it, for the compiler's own tests.
