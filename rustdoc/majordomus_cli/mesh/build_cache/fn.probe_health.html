pub fn probe_health(
    endpoint: &str,
    ready_path: &str,
    budget: Duration,
) -> Health
Expand description

Whether the store at endpoint answers its readiness route with a success within budget. Only an IP-literal endpoint is probed. A refusal or a non-success answer is Unhealthy; a probe that ran out of time or could not be made is Unknown, never Healthy and never a verdict it did not earn.

§Example

use majordomus_cli::mesh::build_cache::{probe_health, Health};
use std::time::Duration;
// a name is never resolved: only an IP literal is probed
let h = probe_health("http://example.invalid:9000", "/ready", Duration::from_millis(50));
assert_eq!(h, Health::Unknown);
