Module deploy 

Source
Expand description

The deployment objects of the layer, typed: .ai/repo/deployments/*.yaml parsed into values that cannot hold nonsense, and validated against what this repository actually contains before anything is built from them.

Nothing here reaches the network, spawns a process or talks to a hosting provider. The question this module answers is the local one — would this deployment work — and it is answered while a test is cheap rather than after a rollout is not. The provider projections (the image definition, the provider configuration) read the values this module produces; they never re-read the file.

Every refusal names four things: the file, the key, the value observed and the correction. A message that names fewer sends the reader looking.
