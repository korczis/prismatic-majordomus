Skills

What an agent can be asked by name, and where each name comes from.

Workflow skills are written once under the layer; command and domain skills are derived from the capability registry. Every editor and agent reads the same projection.

Workflow skills

The layer's own procedures, one directory each under the skills section.

SkillWhen to use itStatus
assess-before-deletingAssess before deletingRemove a file, branch, worktree, record or process only after each candidate has been classified by what depends on it and what would be lost, and the reversible step has been taken first.active
deploy-siteDeploy the site by handPublish the website to GitHub Pages from a terminal, through the one script the Pages workflow runs, when waiting for the Actions queue is not acceptable.active
evolveEvolve the repository's know-howTurn what sessions observed into reviewed knowledge and into the rule, skill, document or test each lesson belongs in, then deliver the change and tell every peer what moved.active
implementImplement a changeCarry a requested change through the repository evidence-first, from the invariant it must keep to a verified, reconciled, documented and committed tree, without widening its scope.active
pack-for-chatgptPack the sources for a ChatGPT projectTurn a committed tree into token-bounded Markdown shards that a ChatGPT project's file search indexes, verified to carry no binary, worktree, link, build output, projection or leaked value, and hand them over with the commit they were cut from.active
pack-for-reviewPack the repository for an outside reviewerPrepare a bounded, reproducible snapshot of the tracked tree for a reviewer who cannot read the repository directly, with the local half and anything secret left out and the questions the review must answer written down.active
repo-reviewRepository reviewAn evidence-driven review of the actual state of the repository, or of one change to it, before meaningful engineering work is recommended or done.active
report-verification-stateReport by verification stateWrite the outcome of a piece of work as claims each marked VERIFIED, PARTIAL or BLOCKED by the evidence actually observed, so a reader can tell what was proved from what was only done or intended.active
