The Procfile. The provider injects the port as PORT; the object’s own port is the fallback, so the process binds the declared one wherever PORT is absent. The interface is the object’s, and discovery is a filesystem walk because the slug carries the layer without the repository that tracks it. On the mesh the process advertises the provider URL the object names and takes its node key from NODE_SEED_ENV (ADR 0220): without that secret its mesh stays off, and the server still answers.

use majordomus_cli::deploy::render::gigalixir_procfile;

let web = gigalixir_procfile(&d, ".ai/repo/deployments/x.yaml");
let line = web.lines().find(|l| l.starts_with("web: ")).unwrap();
assert!(line.contains("serve --repo . --discovery filesystem"), "{line}");
assert!(line.contains("--port ${PORT:-8080}"), "{line}");
assert!(line.ends_with("--advertise https://x-app.gigalixirapp.com --node-seed-env MAJORDOMUS_MESH_NODE_SEED"), "{line}");
