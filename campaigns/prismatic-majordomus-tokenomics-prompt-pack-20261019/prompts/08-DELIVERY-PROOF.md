# Wave: Delivery, proof and hard acceptance

Use after `00-MASTER-CLAUDE-CODE.md`. This is an acceptance contract, not authorization to bypass existing repo procedures.

## Task

Use existing worktree/PR/landing/release seats; never bypass governance. For each completed issue collect runnable test use cases, generated drifts, CI run links, exact SHA, screenshot/route for deployed UI, dataset/source coverage, security review and reconciliation status. Run canonical checks, integration, E2E, performance, failure injection and schema compatibility. Publish claims only to maturity evidence supports; report still missing/blocked items explicitly.

## Required deliverables

- Preflight evidence and canonical code ownership.
- Implemented vertical slice or documented external blocker.
- Exact commands/tests and results, source provenance, generated parity.
- Existing issues mapped to actual acceptance and verified outcomes.
- Any new claim is backed by data or marked unknown.
