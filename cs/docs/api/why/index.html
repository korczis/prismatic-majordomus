HTTP API: why

Provozní způsoby selhání, na které je tento nástroj odpovědí: okamžiky, které čtenář pozná, publikum, které je pozná, oblasti, do kterých patří, a co z vlastních příznaků čtenáře vyplývá. Každý záznam je soubor v sekci why vrstvy; nic zde neobsahuje seznam a okamžik přidaný tam zodpovídají všechny tyto položky bez jakékoli registrace.

GET /api/v1/why why.list

Katalog

Každý provozní moment, který tento repozitář drží, zúžený kterýmkoli z fasetů, které hlásí sám katalog, s publikem, oblastmi, odvozenými filtry a počty. Výchozí je veřejný katalog; předejte status=any pro koncepty také.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • proces cache (max_entries=32)
  • Nástroj MCP majordomus_why
  • zdroj MCP {"name": "why", "uri": "majordomus://why"}
  • $ why list

Diagnostikovat výběr

Co implikují vlastní příznaky čtenáře: okamžiky, na které se výběr vyřeší, provozní oblasti a publikum, k nimž se přiklánějí, a schopnosti, příkazy, tvrzení, pravidla a případy užití, které na ně odpovídají — každé nese okamžiky, které ho vytvořily. Počítání, ne odhad: žádné vážení a žádná procenta.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • proces cache (max_entries=32)
  • Nástroj MCP majordomus_why_diagnose
  • $ why diagnose
