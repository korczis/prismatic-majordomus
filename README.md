# Prismatic Majordomus

A lightweight supervisory control layer for AI-assisted work.

**Status: design phase. Nothing here runs yet.**

This repository currently contains one document, [`docs/DESIGN.md`](docs/DESIGN.md).
It is the product specification for v0.1, derived from studying how AI-assisted
engineering actually fails in practice and what survived as a countermeasure.

No implementation, no CLI, no policy files exist yet. Any capability described in
the design is a target, not a claim.
