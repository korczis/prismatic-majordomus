description = "Two new variants of Runner (apps/majordomus-cli/src/evidence/mod.rs:207), each with a branch in TestId::of (:450) and a reader in the recorder (evidence/record.rs). Its paths are the file names `node --test` finds by default (`*.test.{js,mjs,cjs}`, `*-test.*`, `*_test.*`, `test-*.*`, `test.*`, and files under a `test/` directory), its id is `node:<path>`, and its report is the TAP stream of `node --test --test-reporter=tap`, one top-level test per file. Runner::Playwright is @playwright/test. Its paths are the `*.spec.{js,jsx,ts,tsx,mjs,cjs}` half of its default testMatch. The `*.test.*` half is left to node, so that no path belongs to two runners. Its report is the file its JSON reporter writes. `majordomus evidence record --origin ci --runner node|playwright --report <file>` reads the report at the commit and tree it was run on, and merges it into the ledger as record does for test/run.sh and cargo today. Majordomus never runs node or a browser itself. The runner answers EVIDENCE.md's objection, 'a runner nothing executes is a runner whose results nothing can record', because each variant comes with the reader for the report its runner writes. Second, separately: a criterion whose claim names a path no runner drives keeps that cause up to the intent. After the change it says `criterion <c> cites <path>, which no runner drives (runners: suite test/cases/*.sh, crate apps/majordomus-cli/tests/*.rs, ...)`. A missing runner and a missing run then read differently."
