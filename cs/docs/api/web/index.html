HTTP API: web

Co tento repozitář vystavuje přes HTTP, určeno z producentů, kteří to vytvářejí, a ne z registru, který by někdo udržoval: trasy, na které odpovídá samotný spustitelný soubor, build dokumentace a každá vygenerovaná zpráva, která deklarovala vlastní mount. web

Co tento repozitář vystavuje přes HTTP, určeno z producentů, kteří to vytvářejí, a ne z registru, který by někdo udržoval: trasy, na které odpovídá samotný spustitelný soubor, build dokumentace a každá vygenerovaná zpráva, která deklarovala vlastní mount. Stejné určení obsluhuje router, vykresluje domovskou stránku a skládá publikaci.

GET /api/v1/web/surfaces web.surfaces

Každý webový povrch, rozřešený

Webová topologie v pořadí priority tras, s připojením, kategorií, viditelností, druhem, producentem, artefaktem, runtime funkcí každého povrchu a původem každé hodnoty, která by čtenáře mohla překvapit; a které id se poskytují, publikují a nabízejí člověku. Odpovídá z vyřešení, ze kterého tento proces poskytuje, takže se nemůže rozejít s tím, co směruje router nebo co vypisuje domovská stránka.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache process (max_entries=2, ttl_seconds=5)
  • Nástroj MCP majordomus_web_surfaces
  • MCP zdroj {"name": "web", "uri": "majordomus://web"}

Žádné parametry.

Vyzkoušejte

Port je ten, který server zalogoval; 8741 je ten, o který žádá jako první. Hodnoty jsou první příklad operace.

curl -s "http://127.0.0.1:8741/api/v1/web/surfaces"

Testováno v apps/majordomus-cli/tests/http_serve.rs, který přehrává routu s těmito hodnotami proti serveru na skutečném socketu.

Odpovědi

statustělovýznam

400 ErrorBody invalid_input: Vstup neodpovídá schématu: parametr špatného typu, neznámý parametr nebo hodnota, kterou schopnost odmítne.

Schémata

Komponenty, které používají jen operace tohoto tagu. Každý řádek je pole daného typu, jeho doc komentář je popis; typ vlastněný jinou stránkou na ni odkazuje.

Funkce

"mcp" | "cockpit" | "ui"
Schopnost běžícího procesu, kterou povrch potřebuje, aby mohl existovat.

Registr popisuje účinný proces, ne maximální: build nebo vyvolání, které neodpovídá na žádné MCP, nemá povrch MCP a úvodní stránka na něj nemůže odkázat. Uvedení závislosti jako dat je to, co to drží automatické.

  • mcpTento proces odpovídá MCP přes HTTP.
  • cockpitTento proces obsluhuje Cockpit.
  • uiTento proces servíruje UI: majordomus ui, primární povrch (ADR 0135).

Používá SurfaceReport

SurfaceAvailability

"both" | "served-only" | "published-only"
Zda je povrch součástí statické publikace, servírován jen za běhu procesu, nebo obojí.
  • bothPoskytuje běžící program a publikuje se jako soubory.
  • served-onlyOdpovídá běžící spustitelný soubor a nikdy se nepublikuje: route, kterou proces vypočítá, nebo build vytvořený pro mount tohoto serveru, ne pro nasazení.
  • published-onlyPublikováno jako soubory; běžící spustitelný soubor je servíruje ze stejného adresáře.

Používá Surface

SurfaceCategory

"interface" | "documentation" | "api" | "protocol" | "report"
K čemu povrch slouží, což je způsob, jak se čtenáři ukazuje.

Kategorie je jediný kus záměru, který mount nemůže nést: /openapi.json a /swagger sedí vedle sebe a jsou dokumentem a prohlížečem k němu. Seskupování se odvozuje z tohoto pole a nikdy ze seznamu cest vedeného jinde.

  • interfaceNěco, co člověk otevře a prohlíží: domovská stránka, Cockpit.
  • documentationPróza a reference psané pro člověka: web, Swagger UI.
  • apiStrojově čitelné rozhraní registru schopností.
  • protocolDrátový protokol, kterým mluví jiný program.
  • reportGenerované důkazy běhu: testovací zpráva, zpráva měření výkonu.

SurfaceKind

"static-directory" | "native-route" | "redirect"
Jak povrch odpovídá na požadavek.

Jen to, co tento repozitář obsluhuje: adresář generovaných souborů, cesta, na kterou spustitelný soubor odpovídá sám, a přesměrování. Nový druh je nové chování, nikdy nový název téhož chování s jinými daty.

  • static-directoryGenerovaný adresář, připojený pod svým prefixem a servírovaný z disku.
  • native-routeCesta, na kterou spustitelný soubor odpovídá sám, z vlastního registru nebo ze svých obslužných funkcí.
  • redirectCesta, která odpoví přesměrováním na jinou.

Používá web.surfaces

SurfaceVisibility

"public" | "internal"
Komu se povrch nabízí.

Dvě hodnoty a nic víc: povrch je buď nabízen k objevení člověkem, nebo je součástí topologie, aniž by byl inzerován. Obojí je vždy ve strojově čitelné odpovědi — skrytí obsluhované trasy před introspekcí by ji skrylo jen před lidmi, kteří ji udržují.

  • publicUvedeno pro člověka: objeví se na domovské stránce.
  • internalServírováno a introspektovatelné, ne inzerováno: mluví s ním stroj, nebo na něj odkazuje jiný povrch.
