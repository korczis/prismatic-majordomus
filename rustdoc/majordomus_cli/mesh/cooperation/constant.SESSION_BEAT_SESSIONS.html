Expand description

How many sessions holding exclusive claims one runtime is sized to beat for at full rate (I3990). A session beats at most once a quarter of its ttl, so one window holds at most ceil(window / (ttl / 4)) beats of it, and the runtime’s limit per window is this many times that — see session_beat_limit. A runtime whose exclusive holders outnumber it stops writing beats until the window moves: their claims suspend, which frees scopes rather than holding them, and it says so in the log and in mesh doctor. A total per run that then wrote ttl 0 — the first version of this layer — turned the rule off in silence after half an hour of a beater whose phase changed every second: the 5d incident again, found by the review of 2026-10-23.
