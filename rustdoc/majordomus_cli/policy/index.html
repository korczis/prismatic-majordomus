Module policy 

Source
Expand description

The canonical policy, typed: .ai/repo/policy.yaml and the profiles beside it. The policy is the one canonical input of the provider projections; the shell tool reads the same file with the same subset reader, so the two agree byte for byte on what a projection is and which hash it carries.
