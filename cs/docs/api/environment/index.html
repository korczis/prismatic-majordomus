Používá Preflight

PreflightVerdict

"verified" | "active" | "fresh" | "stale" | "degraded" | "unavailable" | "failed" | "unknown" | "not_applicable"
Co o jednom tvrzení může repozitář ukázat.

Devět slov, ne boolean, protože akce, které vyžadují, se liší: stale je znovu spustit důkaz, unavailable je nic tam není, unknown je nikdo se nepodíval a not_applicable je není co hledat.

use majordomus_cli::environment::preflight::Verdict;
assert!(Verdict::Verified.proves() && Verdict::Active.proves() && Verdict::Fresh.proves());
assert!(!Verdict::Stale.proves() && !Verdict::NotApplicable.proves());
assert_eq!(Verdict::NotApplicable.as_str(), "not_applicable");
// the most urgent first: a failure outranks a stale proof, which outranks an absence
assert!(Verdict::Failed.urgency() < Verdict::Stale.urgency());
assert_eq!(Verdict::Verified.urgency(), None);
  • verifiedDokázáno proti tomuto stromu zaznamenaným výsledkem nebo přímou odpovědí.
  • activeV platnosti nyní, pozorováno přímo, bez zaznamenaného k ověření.
  • freshPosouzeno jako dostatečně čerstvé, aby se podle něj jednalo, vůči deklarovanému prahu nebo aktuálnímu commitu.
  • staleDůkaz existuje, ale týká se jiného commitu, stromu nebo okamžiku.
  • degradedV platnosti, ale ve formě, kterou by tento program neposkytoval.
  • unavailableNení co pozorovat.
  • failedPozorováno a neplatilo.
  • unknownNikdo se nepodíval, nebo se pohled nedokončil.
  • not_applicableNení tu co posuzovat.
