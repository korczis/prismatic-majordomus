Struct WorktreeService

pub struct WorktreeService { /* private fields */ }
Expand description

The repository’s worktrees, decided once.

Built from a directory — any directory inside any work tree — and nothing else.

pub fn scratch_root_of(&self, path: &ResolvedPath) -> Option<ScratchRoot>

The scratch root a path lies under, when it does. The roots are the declarations’ (share/providers.yaml): the tool’s own temporary directories and every provider’s, such as .claude/worktrees/ under the primary checkout, which Claude Code creates and removes with the session that asked for it, or the thread directory an orchestrator keeps under its data directory. A root the primary checkout itself lives under is skipped, as a test fixture’s temporary directory is: nothing beside the repository is a scratch checkout of it.

pub fn resolve(&self, selector: &str) -> Result<WorktreeRecord>

Resolve a selector to exactly one registered work tree: an exact branch name, or an exact path. Nothing is matched by prefix, substring or similarity — these selectors are given to commands that delete things.

Source

pub fn create(&self, request: &CreateRequest) -> Result<CreateReport>

Create the canonical worktree of a branch. The destination is derived and never given. Everything that could go wrong is checked before git is asked to do anything, so a refusal leaves the repository exactly as it was.

Source

pub fn ensure(&self, request: &CreateRequest) -> Result<CreateReport>

The same, answering the existing canonical worktree rather than refusing when it is already there.

Source

pub fn remove(&self, selector: &str, force: bool) -> Result<RemoveReport>

Remove one linked worktree. Never a branch, never the primary checkout, never uncommitted work without force.

Source

pub fn repair(&self, dry_run: bool) -> Result<RepairReport>

Drop the registrations of work trees whose directories are gone, and let git repair the administrative links of the ones that exist. Deletes no directory.
