Conventional commits, read from git and parsed.

The parse is deliberately small and total: a subject that does not match the convention is ChangeKind::Other rather than an error, because the changelog’s job is to say what happened and a commit nobody spelled conventionally still happened.

  feat(commands): one canonical command graph
  ^^^^ ^^^^^^^^   ^^^^^^^^^^^^^^^^^^^^^^^^^^^
  kind scope      subject

  feat(api)!: the route moved      `!` marks it breaking
  BREAKING CHANGE: <why>           so does this trailer, in the body
