# the report-only pre-push names NOT JUDGED only a gate whose launcher refuses with exit 12 for want of an executable of the tree (41937546652); a gate that fails because its tool is absent on the host (cargo on a machine without it, node for ui-check and portable-core on the Linux build host) is labelled failed like a gate the change broke, so a reader cannot tell the host from the change; it should say not judged here, and I4577 makes the probe name such hosts beforehand; reported from an adopting repository's session

# Evidence

- .githooks/pre-push lines 77-79: "A gate whose exit 12 is the launcher's refusal (`run: just build`) while no executable of this tree's generation exists is not judged here: run-plan names it NOT JUDGED ... A gate that exits 12 for a reason of its own is a failure like any other." Introduced by commit 41937546652.
- Nothing else is exempt: a gate whose tool is absent on the host (node on the Linux build host for ui-check and portable-core; cargo on a machine without it) is counted failed. The release-bump pre-push of #3007 on that host listed exactly those host failures.
- I4577 (filed in this run) makes `offload probe` name, per host, the gates it cannot run.
