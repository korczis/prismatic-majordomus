The inputs of the crates this one takes by path, relative to the directory that holds them all (apps/): the portable core (ADR 0170) is compiled into the executable, so an edit to it is a different executable, and Cargo.lock does not move when a path dependency’s source does. Absent beside a crate (a test’s scratch crate), they add nothing.
