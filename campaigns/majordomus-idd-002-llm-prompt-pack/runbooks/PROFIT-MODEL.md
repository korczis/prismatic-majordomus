# PROVEN UNIT ECONOMICS

Optimize: verified accepted outcomes / total resources, subject to safety and correctness. Track before/after medians for: intent-to-verified-release lead time, PR wait time, CI latency, deployment failure/rollback, manual handoffs, flaky tests, regressions, per-intent tokens and money *only when observed*, and reused vs new integration code. Do not compress into an invented composite number.

For each optimization state numerator, denominator, observation window, dataset, confounders and confidence limits. If baseline absent, instrument first and report target as target. Do not trade quality gates for lower cycle time. Make optimization findings themselves canonical issues/intents linked to evidence, not untraceable dashboards.
