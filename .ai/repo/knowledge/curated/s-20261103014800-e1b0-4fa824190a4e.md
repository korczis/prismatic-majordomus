# run-plan --before-push runs only the structure and structure-b gates, so the rust job's gates, intent-check (bin/majordomus-cli intent validate) among them, never run in a train top's pre-push judgement and are first met in CI

Observed as defect about scripts/ci/run-plan in episode s-20261103014800-e1b0.

# Evidence

- `file:scripts/ci/run-plan`
- `file:.ai/repo/ci/gates.yaml`

# Evidence

scripts/ci/run-plan, in its --before-push branch, selects gates with
`jq '.gates[] | select((.job == "structure" or .job == "structure-b") and .selected)'`; nothing else
runs. .ai/repo/ci/gates.yaml declares `id: intent-check`, `job: rust`, `runs: bin/majordomus-cli intent
validate`. The pre-push logs of train 22b's dry run and real push on 2026-11-02/03 (35 gates, 195
cases) contain no intent-check line. The landing seat reported that a record defect of train P passed
the local judgement and failed this gate in CI. The rule whose reach this is:
project.a-push-runs-what-ci-would-find-first. Interim, carried in the integrator skill: a ready report
also carries `bin/majordomus-cli intent validate` with no failure.
