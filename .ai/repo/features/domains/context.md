# Context

What a worker — a model or a person — knows at the moment it begins, and what is left
behind when it stops. The context documents that apply to a path, the session and its
handover, the decisions and knowledge that outlive a conversation, and the procedures a
worker can load: each is a file the repository owns, read through the same commands by
every tool, rather than a transcript somebody hopes to find again.

Not in this domain: who may touch which paths while the work runs, which is coordination;
and whether the rules the worker loaded hold, which is governance.
