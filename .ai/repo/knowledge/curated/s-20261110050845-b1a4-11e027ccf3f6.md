# Evidence

- docs/DISTRIBUTION.md (lines 349 and 358-370) already says the record pull request's own run is created `action_required` and is started by hand: "approve the run on its page, or gh pr close <n> then gh pr reopen <n>". `gh api -X POST repos/<owner>/<repo>/actions/runs/<id>/approve` is the API form of that approval; #2991 then merged on its ci (2026-11-09T19:50:28Z, `gh pr view 2991`).

- The approval moves into the record's dispatch in I2717, pull request #2994 (open on 2026-11-10, "ci(validate): the record's dispatch approves the record pull request's own run (I2717)").
