intents.list

Každý záměr, který model projektu deklaruje, každý se stavem, který plán odvozuje pro jeho milníky, stavem důkazů za každým kritériem splnění, fází, kterou tyto dva odvozují — declared, planned, executing, verifying nebo satisfied, nebo cancelled či superseded, když to záznam říká — a verdiktem, který odvozují samotná kritéria (ADR 0107): satisfied, když je splněno každé kritérium, unsatisfied, když není splněno kritérium testu nebo tvrzení, unknown, když nejsou splněna jen kritéria příkazu či nasazení nebo žádné není deklarováno, s kritérii, která jej drží zpátky.

výstup · IntentList

Každý záměr s jeho odvozenou fází a verdiktem a kolik jich je v každé: čím odpovídají majordomus intent list, GET /api/v1/intents i nástroj majordomus_intents, z jednoho odvození.

use majordomus_cli::capability::builtin::intents::IntentList;
let empty = IntentList {
    count: 0,
    stages: std::collections::BTreeMap::new(),
    verdicts: std::collections::BTreeMap::new(),
    intents: vec![],
};
// a repository that declares no intent answers the route, with nothing in it
assert_eq!(empty.count, 0);
