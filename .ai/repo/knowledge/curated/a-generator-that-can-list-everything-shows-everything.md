# A system that can generate every list tends to put every list on its first screen

The 2026-10-03 review of majordomus.dev found a page that worked as an evidence archive: a hero, then a ten-screen CLI challenge, a large navigation and every capability object. The content was right and derived; the hierarchy was inverted. Choosing what a first screen leaves out, and in which order the rest is disclosed, is separate work from deriving the content, and a derivation pipeline does not do it. The repository answered with a declared story (site/data/homepage.toml) and a budget the homepage-check holds.
