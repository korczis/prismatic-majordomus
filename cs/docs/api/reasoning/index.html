HTTP API: reasoning

Uvažování nezávislé na provideru (ADR 0098): které volitelné poradce lze oslovit a co nabízejí, co si žádá podstatná nejistota, typované záznamy uvažování relace — posouzení, plány, konzultace, neshody, vyřešení, závěry, validace, pokusy — a stav, časová osa a původ, které z nich vyplývají.
