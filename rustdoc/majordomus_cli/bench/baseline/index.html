Module baseline 

Source
Expand description

Accepted baselines and the regression policy. A baseline is a tracked result document of one platform (os-arch-buildprofile), promoted explicitly from a local run by bench baseline update; the policy is data in .ai/repo/benchmarks/rust/policy.yaml (the shell tool keeps its own evidence beside it, under .ai/repo/benchmarks/). A check compares each measurement of a run with the baseline’s under the policy and reports every line; a target the baseline knows and the run does not is reported as stale, never silently attached to something else, and a baseline of another platform is not compared at all.
