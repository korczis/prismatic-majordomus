Parse the issue a start names (I4004): I4004, #184. One to MAX_ISSUE_ID characters of A-Z a-z 0-9 # . _ -, compared byte for byte; anything else is refused with the character named, because the id becomes part of a mesh scope (issue/<id>) and a / or a space would make that scope mean something else.

use majordomus_cli::execution::model::parse_issue;
assert_eq!(parse_issue("I4004").unwrap(), "I4004");
assert_eq!(parse_issue("#184").unwrap(), "#184");
assert!(parse_issue("").is_err());
assert!(parse_issue("I1/../x").unwrap_err().contains("'/'"));
