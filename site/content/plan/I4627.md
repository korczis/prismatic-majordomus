description = "Where the tree's crate came through a merge, scripts/derive uses a borrowed MAJORDOMUS_BIN only when mj_rust_same_generation accepts it: the commit it was built from (MAJORDOMUS_BIN_COMMIT) carries the tree's crate inputs (MJ_RUST_CRATE_INPUTS) byte for byte. Otherwise the derive drops the borrowed executable, prints which merge and which generation answer it refused, and builds this tree's own. The crate came through a merge in exactly two cases. Either MERGE_HEAD is present and the staged merge changes MJ_RUST_CRATE_INPUTS against HEAD, or HEAD is a merge whose crate inputs differ from its first parent's. A merge that leaves the crate alone borrows as before. The scratch derive of a merge in progress is handed the commit its executable is of: the merge commit when the outer derive built it, or the commit a borrowed one was vouched for by. That way it does not build a second time. The release job records the commit its executable was built from right after the build, because the default branch's tip is usually a merge."
