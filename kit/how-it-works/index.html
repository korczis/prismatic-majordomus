How it works

From repositoryto every surface.

Majordomus discovers what a repository declares, builds one typed index and capability registry from it, and projects every interface from that: an HTTP API described by OpenAPI, MCP, the Cockpit and this site, and a command line checked against the registry. One model, many projections.

Use

What one model buys

  • Consistentevery surface reads one registry
  • Deterministicthe same input, the same bytes
  • Discoveredfound through declarations, not hand-kept lists
  • Regeneratedderived files are never edited
  • Checkedgenerate --check refuses drift
  • People and agentsCLI, API, MCP, pages, docs
  • Extensiblea declared capability reaches MCP, HTTP and OpenAPI

Real impact

Measured, or counted.

The token figures measured so far are the context compiler's; the one shown is how much relevant context it leaves out of the budget. Whether a whole session uses fewer tokens is not yet measured, and the token economics page says so.
