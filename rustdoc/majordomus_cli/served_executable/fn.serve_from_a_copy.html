pub fn serve_from_a_copy(command: &Command)
Expand description

When command may hold the lease and this executable is a cargo build output, run this process from a copy of it by replacing the process image (same pid, same standard streams, same arguments). Returns only when it does not: another command, an executable that is not a build output, or a copy that could not be made or run — the last two say why on stderr, and the caller then serves in place.

Called by main once the command line is parsed, before anything is served.

use clap::Parser;
use majordomus_cli::cli::Cli;
use majordomus_cli::served_executable::serve_from_a_copy;
let cli = Cli::try_parse_from(["majordomus", "serve"]).unwrap();
// from target/debug/majordomus this does not return: the process continues as the copy
serve_from_a_copy(&cli.command);
