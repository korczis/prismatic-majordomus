The objects module: the declarative objects of the repository’s layer, listed, read and searched, and the one resolution of a majordomus:// URI that objects.get and the MCP resource read share.

resolve
Resolve a URI: the capability the registry projects at it, then the object behind a resource or the answer of a query. An unknown URI is NotFound; a registry naming an object the index does not hold is Internal; a query that refuses passes its refusal through, and any other failure of the query is Internal, naming the capability.
