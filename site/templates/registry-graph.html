Each registry of this repository stays authoritative for what it owns — the capabilities, the rules, the decisions, the skills, the use cases, the documents — and one derivation composes them into a single graph. The nodes are those things as themselves; the edges are the references their own front matter already carries. Nothing here is authored: a node exists because an object or a capability exists, and an edge exists because one of them names another.
