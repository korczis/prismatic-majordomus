Commands

The Cockpit reads; the command line changes things. Every command below is the same service this page renders, and none of them takes a path — the path is derived.

majordomus worktree                          # where am I, and is that where I belong
majordomus worktree create <branch>          # start work: the branch from the trunk, the worktree at its path
cd "$(majordomus worktree path <branch>)"
majordomus worktree migrate --plan           # what would move; nothing changes
majordomus worktree migrate                  # move, verify, report
majordomus worktree repair                   # drop stale registrations; deletes no directory
majordomus worktree cleanup                  # merged and clean: what could go, and how; deletes nothing
majordomus worktree remove <branch>          # one linked worktree; never dirty work unforced, never a branch
