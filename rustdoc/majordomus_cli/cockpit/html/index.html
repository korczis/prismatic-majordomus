majordomus_cli::cockpit

Module html 

Source
Expand description

Markup that cannot be unescaped by accident. There is no template engine here and no template string: a page is a tree of El values, and the only way text reaches the output is through a method that escapes it.

The Cockpit renders what the repository holds — rule bodies, prompt text, ADR prose, file paths, a peer’s announced intent — and every one of those is content this process did not write. A template string with a {} in it puts the escaping decision at every call site; this puts it in one place, and a page that wants raw markup has to say El::raw and be read for it.
