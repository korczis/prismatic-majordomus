## Controlled budget

Seconds of repository-controlled latency on a GitHub-hosted Linux runner. The Actions queue,
runner allocation and the "pages build and deployment" run GitHub does itself are measured
and reported beside these and never budgeted: they belong to GitHub, not to this repository.

| phase | warm budget |
|---|---|
| checkout | 10 s |
| setup | 30 s |
| build | 20 s |
| check | 25 s |
| publish | 20 s |
| controlled | 75 s |

Cold runner, whole controlled path: 180 s. Push to publicly observable, reported and not
enforced: 60 s.
