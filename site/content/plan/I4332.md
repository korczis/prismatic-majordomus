description = "release.currency compares the newest v* tag the trunk contains with the forge releases that deploy.observed records (apps/majordomus-cli/src/deploy/observed.rs:120-152, ObservedRelease). A tag with no forge release gets a new stance, interrupted, beside current, owed and overdue. The brief and doctor print `WARN release <tag> tagged <age> ago with no forge Release — the publish stopped after its tag (finish: create the Release for <tag>, then its record)`. The second half-state is a tag that has a forge Release while the deployment of that release's commit failed or never happened. That means no ObservedDeployment (observed.rs:84-118) to the environment the release path declares (github-pages for a Pages site) at the tag's commit, or a newer one, has state success. That tag reads `WARN release <tag> released <age> ago, not deployed — <environment> at <sha>: <state>|none (finish: redeploy <tag>, then verify it)`. When no observation exists (no token, offline, never observed), the line carries the qualifier 'forge not observed' and never one of these stances. This is release.currency, which every adopter reads through the brief and doctor. It is separate from I2712, which concerns this repository's own scripts/ci/release-check."
