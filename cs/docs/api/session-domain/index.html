HTTP API: session_domain

Typovaná doména relace: stavový automat životního cyklu, kterým epizoda prochází, deklarovaný jednou ve spustitelném souboru a promítnutý sem, ne překreslovaný na každém povrchu, a identity, které tento checkout zaznamenává — repozitář, checkout, epizoda a vlastní relace providera — každá s kanonickou hodnotou a vlastním zápisem každého úložiště, protože úložiště zapisují šest věcí třemi slovy a nikdo to neřekl.

session_domain

Typovaná doména relace: stavový automat životního cyklu, kterým epizoda prochází, deklarovaný jednou ve spustitelném souboru a promítnutý sem, ne překreslovaný na každém povrchu, a identity, které tento checkout zaznamenává — repozitář, checkout, epizoda a vlastní relace providera — každá s kanonickou hodnotou a vlastním zápisem každého úložiště, protože úložiště zapisují šest věcí třemi slovy a nikdo to neřekl.

GET /api/v1/session/identity session_domain.identity

Co identifikuje tento checkout a jak to který store zapisuje

Repozitář, checkout, otevřená epizoda a relace providera, každé s kanonickou hodnotou, kterou tento spustitelný soubor vypočítá, a vedle ní zápisem každého úložiště. Úložiště zaznamenávají repozitář někdy jako absolutní cestu k .git, jindy jako URL remote, worktree jako cestu i jako digest a relaci jako id epizody i UUID providera; tento povrch to říká, aby čtenář nikdy neporovnával dva zápisy různých věcí a nedošel k závěru, že se neshodují.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache procesu (max_entries=2, ttl_seconds=2)
  • Nástroj MCP majordomus_session_identity
  • Zdroj MCP {"name": "session-identity", "uri": "majordomus://session/identity"}

Žádné parametry.

Vyzkoušejte

Port je ten, který server zalogoval; 8741 je ten, o který žádá jako první. Hodnoty jsou první příklad operace.

curl -s "http://127.0.0.1:8741/api/v1/session/identity"

Testováno v apps/majordomus-cli/tests/http_serve.rs, který přehrává routu s těmito hodnotami proti serveru na skutečném socketu.

GET /api/v1/session/machine session_domain.machine

Životní cyklus epizody jako data

Každý stav, v němž může být epizoda, zda je koncový a kam se může přesunout; každý přechod — open, resume, checkpoint, detach, close, recover — se stavy, mezi nimiž běží, a zda stav vůbec posouvá. Odvozeno z typů, takže diagram, který se rozchází s kódem, nemůže existovat. Na čem stroj záměrně nezávisí, je řečeno, ne ponecháno k dedukci: na stavu úlohy, což je ADR 0052.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache procesu (max_entries=1, ttl_seconds=600)
  • Nástroj MCP majordomus_session_machine
  • zdroj MCP {"name": "session-machine", "uri": "majordomus://session/machine"}

Schémata

Komponenty, které používají jen operace tohoto tagu. Každý řádek je pole daného typu, jeho doc komentář je popis; typ vlastněný jinou stránkou na ni odkazuje.

EpisodeState

"opening" | "open" | "detached" | "closed"
Kde epizoda je: vytvořena, otevřena, odpojena od spojení, které ji drželo, nebo uzavřena do neměnného záznamu.

use majordomus_cli::session::EpisodeState;

assert!(EpisodeState::Open.may_move_to(EpisodeState::Closed));
assert!(!EpisodeState::Closed.may_move_to(EpisodeState::Open), "a record is immutable");
assert!(EpisodeState::Open.may_move_to(EpisodeState::Open), "a resume is not a move");
assert!(EpisodeState::Closed.is_final());
  • openingIdentita byla vyražena a nic trvalého ještě nebylo zapsáno. Existuje proto, aby pád mezi vyražením id a zápisem záznamu otevření byl stavem, který model umí pojmenovat, a ne epizodou, která se nikdy nestala.
  • openOtevřený záznam platí. Pracovník je tady, nebo tu nedávno byl.
  • detachedSpojení, které drželo epizodu, zmizelo, a epizoda ne. Spadlý socket je nejběžnější věc, která se relaci stane; epizoda, která by se při každém odpojení sama uzavřela, by ztratila práci každého pracovníka, jemuž síť škytla. Stále ji lze obnovit a stále je obnovitelná, pokud ji nikdo neobnoví.
  • closedNeměnný záznam byl publikován. Konečný, a konečnost je smysl: čtyři záznamy s-20260909152316-024f existují všechny proto, že nic v předchozí reprezentaci nemohlo říct tohle.

let dir = tempfile::tempdir().unwrap();
let report = IdentityReport {

    findings: Vec::new(),

let subjects: Vec<&str> = report.facets.iter().map(|f| f.subject.as_str()).collect();

assert!(report.machine.transitions.iter().any(|t| !t.moves_state), "a checkpoint is an event");

Používá IdentityFacet

Pravopis

"local" | "shared" | "canonical"
Z kterého úložiště byla zaznamenaná identita přečtena, uchováno vedle hodnoty.

Nejde o to volit mezi mj_git_repo_id a mj_repository_id nebo mezi worktree: a worktree_id:. Jde o to přestat předstírat, že jsou jednou hodnotou. Čtenář, který ví, že řetězec je lokální zápis, jej může porovnat s jinými lokálními zápisy a může odmítnout porovnat jej se sdíleným, což je přesně srovnání, které vyrobilo „tyto dva záznamy jsou o různých repozitářích“ u záznamů téhož repozitáře napsaných s odstupem čtyř minut.

use majordomus_cli::session::Spelling;
// the two halves are different answers to one question, and are never compared
assert_ne!(Spelling::Local, Spelling::Shared);
assert_eq!(Spelling::Canonical.as_str(), "canonical");
  • localZápis lokální poloviny: cesta v .ai/local/state/. Jmenuje tento disk a nikdy se nepublikuje.
  • sharedZápis sdílené poloviny: vzdálená URL nebo digest, v .ai/repo/sessions/. Jmenuje repozitář a putuje s klonem (ADR 0014).
  • canonicalVlastní kanonický digest tohoto spustitelného souboru, vypočtený, ne přečtený.

Používá MachineReport

Přechod

"open" | "resume" | "checkpoint" | "detach" | "close" | "recover"
Co epizodu pohnulo. Slovník, který potřebuje audit ADR 0052: open, resume, checkpoint, detach, close, recover.

Jeden z nich stav nemění a přesto je přechodem. Checkpoint nechává otevřenou epizodu otevřenou — ale je to jedna ze dvou událostí, jejichž absence je to, co audit hledal, a událost modelovanou jako „nic se nestalo“ nelze spočítat. Šest dní ticha bylo šest dní, kdy session.started a session.closed nadále přicházely a dvě události, které vytvářejí záznamy, z nichž pracovník pokračuje, ne. Slovník, ve kterém tyto dvě nejsou události, je slovník, ve kterém je ten výpadek neviditelný.

use majordomus_cli::session::{EpisodeState, Transition};

// a checkpoint is a transition that does not move the state, and says so
let c = Transition::Checkpoint;
assert_eq!(c.from_to(), (EpisodeState::Open, EpisodeState::Open));
assert!(!c.moves_state());

// a resume is canonically the return to a detached episode; a provider's start event
// arriving at one that is already open is the same transition seen from `Open`, which
// the machine allows without a move
assert_eq!(Transition::Resume.from_to(), (EpisodeState::Detached, EpisodeState::Open));
assert!(EpisodeState::Open.may_move_to(EpisodeState::Open));

// and every transition's own move is one the machine allows
for t in Transition::ALL {
    let (from, to) = t.from_to();
    assert!(from.may_move_to(to), "{} is not a legal move", t.as_str());
}
  • openEpizoda začíná: vydá se id a zapíše se otevřený záznam.
  • resumeWorker se vrátil k odpojené epizodě. Startovní událost providera se také znovu spustí při resume a při compactionu proti epizodě, která je stále otevřená; je to tentýž přechod pozorovaný z Open a poctivá odpověď na „vaše epizoda je už otevřená“ je ponechat ji, ne otevřít druhou.
  • checkpointPoznámka o postupu byla zaznamenána k epizodě. Artefakt epizody, ne úlohy (ADR 0052): checkpoint mimo úlohu zaznamená task: none a je to běžný záznam, ne odmítnutí.
  • detachSpojení zaniklo bez koncové události.
  • closeWorker ukončil epizodu a neměnný záznam byl publikován.
  • recoverNikdo ji neukončil a její poslední známka života je starší než práh opuštění, takže ji uzavřela údržba. Záznam to říká: epizoda takto uzavřená je interrupted, protože čtenář, který z ní obnovuje, potřebuje vědět, že může být neúplná.
