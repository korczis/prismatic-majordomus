1//! The `peers` module: the workers of this repository, and what they say they are working
2//! on. Nothing here writes to the repository.
3//!
4//! # The board is the repository's, gathered from every checkout's server
5//!
6//! A board is one server process's memory, and (ADR 0035) a server serves the checkout it
7//! was started in: a linked worktree is a checkout of its own, elects a server of its own,
8//! and keeps a board of its own. So the sentence every worker is bootstrapped with — "one
9//! shared server serves this repository, and every worker attached to it is visible to
10//! every other" — was true of one checkout and false of a repository, and on 2026-09-11
11//! this repository had seven live servers over one git repository, seven boards, and nine
12//! agents spread across sixty worktrees who could not see one another at all. Two of them
13//! built the same subsystem in one afternoon.
14//!
15//! `peers.list` is therefore repository-wide by default. It enumerates the checkouts git
16//! registers, exactly as `server.status` does and through the same reader, reads the lease
17//! of each, and asks every server that answers for its own board — `checkouts=this`, which
18//! is what makes the gather one hop deep and not a cycle. Its own board it reads from
19//! memory. Every peer it returns is stamped with the checkout it came from, because `p1`
20//! is the first session of every board and an unqualified id would be ambiguous the moment
21//! two boards are merged.
22//!
23//! Nothing is written and no server is contacted twice: this is a read of what already
24//! exists. There is no second authority, no registry of servers, no new port and no lease
25//! but the one each checkout already had.
26//!
27//! # What it costs, and how to not pay it
28//!
29//! One lease read per registered checkout, one probe per checkout whose lease names an
30//! address, and one more round trip per server that answers. Measured on this repository
31//! on 2026-09-11 — 118 registered checkouts, 7 live servers — the enumeration and probing
32//! `server.status` already does took 3.0s wall, and the boards are a handful of loopback
33//! round trips on top. A caller that only wants the board of the checkout it is in says
34//! `checkouts: this`, which enumerates nothing, probes nothing and reads one board out of
35//! memory.

57#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
58/// What to ask of `peers.list`: how wide the board is.
59///
60/// The same one field, the same word and the same default as
61/// [`super::server::ServerStatusInput`], because it is the same question asked of the same
62/// set of checkouts, and a caller should not have to learn it twice.
63///
64/// The evidence for that is `the_default_board_is_the_repositorys` below rather than a doc
65/// example here: this module is `pub(crate)`, so a doc test — which compiles as an external
66/// crate — cannot name the type at all.
67pub struct PeerListInput {
68    // The whole of "why `this` exists" is in this module's own documentation: kept to one
69    // line here because a field's doc is rendered into a table cell, and a paragraph
70    // break in it breaks the row (docs/generated/modules/peers.md).
71    /// Which checkouts the board covers. Absent means `repository`; `this` is the checkout the call reached and nothing else, and it is what a sibling server is asked so that a gather can never ask back.
72    #[serde(default)]
73    pub checkouts: Checkouts,
74    /// How many of the covered checkouts are listed in `boards`. Absent means `summary`: every checkout with a server, a worker, or a board that could not be read, the rest counted in `omitted`; `full` lists every one.
75    #[serde(default)]
76    pub view: PeerListView,
77}

79/// How many of the covered checkouts `peers.list` lists one by one — the same two words, and
80/// the same default, as the mesh's own `view` (`mesh::page::View`), for the same reason.
81///
82/// On 2026-10-22 this repository registered 625 checkouts, 601 of them with no server and
83/// nobody attached, and the default answer was 168 kB: past what an MCP client shows, so
84/// the read every worker is told to make before it starts went through a saved file. A
85/// checkout with no server holds no board (`ServerStanding::Absent`, or a `Stale` lease that
86/// names a process that is gone), so listing it says only that it exists; the summary counts
87/// those by standing and lists every other. The evidence is
88/// `the_summary_counts_only_checkouts_that_hold_no_board` below.
89#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
90#[serde(rename_all = "snake_case")]
91pub enum PeerListView {
92    /// This checkout, every checkout with a worker attached or a server standing, and every
93    /// board that could not be read; the checkouts with no server and nobody attached are
94    /// counted in `omitted` by standing.
95    #[default]
96    Summary,
97    /// Every covered checkout, one entry each.
98    Full,
99}

115/// Whether the summary lists `board` rather than counting it: this checkout, any board with a
116/// worker or a reason it was not read, and any checkout whose server stands. What is left is a
117/// checkout with no server and nobody attached, which holds no board at all.
118fn listed_in_summary(board: &BoardView) -> bool {
119    board.checkout.this_checkout
120        || board.attached > 0
121        || board.reason.is_some()
122        || !matches!(
123            board.standing,
124            ServerStanding::Absent | ServerStanding::Stale
125        )
126}

128#[derive(Debug, Clone, Serialize, Deserialize, JsonSchema)]
129/// One checkout's board, as the gather found it.
130///
131/// Present for every checkout the answer covers, whether or not its board could be read,
132/// because a listing that silently drops the checkouts it could not reach is the shape of
133/// answer that made this capability wrong in the first place: a reader would see a short
134/// board and conclude nobody else is working here.
135pub struct BoardView {
136    /// The checkout.
137    #[serde(flatten)]
138    pub checkout: PeerCheckout,
139    /// Where its server stands, by the same reading `server.status` reports.
140    pub standing: ServerStanding,
141    /// The address its lease names, when it has one.
142    #[serde(skip_serializing_if = "Option::is_none")]
143    pub url: Option<String>,
144    /// How many of this board's peers are attached.
145    pub attached: usize,
146    /// Why this board is not in the answer. `None` when it is.
147    #[serde(skip_serializing_if = "Option::is_none")]
148    pub reason: Option<String>,
149    /// The mesh stream of the server whose memory holds this board, when its mesh runs: the
150    /// stream it projects the board's peers into as `board-pN` sessions. A position such as
151    /// `p1` is that server's alone, so only this stream ties a board peer to its session.
152    #[serde(default, skip_serializing_if = "Option::is_none")]
153    pub stream: Option<String>,
154}

156#[derive(Debug, Serialize, Deserialize, JsonSchema)]
157/// The answer of `peers.list`: every worker of this repository, from every checkout's board.
158pub struct PeerList {
159    /// How many peers are attached across every board that was read, the caller included.
160    pub count: usize,
161    #[serde(skip_serializing_if = "Option::is_none")]
162    /// The caller's own peer id, when the call came through an MCP session. A position on
163    /// this checkout's board, not a durable identity: it is handed out again after a
164    /// reconnect, and [`Peer::checkout`] is the half of a worker's identity that is not.
165    pub caller: Option<PeerId>,
166    /// The peers, this checkout's board first and then the siblings in the order git
167    /// registers them, each in its own board's attachment order. Every one carries the
168    /// checkout it belongs to, because `p1` is the first session of every board. A peer
169    /// that announced something and then went away is still here, with `attached: false`.
170    pub peers: Vec<Peer>,
171    /// Every pair of peers whose claimed scope meets, each pair once — now across
172    /// checkouts as well as within one. Empty is the ordinary case, and a reader who sees
173    /// an entry here is looking at two workers about to do the same work.
174    #[serde(default, skip_serializing_if = "Vec::is_empty")]
175    pub overlaps: Vec<Overlap>,
176    /// How many checkouts the answer covers, listed in `boards` or counted in `omitted` — a
177    /// count, where the input `checkouts` is a choice of which to cover.
178    pub covered: usize,
179    /// One entry per checkout the answer lists, reached or not: every covered checkout under
180    /// `view: full`; under the default summary, every one but those `omitted` counts. A board
181    /// that could not be read is always listed.
182    pub boards: Vec<BoardView>,
183    /// The covered checkouts the summary does not list, counted by standing (`absent`,
184    /// `stale`): no server, nobody attached, no board. Empty under `view: full`.
185    #[serde(default, skip_serializing_if = "BTreeMap::is_empty")]
186    pub omitted: BTreeMap<String, usize>,
187    /// Whether every board the answer covers was read. `false` when a checkout's server
188    /// could not be asked, and `BoardView::reason` says which and why — so that "nobody
189    /// else is here" is never reported when the truth is "I could not ask".
190    pub complete: bool,
191    /// The mesh stream of the server that answered, when its mesh runs: the stream its own
192    /// board's peers are projected into. A sibling's answer carries it so that the gatherer
193    /// can name it on that sibling's `BoardView`.
194    #[serde(default, skip_serializing_if = "Option::is_none")]
195    pub stream: Option<String>,
196}

198/// One sibling server's own board, over the route the registry declares for `peers.list`.
199///
200/// Asked with `checkouts=this`, which is the whole of the cycle prevention: a server
201/// answering that question enumerates no other checkout, reads no other lease and probes
202/// no other server, so a gather is exactly one hop deep however many checkouts point at
203/// each other. There is deliberately no retry without the parameter — a server too old to
204/// know it (`Empty` refused unknown fields) would then answer its whole board, and a
205/// server of *this* version that rejected the parameter for any other reason would answer
206/// the repository, and the two of us would ask each other until a timeout. A board that
207/// cannot be read narrowly is reported unread, with the reason.
208pub(crate) fn board_of(ctx: &Context, url: &str) -> Result<Vec<Peer>, String> {
209    answer_of(ctx, url).map(|(peers, _)| peers)
210}
211
212/// [`board_of`], with the mesh stream the sibling's server projects its board into, when it
213/// says (a server older than this field says nothing, and its peers are then joined to no
214/// session).
215fn answer_of(ctx: &Context, url: &str) -> Result<(Vec<Peer>, Option<String>), String> {
216    let path = ctx
217        .registry
218        .get("peers.list")
219        .and_then(|c| c.exposure.http.as_ref())
220        .map(|h| h.path.clone())
221        .ok_or_else(|| "peers.list declares no HTTP route to ask over".to_string())?;
222    let reply = crate::mcp::bridge::request(
223        url,
224        "GET",
225        &format!("{path}?checkouts=this"),
226        &[],
227        None,
228        lease::timings().probe_timeout,
229    )
230    .map_err(|e| format!("{url} did not answer ({e})"))?;
231    if reply.status != 200 {
232        return Err(format!(
233            "{url} answered {} for its own board (a server older than this one does not \
234             know the 'checkouts' parameter and refuses it)",
235            reply.status
236        ));
237    }
238    let value: serde_json::Value =
239        serde_json::from_str(&reply.body).map_err(|e| format!("{url} answered non-JSON ({e})"))?;
240    let peers = serde_json::from_value(value["peers"].clone())
241        .map_err(|e| format!("{url} answered a board this executable cannot read ({e})"))?;
242    Ok((peers, value["stream"].as_str().map(str::to_string)))
243}

245/// The mesh stream this process projects its own board into, when its mesh runs.
246fn own_stream(ctx: &Context) -> Option<String> {
247    ctx.mesh
248        .cooperation()
249        .map(|c| c.journal().own_stream().as_str().to_string())
250}

252pub(crate) fn peers_list(ctx: &Context, input: PeerListInput) -> Result<PeerList, CapabilityError> {
253    let root = PathBuf::from(&ctx.index.repository.root);
254    let root = root.canonicalize().unwrap_or(root);
255    let local_half = server::local_half(&root);
256    let git = repository::git_identity(&root);
257    let checkouts = server::checkouts_of(&root, git.as_ref(), input.checkouts);
258
259    // every checkout is asked at once, a bounded number at a time (server::each_checkout,
260    // I2987), and the answers are folded in the order git lists the checkouts
261    let read = server::each_checkout(&checkouts, |(path, branch, _primary)| {
262        let worktree = path.canonicalize().unwrap_or(path.clone());
263        let this_checkout = worktree == root;
264        let checkout = PeerCheckout {
265            id: repository::identity(&worktree),
266            worktree: worktree.clone(),
267            branch: branch.clone(),
268            this_checkout,
269        };
270        // this checkout's board is in this process's memory: it is never asked over the
271        // wire, which also means the answer holds it even when this process is not the
272        // leaseholder (a superseded server still has its own peers, and they are real)
273        let (standing, url, found) = if this_checkout {
274            let (standing, _, read) = server::standing_at(&worktree, &local_half);
275            let url = read.document().and_then(|d| d.url.clone());
276            (standing, url, Ok((ctx.peers.list(), own_stream(ctx))))
277        } else {
278            let (standing, reason, read) = server::standing_at(&worktree, &local_half);
279            let url = read.document().and_then(|d| d.url.clone());
280            let found = match (standing, url.as_deref()) {
281                (ServerStanding::Ready | ServerStanding::Outdated, Some(url)) => {
282                    answer_of(ctx, url)
283                }
284                // No server, no board, and nobody attached there — which is a complete
285                // answer about that checkout and not a failure to reach one. A stale lease
286                // belongs here too: it names a process that is gone, so its board went
287                // with it. Calling that "unread" would leave `complete` false on this
288                // machine permanently, because an abandoned worktree's lease outlives it —
289                // and a flag that is always false says nothing when it matters. `standing`
290                // already tells the reader the lease is stale, and `server.status` is the
291                // capability that explains it.
292                (ServerStanding::Absent | ServerStanding::Stale, _) => Ok((Vec::new(), None)),
293                // Starting is the genuinely unknown one: a server is binding right now and
294                // may hold peers a second from now. Brief, and reported rather than guessed.
295                _ => Err(reason.unwrap_or_else(|| {
296                    format!(
297                        "its server is {} and has no board to read yet",
298                        standing.as_str()
299                    )
300                })),
301            };
302            (standing, url, found)
303        };
304        (checkout, standing, url, found)
305    });
306
307    let mut peers: Vec<Peer> = Vec::new();
308    let mut boards: Vec<BoardView> = Vec::with_capacity(read.len());
309    let mut complete = true;
310    for (checkout, standing, url, found) in read {
311        let (found, stream, reason) = match found {
312            Ok((found, stream)) => (found, stream, None),
313            Err(why) => {
314                complete = false;
315                (Vec::new(), None, Some(why))
316            }
317        };
318        boards.push(BoardView {
319            standing,
320            url,
321            attached: found.iter().filter(|p| p.attached).count(),
322            reason,
323            stream,
324            checkout: checkout.clone(),
325        });
326        // every peer is stamped by the reader, its own included and whatever the sibling
327        // said about itself: a sibling stamps `this_checkout: true` for its own board, and
328        // from here that board is not this one
329        peers.extend(found.into_iter().map(|mut p| {
330            p.checkout = Some(checkout.clone());
331            p
332        }));
333    }
334
335    let covered = boards.len();
336    let omitted = match input.view {
337        PeerListView::Full => BTreeMap::new(),
338        PeerListView::Summary => summarise(&mut boards),
339    };
340
341    Ok(PeerList {
342        count: peers.iter().filter(|p| p.attached).count(),
343        caller: ctx.caller.clone(),
344        overlaps: overlaps_among(&peers),
345        peers,
346        covered,
347        boards,
348        omitted,
349        complete,
350        stream: own_stream(ctx),
351    })
352}

354/// Keep the boards the summary lists and count the rest by standing.
355fn summarise(boards: &mut Vec<BoardView>) -> BTreeMap<String, usize> {
356    let mut omitted: BTreeMap<String, usize> = BTreeMap::new();
357    boards.retain(|b| {
358        let listed = listed_in_summary(b);
359        if !listed {
360            *omitted.entry(b.standing.as_str().to_string()).or_default() += 1;
361        }
362        listed
363    });
364    omitted
365}

369/// The MCP tool `peers.announce` is projected as. Named once, here, because the bridge
370/// recognises the frame that carries an announcement by this name in order to replay it
371/// after a takeover or a re-attach; the exposure below and the bridge read the same word.
372pub const ANNOUNCE_TOOL: &str = "majordomus_announce";
373
374#[derive(Debug, Serialize, Deserialize, JsonSchema)]
375#[serde(deny_unknown_fields)]
376/// The input of `peers.announce`: what the calling peer is working on.
377pub struct AnnounceInput {
378    /// One line, in the peer's words: the task, the question, the intent.
379    pub intent: String,
380    /// Repository-relative paths the peer expects to touch. Informational: other peers
381    /// read it to avoid a collision; nothing here enforces it.
382    #[serde(default)]
383    pub scope: Vec<String>,
384    /// Which of this peer's claims this is, when the peer holds more than one.
385    ///
386    /// One MCP session is not always one piece of work — a client that fans work out to
387    /// subagents shares its session with all of them — and without a name every
388    /// announcement replaces the last, so the board ends up describing whichever worker
389    /// spoke most recently and the rest of the scope silently stops being claimed. Name a
390    /// claim and it stands beside the others; announce under that name again and it is
391    /// updated. Leave it out and this is the peer's one unnamed claim, which is what a
392    /// single session announcing about itself wants.
393    #[serde(default, skip_serializing_if = "Option::is_none")]
394    pub claim: Option<String>,
395}
396
397impl BenchmarkCases for AnnounceInput {
398    fn benchmark_cases(_: &CaseContext<'_>) -> Vec<NamedCase<Self>> {
399        vec![NamedCase::new(
400            "default",
401            AnnounceInput {
402                intent: "benchmark: announcing".into(),
403                scope: vec!["apps/majordomus-cli".into()],
404                claim: None,
405            },
406        )]
407    }
408}
409
410fn peers_announce(ctx: &Context, input: AnnounceInput) -> Result<Announced, CapabilityError> {
411    let Some(caller) = &ctx.caller else {
412        return Err(CapabilityError::Refused(
413            "announce needs an MCP session: this call came through an interface with no peer identity (call the majordomus_announce tool)".into(),
414        ));
415    };
416    if input.intent.trim().is_empty() {
417        return Err(CapabilityError::InvalidInput(
418            "argument 'intent' is required and must not be blank".into(),
419        ));
420    }
421    let scope: Vec<String> = input
422        .scope
423        .into_iter()
424        .map(|s| s.trim().to_string())
425        .filter(|s| !s.is_empty())
426        .collect();
427    let claim = input
428        .claim
429        .as_deref()
430        .map(str::trim)
431        .filter(|c| !c.is_empty());
432    ctx.peers
433        .announce_claim(caller, claim, input.intent.trim(), scope)
434        .ok_or_else(|| CapabilityError::Internal(format!("peer {caller} is not attached")))
435}

520        };
521        let mut boards = vec![
522            board("here", true, ServerStanding::Absent, 0, None),
523            board("idle-a", false, ServerStanding::Absent, 0, None),
524            board("idle-b", false, ServerStanding::Absent, 0, None),
525            board("gone", false, ServerStanding::Stale, 0, None),
526            board("serving", false, ServerStanding::Ready, 0, None),
527            board("old", false, ServerStanding::Outdated, 2, None),
528            board(
529                "binding",
530                false,
531                ServerStanding::Starting,
532                0,
533                Some("starting"),
534            ),
535        ];
536        let omitted = summarise(&mut boards);
537        let listed: Vec<&str> = boards.iter().map(|b| b.checkout.id.as_str()).collect();
538        assert_eq!(listed, ["here", "serving", "old", "binding"]);
539        assert_eq!(omitted.get("absent"), Some(&2));
540        assert_eq!(omitted.get("stale"), Some(&1));
541        assert_eq!(
542            listed.len() + omitted.values().sum::<usize>(),
543            7,
544            "every covered checkout is listed or counted, never neither"
545        );
546        // a board that could not be read is listed whatever its standing says
547        let mut unread = vec![board(
548            "x",
549            false,
550            ServerStanding::Absent,
551            0,
552            Some("no answer"),
553        )];
554        assert!(summarise(&mut unread).is_empty());
555        assert_eq!(unread.len(), 1);
556    }

560    /// The declaration is the only place these names exist, and every projection — the MCP
561    /// tool, the HTTP route, the OpenAPI operation, the benchmark target — is derived from
562    /// it. A refactor that dropped an exposure or renamed a route would still compile, and
563    /// the suites that exercise the behaviour behind it would still pass. This is the
564    /// assertion that would not.
565    #[test]
566    fn the_declaration_yields_the_projections_it_claims() {
567        let m = module();
568        assert_eq!(m.id.as_str(), "peers");
569        let expected: &[(&str, &str, &str)] = &[
570            ("peers.list", "majordomus_peers", "/api/v1/peers"),
571            (
572                "peers.announce",
573                "majordomus_announce",
574                "/api/v1/peers/announce",
575            ),
576        ];
577        let ids: Vec<&str> = m
578            .capabilities
579            .iter()
580            .map(|e| e.capability.id.as_str())
581            .collect();
582        let want: Vec<&str> = expected.iter().map(|(id, _, _)| *id).collect();
583        assert_eq!(
584            ids, want,
585            "the module declares a different set of capabilities"
586        );
587        for (executable, (id, tool, path)) in m.capabilities.iter().zip(expected) {
588            let exposure = &executable.capability.exposure;
589            assert_eq!(
590                exposure.mcp.as_ref().and_then(|m| m.tool.as_deref()),
591                Some(*tool),
592                "{id} lost or renamed its MCP tool"
593            );
594            assert_eq!(
595                exposure.http.as_ref().map(|h| h.path.as_str()),
596                Some(*path),
597                "{id} lost or renamed its HTTP route"
598            );
599        }
600    }

602    /// A sibling checkout whose board cannot be read is listed with the reason, and the answer
603    /// says it is not complete: a server still starting, and one that answers for the sibling
604    /// with a board this executable cannot read.
605    #[test]
606    fn a_sibling_board_that_cannot_be_read_is_named_and_the_answer_is_incomplete() {
607        let repo = crate::synthetic::SyntheticRepository::small().unwrap();
608        let ctx = crate::monitor::testing::context(&repo);
609        let root = repo.root().canonicalize().unwrap();
610        let git = |args: &[&str]| {
611            let ok = std::process::Command::new("git")
612                .args(["-c", "user.email=t@t", "-c", "user.name=t"])
613                .args(args)
614                .current_dir(&root)
615                .status()
616                .unwrap()
617                .success();
618            assert!(ok, "git {args:?}");
619        };
620        git(&["commit", "-q", "--allow-empty", "-m", "root"]);
621        let sibling = root.join("side");
622        git(&[
623            "worktree",
624            "add",
625            "-q",
626            "-b",
627            "side",
628            sibling.to_str().unwrap(),
629        ]);
630        let sibling = sibling.canonicalize().unwrap();
631        let lease = lease::lease_file(&sibling, &server::local_half(&root));
632        std::fs::create_dir_all(lease.parent().unwrap()).unwrap();
633        let read = || {
634            let list = peers_list(
635                &ctx,
636                PeerListInput {
637                    checkouts: Checkouts::Repository,
638                    view: PeerListView::Full,
639                },
640            )
641            .unwrap();
642            let reason = list
643                .boards
644                .iter()
645                .find(|b| b.checkout.worktree == sibling)
646                .map(|b| b.reason.clone())
647                .expect("the sibling's board is listed");
648            (list.complete, reason.unwrap_or_default())
649        };
650
651        // a lease its owner has not written yet: the server is still starting
652        std::fs::write(&lease, "").unwrap();
653        let (complete, reason) = read();
654        assert!(!complete);
655        assert!(reason.contains("no board to read yet"), "{reason}");
656
657        // a server that answers for the sibling with a board that is not a list of peers
658        let url =
659            crate::monitor::testing::http_stub(repository::identity(&sibling), r#"{"peers": 7}"#);
660        let doc = lease::LeaseDocument {
661            schema: lease::SCHEMA.into(),
662            pid: std::process::id(),
663            token: "t".into(),
664            root: sibling.clone(),
665            url: Some(url),
666            started_at: "2026-10-18T00:00:00Z".into(),
667            executable: None,
668            version: Some(crate::VERSION.into()),
669        };
670        std::fs::write(&lease, serde_json::to_string(&doc).unwrap()).unwrap();
671        let (complete, reason) = read();
672        assert!(!complete);
673        assert!(reason.contains("cannot read"), "{reason}");
674    }
