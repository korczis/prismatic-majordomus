pub fn directory(root: &Path) -> PathBuf
Expand description

Where a checkout’s handover records live. It is under .ai/local/, which is never committed, so a handover is a fact about one checkout until something — this module, or a person — moves it; both halves of this module agree on the location by calling here rather than by each spelling the path.

use majordomus_cli::mesh::handover::directory;

let root = tempfile::tempdir().unwrap();
let dir = directory(root.path());
assert!(dir.ends_with(".ai/local/state/handovers"));
assert!(dir.starts_with(root.path()), "always inside the checkout it belongs to");
