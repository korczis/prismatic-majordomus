pub fn transport(base_url: &str) -> Result<Transport>
Expand description

How base_url would be reached, or why it would not be: Transport::Tls for an https:// endpoint (nothing is resolved), Transport::Cleartext for an http:// one whose every address is not public, and an error otherwise — PermissionDenied naming the public address, InvalidInput for an endpoint that cannot be read, or the resolver’s own. The check request makes before it connects, offered to a self-check that dials nothing.

use majordomus_cli::mcp::bridge::{transport, Transport};
assert_eq!(transport("https://hub.example:443").unwrap(), Transport::Tls);
assert_eq!(transport("http://10.0.0.2:8742").unwrap(), Transport::Cleartext);
let refused = transport("http://203.0.113.5:8791").unwrap_err();
assert_eq!(refused.kind(), std::io::ErrorKind::PermissionDenied);
assert!(refused.to_string().contains("203.0.113.5") && refused.to_string().contains("use https://"));
