The outcome decides as it does for every other shortfall (mj_obl_verdict): a completed finish refuses, partial and blocked report it. The rule an empty input set obeys is written once: one table of cases (inputs that resolve to files, inputs that resolve to none, a token with no inputs, a recorded empty hash, a recorded non-empty hash) that a parity case runs through both engines, so the two judgements cannot drift apart again."
