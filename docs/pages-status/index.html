Controlled budget

Seconds of repository-controlled latency on a GitHub-hosted Linux runner. The Actions queue, runner allocation and the "pages build and deployment" run GitHub does itself are measured and reported beside these and never budgeted: they belong to GitHub, not to this repository.

phasewarm budget
checkout10 s
setup30 s
build20 s
check25 s
publish20 s
controlled75 s

Cold runner, whole controlled path: 180 s. Push to publicly observable, reported and not enforced: 60 s.
