pub fn session_beats_check(tally: &SessionBeatTally) -> DoctorCheck
Expand description

The session_beats check (I3990): whether this runtime wrote every session beat its working exclusive holders were owed. A runtime withholds beats only when its limit per window is reached; a withheld beat is never silent, because a session that is not beaten for has its exclusive claims suspended — scopes freed that its worker still means to hold. It fails while a beat was withheld within the last window, and passes, naming the count, once the window has moved past the last one.

use majordomus_cli::mesh::cooperation::SessionBeatTally;
use majordomus_cli::mesh::doctor::session_beats_check;
let quiet = SessionBeatTally { written: 12, limit: 192, window_seconds: 3600, ..Default::default() };
assert!(session_beats_check(&quiet).ok);
let biting = SessionBeatTally { withheld: 3, withheld_recently: true, ..quiet };
let check = session_beats_check(&biting);
assert!(!check.ok && check.detail.contains("3 session beat(s) withheld"), "{}", check.detail);
