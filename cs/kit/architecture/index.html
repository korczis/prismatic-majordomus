Architektura

Jeden repozitář.Mnoho rozhraní.

Majordomus objeví repozitář jednou, načte ho do typovaných modelů a z nich odvodí svá rozhraní: HTTP API a jeho popis OpenAPI, Swagger UI, MCP, generické stránky Cockpitu a tento web. Příkazová řádka je deklarována podruhé, v clap, a kontrolována proti registru.
