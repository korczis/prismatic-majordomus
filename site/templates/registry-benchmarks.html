Every externally callable operation is a benchmark target, derived from the registry: each executable capability directly and on every transport its exposure declares, with the cases its input type provides, plus the transports' own operations. majordomus bench coverage computes the same table live, majordomus bench times it, and bench --check compares a run with the accepted baseline of its platform under the policy below.

The same matrix as Markdown is docs/generated/benchmarks.md; how to read a measurement is the performance document.
