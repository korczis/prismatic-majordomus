title = "I4669 — An owner's answer is a typed, committed record with its provenance, so a session that receives it relayed cites it by id and a validator proves where it came from"
description = "An owner-answer record kind (majordomus.owner-answer/v1, data-declared in share/kinds.yaml, so the registry validates it and serves it as majordomus://owner-answer/<id> over MCP and HTTP) holds one question put to the repository's owner and the answer, under .ai/repo/answers/<id>.yaml. Its fields are the id, the channel, the provider, the asking session with where that came from, both times, the question, the options and the answer verbatim (as JSON strings, so no byte is folded away), how the text was obtained (text_source: transcript-checked, provider-payload or typed), the transcript locator and the sha256 of its raw lines, sha256 digests of the question and of the answer, an optional translation that never replaces the verbatim text, what it settles, what it supersedes, and the recording session, time and identity, computed. `majordomus question record` writes it, reading the question, options, session and times from the provider transcript when --transcript is given and checking the answer against the result; `question answers` and `question answer <id>` read it back; `question resolve --owner-answer <id>` closes a blocking question with it. A baseline rule (majordomus.owner-answers-are-recorded) and its validator, run by check, doctor and watch, recompute both digests, refuse a label that was not offered, and report every owner-answer:<id> cited under .ai/repo/ that names no record."
