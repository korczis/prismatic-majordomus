adresáře

Adresáře vrstvy jako hierarchie: kontrakt, který každý deklaruje, co dluží a který kontrakt to řekl, a řetězec, který se na něj vztahuje po vyřešení dědičnosti.

GET /api/v1/directories directories.list

Adresářové smlouvy vrstvy

Každý adresář vrstvy, který index zná, s kontraktem, který deklaruje, zda jeden dluží a který kontrakt rozhodl, a — pro pojmenovanou cestu, nebo na požádání pro všechny — efektivní řetěz složený od kořene dolů, nejméně specifický první.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache procesu (max_entries=8, ttl_seconds=5)
  • Nástroj MCP majordomus_directories
  • Zdroj MCP {"name": "directories", "uri": "majordomus://directories"}

Parametry dotazu

názevtyppovinnépopispříklady
path string ne Jeden adresář, relativní k repozitáři a uvnitř vrstvy. Jeho účinný řetěz se vždy rozřeší. Vynechání znamená každý adresář vrstvy. one-directory: ".ai/repo/rules"
účinné boolean ne Vyřešit účinný řetěz pro každý adresář, ne jen pro pojmenovaný. effective-everywhere: true
state DirectoryState | null ne Jen adresáře v tomto stavu: `documented`, `exempt` nebo `owed`. owed: "owed"

Vyzkoušejte

Port je ten, který server zalogoval; 8741 je ten, o který žádá jako první. Hodnoty jsou první příklad operace.

curl -s "http://127.0.0.1:8741/api/v1/directories?path=.ai%2Frepo%2Frules&effective=true&state=owed"

Testováno v apps/majordomus-cli/tests/http_serve.rs, který přehrává routu s těmito hodnotami proti serveru na skutečném socketu.
