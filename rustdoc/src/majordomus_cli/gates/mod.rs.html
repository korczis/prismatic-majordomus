1//! Completion as a provable state: which gates a task's own change set must pass, what
2//! each one said, whether that verdict still describes the tree, and therefore whether the
3//! task may be called finished.
4//!
5//! # The problem this exists for
6//!
7//! A worker saying "done" is a claim about a repository, and until this module the
8//! repository had no way to contradict it at the level of the *validation pipeline*.
9//! `finish` already refused over the task's `requires` — the obligation closure of ADR
10//! 0030 — but the eighteen-odd gates the CI model declares had no bearing on whether a task
11//! could be completed at all: they were a property of a pull request, not of a task. So a
12//! task could be finished with `rust-check` red, or with `shell-suite` never having run.
13//!
14//! # Nothing here is a second declaration
15//!
16//! - **The gates** are `.ai/repo/ci/gates.yaml`, read by `model::GateModel`. `scripts/ci-plan`
17//!   is the other reader; the behavioural case asserts they select the same set.
18//! - **Applicability** is that model's own rules, applied to the task's own change set —
19//!   the paths between the task's starting commit and the working tree. Not a table of
20//!   "source implies tests": the classes in the model already say which paths select which
21//!   gates, and a class edited tomorrow changes the answer tomorrow.
22//! - **The obligations** are `share/obligations.yaml`, judged by
23//!   [`crate::capability::builtin::obligations`]. This module derives which of them the
24//!   change set *implies* — from each token's own declared `inputs` — and reports whether
25//!   the task declared it. It does not re-judge a declared one; `obligations.closure` and
26//!   `mj_validate_obligations` own that and there is one judgement, not two.
27//! - **The evidence and its staleness** are the ledger and the inputs hash, the mechanism
28//!   `majordomus evidence` already writes and ADR 0030 already argues for.
29//!
30//! # The one thing that is new
31//!
32//! A gate run is now a fact the record can hold: `majordomus evidence --gate <id> --exit <n>`
33//! writes a `task.gate` line carrying the hash of the files that select that gate, and
34//! `judge` turns those lines into a status. Recording is the shell tool's, because the
35//! ledger has one writer (ADR 0030); judging is here, because a judgement with two
36//! implementations is how `check` and a gate come to disagree.
37//!
38//! # One lifecycle
39//!
40//! A change set goes through the model to a plan, the plan and the recorded runs through the
41//! judgement to a status per gate, and the statuses fold into one verdict.
42//!
43//! ```
44//! use majordomus_cli::gates::GateStatus;
45//!
46//! // the vocabulary the whole module reports in, and the two rules that make it useful
47//! assert!(GateStatus::Fail.refuses() && GateStatus::Stale.refuses());
48//! assert!(GateStatus::Queued.unverified() && !GateStatus::Queued.refuses());
49//! // and the one word that discharges anything
50//! assert!(!GateStatus::Pass.refuses() && !GateStatus::Pass.unverified());
51//! ```
52//!
53

56// re-exported below, so the public surface is the answer and not the machinery that makes
57// it.

84/// ```
85/// use majordomus_cli::gates::ImpliedObligation;
86///
87/// let owed = ImpliedObligation {
88///     id: "tests".into(),
89///     title: "The cases the change obliges were run".into(),
90///     applicable: true,
91///     declared: false,
92///     reason: "lib/check.sh is an input of this obligation".into(),
93///     because: vec!["lib/check.sh".into()],
94///     remediation: "majordomus start --requires tests".into(),
95/// };
96/// // applicable and undeclared is the gap nothing else reports: the change owes it and
97/// // the task promised nothing, so no validator holds anybody to it
98/// assert!(owed.applicable && !owed.declared);
99/// ```
100#[derive(Debug, Clone, Serialize, Deserialize, JsonSchema)]
101/// One obligation the change set implies, and whether the task promised it.
102///
103/// Applicability is derived and nothing else: a token's own `inputs` in
104/// `share/obligations.yaml` name the files it is about, so a change to one of them is what
105/// makes the token owed. A token with no `inputs` names a fact outside the tree — a push, a
106/// publication, a deployment — which no change to a tree can imply, so those are owed when
107/// the task declares them and reported as not applicable when it does not.
108pub struct ImpliedObligation {
109    /// The token.
110    pub id: String,
111    /// The obligation as a heading, from the vocabulary.
112    pub title: String,
113    /// True when the change set, or the task's own declaration, makes it owed.
114    pub applicable: bool,
115    /// True when the task's `requires` names it, so `finish` already holds the task to it.
116    pub declared: bool,
117    /// Why it applies, or why it does not.
118    pub reason: String,
119    /// The changed paths that implied it, when paths did.
120    #[serde(default, skip_serializing_if = "Vec::is_empty")]
121    pub because: Vec<String>,
122    /// What would discharge it.
123    pub remediation: String,
124}

126/// Which obligations a change set implies, against the shipped vocabulary and the task's
127/// own declaration.
128///
129/// The derivation, in one sentence each:
130///
131/// - a token whose declared `inputs` cover a changed path is owed, which is how source
132///   modification comes to imply `tests`, a document change to imply `docs`, and a change
133///   under `share/` or `.ai/repo/` to imply `generated` — every one of those from the
134///   token's own data and none from a table here;
135/// - `commit` is owed whenever anything changed at all, because work that exists only in a
136///   working tree is not work the repository has;
137/// - every other token names a fact outside this tree, so it is owed exactly when the task
138///   declared it: a deployment-scoped task declares `deploy` and owes verification, and a
139///   task that deploys nothing does not, which is the difference between "not applicable"
140///   and "unknown".
141pub(crate) fn implied(
142    vocabulary: &[Obligation],
143    changed: &[String],
144    task: Option<&ActiveTask>,
145) -> Vec<ImpliedObligation> {
146    let declared: BTreeSet<&str> = task
147        .map(|t| t.requires.iter().map(String::as_str).collect())
148        .unwrap_or_default();
149    let mut out = Vec::new();
150    for o in vocabulary {
151        let hits: Vec<String> = changed
152            .iter()
153            .filter(|p| o.inputs.iter().any(|spec| Glob::new(spec).matches(p)))
154            .cloned()
155            .collect();
156        let is_declared = declared.contains(o.id.as_str());
157        let (applicable, reason) = if !hits.is_empty() {
158            (
159                true,
160                format!(
161                    "the change touches {} file(s) this obligation is taken over",
162                    hits.len()
163                ),
164            )
165        } else if o.id == "commit" && !changed.is_empty() {
166            (
167                true,
168                "the change exists, so it owes being in the branch's history".to_string(),
169            )
170        } else if is_declared {
171            (true, "the task's own `requires` declares it".to_string())
172        } else if o.inputs.is_empty() {
173            (
174                false,
175                format!(
176                    "a fact outside this tree that no change to it can imply; declare it in \
177                     the task's `requires` to owe it ({})",
178                    o.discharged_by
179                ),
180            )
181        } else {
182            (
183                false,
184                "the change touches nothing this obligation is taken over".to_string(),
185            )
186        };
187        out.push(ImpliedObligation {
188            id: o.id.clone(),
189            title: o.title.clone(),
190            applicable,
191            declared: is_declared,
192            reason,
193            because: hits,
194            remediation: if o.discharged_by == "none" {
195                format!(
196                    "majordomus evidence --covers {} --command '<what proved it>'",
197                    o.id
198                )
199            } else {
200                format!(
201                    "{} && majordomus evidence --covers {} --command '{}'",
202                    o.discharged_by, o.id, o.discharged_by
203                )
204            },
205        });
206    }
207    out
208}

212/// ```
213/// use majordomus_cli::gates::Completion;
214///
215/// // the document every surface reads, as `gates.completion` answers with it. The property
216/// // that matters is the one asserted here: a gate that never reported leaves the task
217/// // finishable and *unverified*, which is a different thing from a task that passed.
218/// let c: Completion = serde_json::from_value(serde_json::json!({
219///     "present": true,
220///     "model": ".ai/repo/ci/gates.yaml",
221///     "plan": { "mode": "affected", "reason": "1 path in 1 class", "changed": ["docs/CLI.md"],
222///               "classes": [], "unclassified": [], "selected": {}, "excluded": {} },
223///     "finishable": true,
224///     "unverified": ["reference-check"],
225///     "tallies": { "queued": 1 },
226///     "gates": [],
227///     "obligations": [],
228///     "questions": []
229/// }))
230/// .unwrap();
231/// assert!(c.finishable, "absence of a verdict does not refuse");
232/// assert_eq!(c.unverified, ["reference-check"], "and it is never silently accepted");
233/// assert!(c.blocking.is_empty());
234/// ```
235#[derive(Debug, Clone, Serialize, Deserialize, JsonSchema)]
236/// Whether the active task may be called finished, and everything the answer rests on.
237///
238/// `finishable` is the field a caller acts on and the one thing no surface may recompute:
239/// the shell tool's `check` and `finish` read it, the HTTP API serves it, the Cockpit
240/// renders it, and all of them are reading this one execution.
241pub struct Completion {
242    /// True when a task record was found in this checkout.
243    pub present: bool,
244    /// The task, as its record declares it.
245    #[serde(default, skip_serializing_if = "Option::is_none")]
246    pub task: Option<ActiveTask>,
247    /// The CI model this was judged against.
248    pub model: String,
249    /// Affected or full, and why.
250    pub plan: GatePlan,
251    /// False when a required gate is known to be failing, stale, or blocked by one that is.
252    /// Absence of a verdict does not make this false — it makes `unverified` non-empty.
253    pub finishable: bool,
254    /// The required gates whose status refuses completion.
255    #[serde(default, skip_serializing_if = "Vec::is_empty")]
256    pub blocking: Vec<String>,
257    /// The required gates that have never reported, or cannot be judged here. A task
258    /// finished over these is finished unverified, and the record says so.
259    #[serde(default, skip_serializing_if = "Vec::is_empty")]
260    pub unverified: Vec<String>,
261    /// How many gates stand in each status, by word.
262    pub tallies: BTreeMap<String, usize>,
263    /// Every gate of the model, what refuses first.
264    pub gates: Vec<Gate>,
265    /// Which obligations the change set implies, and whether the task promised them. The
266    /// judgement of a declared one is `obligations.closure`'s, not this module's.
267    pub obligations: Vec<ImpliedObligation>,
268    /// The done invariant: the questions a task must answer before anybody may call it
269    /// finished, each with the source that answered it and the evidence it read. Composed
270    /// from the obligation closure, the gates and the change set; a question nothing here
271    /// reaches is `unknown` and names the command that would answer it.
272    pub questions: Vec<DoneQuestion>,
273    /// What could not be established, each as one line. Never empty when something was
274    /// skipped: a gap is reported rather than left to be inferred.
275    #[serde(default, skip_serializing_if = "Vec::is_empty")]
276    pub findings: Vec<String>,
277}

279/// The paths a task changed: everything between the commit it started at and the working
280/// tree, the uncommitted half included.
281///
282/// The same two questions `scripts/ci-plan` asks of git without a base, and for the same
283/// reason: a plan computed over the committed half only would go green on a worker who has
284/// not committed, which is the failure mode this whole module exists to close.
285pub(crate) fn changed_paths(root: &Path, base: Option<&str>) -> Result<Vec<String>, String> {
286    let mut out: BTreeSet<String> = BTreeSet::new();
287    let git = |args: &[&str]| -> Result<String, String> {
288        let out = crate::git::read_only(root)
289            .args(args)
290            .output()
291            .map_err(|e| format!("git {}: {e}", args.join(" ")))?;
292        if !out.status.success() {
293            return Err(format!(
294                "git {} exited {}",
295                args.join(" "),
296                out.status.code().unwrap_or(-1)
297            ));
298        }
299        Ok(String::from_utf8_lossy(&out.stdout).into_owned())
300    };
301    if let Some(base) = base.filter(|b| !b.is_empty() && *b != "NONE") {
302        for line in git(&["diff", "--name-only", base, "HEAD"])?.lines() {
303            if !line.trim().is_empty() {
304                out.insert(line.to_string());
305            }
306        }
307    }
308    for line in git(&["status", "--porcelain=v1"])?.lines() {
309        if line.len() < 4 {
310            continue;
311        }
312        let path = &line[3..];
313        // a rename reports "old -> new"; the new name is the one a gate would read
314        let path = path.rsplit(" -> ").next().unwrap_or(path);
315        if !path.trim().is_empty() {
316            out.insert(path.to_string());
317        }
318    }
319    Ok(out.into_iter().collect())
320}

322/// Compose the whole answer.
323///
324/// Everything expensive is passed in rather than fetched here, so that the capability, a
325/// test and a benchmark all drive the same function: the model, the change set, the task,
326/// the vocabulary and the per-gate hashes.
327#[allow(clippy::too_many_arguments)]
328pub(crate) fn complete(
329    model: &GateModel,
330    changed: &[String],
331    task: Option<&ActiveTask>,
332    vocabulary: &[Obligation],
333    runs: &BTreeMap<String, GateRun>,
334    hashes: &BTreeMap<String, Option<String>>,
335    standing: &BTreeMap<String, ObligationStanding>,
336    closure_reachable: bool,
337    convergence: Option<&crate::convergence::ConvergenceReport>,
338    on_demand: bool,
339    now: &str,
340    mut findings: Vec<String>,
341) -> Completion {
342    let plan = model::plan(model, changed, on_demand);
343    let mut gates = judge::judge(model, &plan, runs, hashes, task.map(|t| t.id.as_str()), now);
344    judge::report_order(&mut gates);
345
346    let blocking: Vec<String> = gates
347        .iter()
348        .filter(|g| g.required && g.status.refuses())
349        .map(|g| g.id.clone())
350        .collect();
351    let unverified: Vec<String> = gates
352        .iter()
353        .filter(|g| g.required && g.status.unverified())
354        .map(|g| g.id.clone())
355        .collect();
356    let mut tallies: BTreeMap<String, usize> = BTreeMap::new();
357    for g in &gates {
358        *tallies.entry(g.status.as_str().to_string()).or_default() += 1;
359    }
360    if !unverified.is_empty() {
361        findings.push(format!(
362            "{} required gate(s) have never reported: {}. Never-reported is not green \
363             (project.never-reported-is-not-green); a task completed over these is completed \
364             unverified",
365            unverified.len(),
366            unverified.join(" ")
367        ));
368    }
369    let obligations = implied(vocabulary, changed, task);
370    for o in &obligations {
371        if o.applicable && !o.declared {
372            findings.push(format!(
373                "the change implies the obligation '{}' and the task does not declare it, \
374                 so `finish` will not hold it to that: {}",
375                o.id, o.reason
376            ));
377        }
378    }
379
380    let questions = done::answer(
381        standing,
382        &obligations,
383        &gates,
384        changed,
385        closure_reachable,
386        convergence,
387    );
388
389    Completion {
390        present: task.is_some(),
391        task: task.cloned(),
392        model: model::MODEL_PATH.to_string(),
393        plan,
394        finishable: blocking.is_empty(),
395        blocking,
396        unverified,
397        tallies,
398        gates,
399        obligations,
400        questions,
401        findings,
402    }
403}
