Most repositories that "adopt AI" write down how they would like to work. The writing is the
whole intervention: a file of conventions, a paragraph in a README, a prompt that asks nicely.
Nothing decides anything, so nothing changes, and six months later the document describes a
project that no longer exists.

A rule that nothing enforces is a wish with syntax highlighting.

Majordomus separates three things that are usually one pile of Markdown, and gives only the
last of them any authority.
