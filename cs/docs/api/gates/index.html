HTTP API: gates

Dokončení jako stav, o kterém rozhoduje repozitář, a ne tvrzení, které vyslovuje pracovník: validační kontroly, které tento repozitář deklaruje ve svém modelu CI, které z nich vybere vlastní sada změn úlohy, co každá naposledy ohlásila, zda tento verdikt stále popisuje strom, nad nímž vznikl, a tedy zda lze úlohu označit za dokončenou. Kontrola, která nikdy nic neohlásila, je `queued`, ne `pass`, běh, jehož soubory se od té doby změnily, je `stale` a odmítá přesně jako selhání, a kontrola, kterou změna nemůže ovlivnit, je `exempt`, ne neznámá.

Model CI

Každá validační kontrola, kterou tento repozitář deklaruje — job, který ji spouští, příkaz, který spouští, co dokazuje, zda ji vybírá každý plán a zda lze její runner vůbec získat na požádání — s třídami cest, které rozhodují, která změna vybírá kterou kontrolu, a pathspecy, nad kterými se berou důkazy každé kontroly, odvozenými z těchto tříd.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache procesu (max_entries=4, ttl_seconds=5)
  • nástroj MCP majordomus_gates
  • Zdroj MCP {"name": "gates", "uri": "majordomus://gates"}

GET /api/v1/gates/completion gates.completion

Zda lze tuto úlohu označit za hotovou

Vlastní sada změn aktivní úlohy — od commitu, ve kterém začala, po pracovní strom včetně necommitnutých souborů — projitá modelem CI: které kontroly vybírá a proč, co každá z nich naposledy hlásila a nad jakými soubory, které verdikty zastaraly, protože se strom pod nimi pohnul, které požadované kontroly nikdy nic nenahlásily a jaké povinnosti změna implikuje, ať je úloha deklarovala, nebo ne. `finishable` je false jen tehdy, když je požadovaná kontrola známě neúspěšná, zastaralá nebo blokovaná jinou takovou; absence verdiktu se hlásí jako neověřeno, nikoli tiše přijímá.

  • query
  • behaviorally_verified
  • vyžaduje se měření výkonu
  • cache vypnuta
  • Nástroj MCP majordomus_completion
  • Zdroj MCP {"name": "completion", "uri": "majordomus://gates/completion"}

Dokončení

object 
use majordomus_cli::gates::Completion;

// the document every surface reads, as `gates.completion` answers with it. The property
// that matters is the one asserted here: a gate that never reported leaves the task
// finishable and *unverified*, which is a different thing from a task that passed.
let c: Completion = serde_json::from_value(serde_json::json!({
    "present": true,
    "model": ".ai/repo/ci/gates.yaml",
    "plan": { "mode": "affected", "reason": "1 path in 1 class", "changed": ["docs/CLI.md"],
              "classes": [], "unclassified": [], "selected": {}, "excluded": {} },
    "finishable": true,
    "unverified": ["reference-check"],
    "tallies": { "queued": 1 },
    "gates": [],
    "obligations": [],
    "questions": []
}))
.unwrap();
assert!(c.finishable, "absence of a verdict does not refuse");
assert_eq!(c.unverified, ["reference-check"], "and it is never silently accepted");
assert!(c.blocking.is_empty());

Zda smí být aktivní úloha označena za hotovou, a vše, na čem odpověď stojí.

GateStatus

"pass" | "fail" | "stale" | "blocked" | "queued" | "exempt" | "unknown" 
use majordomus_cli::gates::GateStatus;

// the three answers a reader is entitled to, and they are different answers
assert!(GateStatus::Fail.refuses(), "a run that failed refuses");
assert!(GateStatus::Queued.unverified(), "asked and unanswered is a debt");
assert!(!GateStatus::Exempt.refuses() && !GateStatus::Exempt.unverified());

// and the one that is neither: a run whose tree has moved proves nothing about this one
assert!(GateStatus::Stale.refuses());
assert_eq!(GateStatus::Stale.as_str(), "stale");

Co je známo o jedné kontrole. Každé slovo už nesou designové tokeny tohoto repozitáře (share/design/tokens.yaml, status.states), takže ho plocha vykreslí, aniž by se musela učit šestý slovník, a kontrola designu ho neodmítne.

  • passProběhlo to nad těmito vstupy a uspělo. Jediné slovo, které cokoli vyřizuje.
  • failBěžela nad těmito vstupy a selhala. Dokončení se odmítá.
  • staleBěželo to a soubory, které ho vybírají, se od té doby změnily; co to dokázalo, se týká stromu, který už neexistuje. Dokončení je odmítnuto, protože alternativou je zacházet s tvrzením o minulosti jako s tvrzením o přítomnosti.
  • blockedNěco, bez čeho nemůže běžet, neprošlo, takže její vlastní mlčení nic neznamená.
  • queuedPlán ji vybírá a žádný běh nikdy nehlásil. Ne unknown: otázka byla položena a odpověď nepřišla, což je dluh, který někdo dluží, a ne pass, což je omyl, který toto slovo existuje proto, aby ho znemožnilo.
  • exemptPlán ji nevybírá: nic, co úloha změnila, ji nemůže učinit pravdivou ani nepravdivou.
  • unknownZde ho nelze posoudit vůbec — žádný model, žádný git, ledger, který se nedal přečíst. Poctivá mezera, nikdy ne úspěch.

Jedna povinnost, kterou sada změn implikuje, a zda ji úloha slíbila.

Použitelnost se odvozuje a nic jiného: vlastní inputs tokenu v share/obligations.yaml jmenují soubory, kterých se týká, takže změna jednoho z nich způsobí, že token je dlužen. Token bez inputs jmenuje fakt mimo strom — push, publikaci, nasazení — který žádná změna stromu nemůže implikovat, takže jsou dlužny, když je úloha deklaruje, a hlášeny jako nepoužitelné, když ne.
