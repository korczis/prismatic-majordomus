description = "A class of .ai/repo/knowledge/sources.yaml may carry an optional `generator:` block: `command` (an argv list run from the repository root, never through a shell), `inputs` (one or more `:(glob)` pathspecs of tracked files) and `stamp` (the top-level field each generated file carries, default `inputs_digest`). Its kind is declared in .ai/repo/knowledge/kinds.yaml with `lifecycle: derived`, and a class with a generator whose kind is not derived is refused. The digest is sha256 over the sorted (path, git blob id) pairs of the tracked files the inputs match, and `majordomus knowledge digest <class>` prints it so that the repository's own script stamps its output. Discovery compares each file's stamp with the current digest and emits a warning diagnostic `derived_source_stale` naming the class, the file, both digests and the declared command as the remedy; Majordomus never runs the generator itself, so doctor and every read stay free of side effects. A kind entry may also declare `references:`, a map from a metadata field to a target kind among issue, milestone, intent, rule and adr; the graph resolves those fields as it resolves its built-in relations, so an object of the repository's kind shows an outgoing edge in `majordomus entity show`, the issue, intent or rule it names shows the backlink, trace.issue (majordomus_trace_issue, GET /api/v1/trace/issue) lists the objects that reference the issue, and a reference that resolves to nothing is the existing dangling-reference finding. docs/KNOWLEDGE.md and docs/ADOPTION.md describe a derived knowledge source end to end."
