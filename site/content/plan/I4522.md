title = "I4522 — A repository's release records are judged against the repository's own distribution model, or on internal consistency alone when it declares none, never against the installed tool's"
description = "Release records under .ai/repo/releases are judged against the distribution model of the repository that carries them: the distribution-model object its own knowledge sources index (Model::from_index, apps/majordomus-cli/src/distribution/mod.rs:370), which in this repository is share/distribution.yaml through the `distribution` class of .ai/repo/knowledge/sources.yaml:246-250. The installed tool's model, Model::load(&app.share) and Model::locate(&share), stays what describes this build, its installer and its archive names, and stops being what a repository's records are measured against. Releases::findings and Release::findings (apps/majordomus-cli/src/distribution/release.rs:348 and :134) take the repository's model as an Option: with a model, every finding they make today is made against it; with none, the model-bound findings (a target the model does not declare or does not publish, a name the naming function does not derive, a URL outside the model's download prefix; release.rs:174-199) are not made, and the record is judged on internal consistency alone: a semantic version, no pre-release on the stable channel, tag equal to `v` and the version (release.rs:106), every required target carried by an artifact, no target twice, no tag twice, a URL ending in its own tag and name, a 64-hex digest and a non-zero size. The judgement is chosen in one function every caller asks (the generator, distribution validate, distribution metadata, the distribution status capability), so the generator and the command line cannot judge one record two ways. A finding names which model it was judged against, or that it was judged on internal consistency because the repository declares none."
