What it is

Objective
Register observation.recorded in share/events.yaml (emitted_by knowledge; requires task_id, kind, subject, statement, evidence) and add `knowledge observe --kind <friction|workaround|defect|drift|repetition> --subject <ref> [--evidence <ref>]... <statement>` to lib/knowledge.sh, writing one ledger line, refusing malformed input without writing, inside or outside a task, and only inside an open episode; write ADR 0118.
Why
Friction is noticed by workers and written nowhere the repository reads; decision add is the precedent for one typed line per act.
Now
No observation event or command exists; workers keep friction in private memory files.
Wanted
One command any provider can run inside an episode; one typed ledger line per observation.
Done when
unknown: the record declares no `completion`
Risk
unknown: the record declares no `risk`

Acceptance

  • An observation inside an episode writes one line with kind, subject, statement, each evidence reference and the active task or none
  • An unknown kind, a malformed subject or evidence reference, a multi-line statement or a transcript marker is refused with exit 2 and no line
  • A subject is a repository path or capability:, rule:, command:, gate: followed by an identifier, and anything else is refused
  • With no open episode the observation is refused with exit 10 naming session start, and nothing is written
