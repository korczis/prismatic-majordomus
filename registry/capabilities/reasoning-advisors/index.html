reasoning.advisors

Every declared advisor — then every linked mesh peer carrying the review feature — with its status (available, unavailable, not_configured, disabled, temporarily_failed, rate_limited) and why, from presence alone (an executable on PATH, a credential variable set; never a value), the reasoning mode and the recorded outcomes of earlier consultations. Plus the capacity per advisory capability. No advisor is an ordinary answer: reasoning is operational either way.

output · AdvisorsReport

The answer of reasoning.advisors: the mode in force, how many advisors may and may not be asked, every advisor's state, the capacity per advisory capability, and the catalogue's own findings. operational is true whatever the counts.

use majordomus_cli::capability::builtin::reasoning::AdvisorsReport;

let report: AdvisorsReport = serde_json::from_value(serde_json::json!({
    "operational": true,
    "mode": { "mode": "ci", "source": "CI" },
    "available": 0, "unavailable": 0, "advisors": [], "capacity": [],
})).unwrap();
assert!(report.operational && report.advisors.is_empty());
assert_eq!(report.mode.source, "CI");
assert!(report.diagnostics.is_empty(), "absent findings are the ordinary case");
propertytyperequireddescription
advisors array yes Every advisor, declared ones in preference order, then linked peers.
available integer yes Advisors that may be asked now.
capacity array yes Per advisory capability, who can provide it now. A row with nobody is answered by the local review path.
diagnostics array no The catalogue's own findings.
mode reference yes The mode in force and what decided it.
operational boolean yes Reasoning works whatever the advisors: always true, stated so a reader need not infer it from a count.
unavailable integer yes Advisors that may not, each optional.
