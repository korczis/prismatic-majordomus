## 204. The hub is reached privately over the tailnet first; a public ingress is a deployment target, never an application change

### Context

2026-09-11: the owner rejected free PaaS hosting, named Lundra (behind NAT) and a Cloudflare account, and asked to use a Tailscale name now and majordomus.dev later. The control surface can run commands on a workstation.

### Decision

Lundra is the persistent hub. Phase 1 serves it tailnet-only over HTTPS on its ts.net name (no Funnel); phase 2 adds a Cloudflare Tunnel with access in front over the same origin, which listens on loopback. Both may coexist; switching is deployment configuration. Network privacy is not authorisation: edge identity plus application authorisation (ADR 0126, web-sign-in).

### Alternatives rejected

- Free PaaS tiers
- Router port-forwarding
- Tailscale Funnel by default
- An anonymous public Cockpit

### Consequences
