economics.tasks

One record per task, folded from the ledger of every checkout `git worktree list` reports and the archives a ledger rotation left: its issue and intent, checkout and branch, first start, last finish or refusal, wall seconds, refusal count, and the episodes that carried it with their spans. Interventions, CI reruns, spend and acceptance are present on every record as not_observed, each with the reason and the issue that will supply it. Lists every ledger read with its line and skipped-line counts and every checkout not read; an optional since/until window filters by each task's start.

input · TaskEconomicsQuery

Which tasks to answer. A window filters by each task's task.started time, so a task with no start line in the ledgers read is answered only when no window is given.

use majordomus_cli::economics::tasks::TaskEconomicsQuery;
let q: TaskEconomicsQuery = serde_json::from_str(r#"{"since":"2026-10-21T00:00:00Z"}"#).unwrap();
assert_eq!(q.since.as_deref(), Some("2026-10-21T00:00:00Z"));
assert!(q.until.is_none());
assert_eq!(serde_json::from_str::<TaskEconomicsQuery>("{}").unwrap(), TaskEconomicsQuery::default());
// a misspelt bound is refused, never read as no bound
assert!(serde_json::from_str::<TaskEconomicsQuery>(r#"{"after":"x"}"#).is_err());

output · TaskEconomicsList

Every task the ledgers read carry, and what was read to answer it.

use majordomus_cli::economics::tasks::{fold, TaskEconomicsList, TaskEconomicsQuery, TaskEconomicsSource};
let text = r#"{"ts":"2026-10-21T10:00:00Z","event":"task.started","head":"h","branch":"b","by":"me","session":"s-1","task_id":"t-1"}"#;
let source = TaskEconomicsSource::parse("repo", "ledger.jsonl", text);
let list: TaskEconomicsList = fold(vec![source], &TaskEconomicsQuery::default());
assert_eq!((list.count, list.tasks.len()), (1, 1));
assert_eq!(list.ledgers[0].path, "ledger.jsonl");
assert!(list.unread.is_empty(), "fold reads no checkout, so it names none unread");
propertytyperequireddescription
count integer yes How many tasks are answered: the number of distinct task ids within the window.
ledgers array yes Every ledger file read, with its line and skipped-line counts.
tasks array yes One record per task, in the order the tasks started.
unread array yes Every checkout whose ledger could not be read, and why.
window reference yes The window the tasks were filtered by, as given.
